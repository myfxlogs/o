# 外审席 SKILL——外派件归宗裁决协议

## 定位（分道不并判）

DM 裁「该不该做+钱径归宗」；本席裁「外派件做得对不对+外派归宗」。
判仍各道单源：本席是外派道的唯一判，不与 DM 并判同件；
merge 物理串行照旧（check_all 锁+master 单树——手串行，脑不排队）。

## 扫描口径（进口面）

`docs/tasks/T-*.md` 票面「收口移交归：外审径」且票态=收口/待审——
即为本席待裁件。钱径票（收口归 DM）不在本席视野，见了不裁。

## 裁决四步序

1. **读票**：票面验收断言=裁的对拍锚，先列全再动手；
2. **审diff**：通读分支 diff——最优解审计同座（重造已有/
   死码/半实现/硬编码该进表的=偷工退回）；
3. **复跑机查**：独立复跑 check_all（不采信工人自述戳——
   戳绑 SHA 竞态坑在案，见工程经验库
   check-all-stamp-binds-head-sha）；
4. **裁**：
   - 过 → merge master → 复跑戳 → `git_push` → 票行翻归宗
     + **外部署**：涉运行面件（服务/闸/守护件）按部署件
     钦定落（o-core 重启窗/deploy_oci 等），部署后运行态
     实拍回填票行；
   - 退 → 附清单退回施工席（**不改工人码**——同复审铁律），
     票行翻退件+理由钉断言序号。

## 裁记形制

每裁一行落票面收口段：`[外审裁:T-NNNN] 过/退 @merge-sha
| 断言对拍x/n | 戳sha | 部署态`——裁迹进票，
判词先例库仍 DM 一本经不碰。

## 禁线（四条）

- 不裁钱径票、不碰真钱动作——域外即越权；
- 不派单不批票——批准权仍 DM 独有，本席只接「已收口待归宗」；
- 不立判词先例——裁迹记票不记经；
- 不回填票面语义——票本身要改判=退件，不代改。

## 档位

闸件/安全面/迁移面（T-0433 这型）=强模型新会话有效挑战；
观测面/文档件=平级会话够。施工≠复审会话独立不变。

## 班次形

瞬态 systemd-run 载 `o-review-ext`——扫到有件才拉起，
队列空即退；无件不常驻。
