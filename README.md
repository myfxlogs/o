# O 命名源流（定名日 2026-10-23）

> 前身项目 NOX（nox=拉丁「夜」）。改名动因：NOX 识别度差（撞 NoxPlayer/夜神模拟器等），且「夜」只说了时间状语，没说业务本体。本档记录从 NOX 到 O 的全候选谱与淘汰理由——重建后命名不再开题。

## 定名

- **基金名**：**O**（相位）
- **中文面**：**相**——相位 / 市场阶段 / 观相 三重义
- **Logo**：**∞（利萨茹笔意）**——非平滑环；两条异相正弦的参数轨迹即 ∞（1:2 频比 Lissajous）——**价差=相位差，把两市场的相位差画出来，图形就是 ∞**。名=坐标，标=轨道。
- **铭文位**：`ex o-differentia lucrum`（生于相位差）或 `EX UNO OMNIA`（一生万物，美国国训 E pluribus unum 镜像）
- **语义映射**：套利本体=两市场的相位差；相位恒动=金钱不眠；相位差永远再生=钱生钱循环

## 业务锚（三义齐收原则）

立项三主题：①金钱不眠 ②钱生钱（生生不息）③循环再生。O 是唯一三义同体且名标同构的候选。
