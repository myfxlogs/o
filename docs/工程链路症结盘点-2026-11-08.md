# 工程链路症结盘点（2026-11-08）

> 成因：同一日内部署收敛链连环堵塞现场。本文=病灶一本账，
> 每条按「症状→根因→修法→归宿票/状态」归档。供 o-gateway
> （T-0469）设计与后续席位排障引据——本文不是经验库条目替代件，
> 是链路级综览；单点坑的细则仍在 `docs/工程经验库/条目/`。

## 一、已根修（票落主干）

### 1. 绿戳跑步机——「推 HEAD」对「戳绑 sha」的语义错配
- **症状**：check_all 盖戳后，HEAD 被任何 commit 顶动即废戳；
  推程反复撞「戳非当前 HEAD」拒推，同日废戳四次，形成
  跑→废→再跑死循环。
- **根因**：推闸取「当前 HEAD 的戳」而非「待推 sha 的戳」——
  校验对象与推送对象分离，并发下永真失效。
- **修法（T-0467，已 merge+remote）**：`mirror_push.sh` 选最近
  绿戳 sha、推 `<sha>:master`；`deploy_at_sha.sh` 部署钦定 sha；
  commit-msg 闸拒 `[角色:施工]` 直写部署树（含全角冒号变体
  待补——见 §四.6）。
- **状态**：根治。戳即资产，不再过期。

### 2. check_all 锁争用 herd——全谱 40min
- **症状**：全谱 go test 段各 PG 重载包共用 `o_test` 单库，
  `pg_advisory_lock(860223)` 全库互斥——并发包串行传锁，
  40min 墙钟；多工位并跑时呈加法堆积（1跑40m，3跑≈排队2h）。
- **根因**：advisory 锁域=库级，全谱挤一库=锁域全司共一把。
- **修法（T-0468，外审中）**：`O_TEST_SHARDS` 按包目录 fnv 散列
  分 `o_test_s<N>`（K=16）——锁域按库隔离；fail-open 落基库
  只慢不错；GC 白名单放 `o_test_s` 族；裸 DSN 第二池须
  `ShardDatabase()` 钉库（writefail/pipeline_face 两案已修）。
- **实证**：五包子集 A/B 背靠背 K=1→K=16 墙钟 -59%
  （5m33→2m16）；G5 真 PG 探针跨库同键 31ms 不互阻、同库
  2027ms 互斥不破；G6 分库真建零回退。
- **状态**：裁决跑在途（验收跑时长即第二重实证）。

### 3. 环境病三件套
- **GOCACHE 互逐假红**：多 worktree 共享默认缓存互相逐出→
  全冷编译+偶发错报。修：按 worktree 分家 `GOCACHE=/tmp/
  gocache-<topkey>`（T-0466 已 merge）。
- **锁等待失明**：等 PG advisory 锁无观测→「死等」无法定性。
  修：等锁即落 ops_event（key/holder pid/锁龄）（T-0466）。
- **孤儿锁**：持锁进程 ppid=1 逃逸→锁永占。修：30min 扫杀
  timer（T-0466）。
- **根分区 100%**：docker 镜像无保留窗+构建产物无出径。
  修：镜像窗 N=5+prune 双触发+rootfs_highwater>85% 告警
  （T-0466 已 merge；当日实发过一次根分区满）。

### 4. 票号毒源与 seat 豁免洞
- T-9999 占位票消耗票号上限判据→后续票全误拒推。修：改名+
  判据修在案（done/tombstone 参与同号碰撞检查但不抬高
  活跃队列号顶）。
- `O_SEAT_WRITE_ALLOW=1` 粗豁免绕开席位写闸。修：T-0460 粒度
  修，豁免收回域白名单制。

## 二、结构性症结（根修未生，T-0469 主治）

### 5. 席位注意力依赖——「等班」病
- **症状**：无头席 30min 一拍拍轮询；呈批/移交/升件落账后
  无人即时反应；手动 `systemctl start` 撞单例闸 2 秒即退，
  kick≈无效。
- **根因**：「事件驱」只到交互 tmux 层（relay 踢径），无头层
  全兜底拍；开班闸只认 `ops_ticket_state` 待裁集（收口/移交/
  收口待审），升件/处置行不进闸——票「在案」≠「在队」。
- **实证**：同日四张钱径票持「处置/待 CTO 裁定」态却隐形，
  须人工补 `移交` 行才进队；CTO 退班与移交落账差 2 分钟，
  票又等一拍。
- **修法**：T-0469 o-gateway——常驻服务，`ops_event` LISTEN/
  NOTIFY+绿戳 inotify+席位态观测，事件即反应；网关死=席位
  自扫描兜底（降级不瘫）。呈批待 CEO 裁。

### 6. 部署开火真空——「半截部署」
- **症状**：镜像面已发、OCI 面停旧 sha；升件 #4120 鸣一日，
  CTO 三班处置全对（领认停鸣+退班等清窗），但 merge 落、
  挡件清后**无人扣扳机**——探测在、扳机无。
- **根因**：`deploy_window_due` 只判「该不该发」，「窗清→
  执行」无任何席位职卡认领，活在「某席顺手发」隐性约定里；
  席位径固有死法=发动作挂在人注意力上。
- **修法**：同 T-0469——收敛执行归网关一本账（戳落→推→
  发面→验活），人只在判据里。业主当日手动补发清窗。

### 7. 调度散件——9 壳各扫一段
- 现状：mirror_push/deploy_window/seat 拉起/收口移交/升件路由/
  票翻归宗/会话回收/水位监视分散在独立 timer+脚本，各自
  为政无状态协调——判据碎裂、窗间无交接。
- **修法**：T-0469 三本账归一：席权（起退/水位）/路由（派单
  交接）/收敛（推发验+升件）。红线：机械调度归网关，判断
  永归席位；幂等键；败=升件+冻结+不自愈重试。

## 三、制度/流程症结（已识别，部分在修）

### 8. 裁决吞吐=排队×墙钟
- 一票一审一盖顶跑：merge 树≠工人测过树→裁席须全谱亲跑
  （40min/件）。分库（T-0468）砍跑长，网关砍等待——但
  「每件必全谱」的制度成本仍是吞吐顶。
- **待议**：分层验证（diff 面决定跑档）已有三档制雏形
  （docs-only/scoped/full），全谱强制场景应再收窄。

### 9. skip-blind 假绿
- 测试工具缺 `O_TEST_PG_DSN` 静默 skip→绿戳实空跑
  （T-0441 病灶定案）。规：凡报绿须附 RUN/FAIL/SKIP 数，
  skip>0 须逐条解释；裁决席复跑必带真 DSN。

### 10. 闸误伤与误放
- `|| true` 无 `# tolerate:` 锚→tolerate-report 红单
  （T-0464 驳回返修在途）；锚写错位置同样红——闸文本级，
  语义级判断仍靠裁席。
- 全角冒号 `[角色：施工]` 绕开 ASCII 前缀匹配（T-0467 裁记
  已载，归独立票待立）。

## 四、操作面坑（当日实撞，经验库条目级）

1. 活部署树 `git add -A` 把他席 staged 面卷入本 commit；
   他席 merge+reset 窗口内我的 commit 被连带抹除——
   教训：部署树 commit 用最小路径集，禁 add -A。
2. `git mv` 先锁 index 内容→随后重写未再 add→推上去的是
   旧文新名（0469 V0 文顶 V2 名事故）——改名与改写分拍
   须 `git status` 复核。
3. `deploy_oci.sh` 闸：工作树脏即拒+HEAD 须在 origin/master
   ——部署前净树+已推双前置，他席 staged 件也会触发脏拒。
4. worktree 绿戳文件在 `.git/check-green-<sha>`（worktree 的
   .git 是文件非目录——戳实际落主仓 `.git/worktrees/<name>/`），
   查戳勿 `ls wt/.git/check-*` 直读。
5. `ops_ticket_state` 无 `state` 列——查队判据读
   `dm_queue.sh` 脚本源，勿猜 schema。
6. 判「某席在线」权威源=`tmux list-sessions`+`~/devin-relay.
   log`，agent 自带注册表否定结果不得单独定论（查席纪律在案）。
7. 双轨部署面勿混：SG 镜像面（docker 流）与 OCI 面（三臂
   二进制船运）各自独立成功/滞留——「部署完成」须双面各验。

## 五、链路口诀（给后续席的一句话版）

> 戳跟 sha 走不跟 HEAD；等锁要落账；分库消 herd；缓存分家；
> 票进队看事件不看态；开火归机制不归顺手；绿戳须带跑数；
> 部署树最小触碰；判在线查 tmux；双部署面各验各的。
