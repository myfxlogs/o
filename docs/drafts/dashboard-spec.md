## 0. 定位与分工

- **飞书=交互端**（对话：升件/急件/条件请求+按钮回调）。
  永不长报表——长了就退化成喇叭。
- **web=公司运作面板**（全景显影）：业主随时查证
  「名义上是→实际上是」的唯一自助径。只读，不放操作钮
  （拍板走飞书——观测/操作分面，窄门不被 UI 绕过）。

## 1. 军规：后端对前端零信任（业主钦定 2026-11-10）

已在仓律（proto 注「字段折值后端算定，前端零计算」+
ops_event 注释「UI 零信任」），本件升格为面板全律：

1. **前端零计算**——显示值一律后端算定下发；前端不聚合/
   不换算/不判态（绿/陈/死 判词后端出，前端只染颜色）。
2. **前端零真源**——面板每一格可指回一行事实账
   （ops_event/fin_*/ops_face/md_*）；UI 不产「状态」，
   渲染不到的=事实层没有，不虚构显形。
3. **前端零写径**——v1 全只读；未来任何按钮只写
   `ops_event` 意图行，执行仍过既有窄门——
   「业主自己点的」也不破闸。
4. **读件缺显形不假零**——数据缺席显「缺」不显 0/绿；
   冷启动/查询败同律（沿用 TRX 面 `found=false` 判例）。
5. **鉴权**——面板口绑 loopback/业主隧道径（同 readcred
   判例）；公网不开口。每 RPC 独立校验不继承会话态。

## 3. 结构

- **路由**：`/money` `/device` `/decision`（+`/overview` 保留旧面，
  不重排）；单栏移动优先，卡内行可展。
- **新 RPC 三件**：`GetFunnel`（漏斗四级+哑弹榜）、
  `GetFaceGrid`（面鲜度格栅）、`GetDecisionTrail`（处置链
  tail——SQL 全在后端，proto 出平铺行，protojson 直转）。
- **前端**：新三页 `Money.tsx`/`Device.tsx`/`Decision.tsx`；
  复用 ui.tsx/panel.tsx 件；Watch 流沿用（事件驱动刷新，
  不轮询——面板刷新跟 ops_event 写拍）。
- **禁线**：不改 ops_event schema；不加写面 RPC；
  不引新前端依赖（现 react+ts 栈不动）。
