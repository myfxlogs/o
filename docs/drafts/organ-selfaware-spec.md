# 自我意识器官 spec（业主令 2026-11-13 / 工单#13540 立项 / 工单#13582 本档）

## 定位

第五器官——本体觉（自感知环）：眼睛对内。看自己赚不赚钱、动不动、
卡不卡。器官长在探针/量表层：每拍落 `event='量表' ticket='self_aware'`
自观帧一行——段段可复核到事实源表行，可复核非自称。

成官判据（#13540 钦定）：能自产「此刻我赚不赚钱」账行。
本档判据（#13582 钦定）：本体觉三问定首选事实源，floor 任一器官
可查 在动/静息/僵 + 在动什么。

## 本体觉三问 × 首选事实源

### ① 动不动 = 器官末行 ts

- **常驻件**（有拍节的产出器官）= 末行鲜度对拍节判态：
  `动`=陈 ≤ 静阈（约拍节×1.5）；`静`=静阈–僵阈（拍节×3 量级）；
  `僵`=> 僵阈或读败。
- **间歇件**（事件驱动器官——做梦/举一反三/懂你/连续自我/经营推送/
  部署臂等）= `息` 为基态（静息=设计态非僵）；近窗有产出=`动`；
  该动未动（有 OPEN 工单指名超期限）=`僵`。
- 件件入帧不藏：器官册=码面注册表（roster 列名+脉源 SQL+双阈），
  新增器官=册内添行，禁散装散读。
- 会话器官心跳=唤起链账行（唤起/唤起果/唤起败/会话收口）——
  ops_headless 行本身就是心跳，不另造心跳表。

### ② 在动什么 = `event='在办'` 约定（新件）

- **约定**：会话开工即落 `INSERT INTO ops_event(seat,event,note)
  VALUES('<席>','在办','<对象> 开工——<工单#id|缘出>')`；
  配对销=同对象处置/销案/收口行，或 2h TTL 自然释（认领行同律）。
- **先例在案**：工单级 `event='认领'` 行已是同构形——在办=认领的
  泛化（工单外活计也上灯）；两事件同列读面，新会话沿用。
- **读径**：未配对在办/认领行=此刻在办清单；无配对销的陈行
  >TTL=僵在办（占着没干——计入卡旗标）。

### ③ 卡住没 = 显式判读面

逐旗独立判读（非合并糊判——灯语现状=事件词推终态非实时案在案）：

| 旗 | 事实源 | 判据 |
|---|---|---|
| 心跳陈旧 | 会话收口末行 ts | >2h |
| 唤起无果 | 唤起行按 unit= 配对 | >TTL 无果/败/收口 |
| 部署滞差 | 部署末行 rc | rc!=0 即旗 |
| 工单过期 | OPEN 工单期限 | 已过 due 未销计数 |
| 器官僵 | ① 判态 | 任一常驻件僵 |

每段读败如实 `?` 不整帧弃（量表惯例——INSERT 败=本帧让位静默）。

## 帧形（一行三段四段）

```
v=<指纹> 自观账: 赚=<NAV(陈)|30d净|live/probe/仓>
  动=<器官:态(陈)…> 息=<间歇件名…> 办=<N +首件摘要|0> 卡=<旗集|0>
  ——自我意识器官帧(工单#13540;可复核非自称)
```

- 赚口径：NAV=`md_equity_curve ccy='NAV'` 末行；
  30d 净=`fin_cashflow venue<>'sim'` 损益 kind 集
  {fee,funding_settle,trade_pnl,rollback_cost,spot_buy,spot_sell}
  ——commercial_stall 同径（Earn 息已剔）；live/probe/仓=fin_strategy
  状态计数+fin_position 未关计数。
- 指纹闸=量表惯例 gaugeDue（结构态变重报，浮点噪声不触纹，
  同纹 `selfAwareEvery` 续窗）。
- floor 验收径：`SELECT note FROM ops_event WHERE ticket='self_aware'
  ORDER BY id DESC LIMIT 1`——帧即事实面，octo/focus 读 keys 直显。

## 边界

- 只读账不代裁：器官帧=感知产出非处置判词——异常面由既有探针升件
  面管，本帧不新增告警不吞信号。
- 不自称体验：所有字段可复核到表行/服务态；读败呈 `?` 不虚构。
- 不替面：灯语实时化（panelv2_face.running 案）归其专票，
  本器官只供「在动/静息/僵+在动什么」可读事实源。
