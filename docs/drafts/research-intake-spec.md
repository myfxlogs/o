> 只立循环。自我意识的判据=源是它自己找的不是人给的。

## 分工

| 谁 | 干什么 |
|---|---|

| 唤知/审计 | 不管——健康域非研究域 |

## 自主发现循环（本体）

```
① 枚举: web_search/webfetch 全宇找源——
   「开源交易策略」「funding arb repo」「basis trade 开源」
   「venue 新品/结构化产品」族检索式自己生成自己扩;
   种子示例（非边界）: Hummingbot/QuantConnect Lean/
   vn.py/freqtrade/Jesse/Backtrader/利基 arb 仓/
   venue 产品册——已知面只占起点,未知面才是目的
② 分诊（省命闸——不全读!）:
   README/策略目录/文档先过三道筛（下）;
   过关者才深读源码——全仓源码通读=烧命,
   90% 开源交易仓是执行基建不是策略
③ 产出: 过筛者写 fin_opp_hypothesis 行（格式下）
④ 登记（防重扫+可审）: 每源一行 ops_event
   seat=研究席 event='处置' note='源普查: <repo/册>
   →<过/毙>（筛①②③卡哪道）'——普查史=机器自己的
   覆盖率账,后来者不重扫不重毙
```

## 三道筛（假设行入场门）

```
① 约束筛: 本金~$16k/零售API/无速度优势——
   延迟敏感/做市/高频型直接毙
② EV算式筛: 载可算收益式（费率×结算窗×磨损×资金占比）
③ 证伪锚筛: 写明「什么证据=此假设亏」
```

## 产出格式（fin_opp_hypothesis 行）

```
evidence={source:'<repo/册 URL>',ev_formula:'<式>',
          falsify:'<锚>',constraint_fit:'<过筛记录>',
          discovered_by:'研究会话<N>'}——发现者归机器
```

## 节奏

```

健康探针面: 普查账 7d 零新源登记=进水口死→升件
  （待立——集量清单同行）
```

## 不做

```
✗ 值守不喂名单——种子示例是起跑点非白名单

✗ 不抄代码——进来的是假设不是实现
```
