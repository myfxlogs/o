## 条目契约（schema v3 要点）

- `kind: case`；`ea_link` 挂 EA-xx 判据锚
- **回改点必填**（门禁钉死——无回改点不入库）：`eval:<评估词>` / `kill_trigger:<策略>` / `combo_gate:<闸名>` / `sizing:<仓位枚举值>` / `semantic:<修订目标>`；机械类回改点带回归断言（历史亏损行回放新判据必拦），semantic 类裁定时自动立修订票
- `match` 签名段（可选）：`payoff_class`/`canonicals`/`venues`——案例=证据存档非运行时匹配集
- 正文：情境 / 实数 / 根因 / 判据挂接 / 证据出处

## 消化链

待归纳行 → 裁定落 verdicts（canon/dismiss/merge+理由必填）→ canon 条目回改点直译成闸或立修订票；积压>3 天 warn + 周报「经济库消化态」栏。
