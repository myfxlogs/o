# PHASE 工程纪律（法典）

> `[角色:决策]` 立于 2026-10-23。源=`docs/总纲.md` §5–§7（括号内为 nox 决策链 D# 溯源）。**业主令级工程律，PHASE 全继承**；违例=复审直接退回，不降格协商。
> 落地件诚实标记：PHASE 仓内尚无门禁脚本/CI/测试库实例，凡标「待装」者——未装不虚报（D-616 同源纪律适用于自身）。

## 1. 数据面纪律（方向级）

### 流为唯一正路（D-004 业主令）

- 凡有 WS/推送/事件源的数据**必须走流**；决策、执行、风控、展示径**禁吃轮询结果、定时刷新值、快照、缓存陈旧值**——前后端同规。
- **只在无流处拉**：venue 确无对应推送的数据才可低频 REST，且仅限统计/复盘/参考用。举证责任在施工：代码注释须引 venue 官方频道表出处（文档 URL 或抓包）证明该数据不在任何频道；「没找到流」≠「没有流」——无证=违例。
- **唯一合法定时器形**=断流看门狗（检测断连→重连/告警）；看门狗永不产/运/刷业务数据。「定时器兜底刷新」「先轮询后上流」均计违例。

### 快照禁令（D-604 业主令）

- 决策/执行/风控/退役/装配/提案评估/发现扫描径**零快照**（陈旧态表值、冻结列、TTL 缓存、后台轮询产物）。合法数据源仅二：① 事件流（落库行带新鲜度门）；② **判时点 venue 实拉**（评估快照内一次 RPC/REST——「消费点拉取」）。两皆无=fail-closed 拒单+`fin_condition_gap` 条件请求，禁降级读陈值。
- **快照写径禁新增**：不新建任何周期态摄入（定时 REST 拉账户/余额/权益/产品面写态表）。既存 rest 写径只许**事件锚定形**：boot 首读/断流重连愈合/kick 定向补读/手动 Refresh/消费点拉同车。
- 冻结列=档案非现值：评估时刻冻结列留作历史归档，禁当现值消费。
- **事件持久表≠快照**：流事件落库行合法且为唯一权威源，但读径必带新鲜度门——决策径陈了=fail-closed，展示径陈了=明标，禁冒充现值。
- **统计面隔离**：D-004 豁免的统计/复盘 REST 只许写统计专用表，禁写账户/余额/权益态表——态表只许流写（+事件锚定愈合）。

### 数据单源真（D-616 业主令）

- 任何面（决策/执行/账本/证据/报审注）只信 venue 服务端实返或本系统实测记录。**严禁**：凭印象/字段名/函数名推值、默认值冒充实查、mock 冒充现实、「应该有/大概是」句式。
- 查不到=诚实标缺（缺失本身即合法证据）。
- 凡「实测/实拍/实锤」声明必附可复现出处（file:line / 实测输出 / 证据件名）；无源=未证——复审可单凭此项退回。

### 其余数据面硬条

- **单一时间纪元**（D-596 业主令）：一切持久时间戳带 Z 标（`MM-DD HH:MMZ`/`YYYY-MM-DD HH:MMZ`，UTC 单纪元）；禁裸日期/本地纪元冒充 UTC/同档混纪元。交易时段判定用 venue 原生时或显式 UTC；session 内日期判断以 `date -u` 实拍为准。
- **腿级数据只信本腿 venue 回值**；禁以硬编码表顶替 venue 值。
- **判定路径可观测**（D-652-A 业主令级）：任何 `return nil`/`continue`/fail-closed 判定门=拒因不可见即静默杀——判定面必挂 rejects 计数门（面×门预注册键集、原子加零分配、零业务副作用）；注册与挂载的一致性由机检源码对拍锚防。
- **系统自盯**（D-033）：需周期关注的指标/条件由系统算+推（告警）；票与计划永不出现「某时去查 X」。
- **无硬编码域值**：venue/品种/费率/杠杆/额度一律出自 API/配置/DB；无证据=fail-closed 报缺口，禁静默默认。
- **推而不读**：venue 不可回读的参数由系统显式设，然后从配置取值。

## 2. 码面纪律

- **复用为先、最简等价解**：已有等价实现未用=败。禁死码/TODO/调试残渣；错误默认 fail-closed，禁 `_ =` 吞错。
- 功能消失/退化 → 先 `git log`+`blame`，**禁不查历史直接重写**。
- **文件 ≤300 行**（门禁卡）；proto 变更走 `buf generate`。
- 只 `git add` 显式文件，永不 `-A`；**禁 `--no-verify`**。
- 业务配置单源=DB（`app_config`/`app_secrets`）；env 仅 bootstrap（allowlist 只缩不增）；**禁 env 驱动装配**（D-162）：venue/账户/凭据/订阅集全 DB 驱动，env 不许决定装哪个 venue、装不装；只挂 env 分支的功能=死码。
- **前端零信任**：计算/校验/分页/排序全在后端；前端只订服务端流，禁 `setInterval` 拉数，禁把缓存陈值渲染为现值。
- 判据全部机读、全部在判据表，禁代码字面量（毕业/晋级/降级/淘汰判据同规）。

## 3. 机检基线（提交前自跑 + 复审独立复跑；契约全文自 nox §6 继承）

```
go build ./... && go vet ./... && gofmt -l $(git diff --name-only master -- '*.go')
go test ./... -count=1                       # 测试库=独立实例（绝不打生产实例，D-021）
go test -race ./internal/<触碰域>/... -count=1
cd web && npm run build                      # 前端触碰时；前置 buf generate（gen 产物 gitignored 不入库）
gh run list -R <本仓>                        # 推后自查：绿 CI 才算收口
```

- **本地绿≠收口**——红 CI 推者主动返工不等复审（业主令 10-15）；CI 基建故障（auth/网络）报决策席。
- **红 CI 冻结窗**（D-651/D-652）：机检红期间只容修复票并入，其余合并冻结至绿恢复。
- race 前先 `ulimit -n $(ulimit -Hn)`（race+pgxpool fd 压力先例 D-177/D-255）。

### CI 流水线契约（nox `.github/workflows/ci.yml` 原形，PHASE 落位时逐格照搬）

- 触发：push/PR to master；runner ubuntu-latest。
- **postgres:16 service**：容器 5432 → 宿主 **5434**（与本地测试实例同坐标，CI/本地一套 DSN 口径 D-021）；healthcheck pg_isready。
- 步骤序：checkout → setup-go（go-version-file: go.mod）→ setup-node 22（npm cache）→ buf-setup **1.74.0**（钉版规：取最新且发布≥7 天——2026-10-23 实测 1.75.0 昨日发未过窗→钉 1.74.0；CI/镜像内 npm/本地三处同号钉，codegen 版漂=gen 产物噪音）→ `npm ci --legacy-peer-deps`（web/）→ `go install protoc-gen-go@v1.36.12` + `protoc-gen-connect-go@v1.20.0` → `buf generate`（gen 不入库故须先产）→ **`npm run build` 在 `go build` 之前**（`//go:embed web/dist` 依赖）→ `go mod download` → `go build ./...` → `go vet ./...` → `check_import_direction.sh`（分层方向门禁与 pre-commit 同令）→ **gofmt 全树 sweep**（非仅 diff 面）→ `CREATE ROLE <dbuser> LOGIN PASSWORD '<dbuser>' SUPERUSER`（CI postgres 仅 postgres role，补建缺省 DSN 契约角色）→ `go test ./... -count=1 -timeout=1800s`（四路 `*_TEST_PG_DSN` env 注入 5434）→ `go test -race -count=1 ./internal/<触碰域>/...` → `check-lines.sh`。

## 4. 门禁契约（nox `scripts/hooks/` 原形全谱，PHASE 武装走任务单）

武装方式：`git config core.hooksPath scripts/hooks`——永不 `--no-verify`（违例本身即退回项）。

### 4.1 pre-commit 十二道（执行序）

| # | 闸 | 契约 |
|---|---|---|
| 1 | kill_switch | `.kill_switch` 文件存在=拒提交 |
| 2 | 部署树写禁（D-651） | `check-deploy-tree.sh`：部署树 `/opt/<repo>` 只 pull/build/deploy，开发走 worktree——署树内提交即拦 |
| 3 | env 凭据直读（D-564） | `check-env-reads.sh`：硬拒域（`*_API_KEY`/`*_API_SECRET`/`*_PASSPHRASE`/`*_PRIVATE_KEY` 等 venue 凭据键）+ app_secret 域键零直读；白名单 `scripts/env-allowlist.txt` 逐键显式登记、**只缩不增**——「env 能读到」不是理由，白名单才是 |
| 4 | staticcheck 基线（D-512） | 只拦本 commit 新增告警（存量另案治理）；`GOTOOLCHAIN` 钉 go.mod 版本；`export data version` 错文=工具链漂移 fail-loud 直报，毒化基线丢弃重固 |
| 5 | 文件长（D-077） | `check-lines.sh`：≤300 行，与 CI 同令 |
| 6 | 迁移契约（D-496 业主令） | `check_migration_contract.sh`：键域列 COMMENT+CHECK 强制、禁 backup 残留表 |
| 7 | gofmt | staged `.go` 漂移即拒（`core.quotepath=off` 必须带——中文路径 quoted 形态破匹配） |
| 8 | 经验库 schema（D-130） | staged 触 `docs/经验库/`→`noxkb gen --check`；触 `docs/经济经验库/`→`gen-econ --check`；索引自动生成禁手编 |
| 9 | 秘钥扫描（D-460） | staged **新增行**匹配秘钥形态即拒：mrpc token / `api_key=≥20位` / `secret=≥20位` / PEM 私钥块 / `ghp_`·`gho_` / `sk-` / 主仓 AUTH_TOKEN 非占位值；误报找复审席裁定 |
| 10 | `_ =` 吞错（D-508） | 资金/审计热路径清单内文件新增 `_ = <err调用>` 即拒；确属无返回值丢弃须行内 `// audit-noreturn-ok <理由>` 豁免 |
| 11 | import 方向（D-514） | `check_import_direction.sh`：跨包 import 白名单冻结——新增方向违例即拒（放行=评审方向合规+更新表）；删边不拦 |
| 12 | 未推送 warn（D-588） | 本地领先远端 N commit 即 warn「断链风险」指路 `git_push.sh` 带重试；推送成功自消 |

尾行提醒（不拦）：diff 通读无死代码/TODO/调试残留。

### 4.2 commit-msg

- 修复类信号（`fix|修复|bug|hotfix|regression|回归|病灶|坑|patch|revert`）且未触 `docs/经验库/`|`待归纳` → warn 提醒（D-585，不拦；坑成立→条目同 commit 入库，不成立→复审收口注记块「坑处置：无坑」显式声明）。

### 4.3 pre-push

- **唯一远端名闸**：推送远端名须=仓定唯一值（nox 仓=`nox`，PHASE 仓=`origin`）——错名显式失败指路，防裸 push 静默吞件。
- **master 只许从部署树 `/opt/<repo>` 推**；工作分支 `t/<票名>`（nox 旧规 `wip/<票名>`）。
- 远端删 `refs/heads/master` 禁绝；refspec 变形禁绝（`+force` 前缀/tag/映射一律拦）。

### 4.4 reference-transaction

- master 更新非 ff（new 非 old 后代）即拒；显式豁免 `<REPO>_ALLOW_NONFF=1`。

**PHASE 现状**：门禁脚本未搬入未武装——本表是契约规格，落位（写脚本+配 hooksPath+CI workflow）走任务单，逐道验收。
