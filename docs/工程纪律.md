# PHASE 工程纪律（法典）

> `[角色:决策]` 立于 2026-10-23。源=`docs/总纲.md` §5–§7（括号内为 nox 决策链 D# 溯源）。**业主令级工程律，PHASE 全继承**；违例=复审直接退回，不降格协商。
> 落地件诚实标记：PHASE 仓内尚无门禁脚本/CI/测试库实例，凡标「待装」者——未装不虚报（D-616 同源纪律适用于自身）。

## 1. 数据面纪律（方向级）

### 流为唯一正路（D-004 业主令）

- 凡有 WS/推送/事件源的数据**必须走流**；决策、执行、风控、展示径**禁吃轮询结果、定时刷新值、快照、缓存陈旧值**——前后端同规。
- **只在无流处拉**：venue 确无对应推送的数据才可低频 REST，且仅限统计/复盘/参考用。举证责任在施工：代码注释须引 venue 官方频道表出处（文档 URL 或抓包）证明该数据不在任何频道；「没找到流」≠「没有流」——无证=违例。
- **唯一合法定时器形**=断流看门狗（检测断连→重连/告警）；看门狗永不产/运/刷业务数据。「定时器兜底刷新」「先轮询后上流」均计违例。

### 快照禁令（D-604 业主令）

- 决策/执行/风控/退役/装配/提案评估/发现扫描径**零快照**（陈旧态表值、冻结列、TTL 缓存、后台轮询产物）。合法数据源仅二：① 事件流（落库行带新鲜度门）；② **判时点 venue 实拉**（评估快照内一次 RPC/REST——「消费点拉取」）。两皆无=fail-closed 拒单+`fin_condition_gap` 条件请求，禁降级读陈值。
- **快照写径禁新增**：不新建任何周期态摄入（定时 REST 拉账户/余额/权益/产品面写态表）。既存 rest 写径只许**事件锚定形**：boot 首读/断流重连愈合/kick 定向补读/手动 Refresh/消费点拉同车。
- 冻结列=档案非现值：评估时刻冻结列留作历史归档，禁当现值消费。
- **事件持久表≠快照**：流事件落库行合法且为唯一权威源，但读径必带新鲜度门——决策径陈了=fail-closed，展示径陈了=明标，禁冒充现值。
- **统计面隔离**：D-004 豁免的统计/复盘 REST 只许写统计专用表，禁写账户/余额/权益态表——态表只许流写（+事件锚定愈合）。

### 数据单源真（D-616 业主令）

- 任何面（决策/执行/账本/证据/报审注）只信 venue 服务端实返或本系统实测记录。**严禁**：凭印象/字段名/函数名推值、默认值冒充实查、mock 冒充现实、「应该有/大概是」句式。
- 查不到=诚实标缺（缺失本身即合法证据）。
- 凡「实测/实拍/实锤」声明必附可复现出处（file:line / 实测输出 / 证据件名）；无源=未证——复审可单凭此项退回。

### 其余数据面硬条

- **单一时间纪元**（D-596 业主令）：一切持久时间戳带 Z 标（`MM-DD HH:MMZ`/`YYYY-MM-DD HH:MMZ`，UTC 单纪元）；禁裸日期/本地纪元冒充 UTC/同档混纪元。交易时段判定用 venue 原生时或显式 UTC；session 内日期判断以 `date -u` 实拍为准。
- **腿级数据只信本腿 venue 回值**；禁以硬编码表顶替 venue 值。
- **判定路径可观测**（D-652-A 业主令级）：任何 `return nil`/`continue`/fail-closed 判定门=拒因不可见即静默杀——判定面必挂 rejects 计数门（面×门预注册键集、原子加零分配、零业务副作用）；注册与挂载的一致性由机检源码对拍锚防。
- **系统自盯**（D-033）：需周期关注的指标/条件由系统算+推（告警）；票与计划永不出现「某时去查 X」。
- **无硬编码域值**：venue/品种/费率/杠杆/额度一律出自 API/配置/DB；无证据=fail-closed 报缺口，禁静默默认。
- **推而不读**：venue 不可回读的参数由系统显式设，然后从配置取值。

## 2. 码面纪律

- **复用为先、最简等价解**：已有等价实现未用=败。禁死码/TODO/调试残渣；错误默认 fail-closed，禁 `_ =` 吞错。
- 功能消失/退化 → 先 `git log`+`blame`，**禁不查历史直接重写**。
- **文件 ≤300 行**（门禁卡）；proto 变更走 `buf generate`。
- 只 `git add` 显式文件，永不 `-A`；**禁 `--no-verify`**。
- 业务配置单源=DB（`app_config`/`app_secrets`）；env 仅 bootstrap（allowlist 只缩不增）；**禁 env 驱动装配**（D-162）：venue/账户/凭据/订阅集全 DB 驱动，env 不许决定装哪个 venue、装不装；只挂 env 分支的功能=死码。
- **前端零信任**：计算/校验/分页/排序全在后端；前端只订服务端流，禁 `setInterval` 拉数，禁把缓存陈值渲染为现值。
- 判据全部机读、全部在判据表，禁代码字面量（毕业/晋级/降级/淘汰判据同规）。
