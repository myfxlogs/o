## 手术位（两刀）

### 刀① 全局互斥锁

`check_all.sh` 入口加 `flock`（fd 9 落 `/tmp/o-check_all-<repo指纹>.lock`）：

- 拿到锁前如实报「等锁 holder pid」——禁静默阻塞；
- 语义钦定：**阻塞等锁+超时上界**（建议 1800s，超时 fail
  报 holder pid——不报假绿不自杀）；
- worktree 也同锁（锁键按 git toplevel 真实路径——wt 与
  主树不同锁，互不串；同 wt 内并发才互斥）。
  **再核一遍**：wt 是独立树，各 wt 并发跑 check_all 合法——
  锁域=同一 checkout 内，非全机。

### 刀② diff 定向测谱

`go test ./...` 段改「变更包+反向依赖闭包+恒测册」：

- 变更面=同 docs-only 豁免同径：`git merge-base origin/master HEAD`
  → `git diff --name-only` + 工作树未跟踪/未提交 `.go` 文件
  （docs-only 判据现成在 30-56 行，读它抄径）；
- 包映射：diff 文件→`go list` 包→反向依赖闭包（`go list -f`
  Deps 图——改 A 包跑 A+所有 import A 的包的测试）；
- **恒测册**（钱径/风控面，不论 diff 恒跑）：`internal/risk/...`
  `internal/ledger/...` `internal/trading/...` `internal/guard`
  `internal/portfolio/lifecycle/...`——先 grep 包路径核实真实
  目录名再写册，禁猜；
- 兜底：包映射任何一步不确定/变更面含非 `.go` 码件
  （proto/migration/sql/sh/compose/Dockerfile/yaml/json 非docs）
  →**回退全谱** fail-safe 不 fail-open；
- 戳旁 STAMP.mode 三档：`docs-only`/`scoped`/`full`——
  scoped 档戳附实测包集清单（审计可读面，T-0397 三档
  审裁读戳用）。

## 验收（你跑给我看）

1. 并发两跑实证：第二跑报等锁 holder pid 不睡死不假绿；
2. docs-only commit → `docs-only` 档秒绿（现行行为保持）；
3. 改一个非钱径包某文件 → `scoped` 档只跑该包+依赖者+
   恒测册（贴实测包集行）；
4. 改 risk/ledger 域文件 → 恒测册在列（断言）；
5. proto/migration 面变更 → 回退 full 谱（桩测证）；
