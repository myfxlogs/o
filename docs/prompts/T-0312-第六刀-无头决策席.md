**工作树**：`/opt/o-wt/t0312`　**分支**：`t/0312-regime-push` 续提
**钦定形**：裁定席同款三件（tick 闸壳+oneshot unit+SKILL 协议）+事件

## 背景事实（决策席实证，勿再查）

- `ops_event`（SG）=O 域事件脊：O-Dev 收口写 `收口`+`移交` 行，O-DM 写
  `完成`/`裁决` 行；`ops_ticket_state`（view）=每票最新事件——
  **待裁集口径=`event IN ('收口','移交','收口待审')`**。
- eventbus `srcs` 在 `cmd/eventbus/main.go`；metabus `wake` 在
  `cmd/metabus/main.go`；Source.Q 水印 SQL 源级可配（部署四修已落）。
- roster_rw 隧道凭据已持 ops_event/ops_headless 写（O-Dev 自报同径——
  施工实核 SELECT on ops_ticket_state，缺则补授并记债）。

## 范围四件

**① eventbus 源+1**（main.go srcs 加一行零新件）：
```go
"d": {Table:"ops_event_wip", Kind:"dm", DSN:"fin",
  Q:"SELECT COALESCE(max(id),0) FROM ops_event WHERE event IN ('收口','移交','收口待审')"},
```
滤水印钦定——ops_event 心跳行高频（分析席每拍），未滤=水印热表
秒变每分唤。metabus wake 加 `"dm":"o-decision-seat.service"`。

**② `scripts/meta/dm_tick.sh`**（照 verdict_tick.sh 逐字对形）：
- ops_headless `META-DM`/决策席 心跳（全径含 skip/败拍同写）；
- 闸：`SELECT count(*) FROM ops_ticket_state WHERE event IN
  ('收口','移交','收口待审')` >0 才烧；
- `devin -p` 读 `/opt/o/skills/决策席/SKILL.md` 裁决协议批拍。

**③ unit 两件**：`deploy/o-decision-seat.service`（oneshot）+
`o-decision-seat.timer`（30min 兜底——票面「周期扫描兜底」钦定；
拍壳闸自挡空拍）。

**④ `skills/决策席/SKILL.md` 补裁决协议节**（在既有 regime 读面后追加，
本刀核心——裁决规程明文）：
- 读面：票 docs/tasks/T-XXXX+提示词 docs/prompts+diff（收口件 SHA→
  `git diff` 对基）；
- 核查清单：范围红线（diff 文件 ⊆ 提示词清单）/门禁绿（build+vet+test
  +check_migrations+import_direction）/验收锚有实迹非口报/测试 fixture
  生产真形（margin 案教训钉：禁生产不存在字段）；
- 裁词闭集：`通过`（合 master+按需部署）/`驳回`（返修件落
  docs/prompts/T-XXXX-返修N.md+转发文）/`升级`；
- **红线三件升业主不裁**：资金扩投/新平台注册或首单/席位立换——
  O 群升件+留待裁不销（裁定席「升不裁」语义同款）；
- 写面窄白名单：ops_event `裁决`/`完成` 行 INSERT、docs/prompts
  返修件、git merge 通过件、ops_headless 心跳——**禁**：钱径写
  （fin_order/position/app_secret）、venue 注册请求、gate.* 外
  app_config、凭据一切；
- 产出=seat_run 迹（ops_event 裁决行携票号+裁词+理由）——票面
  「seat_run 行+裁决文档」验收锚以此兑现。

## 验收锚

- OCI/SG 侧手插 `ops_event(seat='test',event='收口',ticket='T-TEST')`
  →≤30s META-DM 醒实证（总线径）；timer 兜底径同可手拍验；
- 裁毕 ops_event 落 `裁决` 行+ops_ticket_state 翻非待裁→再拍闸 skip；
- 红线探针（塞「新平台注册」语义收口件）→O 群升件不落裁决；
- `ops_headless` 三席心跳全程不断；stall 卡 META-DM 行显形。

## 禁线

- 事件帧=信号——滤水印 Q 禁带行载荷；
- 决策席写面窄白名单外零写——红线三件升不裁；
- metabus 零 DB 凭据（唤醒径 systemctl 唯一）；
- 桥/推送/拍壳既有件零改（只新增）。
