## 缺陷① okx 腿终局吞码——untradeable 联动死径（票面锚③未兑现）

`internal/trading/execution/flow.go` Execute leg2 败径：

```go
res2, err := r.placeAndResolve(ctx, execID, 2, l2, posRef)
if err != nil || res2.State == "ambiguous" {
    ...
    return execID, fmt.Errorf("leg2 败/歧义→LEGGED 回滚 leg1")   // ← 无 %w
}
```

`placeAndResolve` 对 51xxx 业务拒已 `fmt.Errorf("venue 拒: %w", err)`
携 `*okxexec.APIError` 上浮——leg2 出口不带 %w 全吞。xvenue 腿序钦定
leg2=okx 唯一位→`cmd/core/xvenue.go` `okxexec.TerminalInstErr(xerr)`
**结构性永假**（dead check 给审查假信心）。后果链：okx inst 终局拒
（delist/停盘——T-0142/D-0022 SHEIN 域高频实案）→不入
fin_venue_untradeable→策略不退役→armed 行每 openLive 拍重试→
leg1 mt5 真开→leg2 拒→rollback 真 OrderClose——**无限开平 churn
烧真钱**（reopenCooldown 只盖 guard 平仓后、denyAt 只盖 breakeven 径、
振荡保险丝只数开平轮次——败开环三闸全不盖）。

（同型漏面顺带必修：`xvenueOpen` 中 `loadMeta`/腿构等 Execute 前 okx
面 err 直返不过 TerminalInstErr——终局分类须盖全 err 出口非仅 xerr。）

**修法向**：leg2 败径 `%w` 透传（err==nil 纯 ambiguous 分支保原文）；
xvenueOpen 全 err 出口走 TerminalInstErr 分类（mtexec/okxexec 双判各入
各册在案码径不动）。
**桩测必修**：穿 Execute 端到端断言——fake okx 执行件 leg2 回报终局
APIError→fin_venue_untradeable(okx inst) 落行+双腿退役+提案退役三件全落
（现 TestXvenueOkxTerminalUntradeable 只直打 xvenueUntradeable handler
未走 Execute——wiring 断而全绿，本型「handler 过线径断」测试缺口
正是独立验收存在理由）。

## 缺陷② mt5LazyCli nil-conn panic——自愈钦定违例

`cmd/core/xvenue.go`：ensure 败径 `Conn()=nil`、`MT5()=NewMT5Client(nil)`
——grpc v1.84 `Invoke` 首行 `cc.dopts` 直取（nil deref panic 实证）/
nil interface 调方法即 panic。下游 `e.trading().OrderSend/OrderClose`、
Resolve `OpenedOrders/OrderHistory`、Mt5Sizer.ContractPos 全中招。
xvenue_open 开闸后 mt5 网关断/凭据缺/重连败→执行+guard 现读径 panic
→o-core 崩循环（systemd 拉起→腿在案再试→再 panic）。
票面钦定「RPC 败标 suspect 下次重连——常驻会话跨重启/断链自愈」——
**重连败径应 err 上浮走 Resolve/定态径，非炸进程**；fail-closed 律
同案。

**修法向**：executor 侧 Conn()/MT5() 取用点 nil 守→
`OrderResult{State:"unknown"}+err` 上浮（Cli 面扩 err 载/executor 守
两形择一，保 mtexec.Cli 旧实现零回归）；
**桩测必修**：fake Cli ensure 恒败→Place/Resolve/ContractPos 返 err 非
panic（recover 断言）。
