# 施工提示词：T-0312 第五刀——OCI→dev 事件总线（ConnectRPC server-stream）

**角色**：`[角色:施工]`　**票**：T-0312 ①件（三服务器终态地基——②决策席全
职面依赖此件供唤醒）
**工作树**：`/opt/o-wt/t0312`　**分支**：`t/0312-regime-push` 续提
**钦定形**（票面钦定零再裁）：ConnectRPC server-stream；帧=信号非数据
（source/kind/max_id/ts 四字段，载荷本体禁入帧——数据仍走 PG 读径）；
dev 外拨 OCI（NAT 后零入站口）；ssh 隧道鉴权起步（mTLS 二期债）。

## 拓扑（钦定）

```
OCI: o-eventbus.service ── poll MD_PG_DSN(本地) + FIN_PG_DSN(隧道→SG) ──
     Watch server-stream ──bind 127.0.0.1:15436
        ↑ ssh -L 15436（dev→OCI 反向隧道，restrict+permitopen 钥）
dev: o-oci-bus-tunnel.service ── localhost:15436 ── o-metabus.service
     ── 帧到 → systemctl --user start <席 unit>（唤醒=oneshot 起一拍，
     拍壳内闸自挡空拍零浪费）
```

## 部署件（提示词含——施工或决策席执行均可）

1. `GOARCH=arm64 go build ./cmd/eventbus`→scp OCI→o-eventbus.service
   装启（env 件复用——MD_PG_DSN/FIN_PG_DSN 均在册实证）。
2. dev 生专钥 `~/.ssh/o_oci_bus`→OCI `authorized_keys` 挂
   `restrict,permitopen="localhost:15436" ssh-ed25519 ...`（o-sg-tunnel
   钥同形钦定——无壳钥）。
3. dev 装启 o-oci-bus-tunnel+o-metabus 两 unit。

## 验收锚（票面钦定）

- OCI `md_ctx_fact` 手插一行→dev `journalctl --user -u o-metabus` ≤30s 见
  DataAdvanced 帧+`o-regime-analyst.service` 实起一拍实证；
- `systemctl --user stop o-oci-bus-tunnel`→断中再插行→start 恢复→
  水位续传补帧（漏帧补齐）实证；
- fin_econ_lesson 插桩行→o-econ-verdict 醒（第三源同验）；
- `ops_headless` 两席心跳行全程不中断。

## 禁线（票面钦定逐字）

- 桥件零改动（dualwrite 保留）；
- 帧=信号非数据——禁塞数据本体；
- dev 订阅件不持写权限（零 DB env）；
- bind 仅 loopback——零新公网暴露（隧道即鉴权）。
