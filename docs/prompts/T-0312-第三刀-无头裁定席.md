## 范围

### ①拍壳 `/opt/o/scripts/meta/verdict_tick.sh`

照 regime_tick.sh 形（set -u/env 取径/hb 函数/闸败 skip 零烧）：

- 水印闸：`SELECT count(*) FROM fin_econ_lesson WHERE status='pending'`>0
  才烧——FIN_DSN 隧道径现成（regime_tick.sh 的 FIN_PG_DSN 同 env）。
- 心跳 seat='META-VERDICT' ticket='META-VERDICT'（ops_headless 行——
  stall 卡读面顺带）。
- devin 批拍：`devin -p --model swe --respect-workspace-trust false
  --permission-mode dangerous -- "读 /opt/o/skills/裁定席/SKILL.md 拍
  经济案裁定"`——同分析席调用形。
- `cd /var/tmp/o-verdict`（scratch cwd——零仓件接触）。

### ②unit `o-econ-verdict.{service,timer}`

照 o-regime-analyst 逐字对形——`OnUnitActiveSec` 定 **4h**（裁定频
高于 regime——pending 有水印闸兜底，勤拍零烧）。

### ③裁定 runbook `skills/裁定席/SKILL.md`

新建技能件（frontmatter 三行照 ctx-sources——name: 裁定席 / domain: 经济）。
内容=裁定协议全录（LLM 席的判据件，要点）：

- **读面**：SG psql（FIN_DSN env 径）查 `fin_econ_lesson WHERE
  status='pending' ORDER BY id`——kind/entity_ref/numbers jsonb 全取。
- **逐案裁**：verdict∈{canon,dismiss,merge}+理由一句话+回改点词
  （`kill_trigger:<family>`/`sizing:<x>`/`combo_gate:<x>`/`eval:<x>`/
  `semantic:<slug>`——schema v3 契约同集）。
- **落面**（窄白名单三步）：
  1. 机械词→`UPDATE app_config SET value=to_jsonb('true') WHERE key=
     'gate.<类>.<名>'`——**key 不在册拒写**（SELECT 先查，不在=跳过记
     verdict_ref 注明「键未册」两拍分权）；
  2. semantic 词→`cd /opt/o && go run ./tools/skillgen <id> <slug>`→
     `go run ./tools/kbgen skills`→git add+commit（skills/econ-* 命名域）；
  3. `UPDATE fin_econ_lesson SET status='verdicted',verdict_ref=<裁词:理由>
     WHERE id=<n>`。
- **升不裁**：kind 不熟/理由写不出/涉红线（资金/新平台/席位）→
  `ops_headless` stalled 行+**留 pending 不强裁**——裁定席只裁能裁的。
- **先例读面**：`skills/econ-*/SKILL.md`+`docs/经济经验库/条目/`已册案
  先读——同型案照先例裁，新立案留 match 签名。

## 验收锚

1. `systemctl --user start o-econ-verdict` 手拍→pending=2 种案被裁：
   `status='verdicted'`+verdict_ref 有裁词（业主已亲裁语义→canon）+
   `skills/econ-*` 生成件入库；
2. `ops_headless` META-VERDICT 心跳行在；
3. 零 pending 时拍=skip 零 devin 调用（闸实证——journal 查闸败 skip）；
4. 写面越界禁实证（裁定件不得写 fin_econ_lesson/app_config/skills/econ-*
   以外——runbook 禁线节）。
