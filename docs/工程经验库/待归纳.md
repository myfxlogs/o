## go-build-cwd-artifact-swept（待归纳——两犯）

- 现象：`go build ./pkg/cmd`（无 -o）把二进制写在 cwd——`git add -A` 扫入 commit（T-0085 fillsprobe 16MB、T-0086 core 28MB 两犯，后者 amend 急救）。

## push-ledger-write-before-send（待归纳——三处同病）

- 范式：推送幂等行只在送达后写（Sender 返 msg_id+ok 判成败）；「先占位防重推」换「崩溃重发」丢「失败重试」——送达率优先防重率。
- 判据：审查「查账→动作→记账」三段序，凡记账先于动作完成判定=同病；配套降级计数须出观测面（内存计数=静默丢报）。

## beat-arm-errc-fatal-amplification（待归纳——T-0446 签名面病灶本体）

- 现象：拍环臂级可恢复败（全族 REST/目录瞬断、写败）上抛 errc，
  消费端 `log.Fatalf`=进程全臂死——T-0446 观测盲签名
  `scan:md_tick_scan→discovery` 产者死径：ScanPoller.Run 一拍败即
  errc→cmd/collector 杀死采集主进程，WS tick/sigdist/mt5 姊妹臂陪葬，
  md_tick_scan 停写→depblind 10min 零行窗报同签名。全仓仅此臂拍败
  即进程死（姊妹臂惯例=让位记拍下拍续试）。
- 范式：拍环臂败=让位不拖死主进程；errc/fatal 通道留给真岗终语义；
  持久真死由水位闸（scanwm 族谱）+探针（depblind 观测盲）升件收口——
  臂级瞬断不放大为进程级死亡，瞬断自愈不产假行。
- 判据：新增/审计拍环臂必核 errc 消费端语义——fatal 消费端下臂级
  可恢复败上抛=同病；姊妹臂同型 errc 上抛面未全核（T-0446 偏离
  说明③已呈决策席），再现或全核坐实即升格条目。
