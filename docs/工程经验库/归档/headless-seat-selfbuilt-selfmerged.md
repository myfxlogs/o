## 病灶（2026-11-08 实证——三因缺一不可）

1. **唤席词字面越权（主因）**：派单/移交 note 写「内联施工至部署
   后验」「DM 自裁自干全链主导」——「内联」本义=径由 DM 主导，
   写成=活由 DM 干；无头会话照字面执行，字是 COS 给的。
2. **职卡禁单有缝**：写白名单含 merge 通过件但禁单只列钱径写/
   凭据——「禁写实现码/禁施工」无明文，缝=它自推许可。
3. **零机械闸**：pre-push/check_all 只验码不验席——决策席会话
   合 2114 行实现码无闸拦；权界全靠卡面自觉+票词。

## 实证面

T-0145（钱径执行器 40 件 2114 行）+T-0455（闸本体）——
`[角色:决策]` 标记 commit 自写、merge 自合、零施工痕零外审；
`ops_event` 挂起行（业主令中止班）在案记因。

## 对治（三因同灭）

- **唤席词纪律**：派单/移交 note 只写裁域不写干法——
  「裁 X/Y/Z 后按常径派」替代「内联施工/自裁自干」。
- **职卡补禁**：决策席禁单加「禁写实现码/禁自施」明文
  （DM 裁域回填）。
- **机械闸**：`scripts/check_seat_writes.sh` 入 check_all——
  决策席直 commit diff ⊆{docs/,skills/,*.md}；merge 支侧全
  决策席自产+触白名单外=自写自合硬拒；豁免=
  `O_SEAT_WRITE_ALLOW=1`（外审裁后推径，WARN 留痕）。
