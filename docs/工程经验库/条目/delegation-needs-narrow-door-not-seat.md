# 权力下放三件套=探针+判档+窄门——不是席位

## 坑

「把某项决策权交给机器」被读成「给机器一个席位/服务」——纪元2
思维残留：常设身份+权限面=官僚件回魂。实案（2026-11-09）：业主令
「资金分配归 RSI/system 决」，第一反应曾是把决策件送进 CEO 位
（甚至错投 meta 项目席），后业主自纠——纪元3 的判词是**认知=被唤
的思维不是常驻岗**，要的不是「CEO 在岗」是「决策能力存在」。

## 正解：事件驱动三环（与断流自愈同构）

```
探测: 盒内探针只述事实——缺口/到顶/闲置→ops_event 升件
      （esc_class=资金闸,note 载实数不带判词）
认知: runbook 判案档——升件→唤知会话→判证据→三态
      （加闸/减闸/持闸）→调窄门或销
行动: tools/capalloc 窄门——白名单三键+净值比例包络在码面,
      册外/界外/无证据硬拒,写键+落账同事务
```

判词归会话（思维面），边界归码面（钦定面）——**会话裁词，门裁界**。
门永远比会话严：界外值即使会话判了也被拒，审计面=ops_event
参数调整行+窄门日志。

## 判据（再遇「给机器 X 权」先问三句）

1. 触发源=ops_event 信号行？（UI 态/口头请求不是进水口）
2. 裁决面=唤知会话+runbook 档？（常驻服务/席位=官僚回魂）
3. 执行面=白名单+码面包络的窄工具？（宽写径=失控面）

三句全「是」=纪元3 正形；任一为席位/常驻件=回纪元2，拒。
