# 双车道施工席（信号道×工单道分离）

**病灶**：单串行唤知窗下，限时件（升件/信号）与长活件（工单）共用
一份时间预算——信号烧窗→工单吃「挂起」行→stall 探判滞留→误报
再烧窗（#18484 八票簇三轮负反馈实证）。**被看见≠被做**。

**编制**（owner/consumer 同构的车道分权）：
- **唤知会话**=信号道+工单**验收销号权**（swe-2-max）
- **施工席**=工单专办道（o-worker 单元，`swe-2-flash-high`）——
  OPEN 桌认领→干→`施工席/处置`完工回执；**永不碰信号面永不自销票**

**机制四件**：
- `dispatch_worker.sh`——OPEN 票在案即唤；`o-worker-*` 自有单飞闸
  （不撞 o-cognition-* glob）；PG advisory lock **7970**+`施工机` seat
  唤起行=跨机单飞判据（与唤知锁键 7969 分域——**双锁双账**）
- `run.sh` COG_ROLE=worker——seat 分账（施工席/施工机/WRK- 心跳前缀，
  会话目录按角色隔离）
- `worker_runbook.md`——工单道契约：认领租约（<2h 在办不可抢，
  认领后复读防双唤竞速败）→干→完工回执载证据（sha/部署 ts/实测值）→
  收口行释锁；硬界=禁碰信号/禁自销/禁立案
- `fin_0187`——sem_matrix 补 `唤起×施工机`+`处置×施工席` 两行
  （闸做对了：新 seat 未裁处入册 loud 拒写，入册必须显式迁移）

**坑与同族合修**：「挂起缓期窗锚错」病灶另一半——stall 探改了
s.ts（升件#18484），但 TICKET_N/死题疑云/runbook 桌查三处仍锚 t.ts
（挂票照样唤+上桌）——本 commit 四处修齐，同条目判据覆。

**观测约定**：
- `施工机/唤起`行+`o-worker-*` unit active=工道在飞；
- `施工席/认领`行<2h=票在办（唤知桌剔）；
- `施工席/处置`完工回执=销证候选——唤知验证据行才销；
- `施工席/会话收口` unit=o-worker-*=正常完场（锁释契）。

**边界/余账**：
- 唤知 TICKET_N 唤保留——唤知=工单道后备（施工席死/瘫时票仍可办），
  认领租约天然防双干
- 成本=第二个 LLM 会话预算（flash-high 执行件轻模型对冲）
- 票节流（立案阀）未做——配菜另议，先观施工道出流速率
