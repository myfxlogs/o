# 等待态三无=管道静默死锁（升件无老化·无人领不发声·退路无断言）

## 病灶形

- 部署窗壳三态判据=挡件**全局挡**——半截升件（img/oci 基线岔）无人领，
  **一处升件冻整条部署管**：23 commit 批压 8.5h，批首龄涨满 24h 才有
  OVERRUN 兜底，且死锁本身零发声（挡件清单只在窗壳输出里，无人看=无账）。
- DM 班退判据=本席 review 面 drain 空——「已批未领」（T-0424/0423 型）
  不在其队列视野，**退班零违例零留痕**，派单靠 30min 兜底 timer 撞运气。
- 两病同根：**等待态无老化、无人领不发声、退路无断言**——「静默死」家族
  第六条（前五条见 T-0434 同族条目：自监探针/写器死活根修）。

## 根因三层

1. **升件行是 append-only 死信**——落账后无老化判据无踢径连鸣：eventbus
   只在新行 INSERT 时 kick 一次，错过即沉底；escalation_aged 量表 24h 阈
   +日频1+滞回2拍，对「分钟级冻结」是慢档装饰。
2. **挡件不挂面**——窗壳把 img 面争议与 oci 面干净捆死判：一张 web-only
   在飞票冻掉整条 oci 发窗；reason 不带面标=冻结明细不可读。
3. **退班判据缺全局账**——drain 空≠账清；「要么派要么落行」缺机械位，
   退班理由行（谁挡/等什么/下一拍谁接）无处落。

## 处置（T-0437 已落）

- **升件老化探针**：gauges.tsv `escalation_unclaimed`（⑧mode=连鸣 首用）
  ——升件行>30min 无席领计数，阈内静默阈上**每拍连鸣**（跳滞回/日频——
  冻结必须持续发声）；「领」判据=同票后随 裁决/完成/驳回/挂起 行，或任
  后行 note 引证 `升件#<id>`（先例适用同形——票空升件行唯一可追领据）；
  自鸣行（note 前缀 升件老化）不计防自激。载=既有 o-gauges-tick 30min 拍
  （零新进程）；落行即 eventbus dm-kick（消费码既有径）。
- **部署窗分面**：deploy_window_due.sh 挡件挂面标——OCI 构建源=双面挡/
  image_only=img 单面挡/非部署面=不挡/不可判=保守双挡（不退化）；应发
  面集减被挡面=净发窗面集（faces= 行），reason 携「冻结面/放行面/挡件
  面标」；净集空=有挡。
- **班退闸**：dm_shiftend.sh 机检全局账（已批未领=dm_queue approved+
  有挡项=窗壳 state=有挡）——非空落 ops_event `退班理由行`（谁挡/等什么/
  下一拍谁接三字段必携），shiftend=clean 才算静默退合法；SKILL 班次节
  步序写死。

## 教训

- **冻结必须持续发声**——去重/限频是防误报刷屏的，不是防冻结报警的；
  老化类量表天然属「阈上连鸣」律（新载律=gauges ⑧mode），拿防刷屏机制
  套冻结报警=把火警接到每周一响。
- **挡件要挂域**——全局互斥判据把无关域的争议捆进死锁；分域后争议面
  冻结、无争议面照发，死锁半径=争议域自身。
- **退路要有账**——任何「做完了就退」的判据，都必须补一道全局账断言
  （还有谁在等/等什么/谁接手），否则退出动作本身成为静默死锁的最后一环。
