# 词面语义多解族（五案同母实证）

**坑形**：票态（销/挂起/接续/认领/级）语义以「工单#N+关键词」自由文本
承载，谓词谓语散在 dispatch.sh×4 / dispatch_worker / 三桌面 runbook
各解析一份——修一处漏一处，且每加一条 NOT LIKE 关键词就是一颗新雷：
- 引证误销：处置行引第二张票=邻票被销（引证无边界）
- 容量自锁：挂起条件含「认领窗/施工窗」的容量等待被当真挂起藏票
- 回执无销→销票闸修完，「销票归唤知」名词引用仍字面命中销
- 级降P2/级=P2 措辞变体一解一不解——判词生效面看心情
- 「等裁定」挂起在裁定者桌面不可见=裁定单点饥饿

**判别**：同一语义表达式在 ≥2 个文件里各写一遍正则=病灶族胚胎；
任何「处置行里关键词字面命中」的判据都不是判据是彩票。
真销标=动作记号（销——/销：）非字面「销」字。

**修法**（fin_0190 在案）：语义层单点——ops_event_act 视图把
note→(rel,act,susp_cls,susp_hours,level) 解析收敛全库一处，
ops_ticket_desk 每票派生态（workable/rulable/claimed/closed/level）
供所有桌面读；ops_event.sem JSONB=writer 显式语义槽预留。
处置记号钦定契：销——=销|挂起解==复办|挂起条件==挂起|回执=待验不销；
首引证收窄=一处置行只动作首引「工单#N」一票。

**推广**：语义承载于文本的系统，「解析只许写一次」应与
「事实只许写一次」同级——派生层可以读文本，谓词层必须读派生。
