# stall 探挂起窗锚错——挂起标记对老票恒失效

**坑形**：dispatch.sh ticketstall 探的挂起抑制谓词为
`NOT EXISTS(处置行含 挂起条件= AND t.ts + 票面期限 > now())`——
**缓期窗从票立案 ts 起算**。票面期限默认 24h，票龄>24h 的票被标
挂起后窗恒过期 → 挂起行对老票**永不生效** → 处置席销票（挂起给
依赖）→ 探针 6h 后照判滞留复火 → 再升再挂。实证 8 票簇 3 轮，
每轮簇处置耗一整个唤知会话反挤施工窗——**探针误报挤占它要保护
的容量**，负反馈回路。

**判别**：挂起销票后同票 ticketstall_ 在 >0 周期内复火；票龄>
票面期限；处置行含 `挂起条件=`。

**修法**（dispatch.sh，升件#18484 求助三裁取①）：
1. **缓期锚改挂起行 ts**——每次挂起得真缓期窗：
   `s.ts + COALESCE(挂起期限=Nh, 票面期限=Nh, 72h) > now()`。
   到期仍回列复验（「挂票过期复验」钦定语义不变），复火节奏
   从 ~6h 降到 72h+。
2. **`挂起期限=Nh` 可选字段**——处置席挂起时自供缓期（排队
   等窗 72h 默认不够用就写大），已载 runbook 挂起契约。
3. **SUSPEND_AGE env**——`COG_TICKET_SUSPEND_AGE` 可调不改码。

**未取径**（求助三裁之②③备录）：
- 簇并一件——esc_scope 键域=票行id 承载单票销/恢复生命周期，
  合并破粒度；①落地后簇噪声已消，②不必要。
- 外席接票——处置件非探针件，本坑只修探针。
- feed_esc.go/runbook OPEN 列同锚 t.ts 不改——彼面谓词语义是
  「票终没/该不该压新升件」非「该不该告警」，混改牵连 escalation
  抑制行为系统面。

**推广**：凡「X 在 Y 期限内豁免 Z」谓词，期限锚必问一句
「从哪个 ts 起算」——锚错对象（立案 ts vs 事件 ts）是老数据
恒失效类 bug 的通用母形，比阈值调参更深的层。
