## 「票史存在 X 行」式排除判据盖不住撤销语义——队列推导按 latest 事件判

- **实证**：T-0375 落的外派豁免=`NOT EXISTS(票史有外派行)`——T-0379
  业主令撤外派改内循环（新已批行 00:46 落）后票仍被永排出待派集，
  DM 队列空假象，靠决策席目击手动补派（升件行 00:51 在案）。真库
  截 00:51 重放：旧查询空集、新查询出 T-0379。
- **根因**：「票史存在某事件」是单调谓词——只可累积不可撤销；方向
  类事件（外派/改径/重批）天然可逆，用单调判据表达可逆语义=结构性
  盲区，新事件永远拉不回。
- **教训**：队列/状态推导的排除判据按 **latest 事件派生**——排除
  条件=「某行后无覆盖它的新行」（`NOT EXISTS(外派 w AND NOT
  EXISTS(已批 a AND a.ts>w.ts))`），不查票史有无。同刻批写行按方向
  性更强的事件定（已批+外派同刻=外派向）。事件账可加行不可改行的
  账构下，「撤销」只能靠时序后行表达。
- **收口**：T-0380 判据事件化落地+三形桩测（外派→已批=入/外派→领单
  =不入/纯已批=入）；collab §1 写面判据补「外派可逆」一行。后续同类
  「排除某类历史票」需求先问：该类事件可被什么新事件撤销。
