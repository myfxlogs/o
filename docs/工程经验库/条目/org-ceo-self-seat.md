# 自我席(CEO)——公司「我」的建制与两坑

## 病灶

纪元3 撤管理席后留「反射链无方向」洞：唤知判信号、施工干票、
研究找道，**无席答「整家公司指向钱没有」**——业主当了免费监工。
纪元2 CEO 之死非「有执行席」，是它的产出=流程件（相位/席位规/
票套票），考核=合规——**官僚化=弱判断抓可量化代理指标**。

## 建制

- `docs/组织.md`——公司章程：全岗职责/权限/禁区/KPI/节拍/汇报线
- `docs/态势.md`——连续自我页：自我席笔，全会话进场读（失忆短工
  接班=读前任交接非第一天上班）
- `self_runbook.md`——拍序五段：对账上拍承诺→读钱→读板→判四问
  （方向/先做/该死/我错哪了）→写判词+令票+态势页
- `dispatch_self.sh`——6h 恒唤非事件触发（CEO 对钱负责非对件）；
  锁 7971/自我机 seat 分账，条件插入免 DELETE（append-only）
- 级=判级轴：票 note 或后随处置行 `级=P[123]`，最新者赢，
  未标=P2；桌面排序=级→期限→龄（唤知+施工两桌同径）

## 机制四件

1. **全权但窄面**：方向/排序/生死/探索/各岗 charter 全归 CEO；
   写面只许五类——判词/级=处置行/方向票≤3张/拍/态势页/问董事会。
   物理条件件（钱/户/凭据）走条件请求径问董事会，不绕不猜。
2. **对钱负责**：考核=真账年化（D-013 全费扣）；杀阀=连 4 周
   判词不改板面或年化不改善→董事会裁；判词禁「流程健康」词当成绩。
3. **审计独立**：审计席不归 CEO 辖，CEO 不碰审计产出。
4. **红线三件永不下放**：扩投/新平台/席位立换+组织表岗位定义与
   KPI 判据终裁=董事会件；CEO 可提议不可自改。

## 坑（同族防复)

- **fin 迁移入册**：新 seat 写「唤起」「处置」两闸内词必先
  sem_matrix 放行（本件 fin_0189）——隐式=gate loud 拒写
- **append-only 条件插入**：跨机在飞判=INSERT...WHERE NOT EXISTS
  （唤起行+headless 心跳双面），禁 DELETE 清竞速败行

## 余账

- KPI 探针量表（销案时效/票时效/砍亏/误报率）=后续件
- 独白席归并处置：CEO 判词吸收内省面，timer 去留待董事会裁
