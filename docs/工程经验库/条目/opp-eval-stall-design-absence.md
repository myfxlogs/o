# opp_eval_stall 判例——钦定设计态缺席非断供（#12167/#12290）

**实案**：`dcd_call`/`dcd_put`/`vol_sell_*` 族 48h+ 零评估升件两连
——查证非枚举环死：`fin_opp_eval` 他族近期评行在案、
venue feed 鲜；真因=研究臂 11-10 十七连败后自停（#9519）+
业主亲手驳回重启 gap #241/#242=「不许再开这臂」钦定态。

**判词律**：零评估三因分诊（runbook 同档）——
①枚举环死（他族也零评）→要码修；
②venue feed 断（该族依赖面不鲜）→采集面立件；
③族面自裁/业主驳回（枚举活他族评、只是本族被停）→
**定性销「设计态缺席非断供——钦定停臂在案」**，载自停行号+
驳回行号双锚。勿把钦定缺席修成「恢复评估」——那是逆业主令。

**反面**：枚举活+feed鲜+族未被停而零评估=供给枯（市场面无
候选），同档定性销「供给枯非断供」；三因皆非才转要码修。
