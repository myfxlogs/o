# confGate 两短板：sd=0 同值流 N=3 即放 + N≥30 独立性假设裸奔（O-41389）

**坑形**：`confGate` 毕业统计闸（LB=mean−t·sd/√N>0）两处口径空洞——

1. **零方差捷径**：`confMinFills=3` 配 `sd=0→LB=mean` 退化——三笔等额正
   收入 fill（regime 巧合/测试夹具/结算粒度粗）即 `LB=0.1>0` 秒放，
   「置信下界证伪制」被同值序列架空。
2. **独立性假设裸奔**：LB 公式的 t 修正只保小样本正态性，**事件独立
   假设从不检验**——N≥30 的同向聚簇序列（regime 内连击）按独立样本
   计，LB 系统性高估置信，无任何判词显形。

**根修两件套**（统计闸通用）：

1. **零方差条款**：`sd==0 ∧ N<8 → fail「零方差捷径」`——同值流须八连
   方放（等额八连=真一致可辩护，三笔=巧合嫌疑）；`confMinFills 3→5`
   同步收紧正常径。
2. **独立性上牙**：N≥30 符号游程检验（runs test，自算不引外库）——
   正/非正（零计非正）序列算 R，`E=2n₁n₂/N+1`，
   `Var=2n₁n₂(2n₁n₂−N)/(N²(N−1))`，`Z=(R−E)/√Var`；`Z<−1.96`=游程
   显著过少=同向聚簇=独立假设证伪→fail。N<30 判词升显式「证据期——
   独立性检验未达样本阈（N<30)，LB按独立样本计」；`n₁∨n₂=0` 全同号
   检验退化=按零方差条款判（同值嫌疑归 sd=0 条款管辖）。

**判别式**：凡「均值−置信半宽>0」式统计闸，三问必答——①方差为零时
   判词是什么（sd=0 退化径=捷径温床）；②独立性假设有无检验件
   （聚簇序列使 LB 失效）；③N 阈两侧判词是否显式（证据期/未检
   降级标注不可省）。

**夹具纪律**：靠旧阈过闸的既有测试夹具（3 笔等额 fill 喂晋升断言）
   必须升级到真序列（异额/八连等额），**禁削闸迁就夹具**——保项钉：
   夹具服务闸非闸服务夹具。
