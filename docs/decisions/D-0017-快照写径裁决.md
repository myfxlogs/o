# D-0017 快照写径裁决——禁快照驳回，改裁保留义务

| 字段 | 值 |
|---|---|
| 状态 | **被 D-0018 部分推翻**——取证量错尺（pg_stat 只计超表父表漏 chunk，md_* 实为 2.5GB/日增1.7GB）；「保留期义务」半仍生效并入 D-0018 |
| 裁决 | `[角色:决策]` 2026-10-25 |
| 出处 | 待裁案「全项目禁用快照」（md_* 快照类写径停/留）；T-0117 返修④挂起等本裁 |

## 背景

PG 体积治理（pg-capacity 账，SG 11GB 基线 2026-10-23）牵出提议：项目级禁掉快照写径。
取证（SG 实拍 2026-10-25）：

- md_* 全族合计 <200KB（dcd_product 24KB 为最大件）——**容量嫌犯不在 md_***；
  真犯是 facts 超表 6.8GB、fin_cex_dci_quote 864MB（无保留）、ticks 1.3GB、
  fin_venue_account_snapshot 251MB——已挂 pg-capacity 三板斧施工序。
- md_* 是系统感官层：md_ticks→spot() 估值、md_funding→carry 评估、
  md_dcd_product→枚举宇宙、账户帧→对账——opener/lifecycle/earn/review/
  execution 全家读面。**禁写=致盲系统**，发现/评估/对账三环同死，T-0117
  修臂工作直接归零。
- 真病灶=**追加式快照无保留期**：md_dcd_product 每分追加 ~50 行
  （1517 行/52min），读面只取最新，历史堆积零消费者。

## 选项与取舍

| 候选 | 取因 / 弃因 |
|---|---|
| （选中）快照写径保留+每表保留期义务 | 感官层不可断；病灶是缺保留不是快照本身 |
| 全项目禁用快照 | 弃——致盲发现/评估/对账，且治错对象（md_* 非容量嫌犯） |
| 快照表全改 upsert 最新态 | 弃——时序窗需求真实存在（funding 史/equity 曲线/事件回查），一刀切丢评估面 |

## 结论

1. **快照写径全族保留**——md_* 是合法写径，不设「禁快照」条款。
2. **保留期义务分级**（施工落 T-0123）：
   - 最新态语义表（读面仅取最新）：`md_dcd_product`、`md_earn_rate`、
     `md_mark_index` → 保留 **7d**
   - 短窗时序：`md_ticks`、`md_books5` → **72h**（与 ticks 超表同径）
   - 评估窗事实：`md_funding` → **30d**（carry 回测面）
   - 业绩史：`md_equity_curve` → **不删，降采样**（7d 原始粒→小时粒，
     pg-capacity ④号斧同径）
   - 事件行：`md_account_events`、`md_macro_event`、`md_calendar_push`
     → **90d**
3. **机检闸**：新增快照类表（md_* 或 fin_*snapshot）无 retention 声明者，
   迁移检查拒（check_migrations 增断言）。
4. **T-0117 返修④解挂**——快照写径合法，USDT 计价硬闸照回执④施工。

## 连锁影响

  不完整，复审可退。
- 容量主线不变：facts/dci_quote/ticks/account_snapshot 照 pg-capacity
  三板斧推进，本裁不替代。
