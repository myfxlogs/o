# D-0022 桥二期=蒸馏信号层（方向裁决 2026-10-26）

## 裁决

桥的定位升维：**采集器（机）=桥=信号蒸馏车间**。过桥的从「价格行」
升为「信号行」——SG 消费可直接评估的机会特征，不再搬原始行情。
一期（行情蒸馏写径）已建成是物理前提；二期在其上加**计算层**。

## 信号面三族（分期）

- **P2a 纯 OKX 信号（零新凭据先行）**：
  ① basis 曲线——季度合约 mark vs spot index→年化基差点列；
  ② funding 期限视图——当期+预测+滚动均值（carry 族直接输入）；
  ③ 深度特征——books5 在桥复活（SG 因带宽砍掉的面上桥），
  产出 top-of-book 深度/价差宽度/冲击估算**特征值非原始盘口**。
- **P2b 跨所信号（凭据件）**：MT5 行上桥——
  ④ xvenue_spread：OKX perp/spot vs MT5 CFD（ETHUSDm/BTCUSDm
  实测在采）价差 bps；⑤ carry_diff：OKX funding vs MT5 swap 率
  （SymbolParams 面）——**跨所套利经济学的核心信号**。
  条件：EXR 凭据注 dev 环境（mtapi 公网端点 dev 直连无拓扑障碍，
  凭据分发=唯一新件）。

## 契约钉死

- 存：`md_signal` 有界状态表——PK(kind,key)、val、meta jsonb、ts；
  同键最新 ts 赢（共写语义延续，禁追加快照同 D-0018）。
- 鲜：消费侧过新鲜度闸——信号陈=不存在（信号不是事实源，是派生面；
  桥断=信号面缺席如实，**不得回退用行情现算冒充**）。
- 流：信号→hypothesis 臂新输入源（假想官从「面差」升级到
  「此刻价差张开」）→evaluator→proposal。信号永不触执行径。
- MT5 钱径报价**留 SG 本地**（持仓平仓要看 tick——钱径非信号面，
  双轨不冲突）。

## 防再议

二期=「扩大机会发现」的物理底座（业主令 2026-10-25：只能在已知
范围跑=系统走不出去）。信号行即发现面的燃料——先燃料后假想，
顺序不可反（P2a 无阻塞先行，P2b 等凭据件）。
