## 裁定（按序；①②为钱径码归施工席，③为管道器官件）

**① 钱数先真（P1）。** 写侧正源：simdrill 全写面 `venue=sim`（cashflow/order_leg/execution 同律）；存量行以追加式重标归位。
验收（机检）：`fin_cashflow WHERE venue<>'sim'` 的 7/14/30d 净 == 按腿→执行→策略剔 simdrill 之净，差=0；次日演习批后仍=0。
落地后：止血令#22349 的证据作废重判；death_factor 按真数重算。①落地前，任何席不得据机器口径净产出下经营判断。

**② 钱安全进引擎（P1/P2，在队）。** #22247 第二出口、#22248 停摆键。验收：拔掉全部会话，守卫正径败时敞口仍限时归零。

**③ 落地机械化——落地队列（P1）。** 「复审过的支→master」不再经任何会话或票：
- 事实三件齐即落：(a) 支尖有 check_all 绿戳；(b) 账上有复审过行 `复审过 sha=<尖全sha>`，写行席≠支作者席（非钱径/非免疫径支免 b）；(c) 对 origin/master 可净合。
- 落地件（models 定时件，deploy_watch 同拍）：独立工树 `merge --no-ff`→在合并点跑 check_all→戳→`sha:master` 推→deploy_watch 照旧部署。
  单写者=落地件；红=不落+落一行事实（不升件不立票，日计数）；合并点 commit 体承袭支尖的 `坑处置:`/`免疫件:` 行。
- 同批删除：并支票族、候审消费契①散文、pendbr/p1stall/verdfalse 三探逐支升件（退回日计数行）。
- 过渡（落地队列上线前）：复审过行在案的支，merge 为机械步，施工席可执行（分席已由「作者≠复审者」满足）。

**④ 自管层冻结并做减法。**
- 冻结：即日起不新增规矩/探针/席位；修法只许「删」或「把散文换成机检」。
- 探针二分：钱与采集事实（留，升件）／机器看自己——会话、票、支、帧、白名单（降为日计数行，不升件不立票）。
- 票面只留三类：钱安全、钱数真伪、找钱。其余开票归档（逐票追加销行，注本档）。
- 唤醒：无「钱/采集/部署败」信号不叫醒唤知；「面净」拍占比 79%→<20%。唤知 runbook 991 行→≤300 行核心契（#18757）。
