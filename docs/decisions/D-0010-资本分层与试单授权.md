# D-0010 资本分层与试单授权

| 字段 | 值 |
|---|---|
| 状态 | 生效 |
| 决策 | `[角色:决策]` @ 2026-10-26 |
| 批准 | 业主令 2026-10-26（"10K 一半在 MT5，能进 OKX 的只有 5K，先用现有的试单，确认需要增资时再通知"） |

## 裁决

1. **资本分层定盘**：$10k 盘子≈半数在 MT5（EXR 3001157 权益 ~$3247）——OKX 侧可注入上限 = **~$5k**。双账本口径不变（USD/USDT 各计）。
2. **试单资本=现有 in-situ**：OKX Earn 停泊 ~2133 USDT 即为授权试单资本——不动用业主追加拨款。D-0007「入金是扩张项非开门项」执行化。
3. **增资通报制**：仅当评估卡显示增量容量能使净收益过闸线且现有可部署额不足时，经条件请求明提业主——平时不占用业主注意力。
4. **试单授权**：按 D-0007 首仓序 ④ 执行——funding-hedge 模板最小可行名义额真钱试单，观察窗 ≥1 个 funding 结算周期（OKX 8h/epoch）。T-0050 单在案。

## 试单边界（T-0050 硬线）

- 名义额上限 **$500**（≤现有资本 25%，dust-级规模不承担试单学习成本以外的风险）
- 标的由执行席按当时 `md_funding` 评估卡选净 APR 最优标的；**net_apr ≤ Earn 现率 = 拒开**（D-0006 动态底）
- 双腿原子执行+回滚径已验（okxverify -mut 54 PASS 在案：合约开平/现货买卖/撤单/划转全绿）
- 结算窗内任一腿执行歧态 → 实读仲裁禁猜（exec-error-ambiguous-arbitrate-raw 条目纪律）
- 30 日净值 −3% 全停等硬线全程在位

## 证伪锚

- 首仓结算净收益 < Earn 现率等值收益且无解释 → 复核试单参数与评估卡口径
- 执行链任一环节 fail-open 实证 → 冻结 live_switch 回检修
- 业主资金格局变化（MT5 侧回撤/OKX 已入金）→ 复核分层比例

## 连锁影响

- 命官/执行面配置键名义额以 $500 为试单上限（非 $2100 满额）
- Earn sweep 纪律兼容：试单开仓走 RedeemToTrading 前置赎回径（D-0006②已建）
- 增资条件请求模板待用时落 `fin_condition_gap`，不占本档
