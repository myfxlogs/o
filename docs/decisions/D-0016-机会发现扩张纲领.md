## 实拍病灶（SG 2026-10-25）

| 进水口 | 应是 | 实况 |
|---|---|---|
| 能力账 `fin_capability_surface` | 系统「看得见」的全部可动面 | **3 行**（okx dcd/dcd-test/mt5 catalog），手工迁移播种 |
| 模板书 `fin_opp_template` | 可枚举的赚钱结构全集 | **3 种**（funding-hedge/dcd_put/dcd_call），手写 |
| 行情宇宙 `okx.symbols` | 全市场 | **4 个符号**；`mt5.symbols=[]` |
| 面差→假想卡链（T-0106） | 原创段 | 结构在、输入空：gap 1 行 rejected、假想卡 **0** |
| 能力账 prose 层 `skills/` | — | 12 件 venue 能力账**全在人话里**，机器读不到 |

总纲设计「全模板枚举×能力账匹配」没有错，错在**两个乘数都是个位数**。
假想官再勤快，也只能在 3 个面上重组。

## 裁定：三口同开，缺一不走

### Ⅰ 能力账致密化（机器能看见的面 3→30+）
`skills/okx-*`/`mt5-*`/cmc 的 prose 能力账逐面落机读行——OKX：spot/margin/
swap/futures(季度)/options/dcd/earn-flex/earn-fixed/staking/lending(借贷利率)/
convert/spread-trading；MT5：CFD 符号×swap long/short；CMC：CFD；TRX：
energy/vote。每行带 rw_class/enabled/evidence 指针回 skill。**规则**：skill
新增一面=同票落一行（机检：skill 面数 vs 表行数对账）。

### Ⅱ 模板文法化（手写 3 种→原语组合生成）
模板不再手写，由**原语文法**生成：
```
腿原语 = {spot±, perp±, future±, option 卖 call/put, lend, borrow, stake, cfd±(swap)}
结算原语 = {funding 8h, swap 日结, 到期基差收敛, 利息累计, 权利金}
组合律 = 1 腿(carry/lend/stake) | 2 腿 delta 中性(跨品种/跨到期/跨 venue)
```
文法×能力账 enabled 面 → 全部合法结构自动入模板书（state=`candidate`），
每族配通用评估器（carry=Σ收入率−Σ成本；basis=价差/剩余期；vol-sell=权利金
年化+行权距闸）。缺 executor 的结构照样评估、照样出假想卡（需求清单自动
=缺哪个 executor）——**评估先于执行能力**，这样系统知道自己「看见了但做不了」
并能立条件请求。立刻可得而现在看不见的：季度期货基差、perp-future 基差、
借贷利差、Earn 定/活利差、MT5 正 swap 对冲、真期权 covered call。

### Ⅲ 外部进水口（真正「走出去」）
纯枚举走不出能力账的边界——新经济学来自外部信息。编制**研究员席**
（同 `告警分诊` 架构：短会话、只读、零钱径、零模板写权）：定期读
①venue 产品变更/新上线面 ②文法空格（能力账有面但零模板族）③经济经验库
与外部资料 → 产出 `fin_opp_hypothesis` 假想卡（结构化：腿原语/结算/
需求清单/证据链接）。决策席审卡=唯一晋升径。**产出度量**：周新卡数、
采纳率、采纳卡→live 的转化——写进研究员名册卡的合格判据，0 产出=臂静默告警
（T-0117 同机制）。

### 行情宇宙同步放开
`okx.symbols` 4→全 SWAP（funding 全市场 top-N 排序进评估）+季度期货+期权链
摘要；`mt5.symbols` 从 catalog 面实读。采集带宽受 `net.budget_kbps` 闸。

## 边界
- 三口都只扩**发现与评估**，不扩执行权：live 仍走 paper→probe→live+决策审
- 新 executor 一律任务单实现，禁假想卡自动变执行
- 风险硬线不动

## 证伪锚
90 天内若模板书 candidate 族 <10 或假想卡月产 <4 或零 adopted→本纲领执行失败，
重审机制而非加人力。到期自检：2027-01-25。
