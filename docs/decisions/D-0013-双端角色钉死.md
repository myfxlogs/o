# D-0013 双端角色钉死——本机=只读镜像，mutating 面装配层关断

## 背景

2026-10-25 仓 23 断腿实爆：本机 o-core 的 `sweepResidual` 将 SG 活仓 #23 的
ETH spot 腿归集至 Earn——本机库无仓位行→FundCcy 盲→把活仓腿当残币搬。
perp 裸空 + SG 对账虚差 $23 连刷。同实例此前已实证自写 earn_deposit×4 真钱移动。
本机与 SG **同库分离、同 venue 账户**——本机库永不可能完整映 SG 仓位实况，
其一切「以本节点库为判据源」的 mutating 判定均不可信。

## 选项与取舍

| 候选 | 取因 / 弃因 |
|---|---|
| **本机=只读镜像**（研究/对账/观测面留；mutating 面——sweep/residual_park/earn 摆渡/执行腿/dcd——装配层关断） | 盲库判据源不可修——修库同步=分布式一致性问题，远超收益；只读保留 dashboard/研究价值，风险归零 |
| 双活对等（两库各自记账同跑） | 弃——实爆已证：分账库互盲，扫币/晋升双跑=断腿级+双开仓级风险 |
| active-passive 备援（SG 死本机顶） | 弃——备援需库同步/故障切换基建，现无；且顶班瞬间仍是盲库起量 |
| 本机退役 | 暂不弃——观测/研究面仍有价值，停跑仅是过渡态 |

## 裁决

1. **本机角色=只读镜像**：market data/研究/对账观测面可跑；**一切 venue 写径
   （AssetTransfer/SavingsPurchase|SavingsRedeem/PlaceOrder/CancelOrder/convert-dust）
   在装配层关断**——非配 flag 提示各 worker「自律」，而是凭据装配/客户端构造
   层注只读件，写调用直接不可达。
2. **关断实现归 T-0104**（已批）：装配层开关+mutating 面清单成表+本机复跑验收。
3. **过渡态**：本机 o-core 保持 `docker stop` 停跑，至关断件部署验收后方复跑。
4. **凭据拆分不另立**：只读化靠装配层注件达成，OKX API key 不换（换 key
   牵连 SG 同 key，成本不对称）。
5. legrestore 运维件随 T-0104 worktree 径入库。

## 复启判据

本机复跑条件=T-0104 验收锚全过：只读件生效证明（写径调用=结构不可达而非
业务拒）+ mutating 面清单逐面定性 + 复跑后对账静默。
