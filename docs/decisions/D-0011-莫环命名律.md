# D-0011 莫环命名律

> 业主令 2026-10-25：系统闭环正式称谓=莫比乌斯环衍生态，五字嫌长。

## 钦定三件

| 件 | 名 | 源 |
|---|---|---|
| 系统闭环正式称谓 | **莫环** | 莫比乌斯环缩称——单面双性（钱程单面、路径无限） |
| 项目名 `o` 叙事锚 | **环的象形** | 字母 o=环的极简正投影——名与环同源一体 |
| 元素命名族源 | **莫比乌斯词族** | 新员工/新组件命名从 Möbius 词族取（möb/mob/莫/缪系），不再随机起词 |

## 四层表示（业主令 2026-10-25 追改：文档可用全名+∞ 符号）

| 层 | 形 | 用域 |
|---|---|---|
| 符号 | **∞** | 图/徽章/零注释面——全球通读（莫比乌斯环平面形=lemniscate） |
| 缩写 | **möb**（ASCII 环境 `mob`） | 代码标识/元素前缀/短引 |
| 全名 | **Möbius** | 文档首次定义处 |
| 中文 | **莫环** | 中文文档/告警/票题正式称谓 |

## 禁线

- 「闭环」口语可用但正式称谓莫环/∞（图标注/票题/决策档）
- `mob` 作元素前缀时防英文「暴民」歧义——标识符域内用，面客文案不用
