# D-0038 资金政策固化——大额躺活期最安全且合理

| 字段 | 值 |
|---|---|
| 状态 | **生效** |
| 决策 | 业主令 2026-10-29（负责人转立项固化） |
| 关联 | D-0037 盈利最小闭环（KPI=月净利的执行约束面） |
| 反证锚 | 月净利转正且稳定两季→可复审阶梯节奏；任一月触发风控硬线→敞口回 10% 底 |

## 判词

大额本金停活期/Earn=最安全且合理的默认态。部署敞口扩缩**只认实证
净利**，任何「设计面预估收益」不构成扩口理由。

## 钦定五条

1. **默认停泊**：本金默认停活期/Earn（earn_in/out 轨为停泊正道）。
2. **敞口硬上限**：部署敞口=本金 **10%**（2026-10-29 实计 7.4% 合规），
   **KPI 转正前不得上浮**——任何形式（新族/加量/加腿）不得越限。
3. **阶梯放量**：KPI 转正后每 +10 USDT 月实证净利→上限 +10%——
   逐阶由负责人核（实证数先出，放量令后落）。
4. **禁线**：任何席位禁以「设计面预估收益」为由扩敞口——只认
   fin_cashflow 口径实证净利（interest+funding_settle+已平仓盈亏）。
5. **承诺盘与余款入场**（业主令 2026-10-29 补充）：承诺本金总额
   **10,000 USDT**，已入 **7,251**（72.5%），余 **2,749** 在真实盈利
   证实前不入——月净利转正前余款零入场；转正后随敞口上限需要按③
   阶梯逐步入场，不入即停活期。

## 落点

- 驾驶舱钱面（T-0239 块② / T-0241 标尺）：敞口水位 vs 10% 上限标尺行
  （合规绿/顶格黄/越限红——越限即红牌显形）+**承诺总额 10,000 与
  已入额两行口径**（余款=承诺−已入自算）。
- 放量类票面（T-0238 及后续）：放量判据段统一挂本裁阶梯。
