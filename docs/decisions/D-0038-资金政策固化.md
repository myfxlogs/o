# D-0038 资金政策固化——大额躺活期最安全且合理

| 字段 | 值 |
|---|---|
| 状态 | **生效** |
| 决策 | 业主令 2026-10-29（负责人转立项固化） |
| 关联 | D-0037 盈利最小闭环（KPI=月净利的执行约束面） |
| 反证锚 | 月净利转正且稳定两季→可复审阶梯节奏；任一月触发风控硬线→敞口回 10% 底 |

## 判词

大额本金停活期/Earn=最安全且合理的默认态。部署敞口扩缩**只认实证
净利**，任何「设计面预估收益」不构成扩口理由。

## 钦定五条

1. **默认停泊**：本金默认停活期/Earn（earn_in/out 轨为停泊正道）。
2. **敞口硬上限**：部署敞口=本金 **10%**（2026-10-29 实计 7.4% 合规），
   **KPI 转正前不得上浮**——任何形式（新族/加量/加腿）不得越限。
3. **阶梯放量**：KPI 转正后每 +10 USDT 月实证净利→上限 +10%——
   逐阶由负责人核（实证数先出，放量令后落）。
4. **禁线**：任何席位禁以「设计面预估收益」为由扩敞口——只认
   fin_cashflow 口径实证净利（interest+funding_settle+已平仓盈亏）。
5. **承诺盘与余款入场·跨平台口径**（业主令 2026-10-29 补充+升维）：
   本金按**平台分列**——crypto(okx)/MT5(EXR 3001157)/未来平台；
   承诺总额/已入/停泊/敞口四行各按平台列示，跨平台合计为总盘。
   - 2026-10-29 现读：crypto Earn 停泊 4,133.23+DCD 1,682.48≈5,815.71；
     MT5 equity 3,247.59 USD；NAV 合计 9,063.30。
   - deposit 口径已入 7,251 系 crypto 单边流水——**MT5 资金未入
     deposit 流**（口径缺口实证）。
   - 承诺总额 10,000 USDT 的口径归属（含否 MT5 面）=负责人问业主
     候答；未答前架构先按两平台分列搭好。
   - 余款入场：月净利（跨平台合计）转正前零入场；转正后随敞口
     上限需要按③阶梯逐步入场，不入即停活期/Earn。

## 落点

- 驾驶舱钱面（T-0239 块② / T-0241 标尺）：敞口水位 vs 10% 上限标尺行
  （合规绿/顶格黄/越限红——越限即红牌显形）+**承诺/已入/停泊/敞口
  四行按平台分列**（crypto|MT5|未来——余款=承诺−已入合计自算）。
- 放量类票面（T-0238 及后续）：放量判据段统一挂本裁阶梯。
