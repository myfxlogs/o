# D-0019 容量架构裁决——带宽分级订阅 + 数据面封顶纪律

| 字段 | 值 |
|---|---|
| 状态 | 生效 |
| 日期 | 2026-10-25 |
| 出处 | 业主令：磁盘/带宽未纳入扩张设计=阻塞级，「哪怕重选架构」 |

## 背景实证（SG 实拍）

- **链路**：5Mbps 总带宽，idle 基线 RX≈19kbps
- **病灶 A**：`okx.symbols=["*"]`（507 标的）×全频道订阅→链路易饱和，
  WS 每 ~75s 被 OKX `close 1006` 斩连——重连即全量快照推送，风暴自喂
- **病灶 B**：netmeter 挂 nil（T-0130）——带宽计量面死开关，超占零感知
- **磁盘**：16G 余/58G 盘；md_*/fin_opp_eval 已封顶，fin_proposal 已闸——
  但证明「新追加写径」仍可从非表面径（触发器/事件环）灌入

## 裁定

**采 A 案：单节点分级订阅——宇宙可见性保留，实时精分级**：

- **全宇宙低频面**（507 标的）：funding-rate + mark-price + index-tickers
  ——评估所需三个事实层（费率/标记价/指数价）全留，发现面零损
- **活跃集全频道**（持仓+armed 提案+近期 proposed，量级~几十标的）：
  加订 tickers——临近执行/在管仓才要成交价级实时性
- **tickers 退出全宇宙订阅**——评估不读 last tick（APR 用 mark/index
  即可），执行面只关心活跃标的；现货断流病灶（T-0129）随分级一并根修

**连带裁定**：

- **带宽预算闸必修**（T-0130）：netmeter 挂空序位修复+实测报表落票；
  占用>70% 预算=告警档，>90%=临界档触发订阅降档
- **写径机检扩域**：新增「事件/触发器驱动的高频写径」入 review 清单——
  追加型写径禁绝范围从表级扩到通知级（fin_proposal 洪泛教训）
- **外置线**：若未来评估集或实时精度需求>带宽预算 70% 稳态，
  再裁采集外置（大带宽节点采集→SG 收蒸馏态）——当前不建

## 否决项

- 收缩宇宙保带宽——违背 D-0016 发现面方向，带宽是传输问题非范围问题
- 立即采集外置——运维复杂度与信任边界代价超当前收益，留作扩容后路

## 验证锚

- T-0132 部署后：close 1006 风暴消失（连接稳态>10min）+带宽实测报表
- 评估链不破：funding/mark/index 面照常驱动 eval+提案
- md_ticks 活跃集标的秒级鲜、非活跃集仅评估面频道
