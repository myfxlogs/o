# D-0008 全面禁用快照——决策面读现况不读缓存（业主令 2026-10-24）

## 业主令
「本项目全面禁用快照，NOX 就是死在快照上」

## 业主令扩展（2026-10-24 二令）
「工程面在方法上就禁用快照——彻底禁用 快照/定时任务/轮询 这种垃圾低效方法」

## 裁定（边界钉死——禁的是「快照当现况」非「事实落库」）

### 三件套病灶定义（方法面全禁）
- **快照**：venue 动态事实采集时点记一笔、决策时点当现况读——必陈必错
- **定时任务**：周期触发业务动作（每 N 秒重算/重推/重查）——刷屏病灶实证（T-0032 前的 8640 条/天）
- **轮询**：周期 REST 拉取替代流订阅——低频还占线，REST 界桩账（okx-rest-boundary 卡）已钦定退役面

### 正解谱系（按场景钦定）
- 现况事实→**决策时点现读**（REST 事务面/会话面实拉）
- 连续事实→**流订阅**（私有 WS/market WS/MT5 On* 族事件推）
- 期界动作→**期界等待**（睡到已知边界，非周期拉——T-0032 报表钦定模式）
- 退避/重试→**事件驱动退避**（指数梯，非周期）
- 心跳/存活→连接维持语义豁免（属基础设施非业务方法）

### 禁（决策径读快照=违令）

**病灶定义**：venue 拥有的动态事实（equity/保证金/可开性/posMode/乐器规格/价格/Earn 现率）被**采集时点记下一笔**，决策时点**当现况读**——快照必然陈，陈则错。NOX posID=468（facts=Full/broker=CloseOnly 单腿裸露）即死法。

### 禁（决策径读快照=违令）
- 风控闸/双腿构/可开性预检/动态底评估——**决策时点必须现读 venue**（REST/会话面实拉），禁读 `fin_venue_account_snapshot`/`md_venue_fact`/任何台账行当现况
- 台账类表（snapshot/fact）存在价值=观测/对账/报表留痕——**可读不可信**，决策径禁引用
- 「下单时点现读」已是既有律（T-0039 TradeMode 同款）——本令全域化

### 不禁（历史事实照常落库）
- 不可变事实行：fin_cashflow/fin_order_leg/fin_execution/fin_paper_fill/成交与结算流水——历史不是快照
- 事件流原始行：md_ticks/md_funding 的*按时间排列的历史行*（行情历史=数据非缓存；最新价消费仍须鲜度闸或现读）
- 台账表继续写（对账/报表/盯市需要）——但定位降为「证据留痕」非「事实源」

### 机检机械化（check_no_forbidden_patterns.sh，pre-commit 挂接）
- **A 面**：决策域（risk/execution/openfirst）新增行引用快照表名即拒，`// snapshot-audit-ok` 豁免
- **B 面**：全域新增 `time.NewTicker|Tick|After|Sleep` 即拒——周期调度原语=轮询/定时病灶载体；期界等待/退避/心跳确需者 `// sched-exempt-ok <理由>` 豁免留痕

### 连带裁正
- T-0041 改向：md_venue_fact 定位=实勘证据留痕+慢项参考面；**决策径（risk/sizing/预检）在单内必改现读**——本票范围扩为「现读层装配」
- risk gate 敞口校验读的 `fin_venue_account_snapshot` equity→改 venue 现读（okx balances/mt5 AccountSummary）
- T-0034 不违：期初=刻意记「那时那刻的数」成账——历史记账非快照误用

## 反证条件
若某 venue 无现读径（API 缺面）导致决策只能读台账——该 venue 不得开仓（fail-closed），先补现读件非降级读快照。

## 失效自检
出现「决策代码 SELECT snapshot/fact 表当现况」=本令被违——机检可加 lint（决策域文件禁 import 快照表读径）。
