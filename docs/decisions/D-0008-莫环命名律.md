# D-0008 莫环命名律

> 业主令 2026-10-25：系统闭环正式称谓=莫比乌斯环衍生态，五字嫌长。

## 钦定三件

| 件 | 名 | 源 |
|---|---|---|
| 系统闭环正式称谓 | **莫环** | 莫比乌斯环缩称——单面双性（钱程单面、路径无限） |
| 项目名 `o` 叙事锚 | **环的象形** | 字母 o=环的极简正投影——名与环同源一体 |
| 元素命名族源 | **莫比乌斯词族** | 新员工/新组件命名从 Möbius 词族取（möb/mob/莫/缪系），不再随机起词 |

## 禁线

- 文档/告警/面客出现「莫比乌斯环」全称仅限首次定义处；此后一律「莫环」
- 「闭环」口语可用但正式称谓莫环（图标注/票题/决策档）
