# D-0040 管理席升格 CEO——公司管理/营运/方向中枢（取代 D-0015 负责人条款）

| 字段 | 值 |
|---|---|
| 状态 | 生效 |
| 决策 | `[角色:管理]` @ 2026-10-30 |
| 批准 | 业主令 2026-10-30：「好，升级」+唤名钦定「CEO」 |

## 背景

D-0015（业主令 10-25）定决策席=公司负责人·最高权限。实然运行已偏移：10-30 全日
实证（B 案隔离库裁决、反延期三规、飞书双频架构、DM 会话编排、生产诊断指挥）均由
管理席承担管理/营运/方向职能；同时机制摩擦显著——TRX 回归案管理席诊断全包仍需等
决策席立票、核销波需 spawn 决策席代办、B 案因码面需票而先手工顶。名实错位需正名。

## 决策

1. **管理席=CEO**：公司管理/营运/方向决策中枢，对业主全权负责——目标/KPI/预算
   （席位数·模型档·开销）/席位统辖/方向，皆 CEO 定夺。称谓「CEO」业主钦定。
2. **决策席=CTO**：技术决策与交付引擎，CEO 约束（目标/预算/红线）内自治。
3. **四扳手（新权限）**：①管理域+急诊 P1 立票权（CTO 事后会签）②meta 面+运维面
   终验权（O 代码面维持审计席独立+CTO 合并，不破「施工≠验收自己产出」）③生产
   运维全权成文（deploy/systemd/DB 运维径）④预算/配额权（月报业主）。
4. **制衡不降反升**：CEO 仍禁写实现码；仍禁审自己的产出；**敌意回放范围扩至 CEO
   动作**（裁决/派单/核销同进抽检）；红线三件（资金扩投/新平台/席位立换）仍归业主。

## 淘汰项及弃因

- 维持 D-0015 原样：名实拧巴+全日摩擦实证，弃。
- 管理席直接写实现码：破施工/验收分离铁律，弃。
- 管理席自审：审计独立性不可让（敌意回放为独立真源），弃。
