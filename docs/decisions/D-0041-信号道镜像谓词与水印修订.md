# D-0041 信号道镜像谓词与水印修订——md_signal 全表全 kind 镜像、撤 ts 水印

| 字段 | 值 |
|---|---|
| 状态 | 生效 |
| 决策 | `[角色:决策]` @ 2026-10-30 |
| 批准 | 决策自裁（急诊断供根修——管理席急诊令域内） |

## 背景

2026-10-30 急诊实证：SG `md_signal` 六 kind 三死——carry_diff/funding_view
被 ts 水印跳读（T-0164 血统回戳行落地时 ts 已在 wm 后，永久静默丢失），
mt5_swap/basis_ann 被 D-0030 §三 serve 谓词**设计性排除**（不在
signalGlobalKinds/signalActiveKinds 任一侧）而 SG 侧实需
（`lifecycle/xvenuepair.go` swap_snapshot、`ops_face` 蒸馏行、半速窗判读）。

## 选项与取舍

| 候选 | 取因 / 弃因 |
|---|---|
| **信号道撤 ts 水印、serve=全 kind 全表镜像**（T-0272 钦定） | md_signal=(kind,key) 键 latest-value 小表（~550 行），uSignal upsert `WHERE EXCLUDED.ts>ts` 幂等防回退——全扫=零丢行结构保证、自愈免重启；谓词体量收益对 550 行不存在 |
| arrival 列水印（wts/recv_ts 径） | 弃为本次急诊径（schema 迁移+writer 配合链长）——信号表若未来上量再议 |
| 保留 kind 谓词仅扩 mt5_swap/basis_ann | 弃——补丁式扩列挡不住下个新 kind 同类失明；全量镜像一次根除该类 |

## 结论

1. D-0030 §三信号谓词条目（`md_signal | kind∈{carry_diff,xvenue_spread,funding_view(活跃集),depth5(活跃集)} | ~30`）
   **作废**——md_signal 镜像面=全 kind 全量（serve 与 dualwrite 同径）。
2. 信号道撤 ts 水印：每拍全表谓词扫+upsert 幂等——「stamped ts≈commit 序」
   假设对血统回戳/迟提交行不成立（KB：ts-watermark-vs-stamped-ts-order）。
3. 其余 ts 桥道（ticks/markidx/funding/dcd）水印与谓词不动——其戳序成立
   或已在 recv_ts 径（T-0169 已先修同类）。
