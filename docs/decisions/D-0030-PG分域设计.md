## 二、钱径面对 md 域的真实读依赖（码面 grep 实拍）

| 钱径件 | 读的 md 表 | 读形 |
|---|---|---|
| execution/sizing.go | md_ticks / md_mark_index | 开仓定量取**活跃集**现价 |
| ledger/run.go | md_ticks / md_mark_index / md_macro_event / md_account_events | 账本 MTM 估值 |
| lifecycle | md_funding / md_signal / md_dcd_product / fin_opp_eval / fin_proposal | paper 记账+提案准入 |
| cmd/core（卡/mtm/venues） | md_ticks / md_mark_index / md_account_events | 展示面估值 |
| risk / guard | **零 md 读**（只读 fin_position/execution/strategy/token） | — |

**结论**：钱径面需要的 md 子集=**活跃集价格（512+持仓 inst 的 mark）+
信号精选键+DCD 最新行+funding 最新行**——全是「最新值」形（有界状态表），
零历史依赖。全宇宙 1,997 inst 的 mark 覆写流对 SG 是纯负担。

## 四、同步机制裁决：**b. 应用层推送**（否 a/c）

- **a. 逻辑复制**：PG publication 无法表达「活跃集」动态谓词（WHERE 只支持
  静态行过滤且不可跨表 join）；全表复制等于没分域。否。
- **c. SG 拉取**：隧道依赖不解（拉取方在 SG 侧跨隧道读）；lifecycle 扫拍
  本已 20min，再加远程读=雪上加霜。否。
- **b. 推送（钦定）**：开发机起 **`cmd/projector` 投影臂**——LISTEN PG-md
  本地 ev_* 帧（零轮询，D-0008 律）→按活跃集谓词查最新行→写 SG 镜像表
  （`INSERT…ON CONFLICT DO UPDATE WHERE ts>EXCLUDED.ts` 有界表语义同
  D-0018）。活跃集谓词本身**由 SG 发布**：fin_position/fin_strategy 变更→
  projector 经隧道读一次活跃集（分钟级小表，可接受）或 SG 侧写
  `md_active_set` 小表供 projector 订阅。
- fin_proposal 为**双向桥表**：研究臂写（PG-md）→投影到 SG；SG lifecycle
  改 state（armed/retired）→**回写 PG-md**（研究臂 `open>0` 去重谓词要看
  真态）。回写走 projector 反向订阅 SG ev_strategy（低频）。**这是唯一
  双向面，设计验证重点。**

## 五、争议项裁决

- **fin_paper_fill**：lifecycle（SG）写、promote（SG）读——归 **fin**（非 md）。
  dcdPaperAccounting 读 md_dcd_product 镜像行（活策略 product_id 已投影）。
- **fin_forward_check**：评估前瞻校验，写者 research 域→归 md；若 report
  （SG）读→report 随 T-0165 迁研究席（纯读报表无钱径写）。
- **md_account_events**：名 md 实 fin（账户 WS 事件）——归 fin，**改名
  `fin_account_event` 列入 Ⅲ 级残名清**。
- **fin_employee_registry**：两机臂皆 beat——归 fin，研究臂经隧道 beat
  （30s/行·极低频）；或 projector 代 beat 聚合。择简：直 beat。

## 六、迁移链分流

- `migrations/` 加前缀分链：`md_NNNN_*.sql` / `fin_NNNN_*.sql`；桥表镜像
  DDL 归 fin 链（SG 建表）但 schema 由 md 链定义文件 **同源 include**
  （避免双写 DDL 漂移）。
- `check_migrations.sh` 扩：①两链序号各自单调 ②桥表 DDL 同源断言
  ③研究域表禁出现于 fin 链（反之亦然）。
- `pgstore.Migrate` 接 `-domain=md|fin` 选链。

## 七、新鲜度与失效契约

- SG 镜像表消费**只认 ts**（D-0022「信号陈=不存在」律直接复用）：
  sizing/ledger 读 md_ticks 镜像行 ts 超阈（现 guard 已有 tick 新鲜度闸
  T-0128）→拒开仓/估值标陈，**不回退用隧道现读冒充**。
- projector 死=镜像全陈=SG 钱径面 fail-closed 收敛（禁开新仓/MTM 标陈/
  告警 projector_silent），已有持仓的平仓径走 **MT5 本地 tick+OKX 私有 WS**
  （T-0141 裁：钱径报价留 SG 本地——此律在分域下成为**生存线**）。
- T-0164 血统闸（派生信号 ts=max 上游 ts）在 PG-md 侧生效，投影自带血统。

## 八、运维面

- 备份：PG-fin 账链永久（现制）；PG-md 可重建面（行情/评估均可再采再算）
  ——**备份降级为 schema+配置**，数据丢失可接受（D-0018 状态表语义）。
- 保留账 fin_data_retention 分库各一份；清道夫双实例。
- pgguard xmin/notify 哨兵双实例（PG-md 侧洪泛风险更高——评估 upsert 在此）。
- 开发机 PG-md 容器化 compose（`docker-compose.dev.yml`），数据卷与施工树
  目录隔离；**施工树 `/opt/o-wt/*` 与生产件 `/opt/o-collecto`、PG-md 卷、
  `cmd/research`/`cmd/projector` 单元分 systemd slice**（`o-prod.slice`
  CPUWeight 高 / 施工默认 slice）——业主令「目录隔离」落为 slice+目录双隔离。
