# D-0012 能力面差扫制度

**日期**：2026-10-25｜**席位**：决策｜**触发**：业主质询——探员知识面前
于会话层知识，新机会类结构性不可见。

## 判词
运行系统零知识，认知在会话层，两层间无机制通道。注册表
（T-0102 v2 `fin_capability_surface`）解决「记了就能枚举」，
不解决「谁会去记」。本决补第二层。

## 定则
1. **能力面差扫=在编运行岗，非会话职责**（业主令 10-25 修——
   会话职责=我离线线死，单点在我）。差扫 daemon 周期执行
   「venue 实供面 vs 注册表已记面」：实供面源=venue 自身可枚举
   目录（OKX /finance/* 产品族、/public instruments、MT5 Symbols
   族）；差集=`fin_surface_gap` 行落库排队——检测层永不离线。
2. **判断层仍归会话**：gap 行=候选新面待裁；会话上线读队列即
   见全部积压（离线期间差照积不蒸发）→ 裁定注册/立票/否决。
3. **记录法**：新面→fin_capability_surface 行（T-0102 落地后）；
   探员消费面=只读注册表，禁私读 skill 文档（文档非机器源）。
4. **证伪锚**：venue 新产品族上线后 fin_surface_gap 无对应行=
   差扫岗失职（可机读告警）；纸面面靠「last_seen 实证时戳」防。

## 与硬线关系
差扫只产**候选面登记**——任何写径/钱径仍走 ticket+风控闸，
扩张速度不触 D-030/D-184 硬线。
