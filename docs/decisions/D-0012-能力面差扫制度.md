# D-0012 能力面差扫制度

**日期**：2026-10-25｜**席位**：决策｜**触发**：业主质询——探员知识面前
于会话层知识，新机会类结构性不可见。

## 判词
运行系统零知识，认知在会话层，两层间无机制通道。注册表
（T-0102 v2 `fin_capability_surface`）解决「记了就能枚举」，
不解决「谁会去记」。本决补第二层。

## 定则
1. **能力面差扫=决策席周期职责**：每轮决策会话收口前，执行
   「venue 实供面 vs 注册表已记面」差扫——实供面源=venue 自身
   可枚举目录（OKX /finance/* 产品族、/public instruments、MT5
   Symbols 族）+ skill 档面清单；差集=候选新面，立条入册或立票。
2. **记录法**：新面→fin_capability_surface 行（T-0102 落地后）
   或 docs/能力账/ 条目先行；探员消费面=只读注册表，禁私读
   skill 文档（文档非机器源）。
3. **证伪锚**：若下一新 venue 产品上线后系统仍零感知（无注册行、
   无差扫票、无告警），本决记失职；若差扫产出假面（venue 实际
   无该产品），注册表行须带「last_seen 实证时戳」防纸面面。

## 与硬线关系
差扫只产**候选面登记**——任何写径/钱径仍走 ticket+风控闸，
扩张速度不触 D-030/D-184 硬线。
