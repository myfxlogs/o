# D-0006 闲资承接与动态底线（业主令 2026-10-23）

| 字段 | 值 |
|---|---|
| 状态 | 生效 |
| 上位 | D-286（nox 金钱不眠）PHASE 继承实现版 |

## 裁决

OKX 面 USDT 闲资**默认停泊于 Earn（活期）**——闲置不是中性态，是部署缺口。

1. **动态比较底**：开仓机会的净 APR 必须 `> max(静态底 research.funding.min_net_apr, Earn 现率)`。机会收益<停泊收益=拒开（拿更高收益担额外风险毫无道理）。
2. **开仓前置赎回**：过闸执行前，先把所需名义额+缓冲自 Earn 赎回至交易户（Earn 灵活 T+0）。
3. **平仓自动回拢**：平仓+结算完成后，交易户闲余 USDT 回存 Earn——钱回到停泊态等待下一个机会。
4. 承接动作留痕走 fin_cashflow（kind 扩 earn_in/earn_out）；Earn 现率采集入事实行（评估底的数据源，非配置常量）。

## 含义

- 评估卡五拆之外再加**机会成本比较器**——「能赚钱」升级为「比停泊赚得多」。
- Earn 利率是事实行不是配置键——数据域采、研究面消费；缺失时降级=退回静态底+告警计数（不阻断，记录可查）。
- 资金移动（赎回/回存）非开仓动作，闸内 kind=transfer 留痕不走敞口判。
- **持仓期同样适用「那边高走那边」**（业主令延伸 2026-10-23）：看护拍内比较在仓剩余预期收益 vs Earn 现率——须计入**切换成本**（平仓双腿费+滑点+回存摩擦）；Earn 反超且余量覆盖成本→提前退为合法退出理由（guard 判据集扩展，后续票落）。裸比较不扣切换成本=假信号源。
