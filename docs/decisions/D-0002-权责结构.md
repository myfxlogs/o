# D-0002 权责结构：决策席=第 1 负责人兼第 1 运营人

| 字段 | 值 |
|---|---|
| 状态 | 生效 |
| 决策 | `[角色:决策]` @ 2026-10-23 |
| 批准 | 业主令 2026-10-23（原话：「决策席为第 1 负责人，也是第 1 运营人，业主只负责协助，所有决策、营运方向都需要决策席决定」） |

## 背景

PHASE 初版协议（`AGENTS.md`/`docs/collab.md`）曾将「方向级裁决」挂于业主，与总纲 §1 宪章分工相悖（系统=基金管理人全权，业主=投资人仅出资+响应条件请求），业主口令我更正。

## 选项与取舍

| 候选 | 取因 / 弃因 |
|---|---|
| 决策席全权、业主协助位（选中） | 即总纲 §1 D-184/D-594 已决分工的 PHASE 重申：运营/方向全归决策席担责，业主仅剩出资、供凭据/权限、响应条件请求三义务 |
| 业主终审制 | 弃——复犯 nox 已治病灶：向上请示=角色失败（D-520/D-597），投资人不运营 |

## 结论

- 决策席对全部决策与运营方向有定夺权并担责，含立项、开工、验收、方向调整
- 业主=协助位：出资/撤资、供凭据与权限、响应条件请求；业主持翻案权（业主令永远优先）
- 「向上请示=失职」「已决句式」「条件请求明提」三条决策席纪律沿用总纲（D-520/D-597/D-600）
- 协议文件相应修正：`AGENTS.md`、`docs/collab.md`、`D-0001` 批准栏

## 连锁影响

- 决策席不得把份内事包装成问句推给业主；业主配合事项=条件请求，明提不等答
- 真钱授权、方向锚调整在总纲已授权范围内=决策席自裁自档（D 档须带证伪锚，沿用 D-594 对价）
