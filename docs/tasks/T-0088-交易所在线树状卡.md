## 形态（树状+logo）

```
交 易 所 在 线
◆ OKX            ── venue 行（logo+名）
   ├─ 公开 WS   ●  3s 前
   ├─ 私有 WS   ●  5s 前
   └─ REST      ●  正常
◇ MT5            ── venue 行
   └─ 行情流    ●  迟滞 4m
```

- logo=内联 SVG 矢量标（OKX=三方块标、MT5=MetaTrader 字标）——不引外部图床/URL。
- 灯=静态三色圆点（与员工图同一视觉语言），旁注末拍龄（Ns/Nm/h 自适应）。
- 树线用 CSS 边框画（├─└─ 或 border-left），不引库。
- 零动画零辉光（业主令：灯是信息不是装饰）。
