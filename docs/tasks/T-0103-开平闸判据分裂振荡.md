# 病灶（生产实证 2026-10-25）

`fin_strategy #1662`（BTC funding hedge）晋 live 后进入振荡循环：

```
每分钟：armed 提案过开闸 → 开 $50 BTC 现货买+永续卖
  ~1.2s 后：delta_drift 触发平闸 → 全平
  判决 falsified（归因 funding_flip）→ 同键 armed 再开
```

实测 7+ 轮，每轮净 −$0.085（双边手续费），累计烧 ~$0.6。**开闸判据与平闸判据看的是不同的费率快照**——开时按当期资金费率放行，平闸按预测下一期翻负判定，两闸对同一仓位给出相反结论→每分钟振荡。

## 定性

1. **判据分裂**：开仓条件（funding rate 当期正）与持仓条件（预测下期翻负即平）不对偶——开仓那一刻起平闸就注定触发。开仓闸必须先回答「按平闸标准，这仓能活多久」，活不过最短持仓窗就不该开。
2. **否决不回炉**：判决 falsified+归因 funding_flip 后策略原地待命，armed 提案仍活着再开——falsified 应触发回炉/退役状态位（degraded→retire 径 T-0098 已建，此键未接入）。
3. **刷费敞口**：$0.085/轮 × 每分钟——若无人工干预（本席 10-25 手动 retire+灭 armed 止血），一天烧 ~$120。

## 验收锚

- [ ] 开闸与平闸判据对偶化：开仓评估必须含「预测持仓寿命 ≥ 最短持仓窗（如 ≥ 资金费结算周期）」，寿命不足=开闸拒（落 fin_opp_eval rejected，因 `lifetime_below_min`）
- [ ] falsified 判决自动触发回炉：判决落库时联动策略状态位（armed 提案撤、策略回 degraded/retired——按归因族定），不再原地待命
- [ ] 同键振荡保险丝：同 inst_id 单位时间开平轮次 ≥N（建议 3 轮/小时）触发降级+告警，防判据再分裂时仍有兜底
- [ ] 桩测：开平判据冲突场景→开闸拒；falsified→策略回炉；振荡保险丝触发径
- [ ] 生产实证：#1662 同类键不再有每分钟开平轮
