## 背景（裁决实证，勿再诊）

T-0312 第六刀部署实证发现三尾巴：

1. **unit 首启 200/CHDIR**：`o-decision-seat.service` `WorkingDirectory=
   /var/tmp/o-decision` 先于 `ExecStartPre=/usr/bin/env mkdir -p …` 生效
   （systemd 钦定序——CHDIR 对全部 Exec* 含 Pre 件生效），首启 07:42:31
   实败（status=200/CHDIR），目录经外途创建后 07:43:01 metabus 唤醒成功。
   同形件 `o-regime-analyst.service`/`o-econ-verdict.service` 同须排查。
   修法备选：弃 WorkingDirectory 行（dm_tick.sh 内自 `cd` 已兜）或
   tmpfiles.d/enable 步建目录——施工裁。
2. **待裁集事件/票面 desync**：`ops_ticket_state` 最新事件口径混入
   `T-0301 收口待审`（票面施工中、实已裁决合并 d3611ba9）、`T-0230 收口
   待审`（票面已批）等残件——dm_tick 闸 `event IN('收口','移交','收口
   待审')` 恒热，每 30min 兜底拍空烧一 devin run。修法备选：闸 SQL 联
   ops_event 排除已有 `裁决`/`完成` 后事件者，或票面态交叉校验——施工裁。
   **判禁**：禁删 ops_event 行（append-only 流水）。
3. **T-TESTBUS 探针残留**：eventbus 验收探针 `test|收口|T-TESTBUS`
   （id 1357/1358）滞留待裁集——本次唤醒正是探针触发（属锚内实证），
   但其永不销=闸恒热一员。处置：同件②口径收束后自然销，或决策席
   ops_event 落 `完成` 行退役（白名单内）——施工裁并回填。
