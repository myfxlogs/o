## 结果回填

**实现**：`scripts/check_ticket_numbers.sh`（可执行，bash）双模式——无参=存量
查重（index 全仓票号扫对，逐对红出清单，exit 1=存在共存，供决策/CI 用）；
`--staged`=增量闸（pre-commit 调用）。计数源=git index（本 commit 落定后的
全仓票面：staged 删票不计、加票计），不取工作树 glob（会把 staged 删票误计）。
增量闸滤 `--diff-filter=ACR` 取新路径（A/C 单路径、R 取 `$NF`）——M/D 不触发，
存量票改注不溯（闸只管增量）。新立票过闸后打 NOTE 取号提示（本地最大票号+
「远端为准，push 前 fetch 核对」——票面钉的是提示不拦，网络探测不入钩）。
挂闸：`scripts/hooks/pre-commit` 新增 11c（guarded 落位式，同钩内既有习，
置于 11b 与 12 之间）。
