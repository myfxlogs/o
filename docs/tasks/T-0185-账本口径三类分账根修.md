# T-0185 账本口径三类分账根修——移动/校准不得计入盈亏（业主裁定）

## 态：可领

## 病灶（业主截获+决策席实核）

`fin_cashflow` kind 全混一锅，轧差即「净值」——实证账面：
- `earn_in +301.50 / earn_out −176.43` 净 +125.07=**自有资金内部移动**
  被计入净盈亏（钱还在我们手里）
- `recon_adjust +132.24`=对账校准件（账面掰向 venue 真实的修正项）
  同计盈亏
- 「equity=sum(cashflow)」口径把 deposit 注资也轧进去了——
  权益该对 venue 实拍余额，非流水累加

业主令口径：**移动和校准不算盈利**。D-013 单一账本律下此口径=
报表面虚报盈利直接污染源（净值 +256.55 中真实收益仅 ~+2.3 实证）。

## 施工面

1. `fin_cashflow.kind` 三类语义册落地（迁移加 `fin_cashflow_kind_class`
   册表或 criteria 列——采纳者自选但须机查）：`income`（interest/
   funding_settle/价差真赚）/`transfer`（earn_in、earn_out、deposit、
   withdraw——注资撤资与内部移动）/`adjustment`（recon_adjust 等
   校准修正）。kind→class 映射钦定单源。
2. 报表/权益口径改：`净值`=`Σincome`（纯收益）单列呈现；
   `transfer`/`adjustment` 不入盈亏行（列示但不计）。
3. 既有行回填按 kind→class 映射刷一次（一次性数据件）。
4. 经营面看板/日报（若有 sum(cashflow) 口径件）全换三类口径——
   全仓 grep `fin_cashflow` 消费点普查防漏。

## 验收锚

1. 净值报表=「真实收益」（interest+funding+价差）~+2.3 口径可复现，
   transfer/adjustment 行仍在册但不计盈亏（账本完整+分类正确）。
2. 普查件：`fin_cashflow` 全部消费点过三类口径（清单列票面）。
3. 迁移+桩绿、语义单源机查。
