## 背景

业主两连裁，指向一个事：**全站视觉语言参照 macOS（Tahoe 代 Liquid Glass）重做**——

1. **呼吸灯**：业主「呼吸不够明显」→ ⑮（873e66d）落成「缩放 1.3x+同色光晕」放大球丑态。参照语义=macOS 应用图标活感/Mac 睡眠指示灯：珠体有光感，呼吸=光晕深浅涨落非球体胀缩。
2. **字体**：对齐 Apple 系统字体栈（SF Pro 语系——`-apple-system/BlinkMacSystemFont/"SF Pro"` 优先，Inter/系统兜底），数字/表格字重排印纪律随行。
3. **瓦片（卡/tile）**：Liquid Glass 材质——**通透折射感**非现「磨砂半透明」（⑮ 面透明 72→55% 那版只是更透的雾面）：backdrop blur+saturate、镜面高光边缘（顶部/左上细亮边）、内发光、圆角与投影层次按 Apple 玻璃件语言。
4. **液态玻璃通用面**：同材质应用于面板/卡框/悬件——折射感（折射=背景内容过玻璃有形变感，web 径=blur+saturate+边缘高光仿）、随内容透色（玻璃吸底色非死灰）。

## 目标

打开面板=macOS 质感：珠形活灯、SF 系字体、Liquid Glass 瓦片（通透+高光边+轻折射），整体「苹果系统里应用程序」级完成度。

## 钦定方向（施工可在此框架内落笔）

- **呼吸灯**：珠体 `radial-gradient`/内高光脱平色盘；呼吸主驱换 `box-shadow` 光晕涨落/`filter` 辉度，`transform: scale` ≤1.1x 或弃用。**节奏语言不动**（绿缓 ~2.4s/黄快 ~1.2s/**红=死=静止**铁律+opacity≥0.78 下限+不减动效豁免注释段全保留）。
- **字体栈**：`font-family` 归一 Apple 系栈声明（body/组件一处定义勿散写）；数字列 `tabular-nums`/`SF Mono` 系沿用。
- **Liquid Glass 件**：瓦片/卡面 `backdrop-filter: blur(... ) saturate(...)`+半透明底+顶部高光边（`border-top`/`inset box-shadow` 细亮线）+柔投影分层；深浅主题双态各自成立（现有 o_theme 共键不动）。
- 零逻辑改动：纯样式/字体声明层，组件结构如需仅加类名。

## 验收标准

- [ ] 呼吸灯：s0/s1 无 `transform: scale(>1.1)` 主驱；`.dot` 系含 `radial-gradient` 或等效珠体高光；光晕涨落关键帧在册；s2 红静止断言不动（grep 四锚）。
- [ ] 字体：样式面一处 Apple 系 `font-family` 栈生效（body/根级声明 grep 锚）；无散写异质字体族残留。
- [ ] Liquid Glass：瓦片/卡面含 `backdrop-filter` blur+saturate+高光边件（grep 锚）；亮/暗主题双态截图各一（验收席目检——玻璃通透感、非灰雾）。
- [ ] 布局零晃动：动效仅 paint-only 属性（transform/box-shadow/filter/backdrop）。
- [ ] 目检锚：System+TRX 页截图——绿灯「亮珠缓息」非「圆盘缩放」，瓦片读作「玻璃件」非「灰雾块」；前端 build 绿。

### 实现摘要

- **呼吸灯活灯化**（`10-shell.css`）：三态珠体平涂改 `radial-gradient(circle at 32% 30%)` 活灯球面（左上射光高光→本体→边缘暗一档）；呼吸主驱换 `box-shadow` 辉光涨落（息=贴身微光 3px，峰=弥散 10–11px 光晕），`transform: scale` 主驱弃用（唯一余留 scale 在 `breatheAlarm` 死帧——见偏离②）。节奏语言三锚全保留：绿 `breatheCalm` 2.4s（峰仍踩 0.78 下限）/黄 `breatheQuick` 1.2s/红静止铁律三行原样。动效帧自带描环层（与 20-cards 灯可见性硬化同款 1.5px）防动画覆盖洗环；辉光色显式硬编码状态变量（`breatheCalm` 被 TrxHedgeCard WS 点内联引用，不能走继承色）。Watch 断流黄点（`breathe` 1.6s）同款光晕化。
- **Apple 字体栈**（`00-base.css` L57）：全站唯一 `font-family` 声明点改 `-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "SF Pro", Inter, system-ui, "Segoe UI", sans-serif`（SF 语系优先，Inter/系统兜底）；`tabular-nums` 数字纪律既有面（`.num/td/th/.clock/.mono`）沿用未动。组件面零散写（grep 全仓仅此一处声明）。
- **Liquid Glass 材质**（`20-cards.css`+`12-nox-shell.css`）：`.card`/`.health-strip` 共用一段材质规则——`backdrop-filter: blur(20px) saturate(180%) brightness(1.06)`（通透折射三件）+镜面高光边（顶部 1px 白 42% 亮线+左上射光 16%+内发光 5%）+双层外投影（贴地 1px+悬浮 10px 28px）分层出厚度；底透明度 55%→46%（玻璃吸底色更透，非雾面加浓）；hover 态同构增亮加深。`.pipe-card` 工序瓦片同材质（液态玻璃通用面）。暗态靠亮边定形/亮态靠投影+顶部高光定形——双态各自成立，`o_theme` 共键零触碰。`@supports` 不透明降级保留。
- **组件面零改动**：`ui.tsx` StateDot 既有类名（`dot s0/s1/s2 breathe`）已足够承载新灯语，无需挂类；`index.html` 未动（字体栈落 body CSS 单点即达）。

### 偏离说明

1. **TrxHedgeCard 内联 WS 点未动**：TRX 页对冲结构卡右上「WS 在线」点为组件面内联样式（平涂 background+直接引用 `breatheCalm`）——其呼吸已随新关键帧自动升级为光晕涨落，唯珠体仍平色非径向渐变。TrxHedgeCard.tsx 不在涉及面（组件面仅列 ui.tsx 挂类），施工不越；如需珠体统一，决策裁一行 className 挂载即可。
2. **`breatheAlarm` 键帧保留原样**（含 scale1.25）：按「节奏语言不动」框架保留红急促节奏存档；该帧被铁律永久压制（`animation: none !important`），运行时不可达，非活码。
3. **截图台架字体环境**：Linux 台架栈落点=Inter 兜底（本机 fontconfig 装 Inter 4.0）；SF Pro 本体为 macOS 专有，业主终检如需 SF 原生渲染观感须 mac 真机开面板目检。栈声明本身跨平台成立（锚=单点 grep）。
4. **stub 后端两处数据形状修**（台架侧 /tmp 文件，不入仓）：Timestamp 须 RFC3339 字符串（protojson 形）；流面 Watch 回 `application/connect+json` 信封。与码面零涉。
