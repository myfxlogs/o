## 面况

`/opt/meta/headless-supervisor.sh`（meta 仓——**施工面在 /opt/meta 非
/opt/o**，本票不碰 o 仓码面）三缺陷：

1. **静音条件 shell 优先级 bug**（行 34）：
   `[ -f .done ] || ls 票面 && grep 收口待审`——shell 语义=
   `(A||B)&&C`，`.done` 存在仍要求票面收口待审才静音；应=
   `A || (B && C)`（.done 独立短路）。T-0246/0250 被冤报实证。
2. **存活判定漏审计径**（行 45）：pgrep 模式 `headless-${tid}-prompt`
   匹配不到 `headless-audit-${tid}-prompt`——审计在飞被报死
   （T-0257 10:13 实证）。须宽匹配两式（或 cmdline 含 tid 全式）。
3. **SAID 内存态**：`declare -A SAID` 随监理器重启清空→全量重报
   （10-30 10:10 监理器重启后三连冤报实证）。改落盘标记
   （`/opt/meta/mail/.said/` 或同义持久位——重启后读回已报键）
   或首扫静默（重启首轮只布防不告警），施工定径落结果段。

## 结果回填（施工席·无头 devin-t0260 @2026-10-30）

### 实现摘要（全在 meta 仓 headless-supervisor.sh，commit 03a1f54）

- **缺陷①根修**：完工判定 `A || ls票面 && grep收口待审` 原被 shell 左结合
  解析为 `(A||B)&&C`——.done 在仍要求票面收口待审；改 `A || { B && C }`，
  .done 独立短路。
- **缺陷②根修**：存活判定 `pgrep -fc "headless-${tid}-prompt"` →
  `"headless-(audit-)?${tid}-prompt"`，run/audit 两式 prompt 皆命中
  （audit 包装产 `/tmp/headless-audit-<TID>-prompt.md`，审计在飞不再报死）。
- **缺陷③根修（取径=落盘标）**：`declare -A SAID`→`/opt/meta/mail/.said/`
  键文件（含 gen 代际键存值），重启读回已报键不重报；完工清键、新代际
  再武装语义与内存版全等价。落盘标优于首扫静默：监理器停机窗内新殁的单
  重启后仍会报（首扫静默会吞掉该真警）。
- **试锚 env**：`SUP_LOCK`/`SUP_SAIDDIR`/`SUP_TASKDIR`/`NF_BIN` 四处外注
  （生产默认全走原位）——干跑不碰真锁/真飞书/真票面。
