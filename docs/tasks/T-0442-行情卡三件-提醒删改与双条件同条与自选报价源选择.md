## 钦定三件

- **①提醒删除**：提醒行加删除/停用 affordance——钦定软删
  `state='disabled'` 留痕（fired 史行禁删禁改——已响提醒是
  审计面）；UI 上 disabled 行默认折叠不在主列表占位。
- **②一品种双条件**：同品种 `>=` 与 `<=` 两阈合一逻辑条——
  UI 一品种一卡，上限/下限两阈各可空（双空=禁建），落行层
  仍按 direction 行写（零 schema 破）或票面级等价形制；
  目标=业主视角条目减半、一卡看全双阈。
- **③自选报价源选择**：`fin_quote_watchlist` 扩 venue 约束列
  （venue/inst_type 或 venues 集——施工定形制但禁破坏现语义）；
  自选编辑面按 Nox 形制给 venue chip 集（候选源=md_ticks 实采
  venue×inst_type 派生），空=全部源；订阅晋升+报价行取价
  按所选源过滤；venue 词表走 dialect 面禁硬编码新词表。
