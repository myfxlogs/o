## 背景

索引.md 已 79K——有册无检，领单时坑账靠记忆命中，盲区同型再犯。
现状三缺口：条目 frontmatter 关键词/域标签有而未用；无关键词→条目检索径；
领单协议未挂检索步。

## 钦定界（负责人令）

① **kbgen 扩展**（`tools/kbgen/`）：条目 frontmatter 提取 keywords/scope，
   索引分册化（现单表 79K 不可读——按域或风险分册，选型回填）；
② **`scripts/kb-lookup.sh`**：关键词→命中条目路径+一句话摘要——
   grep 级实现，零新依赖；
③ **领单协议补一行**（`docs/collab.md` 或 AGENTS.md 协议段——选型回填）：
   领单时对票面关键词跑 kb-lookup，命中即读条目。

## 范围外

- 不上向量库、不建独立服务、不改条目 schema v2；
- 不动现 79K 索引既有行格式之外的结构（分册=重组呈现不删信息）。

## 验收锚

1. `kb-lookup.sh` 任取**三个历史坑**关键词全命中（回填记录所用词+命中件）；
2. kbgen 分册索引生成+`--check` 绿；
3. 领单协议行入库（含「无命中不阻塞」语义）；
4. 快径 CI 绿（docs/scripts 面——若触 go 全径照走）。
