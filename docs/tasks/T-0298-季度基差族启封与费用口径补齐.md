## 病灶

**件① 模板禁着**：三模板 enabled=f 系 10-29 清理波连坐（T-0287 禁因台账），非族单独判决；
proposed 率 36%＋paper 在册＋季货行情覆盖实证——有产无路。

**件② basis 评估器零费用项**：`run.go:205-210` `netApr = basis/days×365`，直接比
`> 0.05`——无手续费/滑点/到期滚动成本，且 **0.05 为代码字面量**（违工程纪律
「判据禁字面量」）。启封若不补费用，重蹈 funding 族磨损。

## CTO 会签注记（2026-11-03，码面亲证——件①重定性、件②口径补齐）

**件① 「enabled=f=晋升无路」——实是台账位非功能闸。** 亲证：`fin_opp_template.enabled`
在库内的可执行消费者只有 dcd 自家 runner（`dcd/run.go` join `t.enabled`）与名册显示
（`evalqueue_face.go`）；basis 提案→paper 的真闸是**码面白名单 `paperTemplates`**
（`lifecycle/run.go:113`——`quarter_basis_long`/`perp_quarter_spread` **已在册**，
paper 策略 4 行实存）；evalBasis 由 `Enumerate(enabled 能力面)` 驱动，与模板 enabled
无关——这就是为什么禁着也日产 proposed（36%）。**翻 enabled=true（同时 state→enabled）
是正确的台账归位+名册真化，不是功能解封**——提案→paper 链本就没被它拦。
`quarter_basis_short` 保禁的**结构性原因是它不在 paperTemplates**（spot_short 腿缺
margin 能力面——`run.go:116` 注），不只是「判据欠养」；保禁=enabled=f **且**不入白名单。
ops_event 留痕照旧。

**件② 费用项——口径须与 T-0297 同构，票面现式有洞**：`(taker+maker复合+slippage)/1e4`
是一向两腿型，basis 一样要**往返**。钦定改为：`cost_rt_bps` 复用
`funding.RoundTripBps`（basis=现货腿+季货腿，开两成交+平两成交，保守四腿型=32bps；
季货到期交割费低于 taker 平仓费，四腿型偏保守可接受，evidence 注
`cost_model=roundtrip_taker_x4_conservative`）；`cost_apr=cost_rt/1e4×365/days`；
`net=basis_apr−cost_apr`（同 grammar→funding 或挪共享件——**禁第二份本地算式**，
import 白名单边照 T-0297 例登记）。`perp_quarter_spread` 双腿皆衍生（无现货腿），
同式偏保守，evidence 注 `perp_only_legs`。
- **符号面**：现式 `math.Abs(netApr)>0.05` 会把深负基差也判 proposed——方向语义错。
  判据改**有符号** `net_apr ≥ floor`（quarter_basis_long=正基差收；perp_quarter_spread
  同向；quarter_basis_short 若日后启封，方向符号须在其族定义内翻转，票面留 caveat）。
- **Earn 底**：与 funding 族同一 md_earn_rate 读件——挪共享（如 `internal/platform/`）
  或 grammar 挂同读面，施工自决但**零复制**（D-0006 语义不变：floor=max(静态,Earn)，
  缺/陈=静态降级+rej 计数）。
- `research.basis.min_days_to_expiry` 判「到期 <7d 拒」放在 cost_apr 之前早退
  （days≤0 天然拒，禁被摊销式放大）。

## 钦定目标（修订后——件②③按上段执行，件①按台账归位执行）

1. **启封**：`UPDATE fin_opp_template SET enabled=true WHERE template IN
   ('quarter_basis_long','perp_quarter_spread')`，留 ops_event（出处 D-0043/T-0287）；
   `quarter_basis_short` 保禁不动。
2. **费用摊销**：basis 持仓期＝到期日（`days_to_expiry`），
   `cost_apr = (taker+maker 复合费+slippage)/1e4 × 365 / days`；`net = basis_apr − cost_apr`。
   费率键复用 `research.funding.taker_fee_bps/maker_fee_bps/slippage_bps`（同 venue 同费表，
   不另起一套）。evidence 加 `cost_apr`。
3. **阈值入 config**：新键 `research.basis.min_net_apr`（seed=0.06，与 T-0297 静态底同值）；
   Earn 动态底同 funding 族（`floor=max(静态, Earn)`）。
4. 到期 < `research.basis.min_days_to_expiry`（seed=7）＝rejected（到期前一周滚动/交割风险不进）。
