## 面

1. **MT5 行情腿**（cmd/collector 内挂，复用 internal/mt5 collector 改造
   quote-only 模式——dev 腿**禁账户面**（collector_rw 零 fin_* 写权，
   账户帧会撞权限墙）：quote stream→md_ticks（venue='mt5' 桥写与 SG 本地
   采集同键共存——共写语义）；标的集=app_config `bridge.mt5.symbols`
   热启（首集 BTCUSDm/ETHUSDm 与 SG 钱径清单同——扩集走 venue
   SymbolList 实读方言件）。
2. **swap 率面**：mtapi SymbolParams（swap_long/swap_short）周期拉取→
   `md_signal` kind='mt5_swap'（或 md_* 现状表——按既有键域择一明记）。
   拉取节拍低频（swap 率日级变量——≤1/4h 拍）。
3. **`xvenue_spread`**：app_config `bridge.xvenue.map` JSON 对映射
   （{"ETH-USDT-SWAP":"ETHUSDm",…}）→okx mark_price vs mt5 mid quote
   价差 bps；单边陈/缺=不产如实。
4. **`carry_diff`**：OKX funding_view 现值×3×365 年化 vs MT5 swap 年化
   （swap 点值→USD 年率换算走 SymbolParams 域）→差值 bps；换算缺件=
   该对缺席如实。
5. 验收锚：md_ticks mt5 行桥写 ts<10s；xvenue_spread/carry_diff 行鲜
   ≤2×拍；断 MT5 凭据=该腿缺席不拖 OKX 面；SG 钱径 MT5 采集零影响。
