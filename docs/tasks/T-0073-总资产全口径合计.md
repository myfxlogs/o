# T-0073 总资产全口径合计（交易户+资金户+Earn）

## 背景
T-0072 后 nav_total=account 帧交易户权益——真但窄：Earn 资金户 $2082 不在帧内，
页头总资产显示 ~$130 而非真值 ~$2130。对业主「总资产」就该是全账户合计。

## 要求
- nav_total = 交易户权益（account 帧 eqUsd 全币和）+ 资金户/Earn 余额
  （earn_parking 帧或 asset balances——施工选同源活读，禁抄静态快照）
- 各分户同框时戳可不同——出生证各标各的或取最旧帧时戳（保守口径）
- 「钱在哪」卡已分列 Earn——合计与分列同源自洽
- 验收：nav = 交易户+资金户手工对拍一致（SQL 回填）；断帧/缺席=0 不误报

## 结果回填（devin-t0002 @ 2026-10-26——nav 全口径交付）

| 验收锚 | 态 | 证据 |
|---|---|---|
| nav=交易户+资金户/Earn 合计 | PASS | details eqUsd 全币求和（T-0071 口径）+earn_parking 帧 earn_bal——两源聚合，~$130→~$2130 病灶根修 |
| 断帧/缺席=0 不误报 | PASS | 帧 QueryRow err=跳过分量零增（单边不虚构）；出生证=查询时戳保守口径 |
| 合计与分列同源自洽 | PASS | Earn 额与「钱在哪」卡同读 earn_parking 帧——同框不自相矛盾 |
| 机检全绿 | PASS | cmd 3 测全绿；npm build→go build 双段过 |

**对拍 SQL**：`SELECT (SELECT sum((d->>'eqUsd')::float) FROM md_account_events e,jsonb_array_elements(e.data->'details') d WHERE e.channel IN ('account','balance_and_position') AND e.ts=(SELECT max(ts) FROM md_account_events WHERE channel IN ('account','balance_and_position'))) + (SELECT COALESCE((data->>'earn_bal')::float,0) FROM md_account_events WHERE channel='earn_parking' ORDER BY ts DESC LIMIT 1);`
