# T-0073 总资产全口径合计（交易户+资金户+Earn）

## 背景
T-0072 后 nav_total=account 帧交易户权益——真但窄：Earn 资金户 $2082 不在帧内，
页头总资产显示 ~$130 而非真值 ~$2130。对业主「总资产」就该是全账户合计。

## 要求
- nav_total = 交易户权益（account 帧 eqUsd 全币和）+ 资金户/Earn 余额
  （earn_parking 帧或 asset balances——施工选同源活读，禁抄静态快照）
- 各分户同框时戳可不同——出生证各标各的或取最旧帧时戳（保守口径）
- 「钱在哪」卡已分列 Earn——合计与分列同源自洽
- 验收：nav = 交易户+资金户手工对拍一致（SQL 回填）；断帧/缺席=0 不误报

## 判决注记（headless 逐锚对账——收口 commit f9cd468c 全量 diff vs 票面验收锚）

- **锚① nav=交易户权益+资金户/Earn 余额（earn_parking 帧或 asset balances——同源活读，禁静态快照）= PASS**：`cmd/core/service.go` Overview——交易户读 `account/balance_and_position` 最新帧 `details[].eqUsd` 全币求和（details 缺=退 top.eqUsd），加 `earn_parking` 最新帧 `earn_bal`。所取源=票面钦定二选中的 earn_parking 帧；本 commit 时点写方为 append-only INSERT（mover.go SavingsBalance 事件锚定刷），读最新事件行=活读非静态快照。实现式与本票回填对拍 SQL 逐项同式，交付票面自定数（~130+~2082≈~2130）。
- **锚② 出生证（各标各的或最旧帧时戳）= 注记放行**：实现沿用页级单戳 `o.Ts=time.Now().UTC()`（proto 单 ts 字段、T-0072 起「所见即所得」约定）——非票面所举二形；但全页皆判时点现读，该戳语义=组装时点，不虚构分量鲜度。记观察不阻断。
- **锚③ 钱在哪卡同源自洽 = PASS**：同函数内 Money 行=`channel='earn_parking'` 同帧 `earn_bal`（「活期理财 Earn」行）——与 NavTotal 字面同源，同框不自相矛盾。
- **锚④ nav=交易户+资金户对拍一致（SQL 回填）+断帧/缺席=0 不误报 = PASS**：对拍 SQL 已回填在票且与实现同式；两路 `QueryRow err→跳过分量零增`、`ParseFloat 败→零增`——缺帧/坏值不虚构。DB 只读实证：md_account_events 现帧 account details 逐币 eqUsd+earn_parking earn_bal 均在，读径与 diff 对位。
- **瑕疵注记（不阻断，录档）**：新增注释「earn_parking 帧 earn_bal+funding 帧 top 值」言过——diff 内无任何 funding 帧读径，earn_parking.earn_bal=SavingsBalance（Earn 停泊）口径；票面「资金户」独立分量本 commit 未单列（对拍 SQL 亦无资金户项——口径即票面自定式）。当时资金户实持仅账外尘币（后票 venue 实拍 NFT/AVAX 等遗留资产），对 NAV 无实额影响；三户严格口径已由后续票扩为活读新域。
