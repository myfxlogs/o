## 钦定修法（终裁 §12.2 裁4 乙案定版）

- **判决/状态应用分离**：review 留 OCI 只写判决事实
  （fin_review/fin_review_verdict 追加）；SG 侧判决消费者应用
  `fin_proposal/fin_strategy` 态迁+写 transition（`run.go:200-216`
  逻辑原样搬迁，D-514 内联注释随迁）。
- **终态=判决走 outbox**（md 侧追加→消费者落 SG fin_review）——
  **OCI→SG 写权归零**。过渡期轮询消费 fin_review 增量须携持久
  化游标+幂等键（verdict_id 去重）——过渡件废弃入验收锚
  （outbox 判决道切换后 grep 零引用）。
- **fin_forward_check/fin_template_proposal 留 md**（研究面事实，
  非钱径态）。
- **四角色收窄**（T-0223 册面为审计输入）：
  - `research_ro`：SELECT fin_position/fin_strategy/fin_cashflow+md 只读
  - `review_rw`：INSERT fin_review/fin_review_verdict（+forward_check 按乙案定）
  - `roster_rw`：INSERT/UPDATE fin_employee_registry
  - `projector_rw`：八桥镜像 upsert+fin_position/strategy 读+registry/config
  - `collector_rw` 只留 md 面；projector 模板 collector_rw→projector_rw。
- **env 正名**：`MD_PG_DSN`→`FIN_PG_DSN`（名实归位）；一节点一 env
  文件，`systemctl --user cat` 与模板一致（T-0223 模板列持续对拍）。
- **双跑对拍一周**：判决链新旧径并行，判决不一致以 SG 侧为准，
  保留旧径回滚至切完。
