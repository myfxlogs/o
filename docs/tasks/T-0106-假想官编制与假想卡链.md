## 病灶（业主钦定）

总纲：业主只出资，赚钱由系统完成。现状机会面扩张链**断在原创段**——

- gapscan 已能把「有能力面无模板消费」的面落 `fin_surface_gap` + 生成
  `direction=gap_carry/gap_hedge` **占位**提案（paper 段，gen_cap=3）
- 但占位卡**永远转不了正**：没有岗/链把它升级成真模板（腿结构语义+
  评估器+风控阈）。占位提案进 paper 后无 evaluator 可评估、无 executor
  可执行——死胡同
- 「面差→新模板」现依赖业主/外部灵感→立票→手工注册——业主脑=系统
  扩张瓶颈，违总纲。名册无此岗=孤儿职能

## 钦定设计

```
fin_surface_gap(pending)
  → 假想官 runner 消费 → fin_opp_hypothesis 假想卡
    （surface 实据+family 归类+腿原语候选集+evaluator/risk 需求清单）
  → 决策席审（假想卡是审阅队列不是执行单）
  → adopted → 模板注册径（fin_opp_template 行+direction 枚举+评估臂——
    已知 family 映射现模板即注册；真新族=按卡立实现票）
  → dismissed → 卡结档，gap 记因
```

假想官=**起草席非执行席**：产出是结构化的「这个面可能这样赚」待审卡，
不是可执行策略。批准权=决策席（第 1 运营人份内），不假手业主。

## 边界声明（防误读）

- 假想官产的是**待审草案**——「这结构值不值做」的裁决仍归决策席；
  自动批准=另立票，本票不开
- 真新族（无现模板映射）的 evaluator/executor 实现照走任务单——假想卡
  是需求书不是实现码
- 本票不碰探员枚举面/验证官评估语义/lifecycle 晋升径
