# T-0097 腿平残币活期归口——钱不睡觉（D-286 闲资承接扩面）

> 业主令：腿平后残币不能躺——JIT 出面搬到活期。托管口径只管「物理下限之下
> 搬不动的真尘」，残币是待搬活钱非托管。

## 钦定搬径（优先级钉序）

对在持腿基币**之外**的交易户非 USDT 余量（含腿平残币+历史积存）：
1. **同币申购**——Earn 支持且 ≥起投额：交易户→资金户（asset/transfer）→
   savings purchase（零换手磨损——配管停泊径同构扩币种）
2. **兑后停泊**——低于起投/不支持：兑 USDT（小额转换或市价卖——取 venue
   最省径）→ 汇 USDT 停泊主径
3. **真尘如实**——物理下限之下（兑无可兑）：留托管标注「搬不动 $X」非静默

## 触发面

- 主触发=腿平事件（close 执行后扫交易户非 USDT 余量——事件驱动非轮询）
- 兜底=配管现存巡检拍顺带扫（有件复用不新造环）

## 验收锚

- 桩测：模拟腿平后 ETH 残量 → Earn 申购径或兑 USDT 径落真凭据行
- 低于下限面：如实标「搬不动」不假装成功
- 在持腿基币不误搬（开仓中的 ETH 是仓位不是闲资）
