## 病灶

净产 ≈ 年化 2.9% < mandate 8%）——系统会饿不会找食：阈写死、

## 授权域（业主令重画）

- **DM/系统全权**：放行线、评估阈、模板族启停、仓位重组判定、
  退役闸、paper→probe→live 判据值——「如何去赚」全参数域。
- **硬界残留**（物理+红线，机器不可越）：
  ① 资本总额=业主投入面，不可自创（balance 天然约束照旧）；
  ② venue 扩到需注册/凭证/KYC 处=条件请求抛业主，机器推进
     到边界为止；
  ③ 账本法典/对账三通道/拒因注册表不可动；
  ④ 资金扩投（加本金）归业主。
- 每次参数自调必落 ops_event（参数/旧值/新值/判据证据锚），
  周评审（T-0360）对账复核——自主≠无账。

## 范围

1. `app_config` 键域分册：哪些键=DM 可写（阈/放行线/闸值/模板
   enabled），哪些键=业主面（资金上限/venue 凭证类）——分册表
   落 docs/collab.md 写面判据节；
2. DM 写径：`dm_tick` 或新小件——读判词证据→写 app_config→
   落 ops_event 参数调整行（旧值/新值/证据锚必携）；
3. 饥饿态机读定义+响应：连续 N 天 zero-proposal（票面定 N，建议
   3 天）或 paper 池空 → 自动复审序列：放行线检校→休眠模板族
   再评估→低产 live 重组候选→venue 候选推进（到凭据边界出
   条件请求）；
4. T-0360 票面边界行修订（判词不再仅建议——带内直执+证据行）；
5. skills/策略评估与仓位 + 决策席职卡同步（写域+饥饿响应径）。
