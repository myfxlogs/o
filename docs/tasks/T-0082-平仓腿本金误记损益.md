# T-0082 平仓腿本金误记损益（业主实证抓出——+22.43 盈亏含 $24.9 幻影利润）

## 病灶
仓#1 平仓腿 leg15（BTC-USDT sell 0.00030866）卖款 $24.92571 整额记入 `trade_pnl`——**本金回笼当利润**。开仓腿（leg7 买入 ~$24.9）从未记支出，卖出端却把全额记盈。当前页头「累计盈亏 +22.43」含此幻影，真实经营盈亏 ≈ −2.5（手续费主导）。
实证链：fin_cashflow source_table=fin_order_leg source_ref=15；exec4 开仓无对应支出流水。

## 钦定修法
- 平仓现货腿 trade_pnl = 卖出所得 − 该仓开仓腿 px×qty 成本（T-0077 px 列已供成本锚；历史 NULL 腿=补录或标记无法核算如实报）
- 对称口径：现货买腿开仓=资产置换（USDT→币）非支出——若账本口径已把开仓买记作流出，平仓卖记流入则差即盈亏；**二选一但必须对称**，禁单边
- 回填修正：仓#1 幻影行 $24.92571 改记真值（卖出所得−开仓成本≈ ±零点几）或作废重记——账面不留假利润

## 验收
- 仓#1 的 trade_pnl 修正后，overview 累计盈亏 ≈ 真值（利息+资金费+真价差−手续费）
- 新开仓→平仓全循环的 pnl = 价差级数字非名义额级
