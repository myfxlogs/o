## 病灶

- 机器会分类不会归因：0420 结案判定机只产「哪类异常」，
  「为什么异常」无任何座位——pos34 根因（leg.sz 单位
  错配）靠业主问+人肉考古 7h 定位；
- 工程径自循环缺口：detect→升件→案卷→**诊断(缺)**→
  判词→修法——环断在诊断，链活着但环不回。

## 范围

1. **根因案型**：`fin_eng_lesson`/`trade_postmortem` 族
   升一类「根因诊断案」——异常案卷（postmortem 异常码+
   守卫环+账实差未定性）自动生成诊断任务：目标输出=
   「最可能根因+证据链+建议修法面」草案；
2. **诊断席排班**：裁定席受理节加第四分支（或同工同拍
   新增面——票面不钦定实现形）——LLM 席领案卷+
   代码仓只读面，产出诊断草案（根因假设+证据锚）；
   **禁 venue 写禁 fin_* 写**——草案是唯一产出；
3. **判词归流**：草案→DM 裁（人机分界=机器提假设
   人裁定）——裁过→修法票自动草稿（携根因+建议面）
   或并入既有案判词；裁驳→记驳回因（草案质量自学习
   面——错因入案卷）；
4. **时长锚**：首例跑通后票面回填「案到草案」实测
   时长——目标量级分钟级（对照人肉 7h）。

### 实现摘要（三段分立——机器提假设/DM 裁/机器执行既裁）

1. **根因案型**（Go 确定性——`internal/ledger/diagnosis.go` 新件+
   `postmortem.go` 同拍挂接+migration `fin_0133`）：
   - 结案判定机 bug 形异常（残袋挂账=账实差未定性/trigger_unknown=
     认知集外/attempts≥2=守卫环——三案卷源任一；**纯市况案不生成**，
     诊断额度不烧市况案）自动生成 `fin_econ_lesson kind='rootcause_diag'`
     诊断任务行（entity_ref=position#<id> 与 trade_postmortem 并行，
     UNIQUE 幂等一仓一案；票面「同工案型」择此——econ 表 kind 扩集，
     verdict_tick 水印自动覆盖零改）；
   - 任务载荷=case 案卷原貌+sources 源标签+**seeds 假说族种子**（先例谱
     确定性匹配——首族 `unit_mismatch` 单位语义错配=pos34 KB 条目升谱，
     结构签名=残袋×(幅超阈∨秒级开平)；证据查询锚 {pos}/{exec}/{inst}
     实化=腿对拍/守卫环/账实残袋三条只读 SQL）+target_output 契约；
   - fin_0133：kind 集扩 rootcause_diag+status 集扩 **drafted**（草案
     落位待裁态——水印只数 pending，drafted 不回烧拍；约束换名纪律
     fin_0131 同款）。
2. **诊断受理节**（裁定席 SKILL 受理节第四分支——排班非新席）：
   LLM 领任务→证据锚只读执行+/opt/o 代码仓只读开放考古→诊断草案
   （最可能根因+证据链+建议修法面；族标=seeds 命中族词谱或
   `novel:<定性>`——开放考古不受谱限）→`status='drafted'`+
   numbers.diagnosis 落位（**duration_ms=案到草案实测时长锚**）+ops_event
   `诊断草案` 行（ticket=T-0431 环票号，note 案锚首词机读形）。
   **禁线**：草案是唯一产出——venue/fin_position/fin_order*/fin_holding/
   fin_guard_close/fin_ledger/fin_cashflow/app_config/docs/skills 写径零，
   **禁自批**（status 只到 drafted，verdict 归 DM）。
3. **判词归流**（人机分界=机器提假设人裁定）：
   - DM 裁（决策席 SKILL 诊断草案受理节新增）：证据链亲证+修法面对准
     根域+族标合理→ops_event `裁决`/`驳回` 行（note=`诊断草案
     fin_econ_lesson#<id> 通过|驳回：<理由>`——ops_decision 镜像照旧）；
   - eventbus dm 踢径白名单+`诊断草案`（一行）——草案落位即唤醒决策席；
   - 裁过→归流执行段（裁定席同拍扫未归流裁决，`归流` 行幂等键）：
     修法票自动草稿=fin_ticket_draft pending INSERT（payload 携根因+
     建议面）→dm_tick 既有 ticketdraft 物料化尾段落候选态票（零自派，
     复用 T-0393 全链）；**同族 signature 在飞票→并入既有案判词**
     （verdict_ref 引票并案不起票）；
   - 裁驳→驳回因入案卷（diag_state='rejected'+reject_reason，status 回
     pending——再诊断携错因=草案质量自学习），diag_attempts≥3→verdicted

     判例闸结构性不触，防机器自批回环）。

### 偏离说明

- 诊断任务生成闸=三案卷源（票面「异常案卷（postmortem 异常码+守卫环+
  账实差未定性）」逐字对齐）——非全异常生成：纯市况案（幅超阈/秒级开平
  单发）不烧诊断额度，裁定席既有三分支消化（票面实现形不钦定授权内）；
- 时长锚：机制落位（duration_ms 入草案 jsonb——案卷 ts→草案落位实测）；
  首例生产实测待首案跑通回填（红桩 fixture 重放装配面=毫秒级 Go 确定性，
  LLM 开放考古段分钟级目标待首例实测——票面④「首例跑通后回填」句法）；
- eventbus dm 白名单+`诊断草案`（一行）为判词归流唤醒件——「草案→DM 裁」
  的机械落地，非范围外。
