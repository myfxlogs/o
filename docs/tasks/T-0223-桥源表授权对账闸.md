1. **授权漏配**：T-0214 实证 `md_earn_rate` 入 bridge-reverse 域后
   投影臂崩环——SG 侧 `projector_rw` 无 SELECT；手工授权面无册。

   知——Phase 0（arch 触发器）/Phase 1（outbox 触发器）均依赖其在场。
3. **模板漂移**（D-0036 §2.3/§10）：`deploy/o-collecto/compose.yml:8`

   模板即图的一部分，漂移=下个部署按错图施工。

## 钦定修法（对账闸一体三列）

- **授权列**：`domain.tsv` 桥域表 × 桥消费者角色（projector_rw
  SELECT / research_rw 按需）对账——登记表即名册，差即红。
  或乙案 GRANT 进迁移链（schema 即授权册）——施工调研决，回填选型。
- **存在性列**：桥域 schema 声明的触发器清单（domain.tsv 或迁
  移册派生）× `pg_trigger`/information_schema 实查对拍——缺即红。
  另留「arch-源水印日级对拍」回退径位（DV 件：触发器会丢，显形
  兜底——本票先立闸位，arch 源水印由 T-0230 接入）。
- **模板列**：`deploy/` 模板件 × 实机 unit/compose 关键字段
  （端口/角色/env 路径）对拍——漂移即红报件名字段名。

落点：`scripts/check_schema_live.sh` 或独立 `check_bridge_registry.sh`，
挂 pre-push/哨兵双径——施工选型回填。

## 结果回填

**落点选型**：独立 `scripts/check_bridge_registry.sh`（三列内聚新闸件，
check_schema_live.sh 追加段混域不如单件——哨兵径在其尾调，pre-push 径
挂 check_all.sh 步进 bridge-audit）。授权列选型=登记表对账（非 GRANT 入
迁移链——登记册即名册可 diff 可报差件名，GRANT 入链则差无诊件）。

**三列实现**：①授权=domain.tsv 桥域表（10 bridge+3 reverse）×SG
role_table_grants——projector_rw.SELECT 全桥表必钉+research_rw.SELECT
reverse 表钉；②存在性=迁移册派生触发器（fin_*→SG/md_*→OCI 分侧，仅桥域
表）×pg_trigger 实查，清单空=红（抽取败闸失效 fail-closed）；③模板=
deploy 三件套 DSN user@host:port ×OCI 实机 env 同键（compose/env 双形）。

**实面战果**：闸成即抓活体漏配 fin_data_retention（bridge 册在册 SG 无
projector_rw.SELECT——T-0214 同型，已 GRANT 补权复绿）；模板三件套全漂
已修齐（5433/5544→5435/15433，collector_rw→o/projector_rw 实机值）。

**桩测三红**：doctored checkout 各造一差全过——phantom 表→授权缺双角色
报表名；phantom_trg→触发器缺报 side/表/名；模板 9999→漂移报件×键×双值。

**闸修两真坑**（已入库条目 while-read-ssh-stdin-eat-pipefail-silent-
death）：①pipefail+set -e 下 grep 零匹配静默斩（存在性段初版全死）；
②while-read+裸 ssh 吃 stdin 清单（循环首行即终，18 项实查 1 项绿谎）。
ssh -n+|| true+清单非空断言三修已落。

**审计输入交付**：domain.tsv 桥域表×实机授权矩阵即 T-0232 权限收窄审计
基线——差件名×角色×权三维机读。

现面全符模板未列项）。
