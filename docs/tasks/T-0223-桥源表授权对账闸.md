驳回由（缺陷清单）：

- **D1 阻断——册失=闸静默全绿（实证）**：`mv migrations/domain.tsv` 后复跑
  →「授权列: 0 桥表…齐」「存在性列: 17 声明×桥域实查齐」（实查 0 项）、
  「三列全绿」exit 0。名册亡则闸自认全绿=本票条目钦定修法「声明清单抽取
  后断言非空（第三型静默）」所防型——TRG_LIST 有断言、rev_tables/
  fwd_tables 漏断言。修：两清单非空断言（含 domain.tsv 存在性前置）。
- **D2 阻断——模板列判词不可达（实证，活体漂移当场哑死）**：
  `env_field`/`tpl_field` 的 `grep -oE` 零匹配返 1，pipefail 传出，
  `av=$(env_field …)` 赋值败→set -e 斩脚本——设计的
  `red "模板对拍实机读缺"`/`red "模板键缺"` 两行判词永不打印，闸 exit 1
  零诊断。当场实证：审计窗内实机 `/home/ubuntu/o-collecto.env` 已把
  `SG_PG_DSN` 改名 `MD_PG_DSN`（另含 ROSTER_PG_DSN——真漂移），闸复跑两次
  皆哑死无 FAIL 行（bash -x 定位 av= 处斩）。修：两函数管道尾 `|| true`
  （自录条目钦定形），让空值走到设计的 red 判词。
- **D2b 实面活漂移待对位**：现面 o-collecto.env 键名 SG_PG_DSN→MD_PG_DSN
  （+ROSTER_PG_DSN）——模板 compose 仍写 SG_PG_DSN 名残。判词可达后此差
  即红，重飞须对位：模板键名随实机更名（名残清账）或 pairs 键径改写。
  现状闸红=真漂移非误报——推送面正被此闸实质阻断（见 dialogue
  「推送闸红在案」）。
- **D3 死码两件**：`want()`(L33)、`dsn_fields()`(L77) 定义零调用——码面
  纪律禁死码，删。
- **D4 列级 OK 谎报**：三列 OK 行无条件打印——授权列两 FAIL 同列仍印
  「14 桥表×…齐」。总 exit 正确（fail=1→exit 1），列级自报与实判矛盾；
  改按列 fail 条件打印或附差件计数。
- **D5 坑条目违 schema v2**：`severity/status:active/domain/tags/created/
  related` 皆非钦定字段（应为 kind/risk/status:observed|verified|disputed|
  retired/keywords/scope/first_seen），且缺必填「反证条件」节——kbgen 宽容
  解析产出索引行 kind/keywords/risk 三列空（实见 `|  |  | summary | active
  |  |`），gen --check 只校陈腐不校字段故机检未拦=条目检索面半隐形。
  修：frontmatter 归 v2+正文补反证条件节+`tools/kbgen gen` 重建。
- **注记（非阻断）**：授权判 `[ "$n" = "1" ]` 多 grantor 行将 false-red，
  存在性语义应 `-ge 1`；存在性 OK 文案 trgn=全量声明含非桥域跳过项
  （17 声明≠17 桥域实查，措辞略夸）；模板列只钉 DSN 三维、unit env 路径
  未列——回填偏离段已声明，锚面可容。
