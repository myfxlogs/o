## 钦定修法（对账闸一体三列）

- **授权列**：`domain.tsv` 桥域表 × 桥消费者角色（projector_rw
  SELECT / research_rw 按需）对账——登记表即名册，差即红。
  或乙案 GRANT 进迁移链（schema 即授权册）——施工调研决，回填选型。
- **存在性列**：桥域 schema 声明的触发器清单（domain.tsv 或迁
  移册派生）× `pg_trigger`/information_schema 实查对拍——缺即红。
  另留「arch-源水印日级对拍」回退径位（DV 件：触发器会丢，显形
  兜底——本票先立闸位，arch 源水印由 T-0230 接入）。
- **模板列**：`deploy/` 模板件 × 实机 unit/compose 关键字段
  （端口/角色/env 路径）对拍——漂移即红报件名字段名。

落点：`scripts/check_schema_live.sh` 或独立 `check_bridge_registry.sh`，
挂 pre-push/哨兵双径——施工选型回填。
