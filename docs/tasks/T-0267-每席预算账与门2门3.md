  token 用量（模型侧 usage 或 devin 日志解析——施工据实选源并记取舍）；

  管理席会话（等效 feishu-ingress 叩门径的箱内版，复用 manage-spawn.sh
  孵化器径）；

- 门 1=feishu-ingress 已建（业主私聊→MANAGE 箱+叩门），不在本票。
