## 病灶

迁移序号三犯（canon migration-number-collision）：施工分支基于旧 master
立号，并行票先合占位→后到者同号双注册。票面防撞注记只提醒不执行——
根修=机检硬闸在 commit/merge 时强制断言。

## 验收标准

- [ ] `scripts/check_migrations.sh`（或同等件）三断言：
      ①`migrate_table.go` 登记 version **唯一**（重复号=红）；
      ②每个登记 `{N, "NNNN_*.sql"}` 的文件名前缀号=登记号 N 且文件实存；
      ③`migrations/*.sql` 每个文件恰有一条登记行（孤儿文件=红）
- [ ] 接入既有门禁链（pre-commit 同排或 import-direction 同构
      `scripts/check_*.sh` 面）——撞号态下 `git commit` 实测被拦
- [ ] 负例桩测/实测：人为造双 0048 号提交 → 闸红（留验痕）
- [ ] 不拦历史：当前 master 状态过闸（46/47 并存=合法——判的是
      号重复非序号连续）
