# T-0219 CI 择优省本——setup-go 缓存+并发取消，全量判据不动

> 状态：待验 | 领取：devin-t0219 @ 2026-10-28 | 优先级：P2
> 立项：决策席 @ 2026-10-28

## 病灶

`.github/workflows/ci.yml` 每跑一次 ≈4-7min，浪费面两笔：

1. **setup-go 无 `cache: true`**——`go mod download`+冷编译每跑
   全量重付（actions/setup-go 官方 module+build 缓存，语义零变）。
2. **push 全支 + pull_request 双触发**——同 SHA 在支推与 PR 同步
   各跑一次；连推时陈旧跑不取消，白烧 runner 分钟。

## 钦定界

- **全量测试判据不动**——T-0212 裁决沿行：CI 必须 `-count=1`
  无缓存全谱（防跨包耦合漏检），不做 paths-filter 选择性跑。
- 只砍重复付账面，不砍验证覆盖面。

## 钦定修法

1. `actions/setup-go@v5` 步加 `cache: true`（go.sum 锚自动）。
2. workflow 顶加并发组：

   ```yaml
   concurrency:
     group: ci-${{ github.workflow }}-${{ github.ref }}
     cancel-in-progress: true
   ```

   同支连推→旧跑取消；不同支/PR 互不挤。
3. push 触发面收窄审议：`branches: ['**']` 的存在理由是
   required-check 绑 SHA 供 ff 推 master（见 yml 头注）。现行
   流程全走 PR——改 `branches: [master]`（只留 master 直推
   +PR 两径），若服务端 required-check 仍绑支推 SHA 则保
   原状并在票内回填理由。
4. **票号远端对账升机械闸**（同日 Claude 席撞 T-0217 实证——
   `check_ticket_numbers.sh` 只数本地 index，远端核对仅 NOTE
   建议件：本地树陈时闸盲）：
   - `scripts/check_ticket_numbers.sh` 加 `--remote` 模：
     `git fetch` 后对 `origin/master:docs/tasks/` 扫号，
     staged 新立票号 ≤ 远端最大号/已存在→硬红。
   - pre-push 钩在绿戳闸后调用 `--remote`（推送本要联网，
     fetch 失败降级 WARN 不拦——离线推送不受阻）。
   - `scripts/next_ticket.sh` 新件：fetch 后打远端最大号+1
     ——两决策席取号统一入口，消除「本地最大+1」猜测根因。

## 验收锚

- 改后 CI 绿；二次推送同支观察旧跑被取消。
- `go mod download` 步耗时显著降（cache hit 日志可证）。
- 全量测试面零裁（`-count=1` 原样在案）。
- 桩测：远端存 T-0217 时 staged 新立同号票→`--remote` 硬红；
  `next_ticket.sh` 输出=远端最大号+1。

## 回填（施工）

**实现**：①ci.yml——setup-go `cache: true`（go.sum 锚）、顶加 concurrency
组 `ci-${{ github.workflow }}-${{ github.ref }}`+cancel-in-progress、
push 收窄 `branches:[master]`（gh api 实证 required-check contexts=
[build-test] 绑 PR head SHA，pull_request 跑满足——全支推与 PR 双跑白烧
切除，master 直推兜底径保留）；②check_ticket_numbers.sh 加 `--remote`
模（fetch→origin/master ls-tree 扫号→staged∪merge-base..HEAD ACR 新票面
三径判红：同径异文/同号异名/≤远端max，同径已见远端 t/* 支=同票候并
降级 NOTE）；③pre-push 绿戳闸后挂 `--remote`（fetch 败降级 WARN 不拦）；
④`scripts/next_ticket.sh` 新件（fetch→远端最大号+1，T-0222 实证输出）。

**测试**：bash -n 三件过；`--remote` 桩测——T-0216/T-0217 伪票 staged
→同号异名硬红（列出远端占位件名）、T-0219 异名伪票→≤max 硬红、
本票 T-0219→远端支面已见 NOTE 放行、exit=1/0 对。`next_ticket.sh`
=T-0222（远端 max 0221+1）。

**偏离**：`--remote` 对「≤远端max」补同径远端支已见豁免——票立后决策支
候并期远端号序前进属正常形（本票即实证：master max=0221 而 0219 票在
dec-ci-econ 支），不豁免=闸误伤合法票。`-count=1` 全谱判据原样未动。

**CI 实证**（PR #14 本票推送自证）：run 40692275523 build-test ✓ 6m39s
全绿（`-count=1` 全谱原样）；`Cache restored successfully`（264MB，
`go mod download` 步 ~65ms vs 旧全量下载）；连推取消实证两次——
40690703551/40690936661 均被后续推送 cancel-in-progress 标 cancelled。
**在案坑**：首跑 40690936661 红一次=events 包
TestListenSocketStarvationRootFix 停灌竞态 flake（与本票面零干——
Go 零改），已立经验库条目 starvation-test-flood-cancel-exec-race，
修径（floodCtx.Err() 分流）属另单。
