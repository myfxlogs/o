> T-0086 验收毛边：仓 #23 现货腿 ETH 在「钱在哪」被标 `legacy=true`——它是活仓腿非遗留。
> 根因：白名单只查 `fin_cashflow.ccy`（现金币种），现货腿的底层币（ETH）永远进不了名单。

## 钦定修法

在册口径 = `fin_cashflow.ccy` ∪ 已成交 `fin_order_leg.inst_id` 的基础币（ETH-USDT→ETH，剥 `-USDT/-SWAP` 后缀）。
三处同改：①「钱在哪」legacy 标位 ②对拍白名单（venue 侧豁免集合同源扩） ③保持一致——白名单定义只此一处真源。

## 验收锚

- 页面交易户区 ETH 行 `legacy` 消失；AVAX/COMP/NFT 等真遗留仍 `legacy=true`
- 对拍行为不变（ETH 现货腿本就 MTM 全值并轨——扩口径后对拍集合仍对称）

## 结果回填

**实现摘要**（devin-swe2-1025 @ 2026-10-25）：
- 新增 `internal/ledger/ledgered.go` `LedgeredCcy(ctx,pool)`——在册口径唯一真源：`SELECT DISTINCT venue,ccy FROM fin_cashflow UNION SELECT venue,split_part(inst_id,'-',1) FROM fin_order_leg WHERE state='filled'`（首段取基币，-USDT/-SWAP 后缀天然剥除）。
- 「钱在哪」`ledgeredCcy`（cmd/core/money_card.go）改调真源按 venue 过滤——现货腿 ETH 入册，`legacy` 徽标消失。
- 对拍白名单（internal/ledger/run.go）inline 查询删除改调 `LedgeredCcy`——同集合同源扩，对拍行为不变（ETH 本就 MTM 全值并轨）。

**测试证据**：新增锚 `TestLedgeredCcyLegBase`（USDT cashflow+ETH-USDT/-SWAP filled 腿入册、placed DOGE 腿拒）——本机 O_TEST_PG_DSN 未设按约定 skip（与存量 DB 测同待遇）；`go build ./internal/... ./cmd/...`、vet、gofmt 零告警，`go test ./internal/ledger ./cmd/core` 全绿（web dist 本树重建过——embed 依赖）。

**偏离说明**：无。钦定修法按文执行——三处归一为单一真源函数。
