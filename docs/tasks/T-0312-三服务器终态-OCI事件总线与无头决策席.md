# T-0312——三服务器终态：OCI→dev gRPC 事件总线+无头决策席+stall 读面

> 状态：待施工 | 立单：2026-11-03 决策席 | 锚：业主令「3台独立服务器+gRPC 事件驱动」钦定终态 + T-0311 收口跟件

## 范围

三服务器终态钦定形（业主令）：

```
OCI（采集服务器）──gRPC 事件流──→ dev（meta 算力）
        └── dualwrite 桥（保留不动）──→ SG（钱径生产）
```

**选型原则（决策已裁）**：状态镜像走桥（SG 查表=断链快照可用）；事件信号
走 gRPC（dev 被叫醒=瞬时 ephemeral）。桥不拆、事件面单独立。

### 三件

**① OCI→dev 事件总线**（ConnectRPC server-stream——栈钦定=仓内
connectrpc 现用非新技术）：
- OCI 侧：`o-research`（或独立 `o-eventbus` 件）暴露 ConnectRPC 面——
  `md_ctx_fact`/`md_macro_event` 落行即发 `DataAdvanced` 帧（载荷：
  source/kind/max_id/时间戳——**信号非数据本体，数据仍走 PG 读径**）。
- 拓扑：dev 向外拨 OCI（dev NAT 后不可被直拨——server-stream 订阅形，
  与现「全外拨」拓扑同构，零入站口）。
- 订阅方=dev 常驻小件（`o-metabus`——meta 域非 O 域件，建议放 /opt/meta
  仓或 O 仓 meta 目）：收帧→唤醒对应拍（regime 分析席批件/将来他席）。
- 鉴权：隧道内（15433 径同款 ssh -L）或 token——首版走 ssh 隧道零新暴露
  （钦定起步形，mTLS 列入二期）。
- 断线重连+水位线续传（帧携 max_id——订阅侧重连自查水位差=漏帧自愈，
  不押推送可靠性）。

**② 无头决策席**（meta-gateway `ticket_event`+`seat_run` 机制钦定——
基建在册不另造轮）：
- 唤醒源：收口事件（report.sh 事件环已拍→接 gateway 调和→醒裁决）+
  周期扫描兜底（ticket_event 行径）。
- 当班例行含 regime 刷新（T-0311 分析席同构调用）。
- 红线三件（资金扩投/新平台/席位立换）照旧升业主——权限模型零动。
- 风险缓冲：全动作 git/ops_event/rejects 审计迹+错放大险已明记（业主
  令钦定放行）。

**③ 驾驶舱 stall 读面**（T-0311 跟件）：ops_headless META-REGIME 行
挂驾驶舱存活/活水卡——「分析席·最后心跳 xx 分钟」红绿标
（staleness 阈值 60min=2×拍周期）。读面差事非基建。

## 验收锚

- ①`md_ctx_fact` 落行→dev 订阅方 ≤30s 内收 DataAdvanced 帧实证
  （journal/表迹）；断线重连水位续传实证（手工断 ssh 拍→恢复漏帧补齐）。
- ②收口 commit 落→无头决策席自醒出裁决产出（seat_run 行+裁决文档）；
  红线场景照旧升业主不自动。
- ③驾驶舱存活卡见 META-REGIME 行+staleness 标色。
- 全程 ops_headless 心跳行不中断。

## 禁线

- 桥件零改动（dualwrite 保留——状态镜像与事件面分工钦定）。
- 事件帧=信号非数据——禁在帧里塞数据本体（PG 读径唯正）。
- 无头决策席红线三件不自动——升业主语义钉死。
- dev 侧订阅件不持写权限（读帧+唤醒本席——无跨域写径）。
