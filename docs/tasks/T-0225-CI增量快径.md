## 病灶

T-0219 修掉双跑/冷编译后，剩余病灶：**内容无关全量**——docs-only
决策票也要跑 6-7min Go 全谱（业主点名）。

## 钦定界（诚实增量，非包裁剪）

本仓测试几乎全挂共享 PG+统一迁移链——`migrations/*.sql` 一改影响
全部测试却不在任何 Go 包内，包级增量（affected-pkgs）会把 schema
变更漏出网。钦定=**文件类路由**：

- diff ⊆ 快径白名单（`docs/**`、`*.md`、`.devin/**`、`skills/**`、
  `docs/handoff/**`）→ 跳 Go test/npm/buf/proto 段，只跑
  gofmt+check-lines+check_migrations（≈1min 快闸）；
- 碰 `**.go`/`proto/**`/`web/**`/`migrations/**`/`scripts/**`/CI 自身
  → **全量原样**（-count=1 判据不动——T-0212 裁决沿行）。

实现参考：PR 事件 diff 源=`origin/master...HEAD`（三点 merge-base），
push master 事件 diff 源=`HEAD~1`；diff 集合逐径对白名单全中=快径，
任一越界=全径。

## 验收锚

- docs-only PR：CI 跑时显著降（<2min），go test 步确未执行。
- 码面 PR：全谱原样跑（抽查一 run 证 go test -count=1 在）。
- 越界混合 diff（docs+go）→ 全径不误走快径。

## 结果回填

### 实现摘要

`.github/workflows/ci.yml` 单文件改动：

- checkout `fetch-depth: 0`（路由 diff 需 merge-base/event.before，浅拉取不到）。
- 新增 `route` 步：PR 事件 diff=`origin/<base>...HEAD`（三点）；
  push 事件 diff=`event.before..HEAD`（零 SHA/首推回退 HEAD~1）。
  `git -c core.quotepath=false`（本仓 docs 大量中文名，默认 C-quote
  `"docs/...\345..."` 前缀匹配全灭——不带此参快径形同虚设）。
  逐径对白名单 `docs/*|*.md|.devin/*|skills/*` 全中→`fastpath=true`；
  空 diff/diff 失败→false（fail-safe 宁全勿漏）。
- Go/node/buf/proto/npm/test/race/import 全段加 `fastpath != 'true'` 闸；
  gofmt 全树 sweep+check-lines+check_migrations 无条件跑（快径三闸）。

### 验收锚对账

- docs-only PR <2min、go test 未执行：**机制已证、线上实证待合并后首个
  docs-only 提交兑现**（trigger 限 PR→master，合并前无法造出携带新
  workflow 的 docs-only PR；route 步逐 run 打印 diff 源+fastpath 可审计）。
  本地 scratch repo 实测：中文名 docs-only diff→fastpath=true；
  空 diff→false。
- 码面 PR 全谱原样：**PASS**——本 PR 自身 run（.github 触碰=越界）
  route 判定 fastpath=false，setup-go/node/buf/npm/build/vet/
  import/gofmt/role/go test -count=1/race 全段依序执行
  （run 40790350518，pr#24）。
- 越界混合不误快径：**PASS**——本 PR diff=.github+docs 混合仍走全径；
  scratch 实测 go+.github 混合→fastpath=false。

### 机检

- `scripts/check_all.sh` 全链绿（build/vet/import/gofmt/env/rejects/
  migrations/go test 全谱），绿戳随 commit。
- YAML 语法校验过；路由判定逻辑 scratch repo 12 用例实测
  （白名单内/越界/混合/空 diff/伪 docs 前缀 docsx）。

### 偏离说明

- push 事件 diff 源用 `event.before..HEAD` 而非票面参考的 `HEAD~1`：
  覆盖整段推送（多 commit 推送 HEAD~1 只看顶 commit 会漏越界），
  严格更严不更松；首推/force-push before 无效时回退 HEAD~1。
- `*.md` 按 gitignore 语义判（任意深度 .md 皆白名单）——与钦定
  「docs-only」语义一致；md 文件不参与编译无风险面。
- `收口commit` 填实现 commit 哈希（非状态翻转 commit 自身——哈希
  无法在自身 commit 内预知，自引用不可能）。
- 部署树 `/opt/o` 票面曾有一行未提交 relay 注记（执行径行），已随
  领单 commit 收编进分支版本，部署树该文件已还原至 HEAD 保净
  （出处闸脏树拒）。
