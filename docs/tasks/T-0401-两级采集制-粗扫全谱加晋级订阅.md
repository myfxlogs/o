# T-0401 两级采集制——粗扫全谱+晋级订阅

- 状态：已批（2026-11-06 业主令——「如果不全世界采集，
  如何能找出新的机会」机制缝裁定）
- 领取：待施工
- 优先级：P1——发现面架构件（今天唯一未立的真缝）
- 收口移交归：决策席

## 背景（裁定钉）

tick 级采集=activeSet 38 符（执行精度层），全谱视野仅
funding 527 符——价差类发现（基差/xvenue 腿/流动性型）
在非活跃符上零视野。「窄」是刻意的存储经济，但只建了
执行精度层、漏了筛选精度层——本件补筛选层+晋级径。

## 钦定语义

```
① 粗扫层: REST tickers 轮询(OKX /market/tickers instType=
   SWAP 单请求全谱 last/bid/ask)节拍件——钦定 60s 一拍,
   落 md_tick_scan(venue,inst_id,last,bid,ask,ts) upsert
   最新行表——发现面全谱化,成本≈零(无逐符流储)
② 晋级径: 假想臂评估候选符(粗扫+信号筛过阈而 inst 不在
   activeSet)→请求**临时订阅**(fin_sub_request 或在
   activeSet UNION 加评估臂面)→collector syncActiveSet
   拾取流式采→评估判词出:过=经提案常驻,拒=退订
③ 执行层: activeSet WS 流现状不动
```

## 范围（设计+实现同票，体量归中）

1. 采集臂：粗扫轮询件（cmd/collector 或独立 tick——
   读现有 REST 调用面复用，禁新 HTTP 框架）+md_tick_scan
   迁移表（fin 链号顺延，当前最大 0123）；
2. 晋级径：评估臂提名面（读 hypothesis 评估径找最小挂点
   ——候选符缺 tick 数据时发订阅请求不直接判
   unevaluable）+activeSet UNION 补一臂（legset 同式）；
3. 探针族更新：粗扫活性+晋级滞留（请求超龄未采）入
   0394 枚举面对集；
4. docs/数据流.md 补两级制图段。

## 验收锚

① 粗扫表 500+ 符行（生产实测符号数实证）；
② 某非活跃符经晋级径拿到 tick（桩测或生产观察行——
   评估臂提名→activeSet 含→md_ticks 新行）；
③ 存储增量实测行（行宽×符数×节拍——PG 体积纪律不破）；
④ check_all 绿戳对口。

## 红线

- activeSet 现谓词语义不动——晋级是 UNION 加臂非改旧臂；
- 粗扫零交易语义（只读公共行情）；
- 体积纪律：粗扫表只存最新行（upsert），禁 tick 流水全谱。
