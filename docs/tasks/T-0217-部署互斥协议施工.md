## 施工面（钦定三段，原样落）

改 `scripts/deploy_image.sh` + `docker-compose.yml` 一行：

1. **SHA tag 留痕**：镜像打 `o-core:$(git rev-parse --short=12 HEAD)`
   + `o-core:latest` 同层别名；`docker save` 双 ref 齐运；
   compose `image:` 改 `${O_CORE_IMAGE:-o-core:latest}`；
   SG 侧 `O_CORE_IMAGE=o-core:<sha> docker compose ... up -d o-core`；
   尾拍 `docker inspect o-core --format '{{.Config.Image}}'` 印产地。
2. **SG 部署锁**：`ssh mkdir /opt/o/.deploy-lock`（mkdir 原子=互斥
   原语，dev→SG 实证 rc=1）；持锁写 `holder` 文件=席位@主机+sha+
   ISO ts；陈锁 30min 或 `O_DEPLOY_FORCE=1` 可抢（抢前打 WARN）；
   EXIT trap 释锁。
3. **出处闸**：`git status --porcelain` 非空拒；`git merge-base
   --is-ancestor HEAD origin/master` 假拒（列待推 commits 提示），
   `O_DEPLOY_ALLOW_UNPUSHED=1` 显式放行回滚/热补。

## 验收锚

- `bash -n` 过；锁原语 dev→SG 单测（mkdir 原子/持锁拒/陈龄抢/trap 释）。
- 干跑模拟：脏树/未并 HEAD 各拒一次；holder 文件内容对。
- 下次真实部署后 `docker inspect o-core` image=o-core:<sha> 对上 commit。
- 部署后 o-core 健康（compose healthy + 日志无新错）。
