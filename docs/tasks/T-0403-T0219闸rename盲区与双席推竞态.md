   base→HEAD 全程纯改名——归档同 commit 带状态行/

③ 共享部署树 `/opt/o` 双席并发 commit/push——本地
   master 被另一席 reset 甩 commit（0397 实证 f4c050a4
    dangling，分段推救回）——竞态面零防护。

## 范围

1. `scripts/check_ticket_numbers.sh`：head_archive_move
   放宽——rename 检出后比对「base 行 vs HEAD 行」的
   **非内容差集口径**：done/ 归档+仅状态行/结果回填节
   diff 视为同票（钦定豁免= 状态行首行+「## 结果回填」
   节后内容；其余 diff 仍判分叉）；同目录同号改名
   （key 同 path 异）同式豁免；
2. 双席竞态：部署树推前**自动合流径**入 pre-push 或
   DM 推批规程——本地落后远端先 pull --rebase 再推
   （防 A 席把 B 席未推 commit reset 甩落；rebase 冲突
   则拒推送人工）；
3. 桩测：四案矩阵（纯改名/改名+状态行/改名+正文改/
   同目录改名）断言放行/拦截对。

## 结果回填

实现摘要（devin-t0403）：
① `check_ticket_numbers.sh` `head_archive_move` 放宽——R 检出后走
   豁免径闸（同目录同号改名 或 tasks/→done/ 归档移，皆须同号 key），
   blob 异则剥豁免两面比对（新增 `ticket_norm`：状态行字段整体
   （首行+缩进续行，遇 0 列新行止）+「## 结果回填」节后内容；节头
   行仍比对）。剥后异=正文分叉回落撞号判。补钉：`git diff -M` 与
   `git ls-tree` 各缺 `-c core.quotepath=off`——无全局 quotepath=off
   环境中文票名全盲区（生产靠 /opt/o 本地配置幸中，同族坑顺手钉死）。
② `scripts/master_push_converge.sh` 新件入 pre-push C0 位（master
   推形内、绿戳闸前）——远端先行即 `git rebase origin/master` 自动
   合流（`O_ALLOW_NONFF=1` 钦定哨兵限域于该次 rebase 调用：rebase
   重放非 ff 移 ref 合法位移，non-FF 闸本体未动）；合流成 rc3 本推
   作罢报重戳（绿戳绑 sha 不可代推）；冲突/脏树 rc1 --abort 回原状
   红报人工（报文明禁 reset --hard——0397 dangling 案）。
③ 桩测 `scripts/meta/tests/t0403_gate_converge_test.sh`——
   reference-transaction 真钩装机对拍哨兵放行。

测试证据：`bash scripts/meta/tests/t0403_gate_converge_test.sh`
   → 12 案全 PASS（豁免矩阵×8：纯改名/状态行/多行态收单行/回填节放、
   正文改×2/反归档拦；竞态×4：分叉 rc3 双件零丢失/冲突 rc1 回原状/
   快进 rc0/远端不可达降级 rc0）——0392/0397 形单推直过=B 案断言。

偏离说明：豁免①按「状态字段整体（首行+缩进续行）」计非逐字单行
   ——票面「状态行首行」若解作只豁第一行，多行态票（如本票自体
   3 行状态）归档收成单行会再误判=病灶复发；界收窄于续行须缩进
   且遇 0 列新行即止，越字段差仍判分叉。另 pre-push 三闸变序注记：
   合流闸置于绿戳闸前（非快进先合流，免空跑 check_all）。
