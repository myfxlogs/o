## 病灶（实查在案，勿重复诊断）

**件① SG 出向 IP 遭 faireconomy（CF 挡）间歇限流**——2026-11-03
~00:20–01:09 UTC 实测全 429（宿主 curl/容器 wget/换 UA 皆拒），01:09 自复
200。15min 一拍（~96 次/日）非频率病灶，属 DC-IP 信誉+爬虫特征（Go 缺省
UA）桶限流；生产取证另增负载。封窗期盖过事件预推窗=当次漏推。
`md_calendar_push` 末推 2026-10-30 09:47 UTC（BOJ 准点在窗实证），10-30
午后→11-01 重建间疑漏（FOMC/PCE 类），旧容器日志灭失无法回溯实证但模式
自洽。

**件② Scan 不查 StatusCode**——`internal/platform/notify/calendar.go:72-88`
`resp.StatusCode` 未检：429 页当 XML 进 decode→「解包败」log→下拍照打，
限流期每 15min 续砸拉长封窗，无退避面。

**件③ 镜像缺 tzdata**——`Dockerfile.core:38` `FROM alpine:3.20` 无 tzdata
包（容器内 `/usr/share/zoneinfo` 缺席实证）→ `calendar.go:58` etLoc 兜底
`FixedZone(-4h)`：美国 11-02 入冬令（-5h）后**全部事件时间错早 1h**——
推送提前 1h 且错开窗可致漏报。10-30 前推送准时因彼时尚 EDT(-4) 恰合。

**件④ 计数面缺**——T-0070 票面钦定「计数+log 不炸」，现仅 log 无计数
（该票结果段自记轻量偏离）——限流频次无度量锚。

**臂活实证**（勿疑件死）：2026-11-03 01:20:24 UTC 拍对 feed 解析 IP
（104.18.6.156:443）出向连接在 conntrack 实证；容器内 wget 200+真 XML；
配置键全开、chat_id 在册、sender 凭据与日报推送同源（当日 00:00 推成功）。

## 钦定目标

- **Scan 加 StatusCode 分支**：`!=200`→log（含码）+退避——连败指数退避
  （×2，封顶 4h 档），恢复 200 回 15min 拍。退避窗内不再打源。
- **UA 正经化**：请求挂浏览器形 UA+Accept 头（DC 爬虫特征降分，非伪装
  绕权——公开源礼貌拉取面）。
- **tzdata 进镜像**——`apk add --no-cache tzdata` 或 `_ "time/tzdata"`
  embed 二选（施工裁）；验 `LoadLocation("America/New_York")` 真命中，
  etLoc 兜底仅作缺件备位保留。
- **计数补齐**：拉取/解包/推送败计数随 log 输出（败次入文案即可，不强求
  独立表/prom 面）。
