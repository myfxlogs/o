## CTO 裁定（2026-11-08 裁域五项定案）

### ① 卡粒度内细分

一席之地一卡（业主已裁按席开）。卡面四段：
- **头段**：席名+班态字标——`开班在岗`（unit active∧近事件≤10min）/
  `作业中`（active 但事件老）/`挂起`（挂起行在案）/`退班空闲`（unit
  inactive）/`异常`（异常行在案或事件>2h 无动）。
- **在办段**：当前活件行——最近 `领单`/`收口`/`移交`/`裁决`/`派单`
  行推 ticket+事件名（无活件=「待派」）。
- **队列段**：dm_queue review 深+approved 深（帧拍重算——只读推导面
  不改队列逻辑）。
- **末动段**：该席最新 ops_event 行 ts+event+note 截 40 字。
批量班不糊律：施工席并行≤N 时卡内「并行活件」列 N 行
（tid+model+elapsed），**不开票级卡**；哨兵/分析/裁定席同法一卡聚合。

### ② 基建径

- **卡册**：`ops_seat_card`（fin_0144 迁移）——seat PK + message_id +
  chat_id + last_hash + updated_at；seat→message_id 持久 PG（重启原地
  刷同卡，meta feishu_card 同构先例）。
- **出站**：lark im/v1 REST——懒建 POST /im/v1/messages（interactive
  card）→message_id 落行；改卡 PATCH /im/v1/messages/{id}。凭据复用
  `FEISHU_MANAGE_*` env（feishu-notify.sh 同径同 chat）——不新引凭据。
- **report.sh 与推卡分两径**：文本打点照旧（里程碑推送语义不动）；
  卡=ops_event 派生展示面，同账不同面互不阻塞；卡败落 ops_event
  `seatcard_err` 行**不进事件总线**（防回灌自触发环——meta card.go
  RecordErr 同判例）。

### ③ 写口挂点

- **消费件**：新 `o-seatcard.service`（cmd/seatcard）——与 metabus
  同径 Watch eventbus（localhost:15436 隧道）订 dm 帧（ops_event 源
  kind=dm）。独立进程：卡败不吞账、不拖累 kick 唤醒径。
- **触发集**：dm 帧一律触发——携 seat 列行到→该席重渲；队列深随帧
  重算。状态唯一真源=ops_event（班态=unit 态∧事件龄双证；在办=最新
  领收移裁派行；末动=该席最新行）。
- **去抖双闸**：(a) 内容哈希闸——渲染→sha256→变才 PATCH（meta
  card.go 同款自然合并刷帧）；(b) 渲染时间截断至分钟+每席 PATCH
  下限 5s（秒级事件塌帧）。
- **启动对账**：起环扫活跃席无卡补建（一次性幂等；终态/零活性席
  不补——懒建闸同款）。

### ④ meta 复用 vs O 自立

**O 自立消费件+模式级复用**：照抄 meta card.go 三件套（哈希闸 PATCH/
懒建/启动对账——抄模式不依赖 meta 包；lark 调用走 notify.FeishuClient
扩 CreateInteractive/Patch 或 lark SDK 直调）。**禁延 meta-gateway**：
(a) gateway 本盒死；(b) 席位活性真源=ops_event（O PG）非 meta sqlite
seat_run；(c) 跨系统耦合违边界。凭据与目标群与 feishu-notify 同径。

### ⑤ 验收锚（机判）

- `ops_seat_card` 表在案+CTO/施工/CEO ≥3 席行 message_id 非空。
- 桩测（check_all 内）：(a) 渲哈希同态——同输入两渲哈希同；(b) 事件→
  重渲→哈希变→PATCH 断言（fake lark 注伪缝）；(c) 懒建闸——终态/零
  活性席不补卡；(d) 卡败径——lark 败→seatcard_err 行落账+订阅环不死
  (e) dm 帧→Watch 收到→重渲调用断言。
- 部署后实证：ops_event 席行落账 ≤30s 卡面末动字变（业主视证）；
  PATCH 日志证哈希闸压帧（窗内 N 事件 ≤1 PATCH）。

### ⑥ 部署/灰度

一期=无头三席（CTO+施工+CEO——活性盲域最大）；COS 交互席二期（业主
pane 已直见非刚需）。顺序：seatcard 上线先 dry-run 只渲不发（日志验
渲染正确一周期）→ dmconfig 翻 `exec.seatcard_live=true` 开真 PATCH
（暗发闸默认 false 钱径级灰度律同构——ops_event 参数调整行溯源本票）
→ 稳定一周扩 COS/哨兵。
