## 病灶（踢拍实证在案，勿再诊）

`dm_tick.sh` ①待裁闸只数 `收口/移交/收口待审`——N=0 即 `SKIP_DECISION=1`
跳 LLM 批拍。而 **「已批→派单」恰是该 LLM 批拍职责**（决策席职=裁决
+merge+票翻+常径机派）；零 LLM 补拉闸候选集仅 `派单`(决策席)/
`rate-limit:auto` 挂起——**`已批` 不在任何自动径候选**。

死锁链：已批件等 LLM 发派单 → LLM 只在有待裁时跑 → 无待裁日已批件
永不派单 → 补拉闸永不拉 → **全队列饿死**。今日实证：T-0344/0345/0346
三已批挂账>25min，20:47 手踢 service 1 秒空拍零产出，账面无派单行。

为何今日才炸：待裁集（收口类）全天非空，LLM 批拍顺带派单掩盖了缺口；
T-0343 零 LLM 优化后首次干净队列即暴露——重构削面时「派单」这一隐藏
职责未迁。
