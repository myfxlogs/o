  共享 docker 测试库（o-postgres-test 字母族 a~e）；
- O_TEST_PG_DSN 注入面+字母容器租约协议不清——两跑抢同库
  →Migrate/锁等待→10min 超时→整戳红→重跑（一票付两遍）；

- 假红的真害：红戳≠码病但闸语义上无法区分——重跑是唯一

## 面（钦定）

① **测试库卫生清扫件**：周期件（脚本或 timer）扫
   o-postgres-test 族——陈旧事务>阈（如30min）→
   pg_terminate_backend；遗留测试 schema>阈回收；
   死元组膨胀>阈→VACUUM；清扫行为留痕（ops_event
   或日志戳），不清生产库面禁越界；
② **租约隔离**：check_all 起时给本跑分配独占测试库
   （字母族池化领取/端口固定映射树 hash），无空位→
   排队等库非互踩；DSN 注入与租约结果一致——
   禁出现「租A注B」；
③ **超时假红标识**：go test 超时败（panic: test timed
   out）且栈卡 DB/pgx→戳 .mode 附 `env-contention`
   标——假红可区分于码红（审裁读戳面 T-0397 同形），
   不禁真超时断言；
④ **fail-closed**：租约判不准（容器枚举败/映射撞）→
   落共享库+warn 留痕，不猜不占——争用允许但可观测。
