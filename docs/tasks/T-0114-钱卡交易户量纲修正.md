## 病灶

`/api/overview` money 行量纲分区不一致：
- `交易户`：`amount`=WS 帧 `eqUsd` 美元等值（设计真源，money_card.go:140）
- `资金户`/`Earn`：`amount`=原生币量
前端 `main.ts` 对非 USDT 行一律渲染 `${amount} ${ccy}`——
交易户行 `23.2569 ETH` 实意 $23.26 USD，美元额被挂上币单位。
业主实持 ETH=0.0113（spot 0.00998+earn 0.0013），显示误放大 ~2000 倍。

## 修法（径自裁，语义钉死）

二选一：
- **A（荐）**：交易户行后端补原生币量字段（WS frame details 内
  `availBal`/`eq` 实持量——若无则此径闭）→ 前端照旧渲染原生量+$usd
- **B**：交易户行 `amount` 不改（eqUsd 真源不动），前端按 `section`
  分区渲染——交易户行不挂币单位尾（美元行只显 $值），
  资金户/Earn 行照旧原生量

**禁**：把交易户行 NAV 真源换原生量估值（eqUsd 是钦定口径）；
禁全局统一为美元（资金户/Earn 原生量展示是钦定「真金白银看实物」）。

## 验收锚

- [ ] 交易户 ETH 行不再出现 `N.NNN ETH` 形（或显真实原生量）
- [ ] USDT/USD 行不受影响；读件缺/尘币口径零回归
- [ ] NAV 数值不变（eqUsd 真源未动）
