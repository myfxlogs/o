## 背景

M1 funding 对冲需私有面：余额/持仓流+双腿下单。凭据自 nox 提取（业主已授权）：备份包 `nox-keys-20261023.tar.gz` 的 pg dump（`app_secrets`/`exchange_configs` 密文列）+`.env` 内 `NOX_MASTER_KEY`。master key 原值搬（禁轮换），经密钥文件径入 PHASE。

## 验收标准

- [ ] `NOX_MASTER_KEY`→`PHASE_MASTER_KEY` 密钥文件落位（`/run/secrets` 径或 worktree 约定路径；**值不入仓不入对话**）
