> 立单：决策席 2026-10-27（SG 私有 WS 死亡取证）

## 病灶实证（决策席取证在案）

SG o-core 生产日志循环死：

```
[okxpriv] 连接终：login 败 fail-loud: {"event":"notice",
"msg":"WebSocket port 8443 will be retired soon.
Please migrate to port 443.","code":"64010"}——2s→4s→8s→16s→32s→1m 退避打满
```

**venue 官方退役通知**——`okxpriv` 拨 `wss://ws.okx.com:8443/ws/v5/private`
login 被硬拒（code 64010），非抖动非凭据病，是**端口结构性死亡**。

私有流死→`md_account_events` 私有频道停→兜底 REST 现读加压→
guard 净权益现读 `http 429` 限频（日志在案）——System 页「私有 WS」
红、「REST」黄同源一根。

## 修法钦定

两处硬编码常量同迁（venue 通告全端口退役，公开面当前侥幸在通
但同命，一并迁防二茬病）：

- `internal/data/okxpriv/collector.go:24`
  `wss://ws.okx.com:8443/ws/v5/private` → `wss://ws.okx.com:443/ws/v5/private`
- `internal/data/okxws/collector.go:25`
  `wss://ws.okx.com:8443/ws/v5/public` → `wss://ws.okx.com:443/ws/v5/public`

（`wss://ws.okx.com/ws/v5/...` 无端口形亦合法——带 443 显式更防歧，
钦定显式。）
