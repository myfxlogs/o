# T-0169 分域切换——DSN 切 PG-md+SG 镜像接管+48h 双写对拍（D-0030 §九/反证锚）

## 态：候派（等 T-0168）
## 立项：决策席 @ 2026-10-26
## 决策档：D-0030

## 施工
1. 对拍期：collector/research **双写**（PG-md 正写+SG 旧表旁写）48h，
   对拍脚本逐表比 count/max(ts)/抽样行。
2. 切换：旁写停→SG 旧 md 表改镜像表（DDL 同源零转换）→projector 接管。
3. 回滚预案演练一次（projector 停+DSN 指回——D-0030 §九）。
4. 72h 后实拍：SG PG CPU/隧道载荷/lifecycle 扫拍时长——对 D-0030 反证锚。

## 验收锚
- SG PG CPU 降 ≥40%（r3 下修：SG 本地共写留存）、隧道载荷降 ≥80%、lifecycle 扫拍回分钟级（三锚任一
  不达→反证锚触发，D-0030 复审）。
- 账链面（fin_*）零触动实证：切换前后 fin_cashflow/fin_position 行哈希一致。

## 承接观察项（T-0167 验收钉入）
- **fin_0069 无种子回填**：fin_active_set 触发器只随行变入集——SG 应用后
  已存在的 open 仓/非 retired 策略不入集，谓词源首日为空集。切 SG 轮换前
  补 `INSERT ... SELECT inst_id FROM fin_position WHERE closed_at IS NULL
  UNION SELECT inst_id FROM fin_strategy WHERE state<>'retired' ON CONFLICT
  DO NOTHING`（fin_0069 内一行幂等），或 projector 首 reconciler 直算集。
- **fin_0066 去重成本**：SG md_funding 超表体量大，DELETE USING 自连去重
  一次性慢——轮换窗口预评估。
- app_config 缺席 PG-md（T-0167 观察项 a）：DSN 切换前裁——投影第九桥 or
  config 双 DSN。
- 清道夫双实例（SG 钱径+PG-md 侧）归本票配装。
- SG 暴力计数复核基线口径：journalctl -u ssh 24h=0 vs 施工基线 2,840——
  复核前先钉计数源（sshd 日志落点）。
- **eval 自然键冲突（T-0168 验收钉入）**：fin_opp_eval 另有
  UNIQUE(inst_id,template,direction)——dev 重评存量键产新 id，投影按 id
  upsert 会撞 SG 自然键→批回滚→毒丸重启环。**首选 COPY SG legacy
  fin_opp_eval+fin_proposal 行入 PG-md**（id+自然键+dedupe 面一次继承，
  序列自然落高位）优于裸 setval；次选 setval+冲突行按批隔离留痕。
- **projector 可起三缺**（T-0168 施工移交）：a) SG o-core 轮换（fin_0066~70
  应用——含 funding UQ 去重窗预估）；b) SG projector_rw 角色（八桥 upsert+
  position/strategy 读+registry beat+app_config 读）；c) md 序列对齐
  （守卫文案即指引，或上条 COPY 径）。
