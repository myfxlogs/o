### 实现摘要

1. **假成功门**（缺陷①）：incubate 在 `wait` 后算 `alive=EPOCHSECONDS-s_ts`
   与回音基线——`rc=0 ∧ alive<MANAGE_MIN_ALIVE(30) ∧ ECHO_LOG 零增量`=
   `FAIL 假成功拦截` 落 spawn 日志 + 告警 + rc=5（增量含 unrecognized_model
   则 rc=125）。成功判据=壳存活×产物双证，不再单信退出码。
2. **零静默死**（缺陷②——根因=门1径 wrapper 是 feishu-ingress 普通子进程，
   15:58:21 `systemctl stop` 的 cgroup 连坐 SIGTERM 实证：EXIT trap 不覆盖
   未陷信号→无 exit 行、租约未释）：
   - **scope 自逃逸**：wrapper 起首 `systemd-run --user --scope` 重入
     （`MANAGE_SCOPED`/`MANAGE_TAG` 内代沿用），已在 `.scope` cgroup 或
     `MANAGE_NO_SCOPE=1` 跳过（门2 dispatcher spawn_scope 径不双套）；
     创建败=fail-closed 告警拒裸跑回退（T-0257 同律）。
   - **遗言钩**：TERM/INT/HUP 显式陷（死因+先杀壳）+EXIT 统一落
     `wrapper-exit rc=<n> cause=<因> tail=<末行上下文>`；信号死另发告警；
     exit 行缺席=SIGKILL 级（残余径：租约陈化+下代夺约日志兜底）。
   - **setsid 发壳**：TERM 时 `kill -- -$CUR_PID` 整树随葬，零孙辈孤儿
     （旧版实证孤儿 `sleep 600` 挂靠 systemd）。
3. **模型名解析**（缺陷③逐字定因）：`glm-5.3[1m]`/`sensenova-6.8-flash-lite`
   非脚本传参（MANAGE_MODEL 空→`--model` 未注入），是
   `~/.claude/settings.json` 的 `env.ANTHROPIC_DEFAULT_<tier>_MODEL` 解析
   链产物——该文件在两供应商配置间轮换（token.sensenova.cn↔open.bigmodel.cn，
   17:05/17:24:32 两次 mtime 实证，故各拍打印名不同）。`unrecognized_model`
   =CLI 内置模型表校验遥测（query_source=sdk），上游 router 按原名接受——
   **非致死**（16:28/16:53/17:25 三次共存实证，皆完成工作 rc=0）；15:53 死
   与它无因果（真凶=cgroup 连坐）。落地：死法增量含此名→`FAIL 模型名被拒`
   +rc=125 **直切异壳**（同壳重试无谓）→异壳败=「双壳模型名均被拒」告警。
4. **附修存量 bug**：`incubate "$other" || rc=$?` 成功径不赋值→顶岗成仍报
   124/125 假败+误报双败——已 `rc=0` 归位（staging 条目
   shell-wrapper-rc-stale-and-tr-multibyte 同记 `tr` 多字节坑）。
