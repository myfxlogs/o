## 背景

T-0221 已落 Liquid Glass 玻璃卡（blur+saturate+镜面高光边+内发光+双层投影）。设计令再进三件：噪点纹理层（真实磨砂质感）、hover 微交互加强、玻璃上下边缘 1px 渐变高光线（折射边缘）。

## 目标

全站卡面玻璃质感三件套——`.card` 材质段单点改，全站卡自动继承（含 T-0220c 新 KPI 卡），零逐卡复写。

## 验收标准

- [ ] 噪点纹理层：SVG feTurbulence data-URI 平铺，opacity ~3%，卡面覆一层（pointer-events:none 不吃交互；border-radius 继承不溢出）
- [ ] hover 微交互：translateY(-3px)（现 -2px 加强）+border 亮起+内发光加强；`prefers-reduced-motion` 降级保留（现役块不破）
- [ ] 玻璃面上下边缘 1px 渐变高光线（上亮下淡——真实玻璃折射边缘）
- [ ] 降级链不破：@supports 无 backdrop-filter 走不透明表面降级、reduced-motion 停动——两态目检过
- [ ] `vite build` 绿；全站卡面（Overview/TRX/System/Review）目检一致生效
