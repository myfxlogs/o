# T-0092 「钱在哪」降噪——在册逐行，账外聚合单行

> 业主令：卡面太杂。第一性=只看我需要关注/能使用的钱；遗留/杂币逐行=噪声。

## 钦定口径

- **在册币种**（LedgeredCcy：USDT+成交腿基币）逐行直显——照旧
- **账外/遗留币种**不逐行——每分区聚合**一行**：「遗留资产 N 种 ≈ $X」（N=币种数，X=USD 估值合计；无 tick 估值的按 0 计入但 N 照数）
- NAV 口径不变（总资产仍含全部）；API 行可全量返回，聚合在渲染层折（保未来 drill-down 余地）
- 三分区结构保留（交易户/资金户/Earn），区头不动

## 验收锚

- 卡面每分区 ≤ 在册行数+1 聚合行（当前=交易户 2+1、资金户 1+1、Earn 1+1 形）
- 遗留合计额 ≈ 逐行加总（抽样一币核）
- 遗留行不可点不展开（业主钦定不关注——venue 是唯一事实源，深挖走工具）
