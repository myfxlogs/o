### 三、语义新证（换源评估关键——票面病灶「md_funding 只落已结算费率」双向不实）

- `fundingRate`（current_period 制）=**当期待结算实时预测**，非已结算值：① 帧间变动实采为证（二.2）；② DB 时序亲证——`md_funding` 行 `recv_ts` 早于 `ts`（如 ETH-USDT-SWAP 行 ts=10-30 08:00 拍、recv=10-30 02:56，结算前 5 小时入库）——存的是期中实时快照。
- **真结算值在 `settFundingRate`/`settState`（现行帧新字段），未采**；`md_funding.funding_rate` 列=期初首见实时值冻结——`store.go:80` `ON CONFLICT (venue,inst_id,ts) DO UPDATE SET recv_ts=now()` 不刷值列（审计旁支注记亲证，且该冻结同样伤 funding_rate 口径本身：既非结算值、亦非结算时点终值预测）。
- 即：**预测数据源实际在流（fundingRate），采集口径双错位**（把实时预测标成已结算 + 冲突谓词冻结首见值）。
