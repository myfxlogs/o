# T-0198 投影臂镜像批写 40P01 死锁复发——同键双写撞锁根修

> 状态：待施工
> 域：可靠性/投影臂 · 决策席直派（审计尾账 2026-10-27 夜）

## 病灶实证

`o-projector` 日志 15min 内 3 发 `mirror batch[N/M]: ERROR: deadlock
detected (SQLSTATE 40P01)`——非一次性。机制：镜像批（多行事务按
到达序锁行）与 SG 本臂 okxws upsert（队列序锁行）在 SG md_ticks/
md_mark_index 同键集合上交叠→锁序不一致死锁。败批整弃（行写入
无 partial），下拍 watermark 幂等重追可愈——但窗口内「镜像陈行」
+告警噪音，且持久错配下可放大滞差。

## 施工面（建议，施工可裁）

二选一或并施：
- **锁序归一**：两侧写件批内按冲突键排序再写（collector insertBatch 与
  projector mirror 同序=锁序一致死锁结构性消除）——md_ticks 按
  (venue,inst_id)、md_mark_index 按 (venue,inst_id,channel) 等逐表
  对齐冲突键序。
- **死锁重试**：镜像批捕获 40P01→有界退避重放（≤3 拍 jitter）——
  通用兜底件，不根修锁序但可消噪。

钦定下限：死锁不再以 ERROR 裸曝+log 降级为可计数 WARN；锁序归一为
根修钦定（两写件同表同键集的恒律）。

## 验收判据

- 构造同键双写压测不再死锁（桩锚或实录）
- 40P01 复发率实证归零（部署后 ≥1h 日志对拍）
- 票面无坑注
