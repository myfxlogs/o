## 病灶（业主实屏两症）

① 中列瓦片（生产机/主机资源/采集）间空白过大——疑似列
   容器 space-between 或 grid 行高被拉伸；
② 采集卡 exch-head 展开时左列被向下拉、整页抻高——列间
   联动：同行 grid 行高按最高卡走，或卡片共处一列流。
   钦定语义：**各列瓦片独立排布零联动**。

## 范围

1. 版式结构修：各列改独立 flex/grid 列容器（列内正常
   gap 不随他列变化）——或既有 grid 的 items-start 对齐
   使行高不撑列内间距；
2. 展开行为：exch-head 展开只增本卡高，不推他列；
3. DOM 桩测：列容器独立断言+展开不扰他列几何断言；
4. 人话语义/色标不动（T-0371 面保真）。

## 验收锚

① 展开采集卡→左列卡 y 坐标不变断言（DOM 几何桩测）；
② 列内 gap 正常值断言（无 space-between 拉距）；
③ 视觉回归：现有卡内容零变；
④ check_all+前端测/建绿戳对口；镜像面件并入发窗。

## 红线

- 只改版式层（grid/flex 容器与展开样式）——卡内数据/
  文案/色标零动；
- 不动真单径。
