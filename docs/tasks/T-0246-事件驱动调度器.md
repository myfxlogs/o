## 背景一句话

事件驱动调度取代交互席驱动：订阅 mbusd 事件流（零轮询），按票面生命周期
spawn 无头施工/无头审计，判决唯一真源=票面『状态』机读字段。实现落
**/opt/meta 仓**。

## 钦定界（设计稿 §3+管理修正③）

- **事件契约**：MAIL_NEW to=Dev directive∧T-xxxx→闸（票面存在∧状态∈
  {待施工,待派,驳回:<n<3>}∧pgrep 在飞）→spawn devin-headless-run.sh；
  report∧『收口 T-xxxx @sha』→spawn devin-headless-audit.sh；
  report∧审计判决→过=feishu+升 MANAGE；驳=轮次+1（/opt/meta/mail/
  .rework/<TID>）≤3 重 spawn、>3 异常升 MANAGE；
  STALE/SEAT_SILENT→**仅 report 升 MANAGE 箱，不重复发飞书**（mbusd 已发，
  防业主双条——管理修正③）。
- **判决真源**：票面 `状态` 字段宽匹配（`审计通过|驳回:*`），不猜语义不传话。
- **启动补扫（s1）**：boot 一次扫 Dev 箱未 ack directive+MANAGE 箱未 ack
  report 逐件同路由；幂等由在飞闸保。
- **ack 责任（s2）**：调度器仅 ack Dev 箱 directive；MANAGE 箱只读不 ack。
- **run.sh 接线**：收口/异常分支各加 `MBUS_FROM=Dev mbus.sh send` report
  additive 双轨（relay .done 原样留，M4 才拆）。
- **DRYRUN**：`DISPATCH_DRYRUN=1`→devin -p 调点 echo 桩替。
- **飞书面**：feishu-event.sh 唯一发射口四前缀。
