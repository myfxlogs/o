## 病灶（业主亲指）

前端「在干」卡只渲染 `fin_position` 策略对冲仓——**结构性持仓（DCD）不入列**。
实爆语义错位：DCD `BTC-USDT-261225-95000-C` #11448262 名义 0.0207 BTC
估值 $1,668.71 是基金第二大资产块、基金公司资金所开、收益归基金——却不在
「持仓中」列表。若无策略仓，卡面出空态文案「静持中——**没有持仓**，就是最深
的持仓」——业主所见≠基金实持，所见即所得原则违例。

## 验收锚

- [x] 「在干」列表渲染**全部在持面**：策略对冲仓（现状）+结构性持仓行
  （DCD live 单——productId/ordId/名义+币/行权/到期/USD 估值，数据源
  `c.dcdLive` 同 dcdRows 口径，展示引用非重复入 NAV）
- [x] 静持空态判据修：仅当**基金真空持仓**（无 open 仓、无 DCD live 单）
  才出「静持中」；有 DCD 无策略仓时不得显「没有持仓」
- [x] 读件缺显形：dcdLive 读败时结构性持仓行显「读件缺」而非静默消失
  （不假零不误报——同钱卡纪律）
- [x] 桩测：①无仓有 DCD→列表含 DCD 行无静持文案 ②双有→两行 ③全空→静持
