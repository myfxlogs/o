## 集成落点（决策席已定）

- **前端**：O 前端=vanilla TS 单页零依赖（`web/src/main.ts`，禁引 React 栈）。
  TRX 组件按 O 现有 DOM 风格**重写为同页新分区**：总览页加「TRX 自营盘」
  板块（与持仓/钱卡并列，显式标「自营盘·业绩外」），含四卡——
  账户资源（质押/能量/带宽）、收益雷达（SR APR 榜+当前投票分布）、
  近期 txs、对冲结构。数据经新增 REST `/api/trx/*` 端点（沿用
  `/api/overview` 同构 REST 风，不塞 Overview 响应体）。
- **后端**：采集臂落 `internal/data/trx/`（按 O 域分层非 nox 的
  data/collect 路径）；表迁移续号 0046 起；service 端点挂 cmd/core
  装配，import direction 门禁同步放行。
- **参数**：TRX_STAKE_ADDRESS/能量租赁地址表/采集节奏全部入
  `app_config`（O 律——禁 env 裸键；缺键 fail-closed 采集臂跳过
  不误报）。业主凭据条件请求：质押地址若不可从公开面推断→落
  `fin_condition_gap`（kind=credential/constraint）。
