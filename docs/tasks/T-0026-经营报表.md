## 背景

业主令（2026-10-24）：「日报/周报/月报」——D-0007 承诺「每月以 fin_cashflow 净额交卷」的机读化兑现。报表不是前端（P4 另立），是**定时落表+可取径**的结果呈现件。

## 交付物

1. **`fin_report` 表**（迁移）：`period text CHECK (period IN ('daily','weekly','monthly'))`、`period_start/period_end timestamptz`、指标列（或 jsonb 指标体——按司账既有风格裁定）、`generated_at`、同 period+period_start 唯一约束（幂等可重放）。
2. **报表员工「信使」**（编制册补卡——账本域第四员）：周期到点聚合写行。
   - **日报**（UTC 日切——口径与 `fin_ledger_snapshot` 日切对齐）：当日净 cashflow 合计、累计净值、开仓/平仓笔数、评估卡 proposed/rejected 计数、funding 收入额、Earn 停泊额+当日 Earn 收益、active 策略数、告警计数。
   - **周报**（周一切）：7 日同口径汇总+周化收益折算。
   - **月报**（月初切）：D-030 口径月报——月净收益、年化折算（当月净额/资本基数×12）、月度风控线命中记录、策略退役清单、**对业主交代三行**（赚了/亏了多少、为什么、下一步）。
3. **取径**：HTTP `GET /report?period=daily|weekly|monthly[&n=]` 返最近 n 期 JSON——业主 curl 即得（前端后续消费同径）。
4. **通知推送（可选面）**：若通知凭据在 `app_secrets`（E-3 提取过）则日报落行后推送摘要；无凭据 fail-closed 只落表+日志，不阻塞。

## 判据（纪律）

- **单源**：全部数字出自 `fin_cashflow`/`fin_position`/`fin_strategy`/`md_earn_rate` 在册行——禁重算私账，禁引入账本外数字（核账对账口径同款）。
- **幂等**：同 period+period_start 重跑=UPDATE 非插重行。
- **缺数据诚实**：期内零现金流的日/周/月照样出行（净额=0+「本期无开平」注记），缺席≠静默。
- 资本基数口径：monthly 年化折算分母=期内 `fin_cashflow` 累计净投入（在册可查，不手写）。
