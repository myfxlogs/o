## 背景（根因已亲证——勿重复诊断）

`headless-supervisor.sh:46` 完工判定双锚对 **dispatcher 无头径**单全失效：

1. **主树票面锚**：`grep 收口待审 $TASKDIR/${tid}-*.md` 只查 /opt/o
   主树——收口待审翻转发生在施工支 `t/NNNN-*`（worktree 票面），
   合并回 master 前主树票面恒为「已批/施工中」，锚永不可达。
2. **.done 锚**：`devin-headless-run.sh:86-94` 的 .done 落盘在
   `devin -p` 退出后的全树扫段——T-0265/T-0268/T-0269 三件
   wrapper 与 devin 同亡（日志无「进程退出 rc=」行），扫描段
   从未执行，.done 永不落。对照旧径 T-0261~0264/T-0270 wrapper
   正常退出落 .done 故不误报（T-0267 亦落）。

假警实录（2026-10-30）：16:52 T-0265 / 17:41 T-0267 / 17:50 T-0268 /
18:25 T-0269 四次「进程死亡且未收口」——四件收口自报均先于告警
（relay 17:38:08 / 17:15:34 PR#113 / 18:13:45 @165c24a）。

## 钦定界

修向二选一（施工席择优，可双写）：

- **A 补锚**：无头径收口信号落 .done——收口侦听改到不死进程
  （dispatcher/relay/supervisor 侧 watcher）扫 worktree 票面
  `/opt/o-wt/*/docs/tasks/${tid}-*.md` 或 relay 收口自报行，
  命中即补写 `~/devin-headless-${tid}.done`，走既有 relay §2.7 径。
- **B 拓判据**：supervisor 完工判定增读第三锚——worktree 票面扫
  （同 wrapper 既有 glob）或远端支票面 blob（仅在 `alive==0` 且
  前两锚缺时才查，30s 轮询不得每拍 ls-remote）。

两案公共硬界：**真死讯探测不得稀释**——仅当收口证据（票面翻转/
.done/收口自报）在案才清旗免报；施工中途真亡（无收口证据）照报不误。

## 验收锚

- [ ] 仿真锚①：临时 .said/spawned 布景下伪造「支上票面已翻收口待审
  +无 .done+无存活进程」→ 监理器零假警（贴 SUP_* 试锚跑段输出）。
- [ ] 仿真锚②：伪造「施工中途进程亡+无任何收口证据」→ 死亡警照发
  （贴告警行）。
- [ ] 仿真锚③：既存 .done/主树收口待审两旧锚行为回归不变。
- [ ] `bash -n`+shellcheck（若在机检面）过；meta 仓提交规范从仓俗。

## 范围外/禁线

- 不动 STALL/MAXRUN 阈值、不动 .spawned 代际机制、不动 nf 推送径。
- 禁把「远端支存在」当完工证据（领单即建支=存在≠完工）——证据须是
  票面收口待审态或收口自报行。
- 监理器本体为 meta 仓件——o 仓 docs 面只许本票；跨仓 commit 各守其俗。
