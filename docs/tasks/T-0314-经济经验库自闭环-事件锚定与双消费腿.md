# T-0314 经济经验库自闭环——事件锚定+digest 消化+双消费腿

> 决策席立单 2026-11-03（业主令「自动入+自我学习进化」）。范围/验收/禁线即契约，超单停。

## 背景

经济经验库现状：自动喂径断三处——staging 写容器内文件（`review.go`
`stagingFile` best-effort，o-research 重建蒸发）、触发只 falsified 一类、
消化环无人跑（待归纳零行可裁）；消费端零运行时读面——唯一 canon 条的
回改点当时靠人肉裁定+commit 收紧。**案→经验→行为改变链全断**。

钦定闭环（业主令）：

```
经济事件 → ①确定性检测→PG锚表 → ②digest推裁定 → ③裁定canon
   → ④回改点双腿：机械类→app_config gate.*键（运行时闸每拍读）
                   语义类→skills/自动件（软桥注全会话）→ 行为改变
```

## 范围

### ①锚表 `fin_econ_lesson`（迁移 fin_0102）

fin 域（经济事件源在钱径面；写者=评史官 fin 池——domain.tsv 落 fin）：

- `id/ts/kind/entity_ref/numbers jsonb/status/verdict_ref`
- kind 机械可检测集：`falsified_verdict`/`settled_loss`/`cost_diverge`/
  `venue_degrade`/`flip_exit`
- `numbers` 载荷走 **proto 令**：`EconLesson` 消息 .proto 定义→生成型
  protojson 入列（手写 map=违例）
- 幂等：同 `(kind, entity_ref, 窗口)` 不重复行（unique 或 upsert 语义）
- `status`：`pending→verdicted→canon`；`verdict_ref` 挂裁定行

### ②检测臂（`internal/review/` 扩件）

- falsified→lesson 行，**stagingFile 容器写径退役**（PG 锚即正本——
  旧文件写删干净，测试同步换 PG 断言）
- settled 判决书 `net<0`→`settled_loss` 行（fin_review 结算事件挂点现成）
- `cost_diverge`：fin_cashflow 实费 vs 模板估偏离>阈（默认 20%，
  `gate.lesson.cost_diverge_pct` 可调）
- `venue_degrade`/`flip_exit`：venue_down 实害段+翻面平仓挂现有事件点
- **种案回填**：TRX 口径案+Earn 息充策略利案两行 pending seed
  （迁移或部署后 SQL——让消化环首日有米）

### ③digest 消化环

日拍扫 `status='pending'`→O 群推「经济案 N 件待裁 +kind 分布」→
裁定落 `verdict_ref`+`status='verdicted'`。首版日拍够，不做 LISTEN。

### ④消费腿双轨

- **机械类回改点→`app_config` `gate.*` 键域**：`kill_trigger:<family>`
  →`gate.kill.<family>` bool；`sizing:<x>`/`combo_gate:<x>`→对应数值/
  枚举键。评估器每拍 `cfg.Get*` 直查（热启现成——scout.* 同款读面，
  零重启生效）。**回放断言**：历史亏损行在新判据下必拦（模板回改点
  契约原句照办）。
- **语义类回改点→skills 自动件**：canon 条目→`skills/econ-<slug>/SKILL.md`
  生成件+`tools/kbgen skills` 重建索引——`.devin` 软桥自动注全会话。
- 裁定界面：决策席裁定→标回改点→翻译器落键/skills——先人工裁定机器
  落腿；T-0312 无头决策席上线后全链无人。

## 验收锚

1. falsified/settled_loss 事件→`fin_econ_lesson` 行实证（测试+生产注入各一）；
2. **o-research 重建后 lesson 行不丢**（PG 锚 vs 旧容器 FS——本票修复点）；
3. pending digest→O 群实收；
4. 机械回改点→`gate.*` 键→评估器行为实证（回放断言过）；
5. semantic→skills 件入库+`skills` 命令可见；
6. 全门过（check-env-reads/check_migrations/check_rejects_keys/go test/build）。

## 禁线

- 裁定不自动——canon 改闸归决策席（机械判据生成归机器，闸改动留裁定痕）；
  业主红线三件不在此列依旧归业主。
- `numbers` 载荷 proto 为源（业主令）——手写 map 直存=退回。
- stagingFile 旧径删干净——双轨写=退回。
- skills 自动件只写 `skills/econ-*` 命名域——越域写件=退回。
- `gate.*` 键域只入白名单域（check-env-reads 白名单同步登记）。
