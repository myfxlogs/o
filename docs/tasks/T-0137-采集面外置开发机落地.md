## 设计钉死（决策席定稿 2026-10-26——契约面不许漂移）

### 拓扑

```
OKX ──WS 全量──► dev collecto ──upsert──► SSH 隧道 ──► SG PG md_*
OKX ──REST 60s─► SG o-core（兜底写同键域）────────────────┘
```

### 键域契约（共写语义）

- dev 写：`index-tickers`（现货全量）、`mark_price`（SWAP+期货）、`funding-rate`→md_funding 同源
- SG 兜底写：`spot_last`、`mark_price`（REST 轮询件已在位）
- **mark_price 双写合法**：同键 upsert 最新 ts 赢——dev 断则 SG REST 行顶上，dev 回则自动覆盖，零切换件
- 读面零改：`md_mark_index` 联集取最新行语义天然兼容

### 桥健康指标（免费锚）

`index-tickers` 频道行**只有 dev 写**——其行龄=桥健康直接读数：>90s=桥断（告警走 staleWatch 同径 humanize 注册新 kind `bridge_stale`）；SG 本地 spot_last/mark_price 行龄=兜底健康读数。

### 安全边界

- SG PG 端口只绑 `127.0.0.1`（compose `127.0.0.1:5432:5432`，公网零暴露）
- 隧道：`autossh -L` dev 本地 5433→SG 127.0.0.1:5432，systemd 单元钉存
- **写权收窄**：dev 用独立 PG role（`collector_rw`：仅 md_* 表 INSERT/UPDATE/SELECT——钱径/账表不可写），隧道泄=损失限定在行情面

### 回撤径

停 dev collecto=一键回撤：SG REST 兜底自动续供（≤90s 鲜度），SG 码零改。

### 镜像纪律

collecto 镜像 tag 钉构建 hash 不跟 latest（产研隔离——实验分支构建不得漂移生产采集件）。

## 验收锚

- 开发机 `collecto` 容器跑起，SG `md_mark_index` 行 ts<10s 鲜（WS 级鲜活回归）
- 隧道断→SG REST 接管 ts<90s 不陈死；隧道复→自动回 WS 鲜度
- SG RX 不涨（蒸馏写径 KB/s 级）
- 机检/棘轮全绿
