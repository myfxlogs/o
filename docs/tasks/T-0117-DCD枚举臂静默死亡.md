## 结果回填

- **429 根因**：两臂 boot 同打 `sfp/dcd/currency-pair`+products 族端点撞限频，
  fail-closed 让位成循环静默死亡——修法=cmd/core/dcd.go `get429` 重读件
  （429/5xx ≤3 次指数退避 1s/2s/4s 再让位；4xx 不重试）双消费面共享
  （feed+probe 同径）——错峰语义=单次臂内已 300ms 间隔，跨臂=退避件兜。
- **臂静默告警**：dcd Runner `lastOK/silentRd` 件——超 2×节拍零成功产出=
  ALERT [research_arm_silent] 一次抑刷屏（恢复清标可再报）；
  桩测 TestArmSilentFlag PG 实跑绿。
- **canon**：fail-closed-silent-death 条目高危直写入库。
- 移交面：md_dcd_product 首行+dcd_put 评估行属 SG 部署后实证（本仓零写径）。
