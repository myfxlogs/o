## 目标

`cmd/collector` 加信号蒸馏段：采集拍后由 `internal/research/sigdist`（新包）
算三族信号 upsert `md_signal`——SG 假想官消费的第一批燃料。

## 面

1. `md_signal` 迁移：PK(kind,key)+val numeric+meta jsonb+ts；
   collector_rw 写权白名单 +md_signal（SG 侧 SQL 一次性）。
2. `kind='basis_ann'`：季度 FUTURES mark_price 对 index-tickers 同基币
   →(mark-index)/index×365/到期日数 bps 年化；meta={expiry,mark,index}。
   无到期解析的 inst 跳过如实。
3. `kind='funding_view'`：per SWAP 当期 funding-rate+meta 附
   下一期预测值（venue 返回内含 nextFundingRate 域）+7d 滚动均值
   （md_funding 现读——均值缺数据时字段缺席如实）。
4. `kind='depth5'`：books5 WS 订阅（桥面轻量——**标的集=当时 armed+
   live+probe 策略 inst +funding 前 N 大**的可配置域，非全宇宙——防
   桥自造洪泛）→top5 bid/ask 深度 USD 额+spread_bps。
5. 消费闸：`internal/research/hypothesis` 读 md_signal 作假想输入源
   （本票只接读面——假想生成逻辑改动另票；闸=信号 ts 超 2× 蒸馏拍
   当缺席，禁陈信号当事实）。
6. 验收锚：md_signal 三族行 ts<10s 鲜（桥拍内）；停桥 5min 信号陈死
   不误报；`md_signal` 行数有界（≈标的数×kind 数非时间序列）。

## 禁线

不改 SG o-core 写径；信号件零 venue mutating 径；md_signal 禁时间
序列化（同键 upsert——D-0018）。
