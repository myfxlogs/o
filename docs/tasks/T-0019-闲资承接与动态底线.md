## 背景

D-0006：闲资默认停 OKX Earn；机会净 APR>max(静态底, Earn 现率)才开；开仓前赎回、平仓后回存。Earn 从模板升格为**停泊态+比较底**。

## 范围

1. **Earn 现率采集**（数据域）：OKX USDT Earn 灵活利率→事实行 `md_earn_rate`（venue/ccy/rate/ts）。走公开面（lending-rate 族，按 okx-rest-boundary 界桩选径）；采不到=告警计数不入假值。
2. **动态比较底**（研究域）：评估卡比较器改 `floor=max(min_net_apr, latest_earn_rate)`；net_apr<floor→reject 新 reason `below_earn`（入 verdict/reason 面）。Earn 现率缺失/陈旧（>`research.earn.stale_hours` 键）→退回静态底+告警计数（降级不阻断）。
3. **开仓前置赎回**（交易域扩）：执行链 leg1 前插 `EarnTransfer(redeem, notional+buffer)`——OKX savings redeem 签名径（okx-exec FreshClient 同面）；赎回失败=不开仓留痕（fail-closed，不裸奔）。
4. **平仓回拢**（账本域收口联动）：position settled→检测交易户闲余 USDT>`earn.sweep_min_usd` 键→`EarnTransfer(deposit)` 回存。回存失败=告警计数+重试节拍（不静默）。
5. **留痕**：fin_cashflow kind 扩 `earn_in/earn_out`（迁移改 CHECK 闭集）；资金移动同时落 `fin_risk_decision` kind=transfer 留痕（不走敞口判——内部移动不增敞口，但钱动必有记录）。
6. **员工**：`配管`（闲置承接岗——编制册既有卡：闲置不瞒报/承接位自动枚）Register+BeatLoop(30s)，产出窗=earn 移动行+停泊余额快照。

## 端点参照（业主供 OKX V5 文档#financial-product-simple-earn-flexible）

- `GET /api/v5/finance/savings/balance`——活期持仓余额（amt/earnings/rate）——现率+持仓事实源
- `GET /api/v5/finance/savings/lending-rate-summary?ccy=`——当前利率摘要——md_earn_rate 采集首选径
- `GET /api/v5/finance/savings/lending-rate-history`——利率历史
- `POST /api/v5/finance/savings/purchase-redempt`——申购/赎回（amt+side+rate 参数面——赎回前置/回存动作径）
- `GET /api/v5/finance/savings/lending-history`——申赎历史（对账面）
- 签名/传输/h1 钉死按 `skills/okx-exec`；REST 界桩按 `skills/okx-rest-boundary`（earn 面为事务操作保留域，可留 REST）

## 验收标准

- [ ] md_earn_rate 事实行产出；动态底测试锚三态（net_apr 在静态底与 earn 之间→below_earn 拒；高于 earn→过；earn 缺失→静态底降级+计数）
