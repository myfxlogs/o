# T-0182 TRX 采集三流间歇断供——DNS+401 双病灶定性根修

## 态：可领

## 病灶（24h 实拍）

o-core 每拍三流间歇败（24h 各 4 次——非恒败=间歇型）：
- `[trx] apr 采集败: api.tronscan.org ... no such host`（容器内嵌 DNS
  127.0.0.11 间歇 NXDOMAIN——容器 DNS 层病灶）
- `[trx] txs 采集败: tron GET: status 401`（鉴权层病灶——与 DNS 是两码事）
- `[trx] witness 采集败` 同谱

app_config 有 `trx.trongrid_api_key`——401 面疑 tronscan 端点缺/错 key
（trongrid key 不能通吃 tronscan——两服务两套凭据语义先核）。
TRX 自营盘面（T-0108/0110 全品在役）的 APR/txs/witness 三读面间歇盲=
投票决策吃陈数据——钱径邻面非纯观察件。

## 施工面

1. **401 先定性**：tronscan txs 端点现在要不要 key/在哪挂（`trx.trongrid_api_key`
   是否被误用于 tronscan 径——凭据语义错配典型坑）；如需 tronscan 专用 key=
   条件请求落 fin_condition_gap（业主供件）。
2. **DNS 间歇 NXDOMAIN 定性**：容器 127.0.0.11 embedded DNS 对
   api.tronscan.org 解析抖动——查 resolver 配置/上游；宿主机直解对照；
   必要时 tronscan 客户端加重试+退避（幂等 GET）。
3. 断供期 vote 决策读面=陈旧数据——确认 vote 臂有陈旧度闸（无=禁线，
   数据死而决策照跑=fail-open 形态）。

## 验收锚

- 24h 零 `trx.*采集败`（或败因定性+对症件落位）。
- 若需业主凭据→fin_condition_gap credential/trx 行在册。
- vote 决策侧数据陈旧度闸核证（有=引行号；无=本票补）。

### 决策注（派前钉——迁址裁决）

采集件不迁 dev：三流消费面=vote 决策臂（SG 钱径在役）——采集跟
消费件走（D-0020 本义：分域划「行情发现 vs 钱径运营」非「交易权
vs 只读」）。迁=断供病灶+投影陈旧+桥延迟三病换一病，fail-open
形态放大。病灶在客户端/凭据/DNS 层原地修。
