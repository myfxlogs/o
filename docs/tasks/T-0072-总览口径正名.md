# T-0072 总览三联口径正名（NAV≠现金流求和）

## 背景
页头三数全错（业主实测举报）：
- nav_total=5380 —— cashflow 全求和含 deposit +5251 本金入金（把本钱算成资产）
- pnl_today 同式套当日 → 跟 nav 同数
- pnl_cum=129.2 —— 混入 recon_adjust +106.78 基线调整账
真口径：累计盈亏应 ≈+22.4（trade_pnl+interest+funding+fee 四类经营性 kind）。

## 要求
- **总资产**：取 venue 权益快照（md_account_events account 频道最新帧
  equity/总权益口径——与对账同源的 venue 真值，禁现金流累加充数）；
  多 venue 则分行或合计（票面定）
- **今日盈亏/累计盈亏**：kind ∈ (interest, funding_settle, trade_pnl, fee)
  ——经营性四件；deposit/withdraw/earn_*/recon_adjust 全出局
- **最近动作**：deposit/recon_adjust 可不隐藏（事实流水），但文案须标
  「入金/校账调整」与经营损益可区分
- 每数仍带出生证时戳（所见即所得纪律不变）
- 验收：页头三数与口径公式手算对拍一致（提供对拍 SQL 于回填）

## 非目标
- 不动 ledger/对账语义（那是 T-0071 的场）

## 结果回填（devin-t0002 @ 2026-10-26——总览口径正名交付）

| 验收锚 | 态 | 证据 |
|---|---|---|
| nav=venue 帧总权益（deposit 本金不计） | PASS | md_account_events account/balance_and_position details 全币 eqUsd 求和——与 T-0071 对账同源径；顶字段兜单层帧 |
| 盈亏=经营四件 | PASS | kind IN ('interest','funding_settle','trade_pnl','fee')——deposit/withdraw/earn_*/recon_adjust 全出局 |
| 动作行文案可区分 | PASS | recon_adjust→「校账调整」、deposit→「入金」——经营损益与资本流动分区 |
| 出生证时戳 | PASS | o.Ts=查询时戳不变 |
| 机检全绿 | PASS | cmd 3 测全绿 @5434；build/gofmt/lines 闸过 |

**对拍 SQL（决策席验收用手算锚）**：
```sql
-- 总资产（venue 帧总权益）：
SELECT sum((d->>'eqUsd')::float) FROM md_account_events e,
  jsonb_array_elements(e.data->'details') d
WHERE e.channel IN ('account','balance_and_position')
  AND e.ts=(SELECT max(ts) FROM md_account_events WHERE channel IN ('account','balance_and_position'));
-- 累计盈亏（经营四件）：
SELECT sum(amount) FROM fin_cashflow WHERE kind IN ('interest','funding_settle','trade_pnl','fee');
-- 今日盈亏（经营四件当日）：
SELECT sum(amount) FROM fin_cashflow WHERE occurred_at::date=CURRENT_DATE
  AND kind IN ('interest','funding_settle','trade_pnl','fee');
```
