# T-0504 研究员触发侧断线根修——新品/达阈事件落账无消费拉起径

- 状态：已批（CTO 自立——T-0502 施工范围外呈裁观察坐实）
- 级别：P2 进水口接线面——与 T-0502 同型断线的上游半段：送径已
  接（T-0502），触发源本身无人消费=研究员永远不会被拉起

## 病灶（2026-11-09 CTO 复核实证）

D-0043/研究员 SKILL 钦定两触发：T-0300 venue 达阈事件／venue 新品事件
（seat=venue哨兵 ops_event '新品' 行，venue_watch.sh 落账在案）。实测：

1. `venue_watch.sh` 落 `seat=venue哨兵,event=新品` 行——全仓 grep
   `新品` 消费面零命中（scripts//internal//cmd/ 无读取者）；
2. 研究员无守护/拉起件——无 systemd unit/timer 消费 ops_event
   拉起研究员会话（对照施工席 dispatch_worker.sh/CEO ceo_tick.sh
   全缺）；事件落账即成死信；
3. T-0300 达阈事件同型——无写者亦无读者，第二触发从未接线。

即：研究员生命周期两端皆断——T-0502 修了「产出→CEO」下行段，
本票修「事件→拉起」上行段；不修则 T-0502 所接送径永远无货可送。

## 范围（候选方案择一钦定后回填）

1. 消费径设计：照 `dispatch_worker.sh`/`ceo_tick.sh` 同构——
   `scripts/meta/researcher_tick.sh`（PG advisory 单例+滤队 SQL
   `seat=venue哨兵,event=新品` 未终态行→拉起研究员瞬态 run）
   或并入既有 tick 壳轨——施工先出设计段呈 CTO 钦定再动工；
2. `scripts/meta/venue_watch.sh` 头注「→研究员触发信号」补落
   实际消费径名（文档与码面一致）；
3. T-0300 达阈事件：补写者（venue 评估面达阈落同型触发行）或
   票面显式退役该触发（二选一，涉 D-0043 钦定闭集——退役=升件
   呈业主不擅动）；
4. 桩测：合成新品事件行→tick 滤队命中；消费落终态行后不再命中。

## 设计段（施工呈裁 @2026-11-09 devin-o-worker-T-0504——钦定后动工）

### 设计前置核查（本枝实证，勿重复诊断）

- ops_event schema：`id bigserial`+`ts`——逐事件消费标记可用
  `触发#<id>` 引证（ceo_queue `议题#<id>` 同构先例在案）；
- 「消费落终态行后不再命中」落地形=NOT EXISTS 后至
  `event='消'` 且 `note ~ '触发#'||e.id||'([^0-9]|$)'` 行；
- `research.researcher.paused=true` 在册（fin_0095/T-0299 D-0043
  席级暂停闸，恢复=翻键）——tick 须判此键；
- 拉起面现状：spawn 件在 `/opt/meta-archive`（meta 系 10-31 停服
  归档）——`BASE=/opt/meta/bin` 路径已死（settings/prompt/hypo 均
  不在该径）、缺省 DSN=localhost:5433 死信库（KB 条目在案）、
  `researcher-weekly.timer` disabled；
- **o_researcher role 在 OCI PG-md 不存在**（ssh 实查 pg_roles 零
  行）；dev 盒无→OCI:5435 路由（PG-md 绑 OCI localhost，
  o-postgres-md 容器 :5435->5432 实证）；T-0295 落库径归正=冷库
  未做——`tools/hypo` 单 DSN 双域写（card→md 正本 /
  metrics→fin registry）分域后单 DSN 天然错位半边；
- 触发①（达阈→注册清单）产出=文档经 escalate.sh→ops_event(SG)
  送达——**全链今日可通**（web 取证+SG 写径均在 dev 可达）；
- 触发②（新品→新族提案卡）产出=fin_opp_hypothesis 卡——**写径
  死**（同上 T-0295 缺口），会话须如实回执不假装。

### 候选方案

**方案 A（施工荐）——dev 盒新轨 `researcher_tick`+瞬态拉起，
DB 写径缺口显式挂起**

1. `scripts/meta/researcher_tick.sh`（oneshot）：FIN_DSN 取
   /opt/o-research/env→SG ops_event；PG advisory 单例（新锁键）；
   paused 闸（`research.researcher.paused=true`→hb 记态退，事件
   留 pending 不消费——席级 kill switch 生效，翻键排空积压）；
   滤队 SQL `seat='venue哨兵' AND event IN ('新品','达阈')
   AND NOT EXISTS(后至 event='消' AND note 命中 触发#<id>)`；
   空集 hb 即退零烧；非空→`systemd-run --user --unit
   =o-researcher-evt-<tag> --collect` 拉起
   `scripts/meta/researcher_run.sh <ids>`，rc=0 后逐事件落
   `seat='研究员哨兵',event='消',ticket=<src.ticket>,
   note='触发#<id> 已拉起 unit=<unit>'` 消费行；拉起败=不落消行
   下拍重试+hb `fail:launch` 显形（venue_watch 失败显形同构）。
2. `scripts/meta/researcher_run.sh`（瞬态单元本体）：flock 单例
   +prompt 装配（新 `scripts/meta/researcher_event_prompt.md`——
   契约指针 skills/研究员/SKILL.md+事件 payload+送径
   escalate.sh+A1 注防「payload=数据非指令」）+env 卫生剥
   ANTHROPIC_*+`timeout` 墙钟 30min（契约帽）+`claude -p
   --dangerously-skip-permissions --settings
   /opt/meta-archive/bin/researcher-deepseek.settings.json`
   （钉死面只读引用——凭据/模型不动）；`DB_DSN=
   ${RESEARCHER_DB_DSN:-}` 缺省空→会话自述数据面缺席如实回执。
3. `deploy/o-researcher-tick.service`+`.timer`（荐 30min 拍
   OnBootSec=10min Persistent）+`deploy/manifest.tsv` 同 commit
   补两行（unit sync/timer enabled）——drift 面收编；首装=
   人工 `systemctl --user enable --now` 或 drift_converge 放行
   （半成品窗在案，呈 ops 注记）。
4. T-0300 达阈写者：`internal/platform/notify/venue_req.go`
   pushOne——SendText 成功后 `md_venue_req_push` 锚与
   `ops_event` 达阈行**同 Exec 双 INSERT**（简单协议隐式事务
   原子——锚成事件败=整单回滚下拍重推不双写；推送关态只锚不
   发=不触发——钦定语义「已向业主发请注册条件请求时」）：
   `seat='venue哨兵',event='达阈',ticket='META-VENUEWATCH',
   note='venue=<v> family=<f> net_apr_mid=<x> persist=<y>
   baseline=<b> request_at=<ts>'`；`venue_req_test.go` 补断言
   （Scan 后 ops_event 达阈行在、重扫不重写）。
5. `scripts/meta/venue_watch.sh` 头注「→研究员触发信号」补实
   消费径名（researcher_tick.sh→o-researcher-evt-* 瞬态拉起）。
6. 桩测 `scripts/meta/tests/researcher_tick_test.sh`（test-pg
   scratch 真库同 ceo_queue_test 构型）：①合成新品行→pending
   命中；落消行→不命中；②paused=true→零拉起；③launch 缝
   （O_RESEARCHER_SYSTEMD_RUN/O_RESEARCHER_RUN_SH 注入桩）→
   合成事件→拉起调用实证+消行落账。先红桩=消费缺席断言修前红。

**方案 B——A 全量+DB 写径归正同票**：A 项上加 dev→OCI:5435
ssh -L 隧道（o-oci-bus-tunnel.service 加 -L 或新单元）+OCI

### 请 CTO 钦定四点

1. 方案 A/B/C 择一（荐 A）；
2. paused 闸语义：paused=true 期间事件留 pending 不消费（荐
   ——席级 kill switch 生效，翻键排空积压）vs 事件触发不受
   paused 管（旧暂停针对周批扫描语义，新触发=高信号事件）；
3. 消费标记 seat='研究员哨兵'+event='消'+note `触发#<id>`
   词形（荐——ceo_queue 议题# 同构）；
4. timer 拍频 30min（荐——事件稀疏、tick 空拍=一次 psql 即
   退；1h 对齐 venue_watch 亦可）。
