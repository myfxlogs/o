## 背景

dev 机是验证岗不是营业位。SG（`root@192.229.85.35`，NOX 时期生产宿主）是正式 7×24 位。NOX 有两件可直接继承的部署件，坑都趟过：

- `nox:scripts/deploy_sync.sh`——rsync **git 跟踪面**→SG（.env/logs/产物不推不删）+ stale .go 定点剪枝（禁 rsync --delete，坑正典 deploy-sync-stale-files）+ 宿主侧 rebuild。
- `nox:scripts/backup_pg.sh`——pg_dump+gzip+sha256 滚动 14 份，仓库外 `600` 目录；R2 三落点=rclone+age 加密（NOX 末期 R2 凭据弃配，PHASE 侧 E-5 已授权提取径——若凭据在案则三落点，缺席=本地双份降级+如实记）。

PHASE 差异：部署单元是 **Docker compose**（phase-core+phase-postgres；phase-postgres-test 属 dev 件不上 SG）。SG 侧径=源码同步→SG 上 `docker compose build/up`（不自建 registry，跟 NOX 同型最小面）。

## 交付物

1. `scripts/deploy_sync.sh`（PHASE 版）——git 跟踪面→`$PHASE_SG_HOST:/opt/phase/`（默认 `root@192.229.85.35`），stale `.go`/`migrations` 差集定点剪枝、`-n` 干跑、**禁 --delete**（NOX 坑判据照搬）。
2. `scripts/backup_pg.sh`（PHASE 版）——pg_dump phase 库、仓库外 `/opt/phase-backups/` 600、滚动 14、sha256 校验；R2 三落点凭据在案则装、缺席按 NOX 同款「首失必发+marker 幂等」降级。crontab 行写入票面结果段（实际装机由部署执行步做）。
3. **SG 首装剧本**（结果段实证）：源码同步→compose build→`DB_DSN`+master key 文件（宿主挂 600，**永不进 env/git**）落位→migrate 全绿→phase-core healthy→员工在花名册。
4. **凭据迁移径**：app_secrets/app_config 敏感行是 dev 库内密文——裁定一条迁移径（master key 文件随 SG 安全落位后同 key 密文行 pg_dump 定向复制 **或** 自 nox-keys dump 在 SG 重播），**密文不出会话、不明文落地任何新介质**。业主配合项：SG 宿主 key 文件传递若需人工，明提条件请求。
5. **回切预案**：dev 机保持运行不撤；SG 首跑与 dev 并行（live_switch 仅 SG 侧翻位——双开闸=违令），故障回切=dev 接管采集面，预案写票面。
