# T-0191 ctv 缓存载败饿死窗——重载径根修

> 立单：决策席 2026-10-27（okxws `depth5_no_ctval:13479` 拒因取证）
> 域：`internal/data/okxws`（collector.go ctv 预载+handle.go books5 闸）
> 量级：微件

## 病灶实证（决策席取证在案）

```
depth5_no_ctval = 13,479（帧级拒因计数器）
ctvFeed 载入点：collector.go:183-189——仅连接建立时调一次，
  载败→rej.Inc 一次→c.ctvCache 恒 nil/空
handle.go:46：books5 帧到→ctvCache[instID] 无=depth5_no_ctval 每帧拒
  →一载败=整连接寿命内 books5 全帧饿死（books5 ~秒级帧频，
    8min 重连窗≈数千拒——13479 计数构成实证）
  →下轮重连碰运气才解——「载一次败饿死一窗」结构病
```

当前态：ctvCache 已载（depth5 11 行 0.7s 鲜在流）——**窗口型病灶
非当前死**，但下轮 instruments 读败即复发。

## 修法钦定（二选一，施工判）

**甲案（首选——自愈节流）**：books5 帧到且 ctvCache 空/无此 inst
且距上次重载 >60s→后台重载一次（节流钉死防帧频打 venue）。
载成自通，不绑重连周期。

**乙案**：ctvFeed 独立定时重载（5~10min 一拍——ctVal 本身低频变，
与连接生命周期解耦）。

钦定豁免语义：载败仍 `depth5_no_ctval` 计拒（真源钉不藏），
但**载成即通**不等重连。

## 验收锚

1. ctvFeed 载败场景下 books5 不再整窗饿死（桩或断网重载实证）；
2. 重载节流 ≤1 次/60s（venue 侧调用频不炸）；
3. `depth5_no_ctval` 拒因增速在载败窗后自动归零（不再持续到
   下轮重连）；
4. depth5 行持续流入不回归。

## 状态

驳回:锚2节流键错锚——stale以ctvAt(唯载成更新)计距而非距上次重载尝试,持续载败窗内重载背靠背帧频打venue远≠≤1/60s;锚1重载径零桩/断网实证
审计席：headless @ 2026-10-30

## 判决注记（逐锚对账）

- **锚1（载败场景 books5 不再整窗饿死——桩或断网重载实证）——机制落码、
  实证缺位**：
  - 码面：handle.go:57-76 后台重载径实落（ctv miss+stale→goroutine 调
    ctvFeed→载成填 ctvCache/ctvAt→后续帧过 `ctv>0` 门），载成自通不绑
    重连，「载一次败饿死一窗」结构病机理上可根治。
  - 实证面缺：全包 13 测绿但零测触重载径（`*_test.go` 对 ctvFeed/
    ctvReloading 零命中）；票面在案证据=dev 冷载成功（预载径非重载径）
    +SG 跳订闸——「载败→重载→复通」径从未被桩或断网实证触发，锚括注
    要求的证据形态缺位。
- **锚2（重载节流 ≤1 次/60s——venue 侧调用频不炸）——不达标**：
  - handle.go:49 `stale = !ctvReloading && time.Since(c.ctvAt) > 60s`；
    `ctvAt` 全仓唯二写点=collector.go:201（预载成）+handle.go:74（重载
    成）——**唯载成盖戳，尝试不盖戳**。
  - 持续载败窗（本票标症场景）：ctvAt 恒陈旧→每帧 stale=true，飞行中闸
    一释放下一帧即再点火——重载尝试串行背靠背无 60s 间距，频率≈1/调用
    延迟（快败百毫秒级→数~十 rps；慢超时数秒级→0.2~1 rps），持续无界。
  - 票面钦定机理明载「距上次重载 >60s」（重载=尝试），码面实为「距上次
    载成 >60s」——节流键锚错位；ctvFeed=裸 `PublicGet
    /api/v5/public/instruments?instType=SWAP`（cmd/collector/main.go:
    148-168）零自限，venue 快败环下确被帧频打（429 环还恶化）。
  - 回填行「ctvReloading 飞行中闸≤1/60s」为误述：闸限并发=1，不限尝试
    频率。
- **锚3（depth5_no_ctval 增速载败窗后自动归零）——达标**：
  - dev 面：重载载成→缓存填充→计数停增（机理在码，生效性随锚2 重飞）；
  - SG 改判面：a02ceed 跳订闸实落 collector.go:193-195——`len(
    c.depth5Syms)>0 && c.ctvFeed==nil`→log「无 ctv 读件不订 books5」
    且订阅 args 不入；`AttachCTV` 全仓唯一挂点=cmd/collector/main.go:69
    （git grep 实证 SG o-core 零挂）→SG 侧零订阅零帧零拒，恒零增长；
    未反向挂 feed（禁线守）。
- **锚4（depth5 行持续流入不回归）——达标**：diff 未触 parseBooks5/
  蒸馏写径/5s 节流；dev 侧 feed 非空分支订阅照走；SG 本不产 depth5
  （桥域产出面）→跳订零产出回归。
- **禁线核查——未违**：凭据零入仓零入日志；venue/钱径/部署面零触；
  跳订闸为钦定返修原样（未对 SG 挂 feed）。
- **重飞指向**：节流改锚——点火时盖「上次尝试」戳（新增 ctvTryAt 或
  尝试/载成双戳），stale 判据改 `time.Since(尝试戳)>60s`（含飞行中闸）；
  锚1 补桩/断网重载实证（桩测 ctvFeed 先败后成→books5 帧复通）。
