## 判据

1. 表初版全文随票呈裁——决策批注落票后实施项才生效；
2. 人造尸 pulled→规则#1 命中重派+事件行引证；同票 24h 二次
   不重复动作（防循环闸绿）；
3. 表外动作触发→呈批行非自决；执行失败→升件行且零重试；
4. 全谱零新增 FAIL/SKIP。

## 禁线

- 表外一切=呈批不猜；动作面零碰钱径/venue/资本面；
- 不发明新 seat——动作行 seat 归现行钦定集；
- 规则命中判定须纯机械（查询结果非 LLM 读面）。
