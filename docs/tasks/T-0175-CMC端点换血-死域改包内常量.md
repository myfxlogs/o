## 病灶（生产实证）

`[cmc-ws] runOnce failed: jwt: refreshJWT: Post https://api-cmc.markets.com/api/multirequest: dial tcp: lookup api-cmc.markets.com: no such host`——60s 周期刷。

- `api-cmc.markets.com` = **全球 NXDOMAIN**（1.1.1.1/8.8.8.8/9.9.9.9 实证）——域已死非地缘封锁；mihomo fake-ip 兜底回包造成「可解」假象

- 根因=码面错位：`cmd/core/trx.go` 4 处字面量 `api-cmc.markets.com` 盖过了 `internal/data/cmc` 自带的钦定常量：
  - `NewAuthManager` 形参名 `platformBase`——应传 `cmc.DefaultPlatformBase`（`https://platform.cmcmarkets.com`）
  - `NewPricesCollector`/`NewAccountCollector`/`NewHistoryCollector` 的 `restBase`——应传 `cmc.DefaultRestBase`（`https://connectapi.cmcmarkets.com`）
  - WS 径（`NewWsClient`）已用 `DefaultWsBase`+`DefaultRestBase` 常量——**唯一没坏的面**
- 共享死穴：四径同吃 `refreshJWT`——AuthManager 的 platformBase 死了，REST/WS 全陪葬
