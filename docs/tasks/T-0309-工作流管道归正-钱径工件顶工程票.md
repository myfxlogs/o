# T-0309 工作流管道归正——钱径工件顶工程票行

## 状态

**施工中**（devin-t0309 @ 2026-11-03；原态=已批）

## 背景（决策定论）

「工作流管道」第一性=钱的工件流——工件从「被看见」走向「变成利润」的
在飞集合。工程票（ops_event T-XXXX）=组织内部 JIRA——机制保留但出
业主驾驶舱首屏。现卡「无在飞票」语义错位（拿 meta 流当业务流）。

## 钦定目标

1. **`GetFlowPulse` 扩 `repeated WorkItem work_items`**（同 proto 同请求——
   不新开面）：工件三类 union——
   - `venue`：`fin_venue_candidate WHERE state='measuring'`——ref=venue 名、
     stage=「度量中」、since=首入度量时刻（无行则 metrics measured_at 兜底）、
     progress=「X/30d」可算则算不可算省字段；
   - `proposal`：`fin_proposal` 活态（'fin_armed'+'executing' 族——取码面实
     查态词勿猜）；ref=id/inst_id、stage=「待开仓|执行中」；
   - `position`：`fin_position WHERE closed_at IS NULL`——ref=inst_id、
     stage=「持仓中」、since=opened_at。
   排序：money 近者先（proposal→position→venue），cap 10 行。
   各查询 fail-soft（单类败=该类缺席不炸面）。
2. **③卡下半段换工件行**（消费 fp.data.workItems）：行=ref+stage 徽标+
   在飞时长；空态「无在飞工件」；measuring venue 现 4 行即刻有内容。
3. **工程票管道行撤下驾驶舱**——ops_event 组织流卡整体挪系统页
   （System.tsx 工单板生态位；GetPipeline 端点不删——挪位消费非挂死）。
   「dev 会话 X 在飞」meta 子行照留（T-0308 已定警外中性位）。
4. 验收锚：驾驶舱③卡显 4 个 measuring venue 工件行（生产实证）；
   系统页出现工程票管道卡（现 T-0309 自身在飞当自证）；
   空态文案「无在飞工件」；armed/position 为零时该行缺席非零值。

## 钉注

- WorkItem `{kind,ref,stage,since_ts,progress}`——kind 词串 venue|proposal|
  position（服务端归一）；前端零判据纯渲染。
- fin_proposal 活态词集从 internal/lifecycle 码面取（'fin_armed' 已实查在
  案；executing 词查 gate/exec 写径）。
- 组织流撤舱≠删面——系统页要有同等可读件（业主仍可看组织流，只是不占
  钱径舱）。
- 活水段七段+roster 行不动（上轮刚验绿）。

## 决策席审计注记①（2026-11-03 一轮驳回——两返修项）

骨架方向对（三类 union/fail-soft/cap10/System 挂接），两处失守：

1. **venue 工件 query 读 md_venue_funding——该表 domain=md，SG 无表**
   （to_regclass 实查=f）——子查询拖死整条 SELECT，measuring=4 的工件行
   整类缺席。修：progress 弃 md 表——改读 SG 现成数据（metrics.boards
   persist 比值直显「持续 XX%」或按票面「不可算省字段」置空）。
2. **工程票行未挪位只删**——System 页挂的是同一 PipelineTile（活水+工件
   新件），ops_event 票行 JSX 删除后零渲染：pl.data.rows 死数据、组织流
   业主不可读=验收锚③失守。修：拆两组件——Cockpit 保留 FlowPulseStrip+
   WorkItemsBlock；System 页新挂 OrgPipelineTile 渲染 pl.data.rows 原 JSX
   （票号/标题/步链/灯——从被删块整体挪非重写）。

## 返修① 回填（devin-t0309，同支续提）

- 测试：FlowPulse 族全绿@5434；tsc --noEmit 绿；Cockpit.tsx 287 行达标。
