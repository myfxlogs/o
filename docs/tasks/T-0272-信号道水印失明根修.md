## 背景（急诊诊断已实锤——勿重复诊断，直接施工）

SG `md_signal` 断供真病灶=**投影臂信号道 ts 水印假设「stamped ts≈commit 序」**——对
T-0164 血统回戳行（carry_diff ts=`leastTs(fundingTs,swapTs)`，落后可达 8h）
与一切「写拍时戳略早于提交可见」的行**结构性失明**：行一旦落地时 ts 已在
信号 wm 之后，事件径 `ts>wm` 查不出、10min 活性对账 `max(wm,now-10min)`
同样捞不回——**永久静默丢失，零报错零日志**。

| carry_diff | 22:35:12 | 17:11:50→重启 replay 后 22:35:12 | 血统回戳→出生即在 wm 后 |
| funding_view | 23:09:15 | 17:30:16→replay 后 23:14:08 | 同上（活跃集键在册仍丢） |

## 钦定界

1. **ev_signal 通道撤 ts 水印**：`qSignal`/serve 与 dualwrite 同用
   `SELECT kind,key,val,meta,ts FROM md_signal ORDER BY ts`——无 `ts>$1`、
   无 kind 谓词（**serve 模式 md_signal 全 kind 全量镜像**，撤
   signalGlobalKinds/signalActiveKinds 机制——低体量无谓词收益，谓词
   恰是 mt5_swap/basis_ann 失明根）。bumpWm 保留（无妨）；min-pass 1s
   闸与 upsert 回退防不动。若施工实测全扫有碍（当前 550 行不可能），
   只许加 `ts>now()-interval '9 hours'` 下限（覆盖 8h 血统滞后上限），
   并结果段载明。
2. **回归锚**（测试必写，旧实现必红）：md_signal 行 stamped ts **早于**
   当前 wm（回戳形态）——fixture 实证该行经事件拍后落 SG 镜像。
3. **部署径**：dev 侧 `GOARCH=arm64 GOOS=linux go build -o /tmp/projector ./cmd/projector`
   → scp 盒 `~/o/projector` → `systemctl --user restart o-projector`
   （盒=ubuntu@149.118.58.98；部署后重启 boot replay 自愈，无需回填脚本）。
   ④含 o-core 改动者同船走钦定径 `scripts/deploy_image.sh`（D-0035 锁内径）。
4. **venue 现读 429 退避**（MANAGE-923 同链）：okxexec 私有 REST 读径对
   HTTP 429 加指数退避重试（或等价单飞冷却——施工席择优，dcd 60s TTL
   单飞件可参）；限宽限次（如 ≤3 次、总窗 ≤10s）防拍阻塞，重试尽仍败=
   err 上抛不假零（fail-closed 口径不变）。禁把退避做成「读败返陈值」。
   覆盖 `do()` 层或 fundSaveBalances 调用面——凡事件拍 venue 现读径
   皆须免疫 429 单点炸拍。
