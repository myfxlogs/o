# T-0166 PG 分域设计——行情/研究域 PG-md 落开发机，SG 只收蒸馏结果（D-0029 Ⅱ 级·设计票）

## 态：已批（设计票——先过设计验证再派施工）
## 立项：决策席 @ 2026-10-26
## 域：架构 / 数据面
## 决策档：D-0029

## 病灶（实拍）

单 PG 三域共宿：采集秒级 tick 行经 SSH 隧道跨公网写 SG PG（`md_ticks`
2,418 万写/`md_mark_index` 3,638 万写——隧道抖即采集断，mihomo 事故实证）；
研究面长查询钉 xmin 殃及账链 vacuum（T-0154 实案）；无 role 级隔离。

## 设计产出（本票交付=设计文档，非码）

1. **域边界表**：逐表归 PG-md（开发机）/PG-fin（SG）——原则：
   钱径读写面（fin_position/execution/cashflow/venue_bill/strategy/
   config/app_secrets/employee_registry）归 fin；派生面（md_*/fin_opp_eval/
   fin_opp_hypothesis/md_signal/fin_surface_gap）归 md；**fin_proposal 为
   跨域桥表**（研究产出→执行消费）——归属与同步方式是设计核心。
2. **跨域同步机制三选一（设计验证裁）**：
   a. 逻辑复制（PG publication/subscription，fin_proposal+md_signal 精选键）
   b. 应用层推送（collector/research 进程写 SG 侧——现 md_signal 有界表语义）
   c. SG 侧拉取（lifecycle 扫拍时经隧道读 PG-md）——隧道依赖不解，劣选
3. **迁移链分流**：`migrations/` 按表前缀分 `md_`/`fin_` 两链，
   `check_migrations.sh` 扩断言（md_* 键域断言已有）。
4. **新鲜度契约**：D-0022「信号陈=不存在」律成跨库闸——SG 消费只认 ts；
   + T-0164 血统闸（派生信号 ts=max 上游 ts）同契约。
5. **双库运维面**：备份/保留账（T-0153 fin_data_retention 分库）/
   pgguard 双实例/体积哨兵分库。

## 设计验证锚（过此方派施工）

- 域边界表零歧义（每表一归属，桥表同步机制钉死）。
- 隧道载荷估算：分域后隧道流量降 ≥90%（tick 行不过桥）。
- 回滚径：分域失败可单步回单库（两库 schema 同源保证）。
