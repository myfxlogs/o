## 背景

现告警=计数器+log（`ALERT [guard] …`）。真钱上线后临界事件（回撤触线、kill_switch、LEGGED 回滚败、对账差异、重试耗尽）必须**即时到人**——等日报已晚。飞书 Client+chat_id 全在案，本票只是把它们接到事件源。

## 交付物

1. **`internal/platform/notify/alert.go`**——`Alert(ctx, kind, msg)` 薄封装：复用 FeishuClient（token 缓存在案），`notify.feishu.enabled`+`feishu.chat_id` 同键 fail-closed（缺=只 log 不炸）；**去抖**：同 kind+同 payload 指纹 5min 内只推一次（计数照加），防循环告警轰炸。
2. **接源**（注入 notifier 接口，各域零改网——调用点注入即可）：
   - `dd_hardline_tripped`（guard/ddline）触线拍推：dd 值/阈/peak/cur/触线段
   - `close_gave_up`/`dd_close_exhausted` 首次升级推（逐拍计数不逐拍推——去抖天然处理）
   - `rollback_failed`（execution）+ `transfer_ambiguous`（earn mover 歧态势）
   - `ledger_diff_alert`（ledger 对账差超限）
   - `kill_switch` 状态变迁推（true/false 各一报，不重复）
3. 推送文案≤6 行：`[PHASE告警] kind | 关键数字 | 时间`——可读不求美。
