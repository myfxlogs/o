  （T-0343）不重复消费。
- **消解机械二择**：note 携 `await=<档>:<参>`（全角冒号归一）；
  仅 `绿窗` 档机械复查——`go test -count=1 -run ^<Test>$`
  （可选 `[pkg:]` 前缀收敛包面，缺省 `./...`，timeout 900s
  钉死）在 `/opt/o`（master 部署树）复跑即判；
  绿→`dispatch_worker.sh` 同 systemd-run 钦定径续跑派工
  （模型档从原派单备注恢复同式，拉起行 note 标「挂起续跑」）；
  未消（复跑红/非绿窗档不可机械判/无 await/畸形缺参）且
