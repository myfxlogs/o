1. **序倒转**：SendText 成功才写 `fin_push_ledger`；失败=不记账+`push_err` 计数+log——
   下个期界/拍自然重试（幂等锚语义归位：行=「已送达」非「已尝试」）
2. **降级显性**：push_degraded/push_err 计数挂 `rejects` 输出面（md/status 或
   Overview 捎带）——丢报要能被看见，不能只在内存里
3. 日历 `md_calendar_push` 同序检查——若同病（插行先于发送）一并修
