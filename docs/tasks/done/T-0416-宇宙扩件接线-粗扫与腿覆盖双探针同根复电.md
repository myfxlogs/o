```
宇宙扩件=符号目录供给件(venue catalog枚举):
  okx=/public/instruments?instType=SWAP(REST一次全谱)
```

  ExpandSymbols 已挂而 hunger 探针 legUniverse/depUniverse 无扩件
  读径——`*` 形硬拒 fail-closed。o-core 日志实证（docker logs
  o-core）：`腿覆盖探针败/依赖对探针败: 宇宙读败: okx.symbols=*
  宇宙扩件探针未挂`（部署 9e5ff5ad 起每拍两行）。
- **粗扫零行**：扫臂码在但**从未进生产二进制**——OCI `~/o/collector`
  二进制戳 Nov6 09:24 UTC 早于 T-0401 合入（10:59 UTC），`strings`
  无 `okxscan`；PG-md/SG 两侧 md_tick_scan 皆 0 行实证。复电=本票
  接线+`deploy_oci.sh collecto` 换件（部署动作归决策席发窗）。

### 实现摘要（枝 t/0416-universe-wire）

- **供给件** `internal/data/okxws/universe.go` `UniverseCatalog`——
  /public/instruments?instType=SWAP 一次全谱+FUTURES 季度面实读，
  `swap`=live -USDT-SWAP 目录全集、`all`=swap∪基币现货∪quarter
  期货∪uly 指数键；TTL 常驻缓存（缺省 10min，装配可钉）一处供给
  多处消费；读败上抛不污旧账 fail-closed。原 cmd/core
  `universeExpander` 与 cmd/collector `universe()` 两复制件归一
  （禁第二套归一链）。
- **探针挂点**（范围①③）：hunger.Sensor 新增 `expandUniverse` 缝+
  `AttachUniverse`；legUniverse/depUniverse 两同形件归一
  `subUniverse(ctx)`——`*` 形挂线实读、未挂=原 fail-closed 语义
  不动、读败=fail-closed 不虚构。lifecycle.Runner
  `AttachUniverse` 透传（桩 sensor 静默让位）。cmd/core：
  `uni.Symbols` 同注 collector ExpandSymbols（续 fin_venue_untradeable
  黑名单滤）+`lr.AttachUniverse`——同一供给件实例两处消费。
- **粗扫臂**（范围②）：现径查清=REST tickers SWAP 单请求全谱
  （非读 okx.symbols——不败在同根，生产空因=二进制陈）。谱域仍
  按票面改读目录件：`ScanPoller.Catalog` 挂 `uni.SwapSet`——
  tickers 行须∈目录全集才落表，目录读败=fail-closed 本拍让位。
- **提名闸**（范围④并入）：hypothesis `AttachCatalog`+nominateSub
  前置闸——inst∉宇宙目录=拒提名+`nom_offcatalog` rejects 计
  （MUU 型假符进盒前闸）；目录读败=提名让位 fail-closed。
  user_intent 径已天然受闸（symDomain 选符域=md_ticks∪目录谱）。
- **数据流.md**：新增「宇宙扩件·符号目录供给件」段（供件语义+
  四消费面+既有 okxUniverse 读者让位照守注记）。
