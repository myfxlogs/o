## 病灶（业主实屏两症）

① 中列瓦片（生产机/主机资源/采集）间空白过大——疑似列
   容器 space-between 或 grid 行高被拉伸；
② 采集卡 exch-head 展开时左列被向下拉、整页抻高——列间
   联动：同行 grid 行高按最高卡走，或卡片共处一列流。
   钦定语义：**各列瓦片独立排布零联动**。

## 范围

1. 版式结构修：各列改独立 flex/grid 列容器（列内正常
   gap 不随他列变化）——或既有 grid 的 items-start 对齐
   使行高不撑列内间距；
2. 展开行为：exch-head 展开只增本卡高，不推他列；
3. DOM 桩测：列容器独立断言+展开不扰他列几何断言；
4. 人话语义/色标不动（T-0371 面保真）。

## 验收锚

① 展开采集卡→左列卡 y 坐标不变断言（DOM 几何桩测）；
② 列内 gap 正常值断言（无 space-between 拉距）；
③ 视觉回归：现有卡内容零变；
④ check_all+前端测/建绿戳对口；镜像面件并入发窗。

## 红线

- 只改版式层（grid/flex 容器与展开样式）——卡内数据/
  文案/色标零动；
- 不动真单径。

### 实现摘要

1. **根因实锤**（两症同根=grid 行轨耦合）：旧 `.quad`=两列多行
   grid——行轨高=同行最高卡，行内两列物理共享行高。短列卡底到
   下一卡顶=行高-本卡高+gap 被动撑大（症①）；采集卡 exch-head
   展开→行轨增高→下一行两列同沉（症②）。`align-items:start`
   只防卡身拉伸不防行轨共享。
2. **Cols 独立列容器**（范围①钦定径一）：`components/ui.tsx`
   新增 `Cols` 件——每列一 `.cols-col` flex 列容器（gap 恒
   24px、min-width:0），各列独立格式化上下文，他列几何物理
   不可达；`.quad` 只留桌面双列面（≥1100px `1fr 1fr`+
   `align-items:start`），`.cols` 基面窄屏单列回落。
3. **System 页列归组**（范围②）：五卡 JSX 逐字未动仅重归两列——
   列1=生产机|主机资源|工程票管道，列2=采集|席位（业主⑬ 位序
   沿用）；exch-head 展开只增本卡高（exch-rows 块只在本列流内撑高）。
4. **DOM 几何桩测**（范围③）：`web/scripts/quadcols-domtest.mjs`
   11 断言——真件渲染（Cols）+真 CSS 提取（gap=24px 驱动几何）+
   展开双场景 y 对拍；入 `npm test` 链。
5. **坑条目**：grid-shared-row-height-cross-column-coupling 在案
   （含 floats 非等价解实证依据+适用边界），索引/技能清单 kbgen
   重建。

### 偏离说明

- 窄屏单列序=列主序（整列1先于整列2）——行序交错与列独立
  物理不可兼得（DOM 列归组必然改变单列回落序），钦定「各列
  零联动」语义取后者；桌面双列位序与旧 grid 完全一致。
- `.duo`（Cockpit/Review/Trx 双卡并排面）未动——单行两卡本就
  无列内堆叠、无行轨耦合病灶，非票面钦定面。
- 几何桩=SSR 真件+真 CSS 规则提取+列容器独立语义几何推算
  （本仓 domtest 范式无浏览器——几何断言层级与 flowpulse
  CSS 静态断言同构，结构/规则/数学三层互锁）。
