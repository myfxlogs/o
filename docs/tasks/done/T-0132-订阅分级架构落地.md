## 修法方向（施工裁，照 D-0019 裁据）

- **订阅分级**：全宇宙=funding-rate+mark-price+index-tickers；
  活跃集（fin_position 在册+fin_proposal armed/proposed+fin_strategy
  非退役的 inst_id）加订 tickers
- 活跃集订阅=**动态重订**（集变化时增删订阅帧，OKX subscribe/
  unsubscribe 支持增删 args——不重建连接）
- 读面对账：eval/提案链用到的价格统一走 mark/index 面——审计一遍
  谁在读 md_ticks（open 定价/平仓/guard 失衡），活跃集无 tick 者
  fail-closed 或降级 index 价（按判据语义裁）
- **T-0129 并入**：现货订阅断流在此架构下实修（现货活跃集才订
  tickers/index-tickers）
- **T-0130 并入**：netmeter 序位修复+部署后实测带宽报表
