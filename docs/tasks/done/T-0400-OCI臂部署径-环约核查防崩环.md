- 领取：待施工
- 优先级：P1——生产部署面（断流实证）
- 收口移交归：决策席

## 实证（票面锚）

- 部署链双轨无档：`deploy_image.sh` 只管 SG o-core 镜像；
  OCI 臂（collector/projector/o-research 裸二进制 systemd）
  靠手搓 GOARCH=arm64 build+scp+restart——无锁无健康闸
  无出处闸无环约对账；
- 新 collector 要求 `SG_PG_DSN`（桥写径 fail-closed）——
  旧服务单元 env 缺→`code=exited status=1` 崩环 76 轮；
  断流期 fin_opp_eval 静默（闸有效）但 feed 全停；
- 同事故类:projector/o-research 新件换后未崩但同险在。

## 待查先决（先红桩=事实断言）

新 collector 要 SG_PG_DSN 是**设计内**（桥写职责并采一体）
还是**设计外回归**（桥写本属 projector 被误带）——
对账 dual-write 架构意图（docs/数据流.md+git blame
SG_PG_DSN 引入 commit），定性后定修法：
  - 设计内→服务单元补 env+部署规程含环约对账；
  - 设计外→修码退界，部署规程仍要建（独立价值）。

## 范围

   落票面回填）；

## 结果回填

- **归属定性：设计内（桥写职责并采一体）**。证据非口报：①`cmd/collector`
  创件 commit `01452b0b`（T-0137 返修）即持 `os.Getenv("SG_PG_DSN")→log.Fatal`
  fail-closed 面（git log -S 实证——非新码新需）；②T-0137 票面钉「PG 写径经
  env SG_PG_DSN」；③`deploy/o-collecto/compose.yml` 内嵌 SG_PG_DSN 同值
  （T-0234 注记：名残 SG 实值=盒本机 PG-md :5435，md 正本面）；④数据流.md
  凭据面「collector_rw DSN→盒本机 PG-md(:5435)」。病灶=部署面无环约对账
  ——compose 径 env 内嵌键齐，裸二进制 systemd 径 env 件（escrow 值面）
  缺 SG_PG_DSN 键，换码无预检直换即崩环。修法落「服务单元 env 补装+
  部署规程环约对账」径。
- **实现摘要**：`scripts/deploy_oci.sh`（149 行）——OCI 三臂部署唯一径：
  出处闸（脏树/HEAD∉origin/master 拒，O_DEPLOY_ALLOW_UNPUSHED 放行）→
  盒上 mkdir 原子部署锁（holder+30min 陈锁+O_DEPLOY_FORCE，token 对拍释锁）
  →本地 arm64 build（CGO0 trimpath）+`<bin>.sha` 出处留痕件→staging scp
  +sha256 双端对拍→**环约对账**（`deploy/oci-env-contract.tsv` 需求集
  req=1/0 分列 vs 单元 Environment+EnvironmentFiles 实读键集——req 缺键
  拒换并指路凭据域，可选缺键 WARN）→`cp -a` 备份→install 换件→restart→
  健康闸（ActiveState∧NRestarts 不翻饼；写流断言 md_ticks max(ts) 推进：
  collecto=盒 docker psql 本机 5435，projector=env 件 SG_PG_DSN 经容器
  psql 客端打隧道 15433 侧同断言，research=活性闸）→败即回滚旧件复检。
  ExecStart/EnvironmentFile 径不硬编——systemctl --user show 实读（单元
  漂移免维）。`deploy/oci-env-contract.tsv` 新件（码面 os.Getenv+log.Fatal
  事实抄）；`deploy/o-collecto.env.example` 补件（对齐 projector/research
  先例——collecto 先例独缺）；`docs/工程纪律.md` 4.3 补 OCI 径宣示行。
- **测试证据**：①`bash -n`+check_all 全链绿（build/vet/env/migrations/
  bridge-audit 四列/test 全谱过，绿戳 866bbfc2）；②夹具桩测（fake ssh/
  systemctl 沙盘）：collecto env 缺 SG_PG_DSN→DRY_RUN 拒换报「必需 env
  键缺: SG_PG_DSN」rc=1；env 补齐后→干跑三臂环约全绿 rc=0。
- **偏离说明**：①live env 值面补齐（o-collecto.env 加 SG_PG_DSN 行）=凭据
  域写径，施工三禁不碰——归业主/管理 escrow 径；本票交付的预检闸保证
  「缺键拒换」物理生效，验收锚③实换码待凭据域补键后周末窗执行。
