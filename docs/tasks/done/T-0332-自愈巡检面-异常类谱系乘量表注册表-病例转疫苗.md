### B. 量表注册表（新件——`internal/meta/gauges` 或脚本面）

量表=确定判据（SQL/systemctl/git 输出+阈值），**零 LLM**：
每表登记 {name, class, query/命令, 阈值, 升件模板}；新表入册=
新坑条目修法的**强制伴生件**（病例转疫苗写进坑条目模板）。

### C. 拍（照 dm_tick 对形）

`gauges_tick`（cron/timer 或并入 metabus 兜底拍）：全表跑→
触阈→`ops_event 升件` 行（seat=巡检闸，note=量表名+实测值+阈值）
——零 LLM 拍，LLM 只在升件打包段上工（COS 面）。

### D. 首批量表（钦定五座起步）

- `armed_aging`：fin_proposal armed 且 age>ttl 计数>0→升件
- `escalation_aged`：升件行 N 小时无裁决跟进→升件
- `heartbeat_dead`：ops_headless 死道>7天计数
- `branch_cemetery`：t/* 未合枝计数>阈（与 T-0331 GC 联表）
- `arm_zero_output`：各扫描臂近 N 拍 concrete 产出=0（断供类）
