## 病灶实证（决策席对拍在案）

T-0414 merge `d3f7feb4` 上 master 后手动 `dm_ledger.sh flip` 两拍：

```
拍①/拍②输出同：`[dm-ledger] 批帽 40 到——余票下拍续`

工作树零变、ops_event 零新行。
```

根因（码径对拍实锤）：

- A 面扫描 `ORDER BY l.ticket` 升序——T-0002 起全史票排新票前；
- 收敛守卫 `[ -z "$tf" ] && status_done "$df"` 只在 rc=0（已识别完成态）
  跳票；`status_done` 对古票面三形态全不认（`| 状态 | 完成 |` 表形、
  `### 状态：审计通过` 题头形、无状态字段形）→ rc=2「未识别」；
- rc2 判不过守卫 → 恒入 ACT_T 动作集；
- 锁段 `flip_status` 同锚同式 → 同 rc2 → 不写不翻（`moved=0 && fsrc≠0`
  不入 DONE_TS）→ 零 git 变、零状态变；
- **后果闭环**：同一批 ~40 件 rc2 古票每拍重集吃满 MAX_BATCH=40，
  `ORDER BY l.ticket` 排在新票前 → 新完成票（T-0414 实证）永不进集——
  A 面结构性饥饿，B 面补登不受影响（另查询径）。

实测：T-0002/T-0009/T-0014 三件同式 rc=2；done/ 古票体量估 300+ 件
（远超批帽，饥饿为常态非边缘）。

## 钦定判（裁后施工面）

修径择一判词留痕：

- **A. rc2=保守跳**（荐）：status_done rc=2（未识别形）视同「不属本轨
  翻面责任」直接 continue——rc1（确认识别非终态）才入集。古票异形
  态翻面非机械轨职（认不得的形不碰=机械轨本分），语义最贴票面
  「已收敛票不进动作集」原意。
- B. 状态形谱扩充：收 `| 状态 |` 表形/`### 状态：` 题头形入识别——
  谱张面大、古票史形繁，收益面窄（翻它们无营运义），不荐。
