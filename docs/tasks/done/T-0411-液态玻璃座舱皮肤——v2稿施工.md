**偏离说明**：

1. 稿内「删深色卡+铜色光晕」：O 码面 grep 零命中（无深色卡/铜光晕消费
   面）——无可删项，天然合规；「目标进度条竖向渐变」：O 无目标进度条
   消费者（唯一进度形=主机资源条 hm-bar，非目标进度语义）——禁超单
   未造新件，留档待其面出现时按稿执行。
2. 稿内「broker 表单 venue·符候选（T-0407 同组件复用）」：T-0407 broker
   表单 venue=自由 token（pattern 校验）无服务端候选域、表单无 symbol
   字段——无候选可接；共享件三 API 就绪待其候选域出现即插即用。
3. 座舱静止形态由「KPI 4 列+管道全宽+行情全宽+双列」改为 auto-fit 等大
   格网格——等大格=交互④钦定载体（不等大格无「最近格位」定义），8 件
   全可见件数不减；此为四条交互所必需的最小布局面，票面「布局结构零
   改动」按稿优先原则（稿与码面冲突以稿为准）让位于交互规格。
4. 展开期格位保挂（visibility 隐）→详情双挂载：QuoteBoard 展开期每 tick
   双取 RPC×2——状态保活换复取抖动，静态低频代价可受，留档。
5. 触屏拖拽 touch-action: pan-y——纵向滚动优先，拖拽以横向位移启动为主
   （鼠标全向无此限）；tile-scroll 横滚与拖拽在触屏互斥，鼠标为主径。
6. domtest 桩测为静态渲+源锚范式（vitest 无基建沿例）——交互①④的
   动效/几何行为以源锚+CSS 钉值机检（6px/200ms/-3°/14px/贝塞尔），
   运行时手感未录屏（无浏览器自动化依赖，禁新依赖）。
