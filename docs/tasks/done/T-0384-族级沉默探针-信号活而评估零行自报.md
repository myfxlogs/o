## 结果回填

实现摘要：
- `internal/portfolio/hunger/silence.go`——`Sensor.ProbeFamilies`：
  模板全集（fin_opp_eval.template DISTINCT）逐族两数对拍——驱动
  kind 7d 鲜行数 × 同族 7d 评估行数；信号>0 且评估=0 → ops_event
  `族沉默` 行（template/信号kind/信号行数/证据锚=全映射 kind 计数）
  + `升件`（esc_class='观测盲' esc_scope=template——判类册追记在案）
  ——24h 同窗去重（esc_class+esc_scope 等值键，同族至多一报）。
- kind↔template 映射零硬编码两链派生：①假想卡族注册表链——
  fin_opp_hypothesis.requirements.data_needs 声明词与 md_signal
  kind 实集求交（surface↔template -↔_ 归一+族前缀同认，
  stake_carry-TRX→stake-carry），首命中 kind=驱动信号；
  ②命名规约链——首词元 kind 前缀（funding-hedge→funding_view）。
  两链皆空=族源非 md_signal（ticks/dcd/能力面直读族）出域不报。
- 挂点：hunger Sensor 同缝扩——lifecycle.hungerTick 先于 Detect
  每拍皆测（饥饿与否无关；败情 hungerEscalate 自报不拖主拍），
  tools/hungertick 拍壳同形。
- 信号死=不报（源死归 ops_face 活性面非本域）；从件鲜不翻驱动判。
