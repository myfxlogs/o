## 背景（业主判词）

「开仓/平仓了没人管——赚了还好，亏了后如何处理没人管」。
ops_decision 已记开平理由（记忆面），但**读理由复盘的人
不存在**——记录只进不出。本案=补读侧：每平仓自动结案
判定，常态落账、异常生成监察案喂裁定席。

## 钦定语义

```
结案判定机(lifecycle平仓拍同槽机械件):
  读刚闭仓的:触发类(资金翻/drift/超龄/手平/守卫他类)+
  持仓时长+settled幅+ops_decision理由行
  正常件(判据内): verdict='expected'→ops_decision补
    outcome行——案闭环
  异常件(任一): 
    · 秒级开平(<N分钟开仓即平,T-0419实证15s)
    · |settled|>notional×阈%(本次-49%实证)
    · 触发类不在认知集/残袋>0
    →生成监察案入裁定席pending集
    (kind='trade_postmortem',载仓ref+结案数据)
裁定席侧(已存在只接新kind):
  逐案裁→verdict: bug→升件立票/市况→归档/
  章程(裸袋处置类)→升业主——裁词回ops_decision
量低期: 无案零烧——拍内判定,有案才耗裁定席会话
```

## 范围

1. 结案判定件：lifecycle 平仓路径同槽——分类+判据集
   （时长阈/结算阈/触发类集参数化 app_config）；
2. 正常径：expected 判词写 ops_decision（首消费面实
   证——记忆×结果对照）；
3. 异常径：监察案生成件（kind=trade_postmortem 入
   裁定席 pending 集——读现有案源表找最小挂点）；
4. 裁定席 skill 补 trade_postmortem kind 受理节
   （verdict 词集+处置三分支）；
5. 参数集入 config 钉 + docs/数据流.md 补监察段。
