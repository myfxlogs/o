② **租约隔离**：check_all 起时给本跑分配独占测试库

   排队等库非互踩；DSN 注入与租约结果一致——

③ **超时假红标识**：go test 超时败（panic: test timed

④ **fail-closed**：租约判不准（容器枚举败/映射撞）→
   落共享库+warn 留痕，不猜不占——争用允许但可观测。

### 实现摘要

- **件② 租约隔离**（新件 `scripts/testdb_lease.sh`，check_all source 调用）：
  池=字母族容器名实存映射（base 5434+b..e 5435-5438）；领取=flock -n
  试锁 `/tmp/o-testdb-lease-<port>.lock`（fd8，进程退自动释）；优先序=
  树 hash（TOPKEY）旋转（端口固定映射树 hash，两树同起少撞首选）；全忙
  →排队等首选（上界 1800s 同树锁纪律，超时报 holder fail）——排队非
  互踩。DSN 注入与租约**同源双向推导**：池内领取→DSN 从锁得端口拼出；
  外部 DSN（人工择闲径）→按其端口锁同文件（租A注A），端口出族→不锁
  不改动+warn。fail-closed（票面④）：池空/docker 枚举败→不注入 DSN
  （DB 桩测试 skip 径，不猜不占）+warn；锁面开文件败（判不准）→落共享
  库 5434+warn——争用允许但可观测。docs-only 档不占库。go test 子进程
  8>&-（租约 fd 不传泄漏测试进程）。
- **件① 卫生清扫件**（`scripts/gc_test_schemas.sh` 升级，T-0186 乙案
  扩全；**文件名不动=cron 05:23 契约零手术**）：四扫——①陈旧事务：
  idle in transaction >30min→pg_terminate_backend（active 永不杀：
  30min=go test 单包超时上界，超之的 idle-in-tx 无合法主体；active 长
  事务只留痕观察行）；②孤儿 schema：t_* 族带 `_gc_born` 出生标
  （testutil T-0435 起自动落）超 24h→回收、标新鲜→在租豁免、无标
  （历史/手工件）→T-0186 原语义照清（日拍全清先例在案，非收紧）；
  ③死元组：库级 Σn_dead_tup>200000→VACUUM (ANALYZE)（在线形；FULL=
  一次性手术留人工径）；④遗留库：`o_test_<后缀>`（KB 专库隔离径遗留）
  零活连接→DROP、有连接跳过。生产禁越界 fail-closed：端口白名单
  5434-5438+db 必 o_test，出族 rc2 拒连（守卫先于一切 psql）；public
  永不进清面（relic 处置=决策/管理席待办不动）。留痕=日志戳
  `[gc-testdb] <ts> inst:<port> <动作>`（票面「ops_event 或日志戳」取
  日志戳，不写生产 ops_event 面）；单跑互斥 flock（在途 skip）；
  `--dry-run` 零副作用观察形。
- **件③ 假红标识**（check_all 内 `run_go_test`）：go test 输出 tee
  全吞落盘（KB pipefail-grep-q 修法②同形，下游不早退上游 rc 真传）；
  红转时 `panic: test timed out`∧栈含 jackc/pgx 帧→`.mode` 尾附
  `env-contention` 行+stderr 显式 warn——假红可区分于码红（审裁读戳面
  T-0397 同形）；非 pgx 栈的真超时不标（真超时断言不禁）。
- **testutil.Pool**：schema 创建后落 `_gc_born` 出生表（+now() 行）——
  件①扫②的 24h 豁免锚；information_schema 断言面零触碰（两处在用皆
  specific-table 存在性查询，实证无碰撞）。

  （testutil +1 表=加法非重造，票面「别在已有分片设计上重造」遵从）。

  （未含本件）仍直注 5434 且 schema 无标——gc 扫②对无标件按 T-0186
