## 背景（产侧亲证在案——勿重复诊断）

### 件① 本金虚高（口径漏减出金）

`cockpit_face.go:64-66` `Money.Capital = Σamount WHERE kind='deposit'`——**不减
withdraw**。产侧实证：fin_cashflow deposit 4 行 Σ=17251、withdraw 1 行
amount=**-10000**（FIX01 销警行，负号记账=仓规），真本金=7251 现显 17251。
`crow.Deposited=Capital` 同源错带——敞口分母（`tot.Deposited×10%`）连带虚高。

### 件② 206 假异常（无头面 dead 冤判）

产侧实证：`SELECT state,count(*) FROM ops_headless GROUP BY state` →
**dead=206（seat DM=203/Dev=3）、done=37**，全部 updated_at=2026-10-31
（本日 sweep 重派生），206 票日志文件全在 ~/devin-{headless,audit}-*.log。
前端 `hlBad` 计死亡/停滞/逾期——206 全数上「① 存活」卡异常注行。

根因=泵锚族漏两类正常退场：

1. **旧锚方言漏匹**：旧式审计日志尾锚=`排查审计 T-NNNN 退出 rc=0`
   （例 devin-audit-T-0001~T-0014），`reExitAudit` 只认 `无头审计`——
   203 行 DM dead 绝大多数出此。
2. **自由票号漏匹**：锚族 `(T-\d+)` 票号段不认 WAKEFIX/CMCTOMB/EXTAUDIT/
   REWORK/DOOR5 类运维票号——该类日志无锚命中→`procAlive=doneF=false`→dead
   （`watch.go:101` 补扫尾判「无进程且未完工=死」）。
3. **run 系见证退出无「exit」档**：`进程退出 rc=0`+`退出但全树无收口待审`
   （BASESWP 实证——meta 票收口标记在 /opt/meta 树，全树扫面不及）→
   `reNoDone`→dead。业主定性：**正常收工≠异常**。

## 钦定界

### 件①

`Capital` SQL 改 `kind IN ('deposit','withdraw')` 净和（amount 已带号——
**禁 ABS/禁再乘 -1**）；`crow.Deposited` 同源自动跟随禁另写；
proto `capital` 注释改「deposit−withdraw 净额」。

### 件② 六态机键（五态+exit）

- **exit=正常终态**（新增）：wrapper 见证退出锚在案且 rc=0 但无收口证——
  正常收工。
- **done=完工**（收口铁证）：.done 件 / 收口待审命中行 / 审计退出锚（
  `无头审计` **及 `排查审计` 旧方言**）rc=0。
- **dead=异常**（收窄）：rc≠0 见证退出，或无任何退出锚见证的进程消失
  （静默判死/补扫无锚且无进程）。
- stalled/overdue 语义不动。
- 锚族票号段放宽：onLog/sweep 面锚 `(T-\d+)`→兼匹自由票号（`[A-Z0-9-]+`
  类受限构，禁 `\S+` 裸放宽误中正文）；`reReport` 捕获组语义不动。
- `reExitRun` 须捕获 rc 值供 reNoDone/sweep 尾判分流 exit|dead。
- sweep 补扫同套派生：末锚时序裁决——见证退出 rc=0 无收口=exit；
  audit 系退出锚 rc=0=done；无退出锚且无进程=dead。
