# T-0398 部署窗触发律——攒批变职责

- 状态：待验（施工收口移交决策席——三态壳实跑+SKILL/纪律落文）
- 领取：devin-o-worker-T0398 @ 2026-11-06（DM 常径机派）
- 优先级：P2——运维节奏件
- 收口移交归：决策席

## 背景（业主实证钉）

完成行记「镜像面攒批窗」是标注非触发——SKILL「按需部署」
无判据,批积到 11 件仍不发。业主问「为什么没有触发部署」
=触发律缺位实证。

## 钦定语义

`skills/决策席/SKILL.md` 增部署窗节（或并入班次节）：

```
应发判据(两条件同时成立→当班发窗,非可选项):
  ①批非空: origin/master 与生产部署 SHA(deploy_image.sh
    写的 tag)间 diff 含镜像面路径非空
    (镜像面=入镜像的路径——cmd/internal/proto/web/
    migrations/Dockerfile* 等非 docs/**,skills/**,*.md 件;
    判据机读不自猜)
  ②无挡件: 在飞 o-worker 码件=0 且待裁/收口待审面含
    码件/迁移件=0(docs/研究件不挡窗)
兜底节拍: 批积首件起 ≥24h 未发→无论条件②发窗并升件报
输出面: 发窗=deploy_image.sh 单径;发毕 ops_event 部署行
       携批件清单(票号集)
```

判据做成机读壳 `scripts/meta/deploy_window_due.sh`
（输出 应发|不挡件未到|批空 +理由行,exit 码分态）——
DM 每班查一次,不靠感觉。

## 范围

1. `scripts/meta/deploy_window_due.sh` 新件（机读两判据）；
2. `skills/决策席/SKILL.md` 部署窗节落上语义；
3. `docs/工程纪律.md` 对位一行（部署宣示旁）。

## 验收锚

① 壳三态输出实跑对（批空/有挡/应发各一实证——拿当前
   master↔部署 tag 实测应发为真）；②SKILL 节语义与票面同义；
③ 判据不吞 docs-only 件（docs 批永不触发窗）；
④ check_all 绿戳对口。

## 红线

- 部署单径/SHA tag/推戳闸零动——触发律=给 DM 加职责,
  不动部署机制本身；
- 判据禁读票面状态行当输入（票文不可信——以 git diff+
  ops_event/systemd 实态为准）。

## 结果回填

### 实现摘要

- **`scripts/meta/deploy_window_due.sh`**（新件，机读两判据+兜底）：
  - 部署 SHA 双源——SG `docker inspect o-core` 权威实拍（`o-core:<sha12>`
    剥前缀）→ ops_event 末次 `rc=0` 部署行退化径；双源皆败/SHA 本地
    不可解=exit 78 环境缺不滥判；
  - ①批非空=`git diff <dep>..origin/master` 经镜像面过滤非空；镜像面=
    非镜像白名单（docs/**,skills/**,*.md,scripts/**,.github/**,.devin/**,
    tools/**,deploy/** systemd/env 件——collab §11「meta 脚本/systemd
    检出即生效」同口径）补集，未列名路径按镜像面计（宁滥发勿漏批）；
  - ②无挡件=在飞 `o-worker-*` unit 逐票判码件（支 diff∪wt 脏面∪wt
    未推 commit 碰镜像，同票多支全枚举防 head-1 挑净支漏判；支树皆
    不可定保守按码件）∧ dm_queue.sh 待裁面逐票支 diff 判码件（已批
    未派无支=未动工不挡——挡它永锁窗）；待裁面不可知 fail-closed
    按有挡计；
  - 兜底节拍=批积首件（最老镜像面 commit）龄≥24h→无论条件②发窗+
    ops_esc `DEPLOY-WINDOW-OVERRUN` 升件行（24h 前缀去重）；
  - 三态 `state=应发|有挡|批空`+reason 行（批件票号集自 commit subject
    提 `T-\d{4}`，发窗批件清单面）；exit 0/11/10/78/1 分态。
- **`skills/决策席/SKILL.md`** 部署窗节（班次节与形态域界间）——每班一
  查走壳、应发=当班发窗非可选、发窗=deploy_image.sh 单径、发毕
  ops_event 部署行携票号集。
- **`docs/工程纪律.md`** §4.3 对位一行（推戳闸条后）——触发律机读化
  钉+部署径唯一重申。
