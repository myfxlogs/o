# T-0068 UI 根路径直开（去 /ui/dist/ 尾巴）

## 背景
o.myfxlogs.org 已通，但活页藏在 `/ui/dist/index.html`——FileServer 嵌了 dist 层，`/ui/` 还吐目录列表。业主直开路径应为 `/`。

## 要求
- `GET /` → 直接返 index.html（或 301 → 活页，取一）
- `/ui/` 不留目录列表（FileServer 禁列目录或改挂载径）
- 静态资源路径随动，SSE /api/watch 不受影响
- 验收：公网 `https://o.myfxlogs.org/` 直接 200 出页面，无多余跳转
