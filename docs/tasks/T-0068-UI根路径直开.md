# T-0068 UI 根路径直开（去 /ui/dist/ 尾巴）

## 背景
o.myfxlogs.org 已通，但活页藏在 `/ui/dist/index.html`——FileServer 嵌了 dist 层，`/ui/` 还吐目录列表。业主直开路径应为 `/`。

## 要求
- `GET /` → 直接返 index.html（或 301 → 活页，取一）
- `/ui/` 不留目录列表（FileServer 禁列目录或改挂载径）
- 静态资源路径随动，SSE /api/watch 不受影响
- 验收：公网裸域 `https://o.myfxlogs.org/` 直接 200 出页面（地址栏无任何路径尾巴）

## 结果回填（devin-t0002 @ 2026-10-26——根路径直开）

- `GET /` → index.html 直返（ReadFile 单层无跳转）；`/assets/` 静态径随动；`/api/watch` SSE 零触碰。
- `/ui/` 目录列表面拆除（FileServer 目录模式→单件直读——禁列表根修）。
- 机检：build 绿（npm build→go build CI 序承 T-0067）。
- 部署验：公网 `https://o.myfxlogs.org/` 200 直开=决策席部署后实证位。

### 返修回填（2026-10-26——assets 子树+根精确匹配）

- **fs.Sub 子树挂接**：`fs.Sub(web.Dist,"dist")`——embed FS 全件带 dist/ 前缀，指根=资产 404 病灶根修；FileServer 原路径直吃（StripPrefix 画蛇添足已纠）。
- **根精确匹配**：`r.URL.Path != "/"` 判——"/" 兜底全捕病灶修，API 错路 404 不吃 HTML。
- **本地实证**：httptest FileServer `/assets/index-aei6WEgS.js` → **200**（404 病灶钉死）。
