# T-0222 bridge-reverse 桥源表授权对账闸——GRANT 无册崩环根治

> 状态：待施工 | 优先级：P2
> 立项：决策席 @ 2026-10-28（T-0214 验收实证+两次顺带锚落空——
> 证明非顺带量级单立）

## 病灶

T-0214 验收实证：`md_earn_rate` 加入 bridge-reverse 域后投影臂
崩环——SG 侧 `projector_rw` 无 SELECT（同域 fin_strategy/
untradeable 早授）。根因：**手工授权面无册**——迁移零 GRANT，
新表入桥域时无人机检 projector_rw/research_rw 授权面，漏配
即生产崩环（fail-closed 表现=对账即退）。

## 钦定修法（二选一，施工调研决）

- 甲·机检化：`scripts/check_schema_live.sh` 或 check_migrations
  加「domain.tsv bridge-reverse/bridge 域表 × 桥消费者角色
  （projector_rw SELECT / research_rw 按需）」对账项——登记表
  即名册，差即红。
- 乙·迁移化：GRANT 进迁移链（桥域表新建迁移同件落
  `GRANT SELECT`）——schema 即授权册。

## 验收锚

- 现面全绿：三桥源表（fin_strategy/fin_venue_untradeable/
  md_earn_rate）授权对账过。
- 桩测：模拟缺授权桥域表→闸红报差件名。
- 选型理由+「手工授权面从此有机检覆盖」回填。
