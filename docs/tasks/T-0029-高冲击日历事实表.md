## 背景

funding/carry 账本的日历价值=标注高冲击窗口（FOMC/CPI/NFP 前后 funding、basis 易抽风）。日期一年前已公布——**种成事实表最省**，零第三方 API 依赖、零新凭据。v1 只进评估卡 evidence 当注解，不动判据不做闸（阻尼/拒开是后续候选，届时另裁）。

## 交付物

1. **`md_macro_event` 事实表**（迁移）：`event_date date`、`kind text CHECK (kind IN ('fomc','cpi','nfp'))`、`title text`、`source text NOT NULL DEFAULT 'seed'`——2026 余下+2027 已公布日期种子（FOMC 8 次/年、CPI 月度、NFP 月度——以官方公布历为准录入，种子行在迁移内 INSERT）。
2. **评估卡注解**：funding 评估产卡时查「event_date − today ≤ `research.macro.horizon_days`（新键默认 `"2"`，热启，缺键=不注解 fail-open 此面）」的最近事件，写进 evidence `macro` 字段（kind+date+days_out）——纯标注，不改 net_apr 判据。
3. **报表可选面**：fin_report weekly/monthly metrics 加 `macro_events` 期内事件计数（顺手件，信使已有聚合径）。

## 验收标准

- [ ] `md_macro_event` 种子行在案（≥15 行，kind 三值齐），表名带 `md_` 事实域
- [ ] 评估卡 evidence.macro 注解实证（近窗有事件时字段在；无事件时字段缺省——不缺为异常）
- [ ] `research.macro.horizon_days` 热启+缺键 fail-open 锚
- [ ] 判据不受影响锚：同一输入下加注解前后 verdict 不变（纯 evidence 层）
- [ ] 机检全绿；CI 绿

## 范围外
