## 裁定范围（DM 钦定——下全归它裁，壳面只钉问题不预设计）

②红线保留：永不机批的域——钱径/方向锚/新venue/权限凭据/部署窗策略/

   误批回退径怎么落）
⑤质量缝：draft 噪音滤闸（本批 8/20 是噪音手裁——物料化前滤 or
   批准后滤 DM 定）

## DM 裁定（2026-11-08 决策席落判——五件逐条钦定）

①**机批类册（哪类直批+册存哪）**：册=app_config 键
`meta.autoapprove.registry`（jsonb：签名→钦定文件径白名单；键写死
`=签名字面或 尾* 前缀键`）。册修=dmconfig 写域归决策席。判据钦定=
**签名粒度**（kind:lesion_key 对签名面——非 kind 全域放权，非
evidence 粒度）。种子四签名（migration fin_0143）：观测盲:* /
写败:LIFECYCLE-HUNGER / 写败:LIFECYCLE-MINER / 账链断:ops_event——
皆探针自发现例行工程病灶，各钦定修复径白名单（钦定径即范围节
机读单源——depgate 对拍零歧义）。新签名入册=DM 裁（钦定例径——
本件不钦定自动入册）。

②**红线词表（永不入册域）**：钱径（下单/平仓/卖袋/转账/签名类——
票面 `执行=人工径` 字面拦）、凭据/权限面、方向锚件、新 venue、
部署窗策略、判词/裁定语义件、组织权界件——此七域**签名永禁入册**，
册内零匹配即零机批（册即红线词表同源——T-0456 ⑤钦定接缝）。
册外签名不是驳回=是滞留等人工/DM 裁，滞留 24h 升件呈 DM。

③**人工径死锁根治**：人工径票面字面拦（manual_lane_check）先于册
判——永不机批；滞留消化径=`dm_autoapprove.sh` 对起草滞留>24h 件
升件呈 DM（`候选滞留:T-NNNN` 前缀行，同票查重一次）。死锁点=「
人工径票等会话拍而会话不扫起草集」——今钦定：滞留升件即入口，
DM 班扫见升件即接手裁（移交今实证径保留——升件是第二径非取代）。

④**机批账面形态**：`ops_event(seat='CEO', event='已批', ticket,
note='机批:<签名>——类册钦定 N 径')`——seat='CEO' 即 T-0456 钦定
批权归径（机批行=CEO 无头本体）。可溯=签名+钦定径数在 note 面+
commit `[角色:决策][T-NNNN] 机批类册钦定范围` 落 git 史；可撤销=
ops_event `驳回` 行（approved 谓词最新行翻驳回自然出列，零专用
撤销词表）。

⑤**滤噪位置钦定=物料化后/机批前同一窗**：机批闸即滤噪闸——噪音
签名天然册外→零机批+滞留升件呈 DM（滤后不删件不留 pending 幽灵；
物料化前滤=否决，因起草行证据链须在 git 面留痕）。
