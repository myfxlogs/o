# T-0349 ①存活卡域界根修——工程席与过期行退出生产存活面

- 状态：已批（COS 例行代理批——业主令「基建工程的决策/裁定/施工都不应该在这里显示，除非服务的不是基建工程；已经过期了的就不用再显示」）
- 级别：P3 显示面——生产存活卡混入工程自监面+僵尸行永陈（同一判据簇 T-0344 假红案姊妹病灶）

## 病灶（实查在案，勿再诊）

`web/src/react/components/metaseats.tsx` 对 `GetHeadless`（`cmd/core/headless_face.go`）
返回行 `ticket.startsWith("META-")` **全量渲染**进 ①存活卡——域界错两层：

1. **工程席混入生产面**：`META-DM`（决策）/`META-VERDICT`（裁定）/`META-GAUGES`
   （巡检）/`META-GC`（GC 拍）/`META-Dev-T-*`（施工工位）全为基建工程自监面——
   与 `fin_employee_registry` 生产岗册同卡=两类域混。
2. **僵尸行永陈**：worker 退出从不写 `ops_headless` 终态（实证：META-Dev-T-0329
   完工 20h+ 仍 `state=alive` 冻结在末次心跳）——过期行在卡面永占注行。
   死活告警正路=gauges `heartbeat_dead` 升件径（表在），不靠卡面陈行堆。

业务面 META 席（`META-REGIME` 分析席 / `META-VENUEWATCH` 哨兵）属业务服务
（研报数据面/机会进水口）——**存活面保留对象**，按业主「除非服务的不是基建
工程」界钉。

## 任务（修法供裁）

1. **域界过滤**：①存活卡 META 注行改白名单制——只渲业务服务面
   （`META-REGIME`/`META-VENUEWATCH`；后续业务面新 META 席按名单册扩）；
   `META-DM|META-VERDICT|META-GAUGES|META-GC|META-Dev-*` 工程面一律不渲。
   （或黑名单剔工程面自裁——施工裁列式并记取舍；`GetHeadless` 数据面不动，
   工程席读面归工单/pipeline 面既有径。）
2. **过期不显示**：白名单内 seat 沿 `metaCadenceS` 判龄；超龄行**从卡面剔**
   （非标红展——业主钦定「过期不用再显示」；死席缺席本身即信号，告警归
   gauges 升件径不赘卡面）。`metaCadenceS` 增补 VENUEWATCH=3600s 实钉
   （o-venue-watch.timer 1h 拍）与 GAUGES=1800s（o-gauges-tick 30min）—
   虽剔出卡面，同名常量册若复用别面仍须对（防常量册与实钉漂移病灶再发）。
3. ops_headless 僵尸根修**不在本票面**（worker exit trap 写终态另案立——
   显示面修复先销业主所见；票内注记此欠账）。
