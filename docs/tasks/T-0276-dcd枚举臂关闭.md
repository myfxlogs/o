## 背景

DCD 退场收口不全（D-0037 收敛令：发现层不加族、存量在飞件走完为止——SG 侧 `fin_opp_template` dcd_call/dcd_put 已 `enabled=f`）：

- **PG-md 侧 dcd_call/dcd_put 仍 enabled=t**（10-31 实查）→ OCI `o-research` 的 dcd 枚举臂 `surfaces()` 读到非空集，持续全量扫描：近 6h `[research/dcd]` 日志 **36,724 行**，evals 全 rejected/unevaluable=纯空扫（OKX `/api/v5/finance/sfp/dcd` 每 30min 全宇宙枚举+逐品闸评，零提案产出）。
- **ops_face「dcd 枚举」健康件**盯 SG `md_dcd_product` 鲜度（warn=2h/dead=12h）——投影末帧停在 10-30 02:41，已越 dead 阈亮红（管理目击时为黄）。
- **持仓零依赖**：SG `fin_strategy` 非 retired 无 dcd/vol_sell（live 17 全 funding-hedge + paper funding-hedge/quarter_basis/perp_quarter）——枚举臂关闭无下游断供；vol_sell 执行腿走 `dcdOpen`（OKX trade REST 径）与本臂/本面无关。

## CTO 裁（勿另议）

1. **config 发射闸，非纯 DB 翻模板**——只翻模板→`surfaces()` 空集→臂不扫，但 armwatch 60min 后鸣 `research_arm_silent` 业主告警（把黄灯换成飞书告警=不合格）。故：
   - `cmd/research/dcd.go` `researchArms`：dcd runner 发射加闸 `research.dcd.enabled`（`cfg.GetBool`；**缺 key 缺省 true**=存量兼容；显式 false=不发射+log 一行退役注）。
2. **PG-md 数据面三钉**（与 SG 侧退役态对齐）：
   - `app_config` 写 `research.dcd.enabled=false`；
   - `fin_opp_template` dcd_call/dcd_put → `enabled=f`；
   - `fin_capability_surface` `okx/dcd` → `enabled=f`（退役面出枚举全集；`dcd-test` 已 f 不动；gapscan 只读键集不看 enabled，无连带）。
3. **`cmd/core/ops_face.go` `healthComps` 删「dcd 枚举」行**——退役采集面无鲜度监控义务；留则永红。行内 fix 文案随删。
4. **部署双径**：
   - SG `o-core`：`scripts/deploy_image.sh`（钦定唯一径——出处闸/部署锁/SHA tag/健康闸机内化）；
   - OCI `o-research`：交叉编 `GOARCH=arm64 GOOS=linux go build -o /tmp/o-research ./cmd/research` → `scp` 至 `ubuntu@149.118.58.98:~/o-research/o-research` → `systemctl --user restart o-research`（**ExecStart=`~/o-research/o-research` 非 `~/o/research`**——勿投错径；`~/o/research` 是 10-28 前旧位）。
