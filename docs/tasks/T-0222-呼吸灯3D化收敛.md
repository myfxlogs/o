## 背景

T-0221 已把呼吸灯从「放大球」改为「珠体+光晕涨落」。业主复判：**仍显大**——珠径+弥散光晕合读出的视觉体量超标。本轮双指令：**尺寸收敛 + 3D 立体质**（玻璃弹珠/LED 灯珠那种小而亮、有纵深感的状态灯）。

## 目标

灯=一颗小而立体的珠：聚光高光斑+球面明暗过渡+底部内影/内凹感+环境接触微影；呼吸保留但光晕弥散幅度收窄——远看「一点亮珠在呼吸」非「一团光在胀缩」。

## 钦定方向（施工可在此框架内落笔）

- **珠径收敛**：`.dot` 基径降档（现 9px→建议 7–8px；`20-cards.css` 席位灯 11px 档同比例收）——「小而亮」非「大而闪」，具体值施工目检定。
- **3D 层次三件套**：①更紧的聚光斑（小高光点非大面渐变）②球面明暗（上亮下暗+边缘暗弧）③`inset` 底部内影/内凹+珠外环境接触微影——立体感来自明暗分层非尺寸。
- **光晕收幅**：呼吸仍走 box-shadow 辉光涨落（T-0221 载体不翻），但峰值弥散半径降档（现峰 ~10-11px → 收缩，珠外辉光收敛贴珠）。
- **捎带统一**：TrxHedgeCard.tsx WS 在线内联点（上轮偏离①遗留）——换 `.dot` 类或同构径向渐变一行，珠体语言统一。
- **铁律不动**：绿缓 ~2.4s/黄快 ~1.2s/红=死=静止；opacity≥0.78 下限；不减动效豁免注释段；三态色映射。

## 验收标准

- [ ] `.dot` 基径 < 9px（grep 断言数值）；席位灯档同降。
- [ ] 3D 件在册：`.dot` 系含 inset 内影或等效球面暗弧件 + 紧聚光斑（grep 断言）。
- [ ] 光晕收幅：呼吸峰 box-shadow 弥散半径 < 现行 10px 档（grep 断言）。
- [ ] TrxHedgeCard WS 点珠体统一（grep：内联 background 平涂消失或挂 .dot 类）。
- [ ] s2 红静止断言不动、节奏/下限/豁免段不动（grep）。
- [ ] 目检锚：System+TRX 四态截图——灯读「小立体珠」非「大点光晕」；前端 build 绿+check_all 绿。

### 实现摘要

- **珠径收敛**：`.dot` 基径 9→8px（`10-shell.css` `.live-dot,.dot`）；席位灯档 11→9px（`20-cards.css` `.chip .dot` + `03-table-chip.css` `.chip .dot.sN`，见偏离①）。「小而亮」落地。
- **3D 层次三件套**（`10-shell.css` `.dot.s0/.s1/.s2` 双层径向，canon 配方）：
  ①紧聚光斑——`radial-gradient(circle at 30% 26%, rgba(255,255,255,.92) 0%, transparent 34%)` 小高光点叠顶层；
  ②球面明暗——`circle at 34% 30%` 上亮（45% 混白）→本体 50%→边缘暗弧收浓（52% 混黑）；
  ③inset 底部内影+环境接触微影——`inset 0 -1px 1.5px 黑38%` + `0 1px 1px ink16%`，落 `20-cards.css` 硬化段（静态灯恒驻）+ 呼吸键帧逐帧同携（防闪烁，T-0221 描环同携法的推广）。
- **光晕收幅**：呼吸仍走 box-shadow 辉光涨落（载体不翻），峰值弥散 `breatheCalm` 11px→5px、`breatheQuick`/`breathe` 10px→4px，息相 3px→2px——远读「一点亮珠在呼吸」。
- **捎带统一**（T-0221 偏离①清账）：TrxHedgeCard WS 内联点（10px 平涂+内联 animation/boxShadow）→ 挂 `.dot` 类一行：在线=`s0 breathe`（breatheCalm 2.4s 与原内联逐字同节奏）、断流=`s1 still`（新 `.dot.still { animation:none !important }` 钳住 `.dot.s1` 1.6s 自息——呼吸=活性语言，降级不装活；原语义「兜底=静止」逐字保持）。组件面内联 breatheCalm 引用清零。
- **铁律不动**：绿 breatheCalm 2.4s/黄 breatheQuick 1.2s 节奏原样；opacity 0.78 下限行原样；红=死=静止终裁三行（animation none !important/transform none/box-shadow none）逐字未动；不减动效豁免注释段原样；三态色映射（--good/--warn/--critical）原样。`breatheAlarm` 死帧与 `.dot.breathe.s2` 遗留辉光行按 T-0221 偏离②先例保留存档未动。

### 偏离说明

1. **涉及面外必要联动：`03-table-chip.css`**（票面未列）：勘查实证席位灯实治面是它——`.chip .dot.sN`（特异性 0,3,0，且导入序在 20-cards 之后）平涂+11px 覆写了 10-shell 珠体与 20-cards 档位，T-0221 的珠体在席位灯上从未生效（业主看到的「大」=11px 平涂盘+大光晕，与本案病诉吻合）。不动它则「灯读小立体珠」在 System 页必然落空。处置：平涂→canon 珠体配方（注释标 canon 指向，两处同步改）、11→9px 同降、T-0173 三色回归意图保全（珠体即三色）、s2 认尸环保留。**交决策席裁**：认可则补涉及面，不认可回滚该文件即可（其余面独立成立）。
2. **20-cards 硬化段不再钉径**（尺寸归还基档单点）：原段 width/height 10px 以同特异性后位压过 `.chip .dot` 11px——席位灯「11px 档」实为死值（生效的一直是硬化段径）。收敛后尺寸单点在基档（基 8px/席位 9px），档位语义归位。
3. **`.dot.still` 新类**：票面钦定「换 .dot 类或同构径向渐变一行」的前者需一处 3 行新 CSS（`.dot.s1` 有 1.6s 自息底噪，兜底静止语义须钳）——属灯规则段最小增量，非超单施工。
4. **20-cards `.dot.s2` 死灯描环（L422-425）为既存死律**（被后位硬化段压住）+`.dot.breathe.s2` 遗留 6px 辉光行同理：既存层叠存档非本单产出，按洁净律报备不动，留决策裁是否另案清。
