## 背景

T-0221 已把呼吸灯从「放大球」改为「珠体+光晕涨落」。业主复判：**仍显大**——珠径+弥散光晕合读出的视觉体量超标。本轮双指令：**尺寸收敛 + 3D 立体质**（玻璃弹珠/LED 灯珠那种小而亮、有纵深感的状态灯）。

## 目标

灯=一颗小而立体的珠：聚光高光斑+球面明暗过渡+底部内影/内凹感+环境接触微影；呼吸保留但光晕弥散幅度收窄——远看「一点亮珠在呼吸」非「一团光在胀缩」。

## 钦定方向（施工可在此框架内落笔）

- **珠径收敛**：`.dot` 基径降档（现 9px→建议 7–8px；`20-cards.css` 席位灯 11px 档同比例收）——「小而亮」非「大而闪」，具体值施工目检定。
- **3D 层次三件套**：①更紧的聚光斑（小高光点非大面渐变）②球面明暗（上亮下暗+边缘暗弧）③`inset` 底部内影/内凹+珠外环境接触微影——立体感来自明暗分层非尺寸。
- **光晕收幅**：呼吸仍走 box-shadow 辉光涨落（T-0221 载体不翻），但峰值弥散半径降档（现峰 ~10-11px → 收缩，珠外辉光收敛贴珠）。
- **捎带统一**：TrxHedgeCard.tsx WS 在线内联点（上轮偏离①遗留）——换 `.dot` 类或同构径向渐变一行，珠体语言统一。
- **铁律不动**：绿缓 ~2.4s/黄快 ~1.2s/红=死=静止；opacity≥0.78 下限；不减动效豁免注释段；三态色映射。

## 验收标准

- [ ] `.dot` 基径 < 9px（grep 断言数值）；席位灯档同降。
- [ ] 3D 件在册：`.dot` 系含 inset 内影或等效球面暗弧件 + 紧聚光斑（grep 断言）。
- [ ] 光晕收幅：呼吸峰 box-shadow 弥散半径 < 现行 10px 档（grep 断言）。
- [ ] TrxHedgeCard WS 点珠体统一（grep：内联 background 平涂消失或挂 .dot 类）。
- [ ] s2 红静止断言不动、节奏/下限/豁免段不动（grep）。
- [ ] 目检锚：System+TRX 四态截图——灯读「小立体珠」非「大点光晕」；前端 build 绿+check_all 绿。
