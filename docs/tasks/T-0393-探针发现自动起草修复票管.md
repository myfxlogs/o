# T-0393 探针发现→自动起草修复票管

- 状态：已批（2026-11-06 业主令——「这种缺陷由谁来发现并发起
  处理？不可能次次都由我来提吧？」——benny 报障自动建票径移植）
- 领取：常径待派（DM 常径机派）
- 优先级：P1——自我迭代「发现→立项」断点根修
- 收口移交归：决策席

## 病灶（架构断点）

探针族在长大（饥饿拍/T-0384 族沉默/T-0392 腿覆盖），但升件
行→立项靠人/席注意——业主反复当「注意到的人」。断点=
**升件行→票草案没有自动起草径**。

## 钦定语义（benny triage 径移植）

1. **起草拍**（挂 hungerTick 同槽）：扫 ops_event 探针升件行
   （族沉默/腿覆盖失明/饥饿 acted=false 类）→按病灶签名聚类
   （同一病灶键 24h 去重防灌）→**自动起草 docs/tasks 票草案**
   （状态=候选——非已批，人工/DM 过目才进派发队）；
2. **票草案形制**：病灶行证据引（ops_event id+查询式）+疑似
   根域+建议验收锚骨架+红线继承模板——起草非诊断，DM 裁时
   仍可驳回/改判；
3. **签名级去重**：同病灶键已有在飞/已立票→不重复起草
   （ops_event 记 dedup 跳过行）；
4. **fail-closed**：病灶签名不明/证据链缺→不起草只升件
   （宁漏不猜——benny「not enough evidence=no issue」同律）。

## 范围

1. 起草拍实现（internal/portfolio/hunger 或同级探针域——照
   T-0384 同槽位）；
2. 病灶签名规范（kind=探针类+key=病灶键——ops_event meta 或
   note 结构化）；
3. 票草案模板件（docs/templates/ticket-draft.md 或内嵌）；
4. 桩测：升件行→草案断言/24h 去重/在飞票 dedup/签名不明
   fail-closed 四锚；
5. 产物件=docs/tasks/ 草案文件+ops_event 起草行——**写径只
   落草案态，零自派**（发起权仍 DM/业主——红线件）。

## 验收锚

① 四桩测全绿（起草/去重/dedup/fail-closed）；
② 草案票面形态审：状态候选+证据引+红线模板齐；
③ 生产谱面零误报审计（起草拍dry对拍）；
④ check_all 绿戳对口；并入发窗批。

## 红线

- 起草拍**只产候选草案**——禁自动置已批/自动派发（发起
  权=DM/业主,不越 T-0376 权序）；
- 票草案禁改既有票/禁动真单径语义；
- LLM 不入安全径——起草=确定性模板填充（病灶行→票面槽位）。
