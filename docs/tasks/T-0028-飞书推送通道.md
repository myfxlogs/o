## 背景

拉径已通（GET /report）。推径要件齐：`nox:internal/ir/notify/feishu.go` 全实现可考古（SendText/chat_id 绑定/事件 webhook），凭据在 nox-keys dump。**本票只做发送半张**——webhook/自然语言查询/告警桥不做（NOX 那套是双向交互面，超本票范围）。

## 交付物

1. **凭据迁移**：NOX_FEISHU_APP_ID/SECRET 经 credx 径迁入 `app_secrets`（key=`feishu.app_id`/`feishu.app_secret`）——密文入册零明文出径；绑定目标 `feishu.chat_id` 存 `app_config`（非密，业主向机器人发一条消息后经「获取 chat_id」径取得——用飞书 im/v1 事件或手工填键都可，票面自选最省径，fail-closed：无 chat_id=不推+计数不炸）。
2. **`internal/ledger/report/push.go`**（或同级）——Gen 落行后调用：daily/weekly/monthly 各把该行 metrics+note 压成 ≤8 行中文摘要 SendText 推出。发送失败=log+计数，**不回滚报表行**（投递失败不抹产出）。
3. 飞书面考古自 `nox:internal/ir/notify/feishu.go`：tenant_access_token 获取+缓存（有效期 2h 须缓存不每拍取）、`POST /im/v1/messages?receive_id_type=chat_id`；超时≤10s、单次重试、禁重试风暴。
4. 键面：`notify.feishu.enabled`（热启，默认 true 但缺凭据/chat_id=fail-closed 静默降级）；推送时刻=报表行落库后即时（信使拍内），不另设钟点。

## 验收标准

- [ ] 凭据迁入实证（app_secrets 两键在案，会话零明文）
- [ ] chat_id 绑定径走通（业主一次性动作写进结果段——机器人收到消息后目标键落位）
- [ ] dev 实证：daily 行落库→飞书收到摘要（截图/ message_id 记结果段）；weekly/monthly 同径
- [ ] fail-closed 锚：chat_id 缺/凭据缺=不推不炸+降级计数
- [ ] token 缓存锚（不每拍取 tenant_access_token）
- [ ] 机检全绿；CI 绿
