# T-0340 post-commit 钩词面收紧——返修子串误触 auto 收口

- 状态：已批（决策席升件 2026-11-04：「subject 含返修子串误触 auto 收口建议收紧」——COS 例行代理批常票件）
- 级别：P3 卫生件——ops_event 流水语义污染（事件名错报非丢报）
- 实案：T-0332 驳回 commit `76d09e6c`、T-0331 驳回 commit `6ac51f5f` 均误报 `收口`

## 病灶

`scripts/hooks/post-commit`（或 `scripts/meta/commit_report_hook.sh`）事件
判定按 subject 子串匹配——含 `返修`/`收口` 等词的 commit 一律报 `收口`，
语义错配：驳回/立票 commit 不该产生收口行。ops_event 是业主可见流水，
错报=流水语义污染。

## 任务

1. 查钩判定逻辑现状（匹配表/正则），定性收紧形——钦定形施工裁：
   负向排除（含返修/裁决/立票/驳回不报收口）或正向锚（仅含
   「收口」「完成」类精确词才报），落票说明理由
2. 干跑四实录：返修 commit→零收口行；真收口 commit→收口行照发；
   裁决 commit→零收口行；无 trigger 词 commit→静默
3. 同坑条目登记（钩事件词面误触类）

## 验收锚

- [ ] 收紧后判定逻辑合钦定形在案
- [ ] 干跑四场景逐值实录（触/不触各二）

## 红线

- 只改判定词面——不动触发时机/远端路径/ops_event schema
- 收紧后**真收口不得漏报**（过紧丢报=比错报更坏的缺席类病灶）

## 回填

票面+干跑实录+坑条目路径。
