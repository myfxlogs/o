# T-0076 持仓期对账残差（盯市盈亏噪音）

## 背景
T-0071 后假差从 $23 收敛到 ~$3.2 但仍在刷：venue 权益含持仓盯市盈亏（ETH 现货
市值+合约 upl 随价动），ledger 只记现金流水——持仓期结构性残差必然 >$0.50 阈值。

## 要求
- 诊断定案：残差组构（现货盯市/合约 upl/费率滞延）逐项核
- 修法二选一（施工给裁决建议）：
  a) ledger 侧补「在持仓位盯市值」项——对账=同口径 NAV 对 NAV
  b) 持仓期告警阈值随仓位规模放宽（如 max(0.50, notional×5%)），真差仍秒报
- 原则：宁可放宽阈值也要把「持仓浮动」和「真账实差」分开——不得以噪音名义屏蔽真错账
- 验收：持仓在挂市价微动时零误报；注入真差仍触发
