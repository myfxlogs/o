## 面况

业主驾驶舱首屏为业主第一触面。T-0263 推送制落地后首屏链路仍有三个
可削延迟/传输点——本票一次收编。

## 钦定界（三件）

1. **首轮 RPC 合并**：`getHeadless` 并入 `getCockpit`——首屏一往返
   出全量（dashboardv1 服务面合并，前端撤独立首调）。
2. **流连接不阻塞首绘**：Connect server-stream 建立异步于首屏渲染
   ——首绘不等流握手，流断线退化为快照态不阻塞。
3. **静态资源 immutable 缓存头**：vite hash 件（`/assets/*`）响应挂
   `Cache-Control: public, max-age=31536000, immutable`（index.html
   不缓存/no-cache——鉴别处理）。

## 范围外

- 驾驶舱内容/版面再设计；其他页面；
- 流协议选型（T-0263 已定 Connect 同栈流，本票沿行）。

## 验收锚

1. 首屏 RPC 往返=1（浏览器 devtools/桩测实证 getHeadless 不再单列首调）；
2. 桩测：流连接挂起/失败时首绘仍出（快照态可达）；
3. `/assets/*.js|css` 响应头含 immutable 缓存指令（curl -I 实证）；
   index.html 不吃长缓存；
4. 桩测（vitest 或等价）+typecheck+build 全链绿；check_all 绿戳；
5. 票面回填+产坑 KB（若有）。
