# T-0432 方言对表面——MT5 符号映射：候选机造+席位挑+硬验+漂移探针

- 状态：施工中
- 领取：zcode-t0432 @ 2026-11-07（外派施工 O-Dev 径；gated T-0430 已合 7461c873 核实开工——T-0427 品种目录面在途未合，方言表落库号位避让其 md_1092，按 dispatch 单闸口径）
- 前置依赖：T-0430（向导壳+onboard RPC）、T-0427（md_* 品种目录域=方言表落库窝）

## 背景与判据

业主判：MT5 每家 Broker 符号名各异（XAUUSD/XAUUSD.pro/XAUUSDm 同金多名、
US500 无基报价对、GOLD/USOIL 黑话无穷、同商不同服务器组符号集异）——
「枚举+启发式自动映射」实考证不可靠：GetQuote 探活只证符号存在不证可交易真身。
钦定形：**映射=确认件非推断件**——候选清单机造、挑选是席位行为、机器硬验证。

- 官话唯一天：内部策略/仓位/台账/告警只用 canonical inst_id；
  方言只活在 venue 边界，进仓译官话出仓译方言，方言禁进表进判据
- 方言表按 (venue, account) 落——换服务器组=重映射，不继承品牌级
- 运行时查不到映射=fail-closed 升件，禁静默 fallback 禁官名硬发

## 面（钦定）

① 候选清单机造（向导第④步扩位，T-0430 落地后续建）：
   Symbols/SymbolParams 枚举全表，按 base+quote+类型相似度排序
   给下拉——只省翻页不做决定；实盘用符号仅十几二十只逐只挑
② 硬验机（挑完机械跑，拒收非警告）：
   SymbolParams 对拍官名语义——ctVal/计价币/digits/tradeable
   flag/session 全过；GetQuote 探活+点差合理性快照
③ 方言表落库：{venue, account, venue_symbol, canonical, ctVal,
   tickSz, minSz, 手数单位}——进 T-0427 品种目录同域（venue
   语义表天生字段），T-0426 语义矩阵同源消费
④ 翻译钉 venue IO 缝（T-0426 同缝位）：canonical→方言查表，
   回包方言→官话归一后入消费码；仿真层缝同位可设桩
⑤ 漂移探针：周期 GetQuote 探活+SymbolParams hash 漂移——
   broker 改后缀/下架/换组即升件（ctVal 变=单位错配病重演防）

## 验收

- 一只官名→映射→下单/报价径全环走通（venue 语义词表全取
  自 mtapi 实返，禁自造）
- 查无映射调用→升件 ops_event 不入闸（断言红桩）
- 语义不符候选→硬验拒收（断言红桩）
- check_all 绿戳对口；坑处置随 commit
