## 背景

宪章定位=跨市场套利（OKX+MT5/CFD 双腿）。OKX 面 M1 全通后，MT5 接进来把机会枚举面翻倍——**本票只接数据面**（读），钱径（mt5-exec 执行适配器）是后续票。协议=mtapi gRPC 网关（NOX 已全谱实测，技能卡四件在册：mt5-gateway-admin / mt5-account / mt5-quotes-history / mt5-orders-streams；mutating 面 mt5-trading-mutating 本票禁用）。

## 交付物

1. **凭据迁移**：mt5-demo.env 经 credx 径入 `app_secrets`（key=`mt5.host`/`mt5.login`/`mt5.password`/`mt5.server`——demo 户字样如实注）；gateway 地址键 `mt5.gateway_addr` 入 app_config。
2. **`internal/mt5/`（或 venue 同型包）**：mtapi gRPC client——Connect token 语义按 mt5-gateway-admin 技能卡；只读面：Account/AccountSummary（权益/余额→`fin_venue_account_snapshot` venue='mt5'，USD 本位）、Symbols/SymbolParams、GetQuote/订阅流（→`md_ticks`/`md_books5` 同构落表，venue='mt5'）。
3. **采集员工**（花名册补卡「汇市巡」或按名册既有名——查册不新造）：节拍采 quote/snapshot，心跳注册。
4. **符号映射面**：MT5 符号方言（BTCUSDm 等技能卡在案）——`okx.symbols` 对偶键 `mt5.symbols` 热启落采集清单；跨市场关联（OKX BTC-USDT↔MT5 BTCUSDm）本票只落原始事实不撮合（撮合=研究域后票）。
