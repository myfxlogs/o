# T-0371 段卡语义精修——「闲」字单显饿色 + 行数标单位

- 状态：已批（2026-11-05 业主令——「闲只显示闲即可，不应该是灰色，
  他只是饿，而不是死」+ 行数语义标清）
- 领取：
- 级别：P3 显示面修缮——T-0366 人话面同源域

## 事实

- 提案/执行段 `pipe-card-num` 大格现显整串「闲·评估全拒（无达标
  机会）」——业主令：可见面只显「闲」，拒因全留悬停；
- 「闲」态现走中性灰——语义误读：饿≠死。色律钉死：**灰=死/缺，
  暖=饿/等**；
- 段卡 24h 行数悬停只说「N 行」——「行」单位语义含混：
  - 采集段=md_funding 落行（OKX 资金费率观测记录，~5m 拍上限
    288/天）→ 单位=**条行情数据**；
  - 投影段=md_ticks 帧 → **帧**；
  - 评估段=fin_opp_eval 评估行 → **次评估**；
  - 提案段=fin_proposal 行 → **个提案**；
  - 执行段=fin_cashflow 流水行 → **笔流水**；
  - 报表段=fin_report 行 → **份报表**；
  - 侦察段=fin_venue_candidate 度量行 → **个交易所**（进水口找
    平台线，非策略/非组合）。

## 任务

1. 提案/执行段态标可见面：态标为闲态类（闲·* 全部形态）时大格只
   显「闲」单字；拒因/详述照旧留悬停层（pipeStatus.detail 不变）；
2. 「闲」态配色：新开饿色档（琥珀暖色系，与 warn 调色板同族但
   判读可区分），pipe-card-num 在闲态用饿色；灰（ink-3）保留给
   真死/缺态；判词行「饿殍期·」前缀不变；
3. 段卡悬停 title 行数补单位：按上表「24h N <单位>」渲（服务端
   proto/查询零动，前端静态映射随代码走）。
