## 事实

### A 闲态显示
- 提案/执行段 `pipe-card-num` 大格现显整串「闲·评估全拒（无达标
  机会）」——业主令：可见面只显「闲」，拒因全留悬停；
- 「闲」态现走中性灰——语义误读：饿≠死。色律钉死：**灰=死/缺，
  暖=饿/等**；判词行「饿殍期·」前缀不变。

### B 段卡悬停语义缺口（七段全中）
现格式 `段名 · <detail> · 预期节拍 <Xm> · 24h N 行`：
- **只报"几行"不报"是什么"**——采集/投影/评估/侦察段悬停无
  「该段干什么」语义；
- 「预期节拍 5m/27h/25h」电报体——秒换算非人话；
- **事件驱动段（提案/执行，state=3 恒中性）硬安"预期节拍"=
  误导**——该两段无节拍阈；
- 行数单位含混（事实表见下）；
- 状态点悬停「末行 / 无行 / 查询败显缺」=黑话。
