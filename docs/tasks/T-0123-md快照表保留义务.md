## 施工面

   `INSERT ... ON CONFLICT (键) DO UPDATE`）：
   - `md_ticks`（venue+inst_id）——读面：spot()/sizing/mtm/ledger/money_card
   - `md_mark_index`（inst 粒度）
   - `md_account_events`（venue+channel[+ccy/inst 粒度施工按写径定]）
   - `md_dcd_product`（产品键）、`md_earn_rate`（产品键）
   - 读面 SQL 全部兼容（最新行语义 upsert 天然满足），逐读点验证。
2. **md_books5 停止落库**——零读者实锤；订阅若独为它服务即同撤。
3. **窗口读面举坐标**：`md_equity_curve` 留历史（ddline 回撤窗）+90d
   保留期；`md_funding` 施工核读面——有窗口消费者→30d 保留，无→同转
   状态表。
4. **旧史清空**：转换后 TRUNCATE 各表旧追加史（无消费者；审计链在
   fin_*+venue 账单）。
5. **机检**：check_migrations 增断言——新 md_* 表须声明 upsert 键或
   「窗口读面坐标+保留期」，缺=拦。
