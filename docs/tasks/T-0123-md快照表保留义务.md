# T-0123 md_* 状态表化——追加式快照全废（D-0018 落地票）

| 字段 | 值 |
|---|---|
| 状态 | 已批 |
| 依据 | D-0018（业主令：不想使用快照+库无休止膨胀）；D-0017 推翻面并入 |

## 背景实拍

SG 2026-10-25：md_books5 1.8GB/344万行（**零 SELECT 消费者**）、
md_ticks 446MB、md_mark_index 232MB、md_account_events 64MB——
37h 写出的。所有读面 `ORDER BY ts DESC LIMIT 1` 只取最新。

## 施工面

1. **状态表化**（同表名，超表→普通表+唯一键，写径改
   `INSERT ... ON CONFLICT (键) DO UPDATE`）：
   - `md_ticks`（venue+inst_id）——读面：spot()/sizing/mtm/ledger/money_card
   - `md_mark_index`（inst 粒度）
   - `md_account_events`（venue+channel[+ccy/inst 粒度施工按写径定]）
   - `md_dcd_product`（产品键）、`md_earn_rate`（产品键）
   - 读面 SQL 全部兼容（最新行语义 upsert 天然满足），逐读点验证。
2. **md_books5 停止落库**——零读者实锤；订阅若独为它服务即同撤。
3. **窗口读面举坐标**：`md_equity_curve` 留历史（ddline 回撤窗）+90d
   保留期；`md_funding` 施工核读面——有窗口消费者→30d 保留，无→同转
   状态表。
4. **旧史清空**：转换后 TRUNCATE 各表旧追加史（无消费者；审计链在
   fin_*+venue 账单）。
5. **机检**：check_migrations 增断言——新 md_* 表须声明 upsert 键或
   「窗口读面坐标+保留期」，缺=拦。

## 验收锚

- SG 部署后 24h：md_* 各表行数稳定不再随时间增长（状态表行数=键域）
- 读面零回归：spots/对账/钱卡/liveness 正常
- books5 停写后库日增 < 若干 MB 量级

## 禁线

- 不动 fin_* 事实史表（opp_eval/cashflow/proposal 等）。
- upsert 键选错=丢维度——逐写径核对唯一键粒度再迁。
