# T-0123 md_* 快照表保留义务落地

| 字段 | 值 |
|---|---|
| 状态 | 已批 |
| 依据 | D-0017（快照写径裁决：禁快照驳回，保留期义务分级） |
| 优先 | 中 |

## 范围

按 D-0017 分级给每张快照表落保留策略（pg 侧定期 DELETE 或超表
retention policy，选径施工裁；异构表共存取轻径）：

| 表 | 保留 |
|---|---|
| md_dcd_product / md_earn_rate / md_mark_index | 7d |
| md_ticks / md_books5 | 72h |
| md_funding | 30d |
| md_equity_curve | 不删——7d 原始粒后降采样小时粒 |
| md_account_events / md_macro_event / md_calendar_push | 90d |

## 机检

`check_migrations`（或同族机检）增断言：新增快照类表（md_* 前缀或
fin_*snapshot 命名）须在迁移/票面带保留声明，缺=拒。

## 验收锚

- 各表保留策略在 SG 生效（定时任务/超表策略实拍其一即可）
- md_dcd_product 行数过 7d 窗封顶实证（不再无界堆积）
- 机检断言实测：造一张无保留声明的假 md_* 迁移被拦
