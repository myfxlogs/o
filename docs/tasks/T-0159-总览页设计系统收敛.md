## 背景

2026-10-26 前端评估定谳：双设计系统并存（总览=玻璃拟态暗紫渐变
18px 圆角 blur+悬停浮起；TRX=arbcn 中性极简）=同一产品两张皮，为
美观面最大问题。裁决：**arbcn 系为准**（与 React TRX 页共令牌
00-base.css），总览页渐变底/玻璃 blur/悬停浮起属撤除面。

## 目标

总览页与 TRX 页同一视觉语言：表面/墨线/状态色全走 arbcn 令牌
（--page/--surface/--ink/--line/--good/--critical 双主题），玻璃
拟态件（backdrop-filter/径向渐变底/hover 浮起/18px 大圆角）撤除，
圆角/间距/字级对齐 03-table 系既有节奏。

## 验收标准

- [ ] 双页令牌单源：总览页 CSS 变量并入 arbcn 令牌集（或直引），零
      独立调色板残留
- [ ] backdrop-filter/径向渐变底/hover translateY 浮起 零残留
- [ ] 双主题（o_theme 单源）亮暗双幅截图对表：卡面/行线/状态灯可读性
      不低于现版
- [ ] 呼吸灯撤/字母坐标/响应式断点等 T-0157 既有裁决零回归
- [ ] npm build✓ + 1440/420 双幅渲染对表

## 范围外

- 布局/信息架构不动（七卡结构与坐标契约承前）
- TRX 页不动（其为基准系）
- 组织架构图信息重设计（可读性项另票）

## 结果回填（施工：zcode-glm @ 2026-10-26）

实现摘要：总览页令牌单源并入 arbcn——`web/src/main.ts` 直引
`./react/styles/00-base.css`（与 TRX 页同一令牌文件，零复制），
`web/index.html` 全表改消费 arbcn 令牌名（--page/--surface/--ink/
--ink-2/--ink-3/--line/--ring/--good/--good-ink/--warn/--critical/
--delta-down），独立调色板块（:root 15 变量+body.light 全套）整删。
玻璃拟态撤除：body 径向渐变底→平色 --page；.card/.toggle/.oside
backdrop-filter 全拔；.card:hover translateY 浮起+box-shadow+::before
渐变叠层全拔（hover 对齐 .theme-btn 径=bg 变 --page）；18px 大圆角
→8px（03-table 节奏）；行线 dashed rgba→1px solid --line（03-table
节奏）；主题机制 body.light→`<html data-theme>`（与 React
main.tsx/ThemeButton 同契约，o_theme 共键不动，缺省随系统跟变）。
main.ts 视觉件收敛：PnL 着色 --dn/--up→--delta-down/--good-ink；
VSVG/orgSVG 硬编码色（#34d399/#fbbf24/#f87171/#8b9bb4/rgba 白系）

底撤，金框语义由描边承载）/三态灯 --good·--warn·--critical。
