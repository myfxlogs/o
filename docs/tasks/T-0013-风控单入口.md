## 背景

M1 缺了 G6，钱就到不了 G7。`risk.Check(intent)` 是**全系统唯一交易前闸**——与投资决策物理隔离、fail-closed、每判必留痕、拒必有计数。闸不立，live 态永远只是行。

## 范围

1. **`internal/risk/`**：`Check(ctx, Intent) Decision` 唯一入口。Intent=执行意图（strategy_ref、venue、inst_id、腿面、名义额、杠杆）；Decision=allow/deny+reason code 闭集。**闭集枚举**拒绝原因，禁自由文本。
2. **闸内判据**（全走 `app_config` `risk.*` 热启，缺任一键=fail-closed=deny）：单仓名义额上限、venue 集中度上限、总敞口上限、**kill switch**（一键全拒，最高优先）、 intent 完整性校验（缺字段=deny）。
3. **留痕**：`fin_risk_decision` 表——每次 Check 一行（intent 快照+decision+reason+config 代次），deny 计数可查（reason 分桶）。
4. **放行令牌机制**：allow 决策生成 `risk_decision_id`；G7 执行件**只认令牌**——无令牌/令牌过期/令牌已用=拒执行。机械防绕过，不靠约定。
5. **红线隔离**：risk 不 import invest/research/execution 域包（import 闸实证）；判据只读 config+账本事实行（净额/敞口读面）+策略状态行。
6. **员工**：`门官` Register+BeatLoop(30s)，产出窗=fin_risk_decision 行。
