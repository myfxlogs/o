# T-0382 前端报价点与价格提醒——飞书通知

- 状态：已批（2026-11-06 业主令——「想看到 BTCUSDT/TRXUSDT
  实时报价，并想预设一个价格，飞书通知我」；用例锚=业主自
  营盘 TRX/CMC 空单观察）
- 领取：常径待派（DM 常径机派）
- 优先级：P1——业主观测面 feature 件
- 收口移交归：决策席

## 缺口

驾驶舱无实时报价面；无任何价格提醒件。md_ticks 已在采
BBO（BTC-USDT-SWAP/TRX-USDT-SWAP 在全宇宙集内）——数据
面零新增，缺的是展示+提醒两段。

## 范围

1. **报价点**（前端）：驾驶舱报价卡——**展示面=预设
   symbol 集**（业主令 09:2x：「前端需要展示我预设的symbol
   报价」——提醒单里建的符号即报价卡看的符号，一单两用；
   卡上符号行=该 alert 行同 symbol 渲染），last/bid/ask+ts
   鲜度，人话语义（照 T-0371 段卡规——禁裸机器键）；
2. **提醒设置点**（前端）：符号+方向（≥/≤）+目标价表单；
3. **提醒表**：新迁移件 `fin_price_alert`（或按面谱命名——
   id/symbol/direction/target/state(active|fired|disabled)
   /note/created_by/created_at/fired_at）——迁移号查水位+1；
4. **提醒拍**（o-core 内协程照 hungerLoop 同款正径）：扫
   active 行×md_ticks 最新价，命中→飞书推送（复用现有
   notify 径——venue_req 同款 Sender/chatID 装配）→state
   翻 fired+ops_event 落行（一发即锁防重响）；
5. 删除/停用径：active↔disabled 翻位（前端操作面）。

## 验收锚

① 报价卡桩测/DOM 测：last/bid/ask 渲染+鲜度标；
② 提醒全链桩测：建行→价到→fired 翻位+ops_event 行+
   推送调用断言（Sender 桩）；
③ 重响防护：fired 行不再触发；
④ 败径：notify 败=自报行+票不丢（T-0369 容错律）；
⑤ check_all 绿戳对口；镜像面件并入发窗。

## 红线

- 纯观测+通知面——零交易动作、不碰钱径；
- notify 凭证域照旧 owner 类；
- 提醒语义=单向告警非条件单——票面禁写成下单挂钩；
- 前端人话规照 T-0371（禁裸键名/机器词）。

### 实现摘要

1. **报价点**：驾驶舱新卡「行情·价格提醒」（QuoteBoard.tsx 挂 Cockpit
   管道卡下）——行=fin_price_alert symbol 集一单两用，最新/买一/卖一+
   报价鲜度（龄=now()-recv_ts 服务端派生，前端零判据）；无行情行=
   「暂无行情」显缺不假零；刷新=Watch 新听 ev_ticks 纯信号帧（合并窗
   MERGE_MS 节流重取，零定时器）；
2. **提醒设置点**：卡内表单——品种（md_ticks 在采枚举下拉）+方向
   （涨到≥/跌破≤）+目标价+备注→CreatePriceAlert（同源闸窄写，symbol
   须在采/方向闭集/target>0 校验，建行落 ops_event 审计行）；
3. **提醒表**：fin_0119_price_alert.sql（水位 118+1）——id/symbol/
   direction/target/state(active|fired|disabled)/note/created_by/
   created_at/fired_at+active 部分索引；domain.tsv 入 fin 册、
   migrate_table.go 登记；
4. **提醒拍**：notify.PriceAlert（venue_req 同款 Sender/chatID/on 装
   配）——event_push.go 挂 events.ListenLoop ev_ticks 帧驱动（钦定事
   件径非轮询）；命中→SendText→UPDATE ... WHERE state='active' 条件
   翻位 fired（一发即锁防重响）+ops_event `价格提醒` 行；败径=
   行不翻 fired 票不丢下帧重试+升件自报行（24h 同窗去重，
   NOTIFY-PRICE-ALERT 域——hungerEscalate 同构）；
5. **翻位径**：SetPriceAlertState active↔disabled（fired 终态禁手翻=
   幂等回真值）——卡行停用/恢复钮。
