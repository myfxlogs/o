## 背景

账本=**唯一货币真相**。一仓一决策记录、所有现金流水单源净额。OKX 面 USDT 本位记、MT5 面 USD 本位记，各记各的零换算（业主令）；合成总览时 USDT≡USD 等值并列展示（两本账并陈，非单一净值）。

## 范围

1. **`fin_cashflow` 表**：每笔货币事件一行——kind 闭集（fee/funding_settle/trade_pnl/rollback_cost/deposit/withdraw）、venue、ccy（OKX=USDT/MT5=USD 闭集）、amount、position_ref、source_ref（腿行/结算行 PK）、occurred_at。**禁推断记账**——每行必须挂来源行。
2. **结算**：`fin_position` closed→结算拍（净额=Σcashflow，费用/funding/腿差全计）；`fin_position.settled_amount/settled_ccy` 落位；一仓一「判决书」=净额+构成明细可查。
3. **对账环**：私有流 balance_and_position 快照 vs 账本净额——**差即告警计数**（`recon.diff_alert`，容差走 `ledger.recon_tol_usd` 热启键）。账本不自信闭环，须拿 venue 事实交叉。
4. **日切快照**：`fin_ledger_snapshot` 日切（venue×ccy 净额行）——NAV/报表底数；合成总览=两账本等值加总视图（不落折算行）。
5. **红线**：ledger 不 import execution/risk/invest（import 闸；账本只消费事实行与 venue 私有流事实）；不触发钱动作（纯记账+告警）。
6. **员工**：`司账`（入账+结算）、`核账`（对账环）Register+BeatLoop(30s)，产出窗=fin_cashflow/settled 行/对账计数。
