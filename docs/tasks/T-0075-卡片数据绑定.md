# T-0075 卡片数据绑定（空态不能当真相演）

## 背景
T-0074 清掉 mock 假数后暴露：doing/money/recent/staff 四卡绑了死空态——
main.ts 只渲染 hero 三数+stamp，API 的 doing[]/money[]/recent[]/staff[]
字段全没接。**仓开着页面说「静持中」=比假数更糟的谎言式空态**。

## 要求
- doing[]→「在干什么」卡：持仓行（含已持时长+出生证戳）/静持空态
- money[]→「钱在哪」卡：分户行+金额
- recent[]→「最近动作」卡：流水行
- staff[]→员工卡：API 若未返此面则先藏卡或如实标「待接」——禁静态假名册
- 空态只在 API 真空时出，有数据必渲染真值；断源=卡面灰化露相
- 验收：开持仓在挂时页面显示真持仓行；空仓时出空态（两态均实证）
