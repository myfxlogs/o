## 病灶

T-0375 落地的外派排除按「票史上存在外派行」判——票一旦
有过外派事件,后续任何「已批」新事件都不能把它拉回待派集。
实证：T-0379 业主令撤外派改内循环（latest=已批）,仍被排出
待派集,DM 手动补派。

语义应=latest 事件派生：票史有外派行 + 之后出现「已批」
（或业主令改径）新事件 → 回待派集；latest=外派/已批后接
工人领单 → 不外派集外照旧。收口回 DM 待裁面不受影响
（T-0375 件①已钉）。

## 范围

1. dm_queue 待派集判据改「latest 事件语义」——外派行后接
   「已批」类事件的票归常径待派;
2. 桩测断言三形（照 T-0375 8/8 同款）：外派→已批=入待派 /
   外派→领单=不入 / 纯已批=入;
3. collab/KB 同步一行（外派可逆语义）。

## 验收锚
