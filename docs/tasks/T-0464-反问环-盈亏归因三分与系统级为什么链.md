# T-0464 反问环——「为什么会这样」：盈亏归因三分 + 系统级为什么链（业主令件·COS 立壳）

- 状态：已批（DM 裁 2026-11-08——裁域四件钦定回填过基线；方向件已钦不再裁）
- 业主令（2026-11-08 原话）：「我们差的1个就是反问为什么会这样，包括盈亏的定单，为什么会亏，是市场还是代码的原因」
- 业主层已定两件（不再裁）：
  - **每单归因三分**——每笔平仓判词须答「为什么亏/为什么赚」：市场原因 / 代码原因 / 运维原因 三分取一（postmortem 判词集扩——病形四类是「怎么坏」不是「为什么」，两轴并存）。
  - **系统级为什么链**——北极星指标背离（如 armed 提案积压/零开仓窗）自动起反问：沿链回拽到首个断点归因立案（链：armed→open→fill→settle→PnL 各段实测取证，断在哪段归哪段）。
- 复用锚（禁重造）：postmortem 判定环/`fin_review_verdict.attribution` 字段骨架/裁定席根因诊断支（T-0431 案径）——归因结果走既有裁定+经验库道。
- 归 CTO 裁填四件：
  - 单归词形与判据（市场/代码/运维的机判边界——哪些信号归哪分；裁不了的留「未归因」位还是必须分）；
  - 系统级反问触发面（周期扫还是背离事件驱；北极星指标清单与「背离」判据）；
  - 为什么链的拽法（沿链取证的实际段点/每段取什么证/断点判定）；
  - 归因结果消费径（立案进 fin_econ_lesson 还是新案型；回改点白名单要不要扩）。
- 边界：归因是诊断不是止血——只产出判词与立案，处置仍走裁席/CTO 原道；「未归因」须是显式判词非沉默。

## CTO 裁定回填（2026-11-08 班裁——裁域四件定案翻已批）

- ①单归词形：`fin_review_verdict.attribution` ∈ {market,code,ops,unattributed}——机判序：code 锚（栈错/断言红/拒因异常/病形案对应码件）→code；ops 锚（断供/断链/凭据失效/部署停滞/环境 ENOSPC·网络）→ops；market 锚（费率不利/对手价动/窗口闭合/滑点）→market；零锚→`unattributed` 显式判词（非沉默——业主令钦）。人裁可改判机判（判词面留机判原值+改判者留痕）。
- ②触发面：背离事件驱为主（T-0465 北极星账拍判出背离即起问链）+24h 周期兜底扫（漏背离面）；背离判据单源=T-0465 账页指标集，不另造。
- ③链拽法：段=armed→open→fill→settle→PnL 五段实测；每段取证=段表行数窗（24h）+最末 ts+错因行（armed=fin_proposed 滞留龄/open=fin_position 新行率/fill=执行错因/settle=滞留行/PnL=符号）；断点=自链首起第一段产出异常（率<阈或错因非空）即归该段立案。
- ④消费径：立案走 fin_econ_lesson kind=rootcause_diag 同款案卷（T-0431 裁定席诊断草案受理道复用——问链产出=草案，裁定席裁）；回改点白名单不扩（问链只产假设不动判据，既有窄面够）。
