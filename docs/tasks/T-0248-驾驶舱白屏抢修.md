## 病灶（决策席复核——比令报更深一层）

   全仓零定义——ReferenceError→渲染即白屏；

   在而未入链，CI 放行根因；
3. **可选链雷（同族，决策席补案）**：`d.money?.netMonth.toFixed`/
   `d.money?.capital`/`exposure`/`exposureLimit`/`daily.map`/`platforms.map`

   `.toFixed`/`.map` 照抛 TypeError→白屏**——缺段降级死在前端；
4. 连带核实项（管理令③）：合计行 `value−1` 冒数——`committed<0→"未设"`哨兵
   行已护 committed 一列，但 parked/exposure 若后端同用 −1 哨兵将裸显 -1
   （核后端哨兵词表+前端渲染面逐列对账）；清道夫-md 显示源= T-0241 v4③
   已登记挂账尾件（不在本票界内，票面注记）。

## 钦定界

- `sec(name, children)`=块级降级壳：段数据在→渲染子件；段缺/子件抛错→
  显『该段数据缺』占位注（三律③径——块级 error boundary 或等价实现，
  绝不许一块抛错掀全页）；
- `web/package.json` build 链前置 `npm run typecheck`（或 tsc --noEmit
  与 vite build 串联——复用现存脚本，不另造）；
- **可选链雷全扫**：Cockpit.tsx 全部 `?.`后链式调用点逐处审计——缺段语义下
  该显『缺』的显缺，该给默认的给默认（以服务端 missing 字段为判据真源）；
- 哨兵词表对账：后端 CockpitMoney/PlatformRow 各列哨兵值（-1 系）列出，
  前端每列渲染与哨兵语义对表——负值列该显『未设』显『未设』；
- 桩测（vitest 或等价现有面）：money 块整缺→页面不白屏+『缺』注在；sec 一
  块抛错→余块照渲；typecheck 链断一只报错文件即 build 败。
