### enabled 启用步序（生产执行步骤，本次不执行）

`research.dcd.enabled` 只在 boot 读取。旧 binary 重启若先读到 `true`，会在新 BTC
业主资产域闸生效前裸奔。因此顺序固定如下：

1. 将 fin migration 113 应用到 **SG fin 正本**，确认迁移 113 已登记；PG-md 副本
   不作为配置真源。
2. 部署包含 T-0353 资产域闸、复役条件闸的新 binary，并先在 SG 上重启；此时
   `research.dcd.enabled` 仍为 `false`。核对运行 SHA 等于新 binary 后再继续。
3. 仅在确认新 binary 已运行后，对 **SG fin 正本**执行：
   `UPDATE app_config SET value='true' WHERE key='research.dcd.enabled'`。
4. 重启已核对 SHA 的新 research binary，使 boot 读到 `true`；核查 SG 正本键值、
   新 eval 行及 owner-domain 条件请求路径。若运行 SHA 不符或检查失败，保持键为
   `false` 并停止启用流程。
