# T-0224 呼吸灯呼相体积再收敛——呼吸读「珠内生辉」不读「外廓胀缩」

## 背景

T-0222 已把珠径收到 8px、光晕峰幅收到 5px。业主生产目检复判：**呼吸的相位涨落仍读作大小脉动**——呼相（50% 帧）外辉光 `0 0 5px 1px` 把 8px 珠的视觉足迹撑到近两倍，读作「大灯↔小灯」交替，呼灯太大不美观。

病诉的本质：**呼吸的载体仍是「外廓足迹变化」**（辉光弥散半径涨落）。业主要的呼吸感=珠子「活」——光在珠内流转/明暗缓急，外廓体量应近乎恒定。

## 钦定方向（验收锚）

1. **呼相外廓足迹≈息相**：峰值帧总视觉半径（珠体+辉光）≤ 珠径+2px 量级——辉光弥散不得再把珠撑成「大灯」。允许保留极窄贴边辉光（≤2px 弥散）或不保外辉光。
2. **呼吸改走「珠内生辉」径**：明暗涨落主驱换内通道——可选：聚光斑/珠体亮度层 opacity 涨落（叠层背景或伪元素）、珠体明度/饱和微调、内辉光（inset 正值光）涨落。施工择优，须让灯读「活着的珠子」非「灯灭灯亮」。
3. **铁律不动**：绿 breatheCalm 2.4s/黄 breatheQuick 1.2s 节奏逐字；opacity 下限（信息保读）可在 0.78 附近微调但不得 <0.7；红死静止终裁三行不动；不减动效豁免段不动；三态色映射不动；`.dot.still` 语义不动。
4. **paint-only** 动效纪律不动（transform scale 仍禁作主驱；opacity/filter/box-shadow/background 系允许）。
5. **两档同治**：breatheCalm 与 breatheQuick 同法收敛（黄灯呼相同样禁大廓）。
6. **目检锚**：System+TRX 亮/暗截图——呼相帧须可读「小而活的珠」，外廓不比息相明显大；附呼/吸两相并列特写（同帧对比图或双截图）。

## 范围外

- 灯语节奏/三色/红静止/珠径再议。
- 其他瓦片/字体/玻璃面改动。
- 后端零改动。

## 结果回填（`[角色:施工]` @ 2026-10-28）

### 实现摘要

- **呼吸主驱换轨=filter 珠内生辉**（`10-shell.css` breatheCalm/breatheQuick 两键帧）：明暗涨落载体由「外辉光弥散胀缩+opacity」改为 `filter: brightness()/saturate()`——呼相 `brightness(1.35) saturate(1.1)`（绿）/`brightness(1.3) saturate(1.12)`（黄），作用于珠体双层径向渐变+左上聚光斑，读「光在珠内流转、珠子亮起来」；息相 `brightness(1) saturate(1)` 显式成对基帧（防 none↔值插值陡跳）。
- **外廓足迹恒定（锚 1 最强式）**：两帧 box-shadow 弥散半径逐字相同 `0 0 2px 0.5px` 贴珠（峰弥散 5px/4px→2px 恒定）；辉光色浓度做**亮度对冲预算**——呼相浓度=息相÷brightness 增益（绿 43%→32%、黄 47%→35%），两相有效辉光亮度相等、可见包络恒定。首版（浓度 60%/66%+提亮）经目检判「呼相辉光包络胀大」打回重调，对冲版复检过。
- **opacity 通道撤除**：两帧均无 opacity 声明（恒 1，信息保读下限≥0.7 自动满足；旧绿 0.78/黄 0.6 涨落不再作幅度源）。paint-only 纪律：filter 系显式允许，transform scale 未动。
- **铁律逐字未动**：绿 2.4s/黄 1.2s（L209/L212）、红死静止终裁三行（L276-278）、不减动效豁免段、三态色映射、`.dot.still` 语义（L284）；T-0222 3D 恒驻三件套（描环+底内影+接触微影）逐帧同携保持；`20-cards.css` 硬化段与 `03-table-chip.css` 席位灯**零改动**（带 `.breathe` 的席位灯走同名键帧自动同治）。

### 测试证据

- **grep 锚**（`web/src/react/styles/10-shell.css`）：filter 主驱 L230/238/249/257；外辉光恒定弥散 `0 0 2px 0.5px` ×4（L235/243/254/262）；浓度对冲 43→32（绿）/47→35（黄）；呼吸键帧内旧 `0 0 5px`/`0 0 4px` 峰弥散零命中；2.4s/1.2s、红死三行、still、豁免段逐字在册。
- **前端**：`npm run typecheck` ✓；`npm run build` ✓（dist css 29.19kB/js 453.61kB）。
- **机检**：`scripts/check_all.sh` 全链绿（绿戳落 worktree git dir，对施工收口 commit 重跑）。
- **目检锚**（`docs/design/T-0224-*.png` 六件，真实 SPA 渲染——worktree vite dev+Connect JSON stub 供数（T-0222 同法，台架 /tmp 不入仓）；呼/吸两相以 inline animation 一条 shorthand 重设（-半周期 delay+paused）精确冻结于 50% 峰帧，相位确定性优于 T-0222 的 wait 1.2s 抓拍）：System 亮/暗+TRX 亮/暗全页（呼相冻结）+呼/息两相并列特写面板亮/暗（绿黄各息|呼 ×1x/5x，4x dsf）。图像判读三验全过：呼=息同珠径同辉光包络、仅珠体更亮；System/TRX 呼相帧灯读「小而亮的珠+极窄贴边辉光（1-2px）」，亮暗两底无「大灯/大团光」读感。

### 偏离说明

1. **`@keyframes breathe`（通用 1.6s 自息，L182-192）未治**：票面钦定两档=breatheCalm/breatheQuick，通用键不在列；但其实际仍有使用面——`StateDot` 带 `breathe=false`（如 TrxKpiStrip 年化≤0 的 s1 灯）走此键，其 50% 帧 `opacity 0.35+0 0 4px 1px` 外辉光胀缩病诉同款。属范围外发现，**交决策席裁**是否另立单同治。
2. **opacity 恒 1 的铁律读法**：票面「opacity 下限可在 0.78 附近微调但不得<0.7」按参数下限约束执行（恒 1 合规）；若决策席原意是「保留 opacity 涨落通道」，可回退为呼相 0.78/0.7 微幅叠加（需同步重算辉光对冲预算）。
3. `breatheAlarm` 50% 帧（L267，opacity 0.3+scale(1.25)）为被 s2 终裁压住的既存死帧，T-0222 偏离④同款报备不动。
