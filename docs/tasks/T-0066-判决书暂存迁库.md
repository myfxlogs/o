## 病灶（决策席取证）

`review.go:20 stagingFile="docs/经济经验库/待归纳.md"`——相对路径写容器 CWD，
镜像内无 docs/ 目录 → 每轮 falsified 判决 `open ...: no such file or directory` 刷屏。
**即便 MkdirAll 也是假修**：容器 FS 易失，判决书随 recreate 蒸发——业务事实寄生易失层。

## 裁决（本席定，不再议）

- 判决书（verdict/pred/actual/归因）**权威落库**：新表 `fin_review_verdict`
  （id, position_ref, verdict, pred_apr, actual_pnl, attribution, created_at）——
  迁移 0034。
- 待归纳.md 改为**派生视图**（tools/kbgen 或人工扫表再生——canon 落点不变）。
- 文件写径保留为 best-effort 镜像：**写败只 log 一次/进程**（去噪），不报错刷屏。
- falsified 判决是策略演化输入——落库后可被 SQL 直查，比 md 文件更好用。
