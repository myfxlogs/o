## 事故锚（诊断正本：/opt/meta/docs/诊断-前端HTTP2事故-1030.md）

- 根因归属=浏览器↔CF 边缘跨境腿（h2 PING 无 PONG→整条会话撕毁）；
  origin 纯 h1、tunnel 4×HA、CF↔tunnel 腿实测全健康，非本票施工面。
- 已实证的**放大器病灶**（本票施工面）：
  1. `cmd/core/service.go:201-218` Watch 循环无应用层心跳帧——最坏静默
     ~30s，「静默>100s CF 杀流」残余风险敞口（§2-H1 残余段）；
  2. `cmd/core/service.go:257-269` SPA catch-all 把 index.html 当 favicon
     返回（200 text/html 762B）；
  3. `web/src/react/stream.ts:60-67` pump 断→吞错→**固定 3s 重连**无退避
     无抖动，死路径重连风暴轰炸同一新 h2 连接；
  4. watch_open 帧→页面全量重取**双取**（/ Overview×2+GetSystemHealth×2、
     /system ×2、/trx GetTrxYieldCurve×2——stream.ts:53-57+useLive）；
  5. `web/src/react/components/TrxHedgeCard.tsx:35` 30s setInterval refetch
     与 TrxKpiStrip/TrxYieldRadar 各自首取并存——/trx `getHedgeStructure`×3。

## 钦定界（档一服务端 + 档二前端，同票施工）

1. **Watch 服务端周期心跳帧**：`service.go:201-218` 循环加 ticker，
   ≤20s `stream.Send` 保真帧（select 于 WaitForNotification 不阻塞推送）；
   前端 `stream.ts` ingest 对未知 kind 天然忽略——帧语义纯信号。
2. **favicon 真件**：dist 放真 `favicon.ico`+显式挂接（或 204），消除
   HTML-as-favicon。
3. **重连退避**：`stream.ts` 固定 3s→**指数退避+抖动**（如 1s→2→4→…封顶，
   ±抖动防雷群）；unary 失败同样退避+失败计数降频。
4. **watch_open 双取去重**：同帧触发的全量重取合并，每页各 RPC 恰好一次。
5. **`getHedgeStructure` 去重**：/trx 页三卡共享一次取数（提升缓存/合并
   in-flight/统一数据源任选，落码注释说明取舍）。
