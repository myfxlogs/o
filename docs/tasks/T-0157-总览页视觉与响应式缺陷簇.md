## 缺陷清单（2026-10-26 本地渲染 1440/420px 双幅实证，截图在案）

**响应式（420px）**
1. 12 列 grid 无移动断点——span 6 卡窄幅仍半宽挤两列，文案破行难读
2. hero 第三格「累计盈亏」溢出视口右缘截断
3. 组织架构图 SVG 等比缩至不可读墨团——窄幅应降级列表或藏
4. 侧栏 `display:none` 后无导航替身（汉堡/底栏）——孤儿页

**视觉/一致性**
5. 呼吸灯动画（`.dot`/`.vdot` vbreath）**违 T-0088 自家裁决**
   「灯是信息不是装饰：静态三色，零动画零辉光」——同文件注释与
   代码互斥（doc/码漂移实证）；裁决为准：动画撤
6. 双设计系统并存：总览=玻璃拟态暗紫渐变 18px 圆角；TRX=arbcn
   中性极简——同一产品两张皮。收敛方向：arbcn 系为准（总览改制，
   渐变底/玻璃 blur/悬停浮起撤），分期另单
7. 标题字距用空格 hack（「现 在 在 干 什 么」）——`letter-spacing`
   才对；空格损复制/检索/可及性
8. 主题状态双轨：vanilla `localStorage.th`+`body.light` vs React
   `prefers-color-scheme`+`data-theme`——两页主题互不同步

## 验收标准

- [ ] 420px：单列、hero 三格全显、组织图降级、导航可达
- [ ] 呼吸灯动画零残留（静态三色灯——T-0088 裁决兑现）
- [ ] 标题字距全改 letter-spacing，码面零空格 hack
- [ ] 两页主题单一状态源（localStorage 共键 or 全随系统）
- [ ] 设计系统收敛不在本单（单列方向记档，另票分期）
