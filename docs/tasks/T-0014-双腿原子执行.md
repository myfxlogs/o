## 背景

funding 对冲开仓=两腿原子：现货买+永续空（正 funding）或反向（负 funding）。半成品腿是钱径最危险态——**LEGGED 即回滚**，不留过夜敞口。执行无权决定「该不该开」（那已过 G2/G6），只负责「开成/开不成全收回」。

## 范围

1. **`internal/execution/`（或 trading 域包）**：`Execute(ctx, Intent{risk_decision_id,...}) Result`。
   - **令牌验证为第一件事**：查 `fin_risk_decision`——不存在/非 allow/过期/已消费=拒执（测试锚四条）；allow 令牌同 tx 标记已消费（单次性）。
   - **live 闸**：`app_config` `invest.lifecycle.live_switch`（T-0012 已立的委员会键）非 true=拒执 fail-closed——默认全拒，真钱须委员会位翻。
2. **双腿序列**：leg1 下单（clOrdId 三分支定态——歧态势禁补单，T-0008 坑在案）→ 确认成交 → leg2；**leg2 失败/歧义=LEGGED 态→自动回滚 leg1**（对向平仓腿）→回滚结果留痕。
   - 腿间名义额对冲带校验（delta 中差容忍走 `exec.hedge_band_bps` 热启键，缺键 fail-closed）。
3. **留痕**：`fin_execution`+`fin_order_leg`——每腿 clOrdId/venue/侧/量/价/状态机（placed/ack/filled/failed/rolled_back）；`fin_position` 成交即开（一 strategy-instance 一仓行，delta 中性标）。
4. **红线**：execution 不 import invest/research/risk 域包（import 闸）；venue 调用全走 T-0008 交付的 exec 面，禁另起径。
5. **员工**：`执事` Register+BeatLoop(30s)，产出窗=fin_execution/fin_order_leg/fin_position 行。
