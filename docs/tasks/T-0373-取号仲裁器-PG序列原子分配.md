## 事实

- 票号协议「顺序取用不回收」+ push ff 拒——锁在推送序不在
  取号时；扫描→check_all(~3min)→push 间双席同刻取同号=
  都以为空号，慢者重编改引用（今日实证：COS ls 见 T-0370
  占取 0371，DM 自立票 T-0372 差一轮未撞）；
- 折中案 ops_event 领号行**同样非原子**（先扫后插=同竞态，
  双席同毫秒各插同号行=双簿记同号）——逻辑严谨要求
  仲裁性唯一，非扫描纪律；
- 落点：全席取号入口两处——COS 交互席立票、决策席自立
  返修票/续票（T-0370/T-0372 实证路径）。

## 任务

1. 迁移链新件：`CREATE SEQUENCE IF NOT EXISTS o_ticket_seq`
   （fin 链按序号续编——起始值不钉死，由调用件每次 setval
   自愈对齐）；
2. `scripts/meta/next_ticket.sh` 新件：
   a. 文件最大号扫描（`docs/tasks/T-*.md` git 面+本地面取大）；
   b. `SELECT setval('o_ticket_seq', GREATEST(last_value,
      <filemax>))` → `SELECT nextval` 原子取值——绕径手建
      号自动吸收归队（自愈闭竞态）；
   c. 同事务 INSERT ops_event `领号` 行（seat=调用方入参，
      ticket=T-0NNN，note=用途 slug）——审计痕白名单径；
   d. DSN 缺席退化=文件扫描打印+stderr 降级警告（明载
      窗口非静默）；
   e. 输出=T-0NNN 字面，供调用方拼文件名；
3. 接径：`skills/决策席/SKILL.md` 自立票节钉「取号唯一径=
   next_ticket.sh」+collab.md 指针已在案（本票前落）；
   施工席/其他席取号同律引用；
4. 并发实测：双 shell 同刻调 next_ticket.sh → 得不同号
   （仲裁性实证非纪律性）。
