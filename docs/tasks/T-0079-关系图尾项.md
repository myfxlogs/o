- **底色/风格**：深色底 + 发光连线（SVG `feGaussianBlur` glow filter）；右上徽标「◉ N 个员工在岗」（N 真从 staff 数组 length）

- **边两类**：①实线青色=钱/仓流主链：探员→验证官→命官→门官→执事→司账→核账→信使；②虚线紫色=控制/数据/回环：评史官→探员（退役回炉）、配管→命官、仓巡→执事（平仓触发）、phase-core→全员（心跳环）、数据四岗（行情巡/私流守/汇市巡/集使 采集供给）→决策链
- **拓扑源**：节点按 registry `dept` 分组定位，连线按上表钦定拓扑写死（16 岗语义固定——非力导向自动布局）；staff 缺面藏卡如实，禁静态假名册
- **图例**：底部一行「实线=钱/仓流｜虚线=控制/数据/回环｜灯三色」
