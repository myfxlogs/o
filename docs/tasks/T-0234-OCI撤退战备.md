## 病灶（决策席实勘 2026-10-28）

- OCI PG-md（206MB）**零备份**——backup_pg.sh 早已泛化支持 o-postgres-md（T-0176），但盒上无任何调度跑它；SG→OCI 只有 fin 方向备份在跑。
- OCI 同时是 SG fin 的唯一异地备份落点——OCI 亡则 SG 账链只剩本机。
- 盒级重立无册：三 user-unit（research/projector/collecto)+env 文件+sg-tunnel+sing-box 全是手工件，换盒=重新发明。
- Reality 径已实证被针对性掐（TCP 通、TLS 握手 eof）——被盯风险非假设。

## 任务（三件）

1. **PG-md 备份链活起来**——OCI 上起 `backup_pg.sh` 日调度（systemd timer 同 o-backup-fin 例），dump+gzip+sha256 滚动 14 份；链调 `backup_push_sg.sh` 同款 scp 推 SG `/opt/o-backups/oci-inbox/`（方向反转、键前缀 `o-md-` 钦定不变）。**R2 前缀改 `oci/`（业主令语义归位——前缀=数据产地：dev 已不产 md dump，R2 现存 dev/ 键确系 dev 期历史件留原地；oci 新键名实两清）**：`backup_pg.sh` 的 dev-inbox→dev/ 段改 oci-inbox→oci/、`backup_push_sg.sh` INBOX 改 oci-inbox、哨兵「inbox 陈>26h=CRITICAL」检查径随改名、SG 上建空 `oci-inbox` 留 `dev-inbox`（兼容 dev 期残余件自然消化完再退）。零新凭据——同 env 同 age 键。验收：首份 dump 落 SG oci-inbox→R2 oci/ 前缀列见实证。
2. **盒级重立册**——`scripts/oci_bootstrap.sh`（或 docs runbook 件）：新盒一键复立（三 unit 安装/env 模板位/PG-md 容器+迁移+末份 dump restore/sg-tunnel/sing-box 配置模板）。验收锚=干跑文档级可复立推演，不真买盒。
3. **配置 escrow**——env/单元/sing-box/ssh 件每日 tar+scp 随 md dump 同链落 SG（小件零成本）。

## 边界

- 不碰 Reality 协议层修复（归 T-0227）；本票只管「盒死了怎么活回来」。
- R2 链复用现产件（同 env/同 age 键/同桶）——只改前缀名 dev→oci（产地语义，业主令）；桶/加密面不动。
- 备份件含数据不含秘密；env tar 走同键加密径不单开明文道。

## 验收锚

- OCI 上 `systemctl list-timers` 见 md 备份 timer active；SG `/opt/o-backups/oci-inbox/` 落首份 o-md dump+sha256。
- 重立册落 docs 或 scripts，决策席审阅可推演。
- 回撤演练记录（restore 到 dev 本机 o-postgres-md 冒烟一遍）入票回填。

- **锚③ 回撤演练**：PASS——首份 dump 拉至 dev，sha256 值比对 OK；dev `o-postgres-md` 容器起→灌隔离库 `o_restore_smoke`（ON_ERROR_STOP=1）→**69 表精确对齐**（源库同查询 69）；行数对拍 `fin_strategy` 2008=2008、`md_mark_index` 1032=1032、`md_dcd_product` 9842 vs 源 9845（dump 后源库采集臂活写 +3，非还原缺陷）→DROP 隔离库+容器停回原态（Exited）+临时件清零。**选径说明**：dev 容器旧库在位故用隔离库不覆盖（同容器同 PG 版还原语义等价）；bootstrap 新盒场景为空库直接灌 `o`，两场景分立有据。

### 实施

- **件①备份链**：`scripts/backup_pg.sh` 收罗段 dev-inbox→dev/ 改 oci-inbox→oci/（R2 dev/ 冻结不转）；陈化哨兵径随改名（>26h=推链死 CRITICAL）；`R2_DISABLED=1` 显式跳过段（OCI 凭据缺席属设计非失格，不记 marker）；`scripts/backup_push_sg.sh` INBOX→oci-inbox+PUSH_KEY 键位注入。OCI 侧：`scripts/arm/o-backup-md.sh` 链闸（dump→推 SG→escrow）+`o-backup-md.service/.timer` 系统级 unit；`backup_pg.sh`/`backup_push_sg.sh` 同件双部署（OCI /usr/local/bin+SG /opt/o/scripts——MD5 与支上 canon 逐对齐）。SG 侧：oci-inbox/dev-inbox（空，留档）并列。
- **件②重立册**：`scripts/oci_bootstrap.sh`（锚②）+`docs/运维/OCI盒档案.md` 重灌径一键化指路+服务清单/凭据存放点补实（fin/md/sentinel timer、推送键、escrow 锚）。
- **件③escrow**：env（collecto/projector/research/backup-md/backup-fin）+系统级/用户级 unit+sing-box config+ssh authorized_keys/known_hosts 每日 tar+age 同键加密+scp 落 SG `/root/oci-secrets/escrow/`（盒档案信托锚义）；滚动 14 由 SG backup_pg.sh 裁尾（保留逻辑 SG 集中）；**私钥不入 escrow**（钥对现场重生，bootstrap 打印收口行）。首件已落：`o-md-escrow-20261028T191254Z.tar.age`+sha256。
- **凭据面**：推送专用键 `/root/.ssh/id_ed25519_backup_push` 新立——「零新凭据」读作 R2/env/age 面（scp 径无钥不可达）；SG 侧 `restrict,command="internal-sftp"` 收口，exec 拒实证（`This service allows sftp connections only.`）。AGE_PUBKEY 公钥（非密件）SG→OCI 中继零打印；R2 密钥/age 私钥主权梯不动。

### 偏离与判断（交决策裁）

1. dev 死 cron 行退役（`30 3 * * * … backup_pg.sh && backup_push_sg.sh`）：链死三重证据（末次 OK=2026-10-27T19:30Z 后 push `scp: Connection closed`；容器 10-28 退出；md 域已迁 OCI）——且不退则 dev 容器复活时会向 oci-inbox 产 dev 地 dump，破「前缀=数据产地」义。dev 遗留末份 `/opt/o-backups-md/o-20261027T193001Z.sql.gz`（1.2M，迁移前 dev 期数据）留原地自然滚动——是否补推 R2 dev/ 存量交决策。
