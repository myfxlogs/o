## CTO 裁定（2026-11-08 裁域四件定案）

### ① 配对表钦定（`scripts/meta/handoff_pairs.tsv` 单源——交event⇥接行集⇥阈秒⇥说明，gauges.tsv 同形政策/机构分件）

| 交行 | 接行集（同票、ts>交行 ts，同刻 id 大者序后） | 阈 |
|---|---|---|
| 派单 | 领单,拉起,驳回,挂起,作废,完成,处置 | 30min |
| 移交 | 审计中,领单,开工,已批,裁决,驳回,完成,处置,派单,外派,挂起,作废 | 30min |
| 收口 / 收口待审 | 裁决,驳回,完成,处置,挂起 | 2h（班次级——裁决走会话班，队列深合理滞后，=兜底拍×4） |
| 呈批 | 已批,裁决,驳回,领单,处置,挂起 | 60min |
| 已批 | 派单,领单,拉起,外派,驳回,挂起,作废,完成 | 4h（depgate 交集/水位留队属常候；与退班闸 approved 面互补——闸管班退清账，哨兵管龄超即鸣） |
| 外派 | 收口,收口待审,移交,驳回,挂起,作废,已并码 | 8h（外派回执周期天然长） |

**在案不双哨**（表列注记、哨兵 SQL 不扫）：`升件`→裁决/处置/消=escalation_unclaimed 量表在案（30min 连鸣 T-0437）；`挂起`→消化=dm_suspend 看门狗在案（T-0365）。

### ② 哨兵挂点

新件 `scripts/meta/dm_handoff.sh`（dm_suspend 同族消费窗），钩点=dm_tick.sh 尾段 dm_suspend 段后同形块：`FIN_DSN` 守护→跑→rc 非零 `dm_esc "交接哨兵本体败"`（败≠空集 T-0372 律）。节奏=每 dm_tick 拍（兜底拍 30min 同乘）。检测=按表逐行反连：交行龄>阈∧无接行∧未报过→`escalate.sh "CTO" <tid> "" ""` 无类升件（dm_suspend 同款——断链裁断上下文各异，不入判例面）。

升件词形：`断链:<交event>:<tid>——交行#<id> <交seat> 「<note 截40字>」龄<X>m>阈<Y>m`——携交行 id 引证；消音协议同 escalation_unclaimed 式（处置落行携 `升件#<断链行id>` 停鸣）。持续压不另造径——断链升件行落账即入 escalation_unclaimed 视域，30min 连鸣至处置。

### ③ 幂等/免误报面

- **终态杀票**：票内最新生命周期事件∈{完成,驳回,作废,处置}→该票全部交行免报（票已终交行失效）。
- **免报词表**：交行 note 命中 `作废|测试票|人工径` 免报（DBP3 词表缺口同型防）。
- **evergreen 去重**：交行 id 锚——已存升件行 note 含 `断链:<交event>:<tid>——交行#<id>` 字面→零再报（不用 24h 窗，断链不因窗过期复鸣；持续压归 escalation_unclaimed）。
- **扫窗**：交行 ts>now()-7d 且龄>阈。首跑捕现存断链属预期捕账非误报（终态/词表滤后余者=真链断）；每交行捕一次后永不再报。
- **自激防**：接行集不含 `升件` 词——哨兵自鸣行永不充当接行。
