## 一、病灶

`docs/工程经验库/` 条目持续增长（坑 canon 业主令不待归纳即写），但
召回=人/会话记得+grep——**写过但想不起来**类病灶实发：同类坑重复
踩（tolerate 锚案 0464/0465 连续撞）、条目在库无人读。Voyager 实证：
验证过的技能入库+检索召回=能力复利；只有入库没有召回=死档案。

## 二、提案面

1. **嵌向量**：kbgen 建索引时顺手生成条目 embedding（summary+
   keywords 字段即可，源选型见下）；向量索引件入库 gitignored 再生物
   （与 kbgen 索引同律——可再生不入册）。
2. **召回挂点**：`dispatch_worker.sh` prompt 装配面加「相关经验」段
   ——领单时按票面（标题+范围域+涉及路径）检索 top-K（K≈3）条目
   摘要注入提示词；会话席领单提示词同径（施工席职卡已有「读经验库」
   义务——本件把「记得读」换成「喂到嘴边」）。
3. **源选型定案**（业主令 2026-11-08）：存储面=**pgvector@fin 库**
   ——PG 已在用零新设施成本最低；embedding 生成面=Ollama
   **qwen3-embedding:4b**（~2.5GB——业主令 2026-11-08「钱径
   是大头」重裁升档：召回质量在钱径最值钱选 4b 档；0.6b 为
   内存紧兜底；英文金融专用件 voyage-finance-2 等皆英文向
   +API 费，对中文金融语料反输 qwen3 多语训练——「中文×
   金融」交集本地无更对口件；bge-m3 备选）；**分阶**：首阶
   keywords+frontmatter 字段机械
   匹配即可上（零模型零设施——命中率先实测），召回不足再开
   嵌入阶——向量面就位但不为用而用。
4. **降级径**（fail-open=增强件缺席跳过不炸，非链环）：检索服务/
   嵌入模型缺席→装配面跳过「相关经验」段照发——KB 召回是增强
   非闸件，与 dispatch_order fail-open 同律。

## 三、判据（草案）

- 人造票面含「tolerate/锚」域词→领单提示词带出既有锚坑条目；
- 检索面缺席→装配照跑零段；
- 桩测：top-K 相关性人工抽检 ≥2/3 命中；
- 全谱零新增 FAIL/SKIP。

## 四、红线

- 不碰钱径；embedding 商用 API 选型=业主裁（凭据/成本）；
- 召回只做「提示词增强」不做自动改码——KB 是读物不是执行件。
