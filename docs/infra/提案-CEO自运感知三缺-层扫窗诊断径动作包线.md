# 提案：CEO 自运感知三缺——层扫窗+诊断径接线+白名单动作面

> 目标句：**CEO 不依赖业主/COS 即席补位即可自治常径**——业主保留
> 的只剩红线三件+方向，这是宪章不是缺陷。
> 域：工程基建（机械轨/席位管线）；不动钱径。
> 立据：2026-11-09 清账夜实证——业主+COS 人工补位的全部动作可逐条
> 归三类，且 85% 属机械可枚举面。

## 一、病灶（实证锚）

现状：CEO 职卡钦定「升件驱动不巡场」；探针族哨**已知病形**清单。
三处人工补位实证（全部发生在清账夜）：

- **跨层矛盾**：相位=dispatched 而补拉窗全盲（seat 白名单断层），
  探针各查各形无「相位↔消费面」一致性检查——靠人跨层看；
- **尸堆积**：pulled 无 unit / error 16 张 / 拼接伪键——任何单探针
  都不报「总量异常」，靠人翻全景；
- **根因诊断**：断链探针报了「断」，但「为什么断」要 seat 语义
  对拍才懂——诊断动作无自动接续，异常升件后停在等裁。

## 二、提案面（三件同案，分票施工）

### ① 层扫窗（感知面——挂 mech_tick 新窗零新守护件）

周期层一致性机械扫，产出两类行：

- **异常升件行**（seat=MECH,event=升件,note=层扫定性）——枚举
  不变量破例即报，覆盖五片：
  a. 队列一致：dispatched 老化无拉起∧无在飞（龄阈 30min 初值）、
     pulled 无存活 unit、review/approval 老化、draft 滞留；
  b. 相位↔实体：相位非终而票件无（幽灵行）、票件 done/ 而相位
     非 done（翻漏）、相位终而事件链断（无收口行却完成）；
  c. 容量水位：连续 N 拍 spawn rc≠0、候选集非空而拉起=0、
     worker 退出无收口事件链；
  d. 账本真值（抽查面）：新完成票的收口 commit 在 master 可解、
     桩测引用文件实存——敌意回放抽检非全量；
  e. 外事真值：origin/master 落后龄、deploy 批龄、OCI 回报缺席
     （已有探针者不重复——层扫只做聚合判断不做新探针）。
- **健况 digest 行**（seat=MECH,event=层扫,note=各面相位计数+
  异常计数）——定时落 ops_event，进 ceo_queue 收件面（层扫行
  加入 CEO 队列白名单词）——**CEO 仍升件驱动，但收件箱从此
  含全景体检行**。

### ② 诊断径接线（判断面——补缺口不是新建）

层扫异常行 → `fin_ticket_draft` 自动起草「诊断型草案」
（signature=层扫定性串 dedup）→ 物料化 → 走既有派单/裁定径。
裁定席根因诊断分支（T-0431 第四分支）已存在——本件只接
「异常→诊断票」的进水口，诊断/判词/根修票生成全走现行轨。
**未知病形在此层被消化**：扫只须报「矛盾存在」，诊断席负责
「为什么」——感知与判断再次分层。

### ③ 白名单动作面（动作面——最敏感最后做）

CEO/机械轨常径动作白名单表（库表或钦定清单）——表内动作机械
自决不落呈批：

- 相位归位类：尸 pulled→重派（决策席 seat 转正）、error→作废
  归档（伪键/无票件可判时）、await 锚至→醒票重派；
- 席位活性类：oneshot 席 kick（同事件 kick 语义）、
  worker 槽补拉（既有）；
- 配置微调类：白名单键+界内值域（如 O_WORKER_PARALLEL_LIMIT
  ∈{1,2}）——**超界=呈批业主，表外=呈批业主，两件红线级
  永不入表**。
- 每条动作行落 ops_event（seat=CEO/MECH,note=规则命中引证）——
  动作自决≠动作无账。

## 三、判据

1. 回放清账夜三病灶：层扫窗上线后，同型态各报出升件行
   （人造 dispatched-无拉/pulled-无unit/拼接键残存→对应类目出报）；
2. 诊断接线：人造层扫异常→诊断票物料化→裁定落案——全链零人触；
3. 白名单动作：人造尸 pulled→自动重派+事件行引证规则号；
   表外动作→呈批行非自决；
4. CEO digest：层扫行进 ceo_queue 出列；全谱零新增 FAIL/SKIP。

## 四、边界与红线

- 钱径/venue/资本面一切不动；红线三件（资金扩投/新平台/席位立换）
  永不入白名单；
- 层扫只报不判（机械），诊断只诊不动手（席），动作只行表内
  （白名单）——三层各守形，不自相授权；
- 「静默无事发生」类未知诚实在界外——感知覆盖的是「状态矛盾」
  类，真零信号型异常仍需业主直觉，不吹全知。

## 五、分票建议（供决策裁）

- 票 A：层扫窗（mech_tick 新窗+不变量集+升件/digest 行）——先行；
- 票 B：诊断接线（层扫→draft signature+消行语义）——依赖 A；
- 票 C：白名单动作面（表+执行器+呈批兜底）——依赖 A+B，
  且表内容初版逐条列明随票呈裁。
