> COS 直办稿 2026-11-07。缘起：业主令「O 系统复杂，要不要把
> o-core 搬到 OCI，维护 1 台主机算了」——本文=迁不迁的
> 判据底稿，非施工票。

## 1. 现态拓扑（实机取证）

| 机 | 角色 | 在跑件 |

## 2. 分裂历史成因（D-0029/D-0036 取证 + 业主校准）

**不是意外，是三桩设计——但权重有主从**（业主校准
2026-11-07：**主因=算力界**）：

1. **算力隔离（主因）**——D-0029 时代 SG=4 核 PG CPU
   114%、load 2.66，md 写放大（ticks 2418 万行级）压钱径。
   **关键反转（2026-11-07 实测）**：当年的病灶（md 域
   写放大）已经住在 OCI PG-md 里——SG 如今 load 0.22、
   PG 占 1.2G/19% CPU，算力论据比立界时弱了一档。
2. **钥匙界**（D-0036 钦定「做对的不要动」）——
   发现层无 venue 写钥：主权钥/交易钥不出 SG。
   OCI 被破≠钥匙丢——刻意炸半径收窄。
3. **毕业权独占**——paper→probe→live 只在 SG 判，
   发现层信号永不直下单（D-0022 动作桥纪律）。

### 容量对拍（2026-11-07 实机）

| 机 | 核/内存/盘 | 现载 | 合并后投影 |
|---|---|---|---|
| OCI | 4c/23G/45G(43%) | load 0.80 | +o-core+fin PG≈1c/5G 内存——**吃得下** |
| SG | 4c/7G/58G(54%) | load 0.22 | — |

**瓶颈=盘**：45G 盘装不下两边合计 ~50G——OCI 块卷
可在线扩，非阻断项。内存 23G 富余、CPU 合并 ~1 核。

## 3. 分裂税清单（今晚实证级）

```
① 投影桥整层=纯双机税:projector+reverse桥+桥册审计+
  水印对账——单机后整层可删
② 两半部署制:deploy_image(SG镜像)+deploy_oci(OCI二进制)
  ——T-0423/0425 实证:发窗只盖SG半→投影臂老二进制
  恒过期→md_tick_scan镜像恒空→半截部署在产
③ 双DSN/双env契约/双隧道端口(漂移已在D-0036咬人两次)
④ 故障面×2:任一机瘫=链断(已耦合,合并不 worsen)
```

## 4. 合并所得 vs 所失

| 得 | 失 |
|---|---|
| 桥层整体删除（投影/水印/桥册） | **钥匙界消失**——venue 主权钥与研究件同机，OCI 被破=钱径钥匙暴露 |
| 单径部署（半截部署绝版） | **算力归一争用**——collector+research+eval+fin PG 全挤一机，须实测容量 |
| 单机运维面 | 迁移本身=生产最高风险操作（数据搬迁+回滚案+访问径换） |
| | 访问径：座舱/serve 现指 SG IP，换机要迁访问径 |

## 5. 迁移清单粗估（真要搬的话）

```
① fin域PG迁OCI(或md域PG迁SG——方向抉择:钱径机还是发现机?)
② OCI装compose栈+secrets+部署径重写(deploy_oci退役)
③ 主权钥迁移——钱径钥匙搬家本身是最高敏操作
④ 座舱访问径+feishu回调径换
⑤ 回滚案——迁期双写或DNS切,任一阶败可回
估: 多窗工程(非一票),期间双态共存比单机更复杂
```

## 6. 判词（COS 建议，非裁定）

**主因校准后，论点翻面：合并=可证题非禁区**

业主校准「主因=算力界」+实机容量对拍后，账重排：

- **算力论据已弱化**——当年逼出分裂的 md 写放大如今
  住 OCI PG-md 本地，SG 只剩 fin 轻载（load 0.22）。
  把 o-core+fin PG 搬去 OCI=加 ~1 核/~5G 内存到一台
  23G 富余机——**容量上成立**；
- **保留的真成本收窄到两条**：
  ① 盘（45G 装不下，需 OCI 卷在线扩——机械操作）；
  ② 钥匙界（主权钥与研究件同机——唯一不可恢复项，
  业主需明裁接不接受）；
- **迁移窗本身=生产最高风险操作**——即便方向对，
  也建议排在盈利环证毕+T-0425 窗规修后，作独立
  Phase 立项走，不顺手做；
- **业主裁 2026-11-07：缓议**——OCI=免费层主机，
  Oracle 有容量紧张回收 Always Free 实例先例，回收
  韧性未验证前不把全部身家压上去。**议题挂起**，
  注意力归盈利主线；复核扳机=OCI 转付费层或
  存活观察期证毕。

折中位备忘：若钥匙界不可弃——B 案「PG 合库双机留」：
fin/md 两域同 PG 分 schema（SG 上），OCI 只跑采集
二进制——桥投影删一半，钥匙界不动，部署仍双径
（收益打折）。
