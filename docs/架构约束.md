## 2. 组织结构=钱径六域 + 平台横切 + 一个判断工作者

（公司架构 v3 结构，PHASE 重建沿用其域界）

- **六域**（写权域）：`数据`（可观测世界，流为唯一正道）/ `研究`（候选+评估卡+投资人请求）/ `投资`（策略生命周期+资金配置）/ `风控`（**唯一 pre-trade 入口** `risk.Check(intent)`，fail-closed）/ `交易`（多腿原子成交，无开仓决策权）/ `账本`（唯一钱账+一仓一判决书，口径 D-013，不改历史行；复盘挂此域）。
- **三条独立性红线**（机检强制，import 方向脚本）：**风控独立于投资 · 账本独立于交易 · 研究独立于执行**。
- **平台横切**（非域，无 KPI/日报/决策权）：platform/infra/ir/api/store/门禁——配置凭据、RPC、推送、调度健康备份。
- **一个判断工作者（LLM）**：判定线=离钱径距离——思考类可用，钱径类永不（下单/签名/记账/风控/采集）。一个 client+角色注册表；调用逐次落 `fin_llm_call` 账（LLM 对 8% 负责）；四铁律：失败落 warn、输出过 schema、无 git/DB 直写、数学归 Go。
- **称谓层**（业主令 D-0003）：台账实体对外拟人称**员工**、`fin_employee_registry` 称**花名册**、Dept 标签称**编制**，六域+平台即「部门」挂靠面——**称呼放行机制不动**：虚席=事故、汇报不报考勤、投资人面无组织图。

## 3. 主流程=一笔钱的旅程（G0–G11）

枚举 → 匹配（缺条件明提请求，禁静默）→ 经济学验证（净 APR 五项拆解，任一无证据=「不可评估」）→ 纸面沙箱 → 晋级（判据表机读，首次真金翻开关）→ 配置 → pre-trade 风控单入口 → 执行（多腿原子/LEGGED 即回滚）→ 看护 → 结算 → 复盘（预估 vs 实际回写）→ 淘汰/升级。

流程里不出现任何「某时去查」（D-033）；提案滞留禁超 SLA。

### 7.3 发布流（唯一正路，D-105 双主机拓扑后形）

```
本地 docker build --network=host -t phase-core:latest -f Dockerfile.core .
   # --network=host 必须——宿主流量走 mihomo 代理而 docker NAT 裸出，包拉取否则 ECONNRESET；
   # 镜像内 buf 钉 @bufbuild/buf@1.74.0（钉版规同工程纪律 §3——三处同号，最新且≥7 天）
→ docker save phase-core:latest | gzip -1 | ssh root@<SG> 'docker load'
→ scripts/deploy_sync.sh            # 源码同步唯一入口
→ ssh <SG> 'cd /opt/<repo> && docker compose -f docker-compose.yml -f docker-compose.sg.yml up -d'
```

本机 `docker compose up -d --build` 只起本机服务，非生产。

### 7.4 deploy_sync 契约（10-09 手写 rsync 毁树事故后钉死唯一入口）

- `rsync -az --files-from=<(git ls-files)`——**只推 git 跟踪面**：`.env`/`bin/`/`logs/`/`docs/报告` 等 SG 侧运行时/构建产物不推不删。
- 陈件 prune：SG `find '*.go'` − 本地 `git ls-files '*.go'` 差集**定点 rm**（git 删了的 .go 永留 SG 会进编译面炸 build）；**禁 `--delete`**（`--files-from` 下会扫删非跟踪活件）。
- 同步尾步=宿主侧 `build_host_tools.sh` 重建 host 二进制（rsync 不重建则 cron 跑旧码——10-15 漏步实证）。
- `core.quotepath=false` 必带（CJK 文件名转义破 link_stat）；`-n` 干跑只报不删。
- cron 永远指仓内 `scripts/` 权威版，不指 `bin/` 副本。

### 7.6 备份三落点（D-110）+ 还原契约

- ① SG 本地 `/opt/<repo>-backups/*.sql.gz` 滚动 14 份（仓外、权限 600、sha256 校验、不进 git/日志/聊天）。
- ② R2 `rclone` age 加密滚动 14 份（配置=仓外 `backup-r2.env`：`AGE_PUBKEY`/`R2_REMOTE`/`R2_BUCKET`；**私钥业主离线持有，系统内零副本**）。fail-open 只许在上传段——本地链路任何情况不阻不断；加密/上传失败=alerts critical（D-033 自盯）；配置缺失=降级「仅本地」且首失单发落 marker（D-635）。
- ③ github 代码。
- 还原：`age -d -i <私钥> x.age | gunzip | psql`。三要素（10-20 演练实证）：**①目标实例=tsdb 镜像+`shared_preload_libraries=timescaledb,pg_stat_statements`**（裸 postgres 容器还原=hypertable 数据静默全丢）；**②角色预建** `CREATE ROLE nox_ro LOGIN`（dump 含其 GRANT，不建=135+ 角色错噪音）；**③对账锚** facts/ticks/positions 三表 count 与生产差≤采样窗增量；scratch 容器清收 `docker rm -v`。
