## 2. 第 1 阶段目标（业主令 2026-10-23）

**最小版盈利系统——全公司流程端到端跑通且真盈利。** 选型裁决：首条全链试跑策略=**OKX 资金费率对冲**（delta 中性 carry：现货多+永续空双腿原子、无方向敞口、单笔费用结构可测）；闲资承接=OKX Earn。MT5 面排 M1 后。

**M1 全链最小件**（G0→G11 竖切，非横铺）：
- 数据：OKX 公开流（T-0007 在途）+私有流（E-1 凭据提取前置）
- 研究：funding 机会枚举+评估卡（净 APR=funding−双腿费）
- 投资：策略生命周期最小机（paper→probe→live）+预算行
- 风控：`risk.Check` 最小闸（仓位上限/集中度/kill switch）
- 交易：双腿原子执行+LEGGED 回滚
- 看护：funding 翻面/偏离→自动平仓
- 账本：cashflow+结算+USDT 账本日切；复盘：一仓一判决书
  - **G10 采纳 DSHQ 五池远期验证模式**（外部参照 deepseek-harness-quant）：决策后多时间窗复测（8h/24h/72h funding 结算点），**否决提案同样排期复测**（拒对/拒错=提案闸质量考据）；判决书 verdict 分级（强成/弱成/勉强/证伪）
  - 同参照采两件入数据域：覆盖率审计（md_* 按 inst_id×日查洞，评估证据有洞=fail-closed）；证伪留档纪律入经济经验库
- 公司面：花名册在岗、config 热启、请求/报告上行（E-3 token 提取）
