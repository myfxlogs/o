# O-派单/收口规约（机读正本 v1——agent 消费形，人类可读性非目标）

## A. 流

```
工单文档(落盘) → fwd:行(业主原样转发) → 施工接票落账(ops_event) → 读档开工 → 收口报回(ops_event)
```

## B. 工单文档（SSOT——施工只读档不读会话转述）

- 落点：`/opt/o-research/prompts/O-<票号>-<slug>.md`（本地盘共享，双端零落地延迟可达；票号=ops_event 工单行 id）
- 头行 `fwd:` =可整行抄走的转发词——派单=复制该行，禁手写漂移
- 块序固定（缺块=档不完整）：

```
fwd: [角色:施工] 工单O-<票号>:读<本档绝对路径>按spec施工——收口报[施工收口:O-<票号>] @ sha=<40位全sha>
id: O-<票号>
seat_req: 施工
repo: /opt/o
obj: <对象件/器官——路径级>
bug: <病灶一句话——事实非修辞>
spec:
- <修法断言逐条——可执行级>
accept:
- <验收断言逐条——可判真假>
ban:
- <禁线逐条——部署树直改/手工合master/绕复审等>
pipe: worktree→接票落账(ops_event)→bootstrap_worktree.sh→check_all→戳→候审回执(ops_event)→push支
close_fmt: [施工收口:O-<票号>] @ sha=<40位全sha>
refs:
- <file:line|ops_event#id|commit_sha>
```

## C. 转发词（业主手转件——唯允许形）

```
[角色:施工] 工单O-<票号>:读<档绝对路径>按spec施工——收口报[施工收口:O-<票号>] @ sha=<40位全sha>
```

- 恒取档头 `fwd:` 行原样发——加字减字皆漂移违例
- 一行：角色头+票号+档路径+收口形四元齐备

## D. 施工落账两钉（接票+收口——ops_event 行 note 载）

### D0. 接票（开工首动作——长任务有迹可查钉，业主令 2026-11-25）

```
[接票:O-<票号>] seat=<席位标识> wt=<worktree名>
```

- 时点=worktree 建立后、动码前——先落账后开工，接而落账
  方算在飞；event='接票' ticket='O-<票号>' note=上框契形
- seat=终端标识（业主侧知如 0-施工-11-21——自报终端名，
  不识则以 worktree 名充）；wt=支/树名
- 用=「谁接了哪票/几时起工」有账可问——滞留探针可判
  「接了未动工」vs「无人接」，派发径从此不盲

### D1. 收口（施工报回）

```
[施工收口:O-<票号>] @ sha=<40位全sha>
```

- `@` 后=支尖全 sha（40 位）——与 land_queue `复审过 sha=<尖全sha>` 闸同口径，机读零转换；短码可撞前缀禁采
- 支名/谱结论可附尾（可选——闸只验 `sha=` 后 40 位形）
- event=记事（现相位）；升「施工收口」独立事件+sem_gate 形闸=后续固化件（错形 INSERT 物理拒）
- **落账行=契形行（O-38751 硬条款）**：收口报回分两个动作——会话
  里发契词 ≠ ops_event 落账行取契形。落账行 note 必须以上框契形
  起笔（取证段/谱结论可附尾）；以 event=处置+「O-票 …@sha」取证
  形充收口落账=#38590/#38618 实证违例——landq 容错兜同格认
  （谓词已扩），但纪律判违仍属错形。
- **调用径实证段（工单O-32269——触发类件必填）**：凡交付 diff
  （origin/master...支尖）命中下列任一=触发类，收口词 note 必附
  `调用径实证:` 段载**真实调用回执摘录**（实际 psql 输出/实际运行
  行/实际 INSERT 返回 id——禁「描述调用径」充数）：
  - ① diff 新增/修改 `*.sh` 文件（A/M 态）
  - ② diff 增行含 `CREATE [OR REPLACE] FUNCTION`（.sql/迁移面，大小写不敏感）
  - ③ diff 增行含 psql 调用形（命令位 psql+参数/连接串）
  - 豁免=纯 Go/文档码件（桩测覆盖调用径——spec 钦定）；生效锚
    前收口件豁免。机械判=`scripts/cognition/closeoutcert.sh`
    （`--check <sha> ['<note>']` 单件判 rc0过/rc1要件缺/rc2不可解；
    dispatch 拍前预扫自动升件 `审计/closeout_callpath`）——审计面
    检收口词：命中触发类∧实证段缺=要件缺，不审过。

## E. 违例面（检出归hunger/landq探针族）

- 派单手编转发词非 fwd: 行 → 漂移源，施工可拒收请重发
- 收口缺/错形 → 工单挂开不完，滞留探针显形
- 档 spec 外延施工 → 越界，复审席驳因

## F. 附则

- 票号锚：ops_event `event='工单'` 行 id（两面可对拍——档名/收口/候审全携 O-<id>）
- 既往人读形 prompts/*.md 不溯改；新件一律本规约
